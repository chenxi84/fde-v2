FDE 应用组构建

流程步骤：① 建应用组（中文名 + 英文名，自动建 app/<英文名>/ 与 brd/） → ② 上传 / 删除业务设计文件（存入 brd/，含子文件夹）→ ③ 架构创建（长文本业务描述，后台大模型按 design/架构设计.md 技能生成 app/<组>/architecture.md）→ ④ 应用详设（基于 architecture.md + brd， 后台大模型按 design/应用设计.md 技能为每个聚合根生成 app/<组>/<应用名>/应用详设.md） → ⑤ 应用编码（基于 应用详设.md，后台大模型按 design/CONVENTION.md 为每个聚合根生成 app/<组>/<应用名>/<应用名>.py + README.md，生成后过静态门禁） → ⑥ 测试用例（基于 architecture.md + 各详设，后台大模型按 design/应用测试.md 为整组生成 app/<组>/测试用例.md，覆盖主链 + 分支 + 异步回执模拟，含自洽测试数据；生成与执行分离） → ⑦ 测试执行（第⑤步，基于 测试用例.md，后台大模型按 design/测试执行.md 把用例翻译成 verify_chain_<组>.py 并真实树直跑，失败自动 triage + 修脚本重跑，产出测试报告； 清表初始化：运行会清空该组全部业务数据（测试环境语义；config/ 平台库不受影响） → ⑧ 契约冻结（第③步收尾 · 前端段依赖屏障：隔离沙箱内跑契约 dump，生成 app/<组>/_contracts.md——服务签名 + 真实返回样例；代码变更后重跑刷新）。 任务后台运行，关闭本页不停止，重启可续跑。本页不自动刷新——上传 / 生成 / 删除后会即时更新， 生成完成后点「刷新」查看结果。
