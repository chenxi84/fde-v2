# FDE v2 国际化方案

## 设计原则

1. **平台层国际化，应用层自愿**——平台 UI 必做多语言；应用代码的中文保持原样
2. **不破坏现有功能**——翻译缺失时原样返回中文，已有页面零影响
3. **浏览器自动 + 手动切换**——Accept-Language 自动判断，用户可手动切

## 二、模板改造（8 个文件，约 80 处替换）

每个模板里的中文静态文本 → `{{ _('xxx') }}`：

| 文件 | 中文内容 | 替换数量 |
|---|---|---|
| `login.html` | 登录、用户名、密码、登录按钮 | ~8 |
| `base.html` | 应用清单、定时任务、大模型等导航 | ~5 |
| `users.html` | 用户管理、角色管理、创建、删除等 | ~25 |
| `scheduler.html` | 定时任务、Cron 表达式、启用等 | ~10 |
| `change_password.html` | 修改密码、当前/新密码、保存等 | ~6 |
| `index.html` | 应用组、应用、服务等 | ~8 |
| `app_detail.html` | 服务调用、参数、返回等 | ~10 |
| `error.html` | 错误提示 | ~3 |
| `llm_settings.html` | 模型配置、API Key 等 | ~8 |

改法示例（login.html）：
```html
<!-- 改前 -->
<h3>登录 FDE 平台</h3>
<label>用户名</label>

<!-- 改后 -->

```

## 四、新增 `view/lib/i18n.js`（前端翻译，约 50 行）

```javascript
let currentLang = document.documentElement.lang || 'zh'
const MAP = {}

export function t(key) {
  return (MAP[currentLang] && MAP[currentLang][key]) || key
}

export function register(langMap) {
  for (const [lang, entries] of Object.entries(langMap)) {
    MAP[lang] = { ...MAP[lang], ...entries }
  }
}

export function setLang(lang) {
  currentLang = lang
  document.documentElement.lang = lang
  localStorage.setItem('fde-lang', lang)
  // 触发页面重渲染
  window.dispatchEvent(new Event('fde-lang-changed'))
}
```

## 五、语言切换 UI（2 个模板，约 15 行）

`view_shell.html` 和 `base.html` 各加语言切换：

```html
<div class="lang-switch">
  <a href="?lang=zh" class="{{ 'on' if lang == 'zh' }}">中</a>
  <a href="?lang=en" class="{{ 'on' if lang == 'en' }}">EN</a>
</div>
```

Cookies/URL 持久化当前语言选择。

---

## 六、语言检测优先级

```
1. URL 参数 ?lang=en     （最高优先，用户手动切）
2. 用户 Cookie            （记住选择）
3. 浏览器 Accept-Language （自动判断，首次访问）
4. 默认 zh               （兜底）
```
