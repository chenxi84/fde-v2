### 技能定位（九步法 · 后端段）

```text
第①步  聚合根识别（规格《架构设计.md》）     业务说明 → app/<组>/architecture.md                      ← 已定义
            ↓
第②步  逐聚合根应用设计（规格《应用设计.md》） architecture.md + brd/ → 每个聚合根一份 应用详设.md       ← 已定义
            ↓
★第③步  应用编码（本文件）                  应用详设.md → app/<组>/<应用>/<应用>.py + README.md         ← 本规格
            ↓
第④步  测试用例生成（规格《应用测试.md》）   architecture.md + 各详设 + _contracts.md → app/<组>/测试用例.md  ← 已定义
            ↓
```

### 必给参数
- 英文应用组名 `<组>`（snake_case），逐字绑定 `app/<组>/`。
- （可选）`<应用名>` 子集：只编码指定的某些聚合根；缺省＝architecture 总表内**全部**聚合根。

| ④ 服务契约（可选） | `app/<组>/_contracts.md` | 若已冻结，作为跨应用调用签名参照（契约先行）。 |

### 产出（每个聚合根，落应用文件夹）
- `app/<组>/<应用>/<应用>.py`——聚合根类（PascalCase）+ 公共方法（服务）+ `_init_db`（幂等建表）。
- `app/<组>/<应用>/README.md`——写给该应用 Agent 的操作指南（CONVENTION §11 五章）。
- **不生成** `<应用>.db` 与 `resource/`：二者由平台**运行期加载时自动创建**（CONVENTION §1 / §10），手写反而违反约定。

### 详设 → 代码映射
| 应用详设（第②步） | → 应用代码（按 CONVENTION） |
|---|---|
| §4 功能清单 / 功能详细说明 + 字段表 | `_init_db` 幂等建表字段 + 公共方法（§3 方法即服务） |
| §3.2 业务规则 BR（边界不变量 + 逐字段校验） | 方法内校验，违反 `raise FdeError("人话")`（§7） |

### 编码铁律（详见 CONVENTION，关键几条）
- 文件顶部 `from fde import FdeError`；聚合根类名＝应用名 PascalCase（`sales_order` → `SalesOrder`）。
- `_init_db(self)` **必选**、幂等 `CREATE TABLE IF NOT EXISTS`；字段严格按详设 §4 字段表。
- ⚠️ **公共方法禁写返回类型注解**（§12.1，内省陷阱 `'function' object is not subscriptable`）；参数注解可保留。
- 不 `sqlite3.connect`（用 `self.db`）、不 `import` 其它应用（用 `self.fde.call`）。
- 成功返回可 JSON 序列化业务值；业务失败 `raise FdeError("人话")`。
- 不写 `__init__`、不写鉴权（仅读 `self.ctx`）；事务归平台（不手动 commit/rollback）。
- **缩进只用空格（4 的倍数）、禁 Tab**；类内方法定义行（`def xxx(self, …)`）恰好缩进 4 空格（方法体 8 空格）。平台拼接层对 Tab / 全角空格 / 方法定义行层级漂移有归一兜底，门禁报语法错时还会带错误上下文**自动重生成修复**（≤2 次）——兜底不是放纵理由，编码仍须严守缩进铁律。

### 收尾衔接（推荐 · 契约初始冻结）
编码完成且加载 / 扫描通过后，建议 dump `app/<组>/_contracts.md`（组内各应用服务签名 + 真实 `get()`/`list` 返回）作为**初始冻结（参考版）**：第④步测试用例的服务名/参数名/返回形状以此为最准，且 dump 须真实 `load_all()` introspect，顺带完成整组加载冒烟。注意它**不是**前端段的最终依据——第④⑤步可能修复后端代码，前端段消费的是第⑤步跑绿后无条件重跑的**最终冻结**（两级冻结见《工具链使用说明.md》第 6 步）。`_contracts.md` 运行时不加载。

### 验收标准（可机器化）
- `<应用>.py` 含 `from fde import FdeError` / `class <Pascal>` / `def _init_db` / `CREATE TABLE IF NOT EXISTS`（CONVENTION §13 清单）。
- 平台加载该应用不报错；`python -m fde_platform.scanner` 退出码 0（跨应用调用目标 + 参数契约通过）。
- 公共方法无返回类型注解；`README.md` 五章齐全且与代码签名一致。
- 详设 §3.2 的每条 BR 在代码中有对应校验（`raise FdeError`）。

### 命名与边界铁律
- 应用名 / 文件夹 / 类名 / 库名逐字取自 architecture 总表第 3 列（snake_case → PascalCase 类名）。
- 一个聚合根 = 一个应用 = 一个同名文件夹 / 类 / 库 / 事务边界（CONVENTION 核心约定）。
- 不臆造：详设 / 架构未说清的字段 / 规则标「待确认」，不编造实现。
