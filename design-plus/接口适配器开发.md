# 接口适配器开发（接入外部系统接口）

> 面向「要把外部系统的接口（SAP / ERP / 外部 HTTP 服务等）接进 FDE」的场景。
> 核心原则（正本见 `CONVENTION.md` §12.2）：**外部系统不建聚合**，在自有聚合根内用
> **`_` 前缀适配器方法**接入、弱引用外部标识。本说明是 §12.2 的**落地操作手册**。

## 一、适配器声明（决定能否被 /integration 发现）

适配器方法在应用聚合根类里**显式声明**（`_EXTERNAL_ADAPTERS` 元组），不再靠命名白名单推导：

```python
class SalesHistory:
    _EXTERNAL_ADAPTERS = ("_http_fetch_sales_history",)   # 显式声明可配置的外部适配器
```

- ✅ `_EXTERNAL_ADAPTERS = ("_http_fetch_sales_history",)` → 该方法是适配器，会被 /integration 发现
- ❌ `_do_http_call` / `_http_get`（未声明）→ 内部辅助，不会被发现，命名自由

> 命名建议（非判定依据）：仍可用 `_<系统>_<操作>` 风格（如 `_http_fetch_sales_history`、`_erp_sync_order`）
> 便于人读；但「是否适配器」**只由 `_EXTERNAL_ADAPTERS` 声明决定**，与命名无关。
> 未声明 `_EXTERNAL_ADAPTERS` 的应用 = 无适配器（默认安全）。

## 二、适配器 vs 对外服务（关键区别）

| | `_` 前缀适配器方法 | 对外服务（公共方法） |
|---|---|---|
| 是否暴露 | ❌ 不暴露 | ✅ 是 |
| 定时任务能调吗 | ❌ 不能（`validate_service` 拒绝 `_` 前缀） | ✅ 能 |
| Agent 能调吗 | ❌ 不能 | ✅ 能 |

因此，若要让定时任务/Agent 触发「拉取外部数据」，需加一个**对外服务包装**：

```python
def sync_external_history(self):
    """对外服务：拉取外部历史台账接口并落库（供定时任务/Agent 调用）。"""
    return self._http_fetch_sales_history()
```

定时任务配 `service=sync_external_history`，而不是 `_http_fetch_sales_history`。

## 三、集成配置流程

1. **发现**：应用里写好 `_` 前缀适配器后，到 `/integration` 点「扫描接口」，或让 Agent 调
   `platform_discover_integrations`——能看到该适配器（含 target、是否已配置）。
2. **配置**：`platform_save_integration` 或 `/integration` 界面，填
   `app_name`（如 `psc/sales_history`）、`method_name`（如 `_http_fetch_sales_history`）、
   `url`、`auth_type`（none/bearer/basic/apikey）、`mock_enabled`。
3. **测试**：`platform_test_integration` 或 `/integration`「测试」——发真实请求返回 `body_preview`，
   **自动探测 HTTP 方法**（POST 404/405 时改用 GET 重试）。

配置落 `config/integration.db`；凭证加密保存，`get_endpoint` 取用时解密。

## 四、适配器实现要点（照抄即可）

一个完整的 `_` 前缀适配器方法，固定做四步：

```python
def _http_fetch_sales_history(self):
    from fde_platform import integration

    # ① 读集成配置（url/鉴权/mock）
    ep = integration.get_endpoint("psc/sales_history", "_http_fetch_sales_history")
    if not ep:
        raise FdeError("外部接口未配置（请先到 /integration 配置目标 URL）")
    if ep.get("mock_enabled"):
        return {"status": "mock", "imported": 0, "message": "Mock 已启用，跳过真实调用"}

    # ② 发请求（含鉴权 + 自动 GET 探测）
    body = self._do_http_call(ep, ep.get("url"))

    # ③ 解析 + 字段映射
    rows = self._parse_external_rows(body)

    # ④ 落库（走本应用的幂等导入服务）+ 记日志
    result = self.import_batch(rows)
    integration.log_call("psc/sales_history", "_http_fetch_sales_history",
                         ep.get("target", "external"), f"GET {ep['url']}", "success", 0,
                         response_summary=f"导入 {result.get('success', 0)} 行")
    return result
```

### 4.1 响应解析：支持四种结构

外部接口返回结构各异，`_parse_external_rows` 应兼容：

```python
data = json.loads(body)
raw = None
if isinstance(data, list):
    raw = data                     # 直接列表
elif isinstance(data, dict):
    for key in ("rows", "data", "items"):   # 常见包装字段
        if isinstance(data.get(key), list):
            raw = data[key]; break
if raw is None:
    raise FdeError("外部接口返回结构不符合预期")
```

### 4.2 字段映射：外部字段 → 内部字段

用类级字典 `_EXTERNAL_FIELD_MAP`，外部字段名与内部不一致时改这里：

```python
_EXTERNAL_FIELD_MAP = {
    "material_no": "material_no",   # 外部字段 → 内部字段
    "customer_no": "customer_no",
    "period": "period",
    "qty": "qty",
}
```

### 4.3 方法探测：POST 404/405 自动改 GET

`_do_http_call` 里，按配置方法发请求，若 404/405 且非 GET，自动用 GET 重试（外部「拉数据」接口常为 GET）。

## 五、Agent 侧工具

| 工具 | 作用 |
|---|---|
| `platform_discover_integrations` | 扫描发现可配置的外部适配器 |
| `platform_save_integration` | 配置 url/鉴权 |
| `platform_test_integration` | 连通测试（自动方法探测） |
| `platform_integration_logs` | 查调用日志 |

配置/测试均属危险操作（`dangerous=True`），会触发 HITL 人工确认。

## 六、红线

- 外部系统**不建聚合**、不 import 其他应用（§12.2）。
- 适配器只读外部接口、只返回数据，**业务逻辑/落库走本应用的公共方法**（如 `import_batch`）。
- 凭证经 `/integration` 加密保存，不硬编码。
- 定时任务/Agent 一律调**对外服务包装**，不调 `_` 前缀适配器。
