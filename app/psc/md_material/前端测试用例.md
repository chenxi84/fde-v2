## §1 本页渲染（防粘滞）

- **VT-ROUTE-01 路由渲染**
  - 页面: `psc:md_material`
  - 造数: 无（空库渲染断言，先于任何造数）
  - 操作: 登录 admin → location.hash = '#/md_material'
  - 断言: `main .card` 数 > 0（工具栏 + 表格 + 分页条三段式渲染）；**非看板页 `.kpi` 数 == 0**（防挂载粘滞假过，pitfalls #2）
  - 选择器注意: `.kpi` 计数用 `count()`，必须等于 0（隐藏元素也在 DOM，勿用 `:visible` 判定存在性，直接断言计数）

## §2 造数后列表有数据

- **VT-LIST-01 列表含所造单号**
  - 页面: `psc:md_material`
  - 造数: 经 create 造 M1–M4（见 §0 字典）
  - 操作: 进入 #/md_material（或 pg.reload() 强制重扫）
  - 断言: 列表含 M1 单号（`.b-link` 精确 has_text 定位，不假设顺序，pitfalls #17）；M1 行含物料名称「螺栓-标准」与状态徽章「正常」
  - 选择器注意: 用 `has_text=r["M1"]` 精确单号，勿 `.first`（列表按新到旧，顺序不定）

- **VT-LIST-02 物料号模糊搜索**
  - 页面: `psc:md_material`
  - 造数: 同 §0 M1–M4
  - 操作: material_no 输入框填 `M1` → 点「查询」（或 Enter）
  - 断言: 结果集收敛，含 M1、不含 M2/M3/M4（后端 LIKE 模糊匹配，US-03-AC1）
  - 选择器注意: 用精确单号 has_text 断言存在/不存在

- **VT-LIST-03 状态 chips 精确过滤**
  - 页面: `psc:md_material`
  - 造数: 同 §0 M1–M4
  - 操作: 点状态 chips「正常」
  - 断言: 结果含 M1、M4（正常），不含 M2（EOP）、M3（停用）（BR-04 枚举精确匹配，US-03-AC2）
  - 选择器注意: chips 为 `:visible` 单选互斥，点击后重置回第 1 页重载

- **VT-LIST-04 物料名称模糊搜索**
  - 页面: `psc:md_material`
  - 造数: 同 §0 M1–M4
  - 操作: material_name 输入框填 `螺栓` → 点「查询」
  - 断言: 结果含 M1、不含 M2/M3/M4（US-03-AC3）；再清空过滤，空条件命中 M1–M4 全量（列表行数 ≥ 4）

## §3 模态全字段

- **VT-MODAL-01 详情模态全字段**
  - 页面: `psc:md_material`
  - 造数: 同 §0 M1（全字段样例）
  - 操作: 点 M1 的 `material_no` `.b-link` → wait_modal()（轮询 `.modal-mask:visible .loadbox` 消失，pitfalls #16）
  - 断言: `.modal-bd.first` 内_text 含**全部 15 项业务字段标签/值**：`material_no`（值 M1）、`material_name`（螺栓-标准）、`status`（正常）、`unit_value`（12.50，fmt 金额）、`value_class`（高）、`change_cost`（300.50，fmt 金额）、`prod_days`（10）、`logistics_days`（5）、`change_risk`（低）、`service_level`（0.95，小数口径 0~1）、`batch_window`（28 天 + 「≈ 4 周」换算提示）、`base_method`（移动平均）、`base_params`（**tryParse 结构化：逐键展示 `window` = 6**）、`fit_version`（空值 dash）、`fit_effective_at`（空值 dash）；「原始数据」折叠区默认收起、可展开（get 返回全量 JSON）
  - 选择器注意: 多 `.modal-bd` 用 `.first`（详情 + 内嵌编辑区，pitfalls #15）；读页脚按钮文案读整个 `.modal-mask:visible`；`fit_version` / `fit_effective_at` 由 set_fit_params 跨应用回填，本页造数未回填故为 dash，断言标签存在 + 值 dash 即可
  - 页脚断言: `.modal-ft` 含【编辑】（admin 主数据管理员可见）【关闭】；**无状态机流转按钮**（status 外部维护只读，页脚不按状态放按钮）

## §4 表单落库回显

- **VT-FORM-01 创建（全字段 + status 不进表单）**
  - 页面: `psc:md_material`
  - 造数: 无（经 UI 表单新建）
  - 操作: 点「+ 新建物料」展开创建表单 → 填 `material_no`=M-NEW（★必填）、`material_name`=新物料（★必填）→ 填库存策略参数 `unit_value`=5.00 / `value_class`=低 / `change_cost`=100.00 / `prod_days`=3 / `logistics_days`=2 / `change_risk`=高 / `service_level`=0.90 / `batch_window`=14 → 填预测方法参数 `base_method`=移动平均 / `base_params`=`{"window":4}` → 点「保存」
  - 断言: toast「物料主数据创建成功」→ 模态关闭 → 列表回第 1 页回显新单号 M-NEW，且状态徽章「正常」（create 后端默认 status=正常，status 不进表单）
  - 选择器注意: 断言表单内**无 status 输入控件**（status 只读不进表单，BR-04）

- **VT-FORM-02 创建空必填校验（前端拦截）**
  - 页面: `psc:md_material`
  - 造数: 无
  - 操作: 点「+ 新建物料」→ material_no / material_name 留空直接点「保存」
  - 断言: toast 警告（必填拦截），不发 create 请求（列表无变化，US-01-AC3）；模态保持打开便于补填

- **VT-FORM-03 编辑态（material_no 只读 · status 不进表单）**
  - 页面: `psc:md_material`
  - 造数: 同 §0 M1
  - 操作: 点 M1 行的【编辑】按钮（`:visible`，主数据管理员可见）→ 断言表单 `material_no` 输入框 `:disabled`（主键只读，BR-19，US-04-AC2）、**无 status 输入控件**（US-04-AC3）→ 修改 `material_name`=螺栓-标准-改 → 点「保存」
  - 断言: toast「物料主数据更新成功」→ 关闭模态 → 列表 M1 行回显新名称「螺栓-标准-改」；重开 M1 详情模态，`material_name` 字段值同步为「螺栓-标准-改」（US-04-AC1）
  - 选择器注意: `:disabled` 断言针对 material_no input；【编辑】按钮用 `:visible` 限定（pitfalls #14）

- **VT-FORM-04 批量导入（摘要 + 错误明细）**
  - 页面: `psc:md_material`
  - 造数: 无（经 UI 上传文件造数）
  - 操作: 点「批量导入」→ 上传 CSV（表头含 material_no, material_name, status, unit_value, value_class, change_cost, prod_days, logistics_days, change_risk, service_level, batch_window, base_method, base_params）→ 文件含 2 行：① 合法新行 material_no=M-IMP / material_name=导入件 / status=正常；② 缺 material_no 的错误行 → 提交
  - 断言: 摘要弹窗展示「成功 1 条 / 失败 1 条」+ 错误明细含「物料号不能为空」（US-05-AC3）→ 关闭摘要 → 列表刷新回显新行 M-IMP（US-05-AC2）
  - 选择器注意: 上传用 `set_input_files` 临时 CSV；导入是 status 唯一随外部冗余同步更新入口（BR-04），断言 M-IMP 状态徽章「正常」
