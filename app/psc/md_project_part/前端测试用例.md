# 应用组 `psc` · md_project_part 前端测试用例（项目零件映射）

> 产出技能：前端测试用例生成（第⑧步，规格 design-plus/前端测试.md）。
> 页面：`psc:md_project_part`（本文件全部用例针对本页，条目内「页面」一律省略）。输入：app/psc/md_project_part/前端详设.md + app/psc/_contracts.md。
> 执行：第⑨步翻译成 app/psc/tests/verify_view_psc_md_project_part.py（自包含：dbguard 隔离→起平台→登录 admin→造数→断言→0 报错）。
> 本页性质：主数据映射页（可写），复合主键 project_no + material_no；无状态机、无 delete、无 KPI 指标带。

## §0 测试数据字典（冻结 · 本脚本自足）

| 别名 | 类型 | 造数服务 | 关键参数 |
|---|---|---|---|
| PRJ-1 | 项目（跨应用前置） | md_project.create | project_no=PRJ-1, project_name=项目一, owner=S001, stage=进行中 |
| PRJ-2 | 项目（跨应用前置/过滤辅助） | md_project.create | project_no=PRJ-2, project_name=项目二, owner=S001, stage=进行中 |
| M1 | 物料（跨应用前置） | md_material.create | material_no=M1, material_name=前保险杠总成, status=正常 |
| M2 | 物料（跨应用前置/过滤辅助） | md_material.create | material_no=M2, material_name=后保险杠总成, status=正常 |
| PP1 | 项目零件映射（本页主数据） | md_project_part.create | project_no=PRJ-1, material_no=M1, veh_model=车型A, usage=2, share=0.8 |
| PP2 | 项目零件映射（本页主数据） | md_project_part.create | project_no=PRJ-1, material_no=M2, veh_model=车型B, usage=1, share=0.5 |
| PP3 | 项目零件映射（本页主数据） | md_project_part.create | project_no=PRJ-2, material_no=M1, veh_model=车型A, usage=3, share=1.0 |

- 造数走真实 REST（浏览器内 fetch `/api/apps/<应用>/call/<服务>`，带会话 Cookie，pitfalls #18）；跨应用前置（项目/物料）在本字典内自足。
- 复合主键唯一性：PP1/PP2/PP3 已占用 (PRJ-1,M1)/(PRJ-1,M2)/(PRJ-2,M1)，新建用例须用未占用组合 (PRJ-2,M2)。

## §1 本页渲染（防粘滞）

- **VT-ROUTE-01 路由渲染有内容**
  - 前置造数：无（空库亦可挂载）
  - 操作：登录 admin → `location.hash = '#/md_project_part'`
  - 断言：`main .card` 数 > 0；列表三段式（工具栏「查询 / + 新建映射 / 批量导入」+ `.tbl.tight` 表格 + 分页条）可见；**非看板页 `.kpi` 数 == 0**（pitfalls #2 防挂载粘滞假过）
  - 选择器注意：`:visible` 限定；`.kpi` 计数必须为 0

## §2 造数后列表有数据

- **VT-LIST-01 列表含所造映射**
  - 前置造数：依次 md_project.create(PRJ-1, PRJ-2) → md_material.create(M1, M2) → md_project_part.create(PP1, PP2, PP3)
  - 操作：进入 `#/md_project_part`（或 `pg.reload()`）
  - 断言：`table.tbl tr.data` 行数 >= 3；含 project_no=PRJ-1 且 material_no=M1 的行；该行 share 列显示 80%（0.8 百分比格式化）；veh_model/usage 列非空
  - 选择器注意：精确 `has_text("PRJ-1")` / `has_text("M1")` 定位行，不假设列表顺序（#17）

- **VT-LIST-02 project_no 模糊过滤**
  - 前置造数：同 VT-LIST-01
  - 操作：project_no 输入框填入「PRJ-1」→ 点「查询」（或 Enter）
  - 断言：结果集仅含 PRJ-1 两行（PP1+PP2），PRJ-2 行（PP3）不可见
  - 选择器注意：过滤变化重置回第 1 页；`:visible` 限定

- **VT-LIST-03 material_no 模糊过滤**
  - 前置造数：同 VT-LIST-01
  - 操作：material_no 输入框填入「M1」→ 点「查询」
  - 断言：结果含 PRJ-1/M1（PP1）与 PRJ-2/M1（PP3）两行，M2 行不可见（后端 LIKE 模糊匹配）
  - 选择器注意：精确 `has_text` 定位，不假设顺序

- **VT-LIST-04 veh_model 模糊过滤（含组合）**
  - 前置造数：同 VT-LIST-01
  - 操作：veh_model 输入框填入「车型A」→ 点「查询」
  - 断言：结果含 PP1（车型A）与 PP3（车型A）两行，车型B（PP2）不可见；再叠加 project_no=PRJ-1 过滤 → 仅 PP1 一行
  - 选择器注意：无关键字搜索框（契约无 keyword 参数），三条件为独立模糊输入

## §3 模态全字段

- **VT-MODAL-01 详情模态全字段**
  - 前置造数：PP1（PRJ-1/M1, veh_model=车型A, usage=2, share=0.8）存在
  - 操作：点 project_no=PRJ-1 所在行的 `.b-link` → `wait_modal()` 等 `.loadbox` 消失（#16）
  - 断言：`.modal-bd.first` 含全部业务字段标签/值：project_no=PRJ-1 / material_no=M1 / veh_model=车型A / usage=2 / share=80%；墨青头带展示「PRJ-1 × M1」复合主键、无状态徽章；「原始数据」折叠区可展开（含全量 JSON）
  - 选择器注意：多 `.modal-bd` 用 `.first`（#15）；`:visible` 限定

- **VT-MODAL-02 页脚按钮可见性**
  - 前置造数：同 VT-MODAL-01
  - 操作：点 PP1 行 `.b-link` → wait_modal
  - 断言：`.modal-mask:visible` 页脚含【编辑】【关闭】两按钮；**无【删除】**（契约无 delete）
  - 选择器注意：读页脚文案读整个 `.modal-mask:visible`（#15）

## §4 表单落库回显

- **VT-FORM-01 创建落库（双 autocomplete 选项目/物料）**
  - 前置造数：PRJ-2 + M2 存在（用未占用组合，避免与 PP1/PP2/PP3 撞主键）
  - 操作：点「+ 新建映射」→ project_no autocomplete 展开选「PRJ-2 - 项目二」→ material_no autocomplete 展开选「M2 - 后保险杠总成」→ 填 veh_model=车型C, usage=2, share=0.6 → 点「保存」
  - 断言：toast 含「项目零件映射创建成功」；模态关闭；列表刷新后含新行（project_no=PRJ-2 + material_no=M2 + veh_model=车型C + share=60%）
  - 选择器注意：`:visible` 限定表单控件；双 autocomplete 下拉项可点击；提交期「保存」loading 防重复

- **VT-FORM-02 autocomplete 下拉交互**
  - 前置造数：PRJ-1/PRJ-2/M1/M2 存在
  - 操作：点「+ 新建映射」→ 点 project_no autocomplete → 点 material_no autocomplete
  - 断言：项目下拉含「PRJ-1 - 项目一」「PRJ-2 - 项目二」（来自 quiet 拉取 md_project.list）；物料下拉含「M1 - 前保险杠总成」「M2 - 后保险杠总成」（来自 quiet 拉取 md_material.list）；输入「PRJ」实时过滤命中代号与名称；选中后表单回填对应编码
  - 选择器注意：autocomplete 下拉 `:visible` 限定（x-show 隐藏 ≠ 不存在 #14）；两个选项源各用独立扁平数组 projectOptions/materialOptions

- **VT-FORM-03 空必填字段被拒**
  - 前置造数：无
  - 操作：点「+ 新建映射」→ 不填任何字段 → 点「保存」
  - 断言：toast 警告必填；不发 create 请求（HTTP 无 `/call/create`）；模态保持打开
  - 选择器注意：toast 选择器；`:visible` 限定

- **VT-FORM-04 重复主键后端拒绝**
  - 前置造数：PP1（PRJ-1/M1）存在
  - 操作：点「+ 新建映射」→ project_no 选 PRJ-1 → material_no 选 M1 → 填 veh_model/usage/share → 保存
  - 断言：后端 FdeError toast「该项目-物料映射已存在」；模态保持打开便于修改重试
  - 选择器注意：错误 toast 选择器

- **VT-FORM-05 usage/share 范围校验**
  - 前置造数：PRJ-2 + M2 存在
  - 操作：新建映射选 PRJ-2/M2 → usage=0 → 保存 → 观察；再改 usage=2、share=1.5 → 保存
  - 断言：usage=0 时 toast「单车用量须大于0」；share=1.5 时 toast「供应份额须在0~1之间」；均不发成功请求、模态保持打开
  - 选择器注意：错误 toast 选择器；usage/share 为 number input（step=0.01）

- **VT-FORM-06 编辑态主键只读 + 变更回显**
  - 前置造数：PP1（PRJ-1/M1, share=0.8）存在
  - 操作：点 PP1 行【编辑】→ 断言 project_no / material_no 只读不可改（复合主键 BR-01）→ 修改 share=0.4 → 保存
  - 断言：toast 含「映射更新成功」；模态关闭；列表刷新后 PP1 行 share=40%；再开详情模态 share 亦为 40%
  - 选择器注意：编辑表单 project_no/material_no 为只读展示；`:visible` 限定

- **VT-FORM-07 批量导入摘要**
  - 前置造数：PP1 存在；PRJ-1/PRJ-2/M1/M2 存在
  - 操作：点「批量导入」→ 粘贴/上传含「3 合法新行 + 1 已有主键行（PRJ-1/M1 更新 share）+ 1 缺物料行（material_no=NOPE）」的数据 → 提交 → 等 loading 消失
  - 断言：模态内展示摘要：成功 4（3 新增 + 1 更新）/ 失败 1，并含失败行错误明细（缺物料）；关闭后列表刷新
  - 选择器注意：`:visible` 限定导入模态；等待导入 loading 消失后再断言摘要
