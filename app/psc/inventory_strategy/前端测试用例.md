## §4 计算入口落库回显（表单豁免 · 自动参考创建）

> 豁免理由：数据来源「自动参考创建」，三层水位 / 对冲工具为系统计算派生值、禁止手工录入（详设 §1.3.2、BR-13）；契约无 create/update 写服务，仅 `calc` / `calc_batch` 接受计算定位键 version_no + material_no。故以「计算入口条」承载计算动作，本节断言计算落库回显与入口交互，替代创建/编辑表单。

- **VT-CALC-01 计算入口落库回显（单物料）**
  - 页面: `psc:inventory_strategy`
  - 前置造数: §0（M2 已造、未 `calc`）
  - 操作: 进入 `#/inventory_strategy` → 在「计算入口」卡片：版本下拉选 `202608` → 物料 autocomplete 点开选 `M2` → 点【计算】
  - 断言: toast「已计算 · M2」；列表出现 `M2` 策略行（has_text `M2`）；该行对冲工具 `库存`
  - 选择器注意: 「计算入口」卡片与「库存策略台账」卡片各有一套版本下拉 + 物料输入框，须 scope 到含「计算入口」的卡片（`:has-text("计算入口")`）；物料选中后存 `material_no` 回填输入框

- **VT-CALC-02 批量计算（整版本）**
  - 页面: `psc:inventory_strategy`
  - 前置造数: §0（V202608 + M1/M2）
  - 操作: 在「计算入口」卡片版本下拉选 `202608`（物料留空）→ 点【批量计算】
  - 断言: toast「批量计算完成：成功 2 / 失败 0」（本字典仅 M1+M2 两正常物料）；列表含 `M1` 与 `M2` 两策略行
  - 选择器注意: 批量计算仅需版本、物料留空即批量语义；单个失败不中断其余（US-02-AC2）

- **VT-CALC-03 行内重算覆盖（BR-01）**
  - 页面: `psc:inventory_strategy`
  - 前置造数: §0 + §VT-CALC-02（M1/M2 均已计算）
  - 操作: 记当前分页条「共 N 条」→ 点 `M1` 行的【重算】按钮
  - 断言: toast「已重算 · M1」；列表行数不变（主键 version_no+material_no 覆盖更新，不新增行，分页条「共 N 条」保持）；`M1` 行仍存在
  - 选择器注意: 行内【重算】按钮在 `.rowact` 内，用该行 `has_text` scope 后取 `.b-ghost`（`has_text="重算"`）

- **VT-CALC-04 必填校验（空版本 → 警告 toast 不发请求）**
  - 页面: `psc:inventory_strategy`
  - 前置造数: §0
  - 操作: 版本下拉留空、物料选 `M1` → 点【计算】
  - 断言: toast「请选择月度版本」（warn）；列表不新增行；无网络请求发往 `calc`（可通过捕获请求断言或断言列表 total 不变）
  - 选择器注意: toast 文案由前端 `toast(…, "warn")` 发出，非后端错误

- **VT-CALC-05 必填校验（空物料 → 警告 toast 不发请求）**
  - 页面: `psc:inventory_strategy`
  - 前置造数: §0
  - 操作: 版本下拉选 `202608`、物料留空 → 点【计算】
  - 断言: toast「请选择物料」（warn）；列表不新增行；无 `calc` 请求
  - 选择器注意: 同上

- **VT-CALC-06 非法物料计算 → 后端 FdeError toast（BR-15）**
  - 页面: `psc:inventory_strategy`
  - 前置造数: §0
  - 操作: 版本下拉选 `202608` → 物料输入框手输不存在的 `NONEXIST` → 点【计算】
  - 断言: toast「物料 NONEXIST 不存在」（err，来自 api.js 统一通道，业务错误 HTTP 200 非 ≥400）；列表不变；**不产生 HTTP ≥ 400、不产生 console error**
  - 选择器注意: FdeError 经 `api_call` 返回 `{status:"error", kind:"business"}` 且 HTTP 200，api.js 弹 err toast 后 throw、页面 catch 吞掉 → 不计入 §6 红线
