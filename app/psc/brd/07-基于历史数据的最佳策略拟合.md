# 第7章 管理体系详述——基于历史数据的最佳策略拟合

前几章给出了预测方法和库存参数的**默认值**，但「最优值」因物料而异。本章用历史数据**回测拟合**，为每个物料找到最适合的预测方法与库存参数，把「一刀切的经验值」变成「按物料的定制参数」。

## 7.1 定位与目标

拟合回答两个问题：

1. **该用哪个预测方法、什么参数？**（使预测误差最小）
2. **该设什么库存水位、什么组批窗口？**（在满足率达标下，库存与切线成本最低）

拟合的输出，回填到物料主数据（第 3 章的「基线方法 / 基线参数」、第 4 章的「水位 / 组批窗口」），作为日常运行的参数来源。

## 7.2 拟合的两大对象

| 对象 | 候选参数 | 评价指标 |
|---|---|---|
| 预测拟合 | 4 种方法 × 各自参数网格 | sMAPE（预测误差） |
| 库存拟合 | 服务系数 × 组批窗口 | 满足率、库存天数、切线次数 |

拟合**按物料逐一进行**：每个物料独立跑完预测拟合与库存拟合，互不影响。

两者**完全解耦**：预测拟合用滚动回测选「方法 × 参数」（让基线尽量准）；库存拟合用**实际干净需求回放**选「水位 × 窗口」（让水位覆盖波动、窗口摊薄切线）。库存拟合不依赖预测结果——安全库存 C 覆盖「需求波动 σ」，预测的残余误差最终也体现为需求波动（预测偏低 → 实际需求超出 → 波动加大），被 C 一并覆盖；客户预测的**系统性偏差**则由第 3 章置信度 MAPE / bias 在预测层先行修正。二者在运行时分层（第 5 章毛需求 = 销售预测 + 库存策略）。

## 7.3 拟合方法：滚动回测（Walk-Forward）

核心原则：**只用「当时已知」的数据去预测「当时未知」的未来**，避免「用未来数据预测过去」的作弊。

```
历史需求 D1, D2, …, Dn（n 期）
训练窗口 = 前 k 期 → 预测第 k+1 期 → 对比实际 → 记误差
滚动 k 前进 → 累计所有滚动步的误差 → 得该参数组合的总误差
```

滚动回测模拟了真实预测的时序，是参数选择的可靠依据。

## 7.4 预测拟合

**候选参数网格**：

| 方法 | 参数网格 |
|---|---|
| 移动平均 | window ∈ {3, 6, 12} |
| 指数平滑 | alpha ∈ {0.1, 0.3, 0.5}，trend ∈ {false, true} |
| 阶跃检测 | threshold ∈ {0.2, 0.3, 0.5}，confirm_periods ∈ {1, 2, 3} |
| 借用参考 | ref_material（人工指定），scale ∈ {0.5, 1.0, 1.5} |

**流程**：对每个物料，遍历「方法 × 参数」组合 → 各自滚动回测 → 取 sMAPE 最小者 → 回填物料主数据。

**注意**：数据不足的新品 / 断点新件，跳过网格搜索，直接走「借用参考」（或断点历史拼接后拟合）。

## 7.5 库存拟合

库存拟合与预测拟合解耦，用实际干净需求回放库存推移，遍历库存参数：

**候选参数网格**：

| 参数 | 网格 |
|---|---|
| 服务系数 | 对应满足率 {90%, 95%, 98%, 99%} → {1.28, 1.65, 2.05, 2.33} |
| 组批窗口 | {2 周, 4 周, 8 周, 12 周, 16 周} |

**评价指标**（每个组合回测出三个数）：

| 指标 | 含义 | 方向 |
|---|---|---|
| 满足率 | 缺货与否 | 越高越好 |
| 库存天数 | 平均持有库存 | 越低越好 |
| 切线次数 | 组批切换次数 | 越少越好 |

**选择规则**：满足率与库存天然矛盾（满足率高 → 库存高），故采用**约束优化**框架——在 `满足率 ≥ 目标（如 95%）` 的约束下，选「库存持有成本 + 切线成本」最小的组合。

这与第 4 章组批窗口的经济批量模型同源：窗口越长库存越高但切线越少，回测把这条权衡曲线用历史数据实测出来，选出最优点。

## 7.6 拟合流程

```
1. 数据准备：取物料近 N 期（如 24 个月）干净需求，断点前后拼接
2. 预测拟合：遍历方法 × 参数 → 滚动回测 → 选 sMAPE 最小 → 定预测方法参数
3. 库存拟合：用实际干净需求回放 → 遍历服务系数 × 组批窗口 → 回测 → 选满足率约束下成本最小
4. 回填：把最优预测方法参数、最优水位与窗口回填物料主数据
5. 定期重拟合：每月执行一次，适应需求模式变化
```

## 7.7 注意事项

1. **数据量要求**：拟合需足够历史（建议 ≥ 24 期）；不足者用借用参考 / 断点拼接；
2. **过拟合风险**：参数网格不宜过密，否则会拟合到历史噪声而非真实规律；
3. **生命周期分段**：SOP 爬坡期、稳定期、EOP 衰退期的需求模式不同，宜分段拟合（尤其阶跃检测对 SOP 跳变敏感）；
4. **干净需求**：拟合前剔除一次性脉冲事件，否则脉冲会污染参数（σ、MAPE 均虚高）；
5. **计算量**：SKU 数 × 方法 × 参数组合 × 滚动步，计算量大，需批量 / 异步执行，结果可离线缓存；
6. **人工复核**：拟合结果作为**建议值**，异常结果（如参数突变）需人工复核后生效。
7. **模拟粒度**：库存拟合的模拟建议**逐日（或逐周）**推进，与第 6 章库存推移表一致；若用逐月粒度，会漏掉月内需求集中导致的时点缺货、高估满足率。

## 7.8 系统实现机制

### 7.8.1 触发与调度

- 每月执行一次（月度版本发布后或月初定时触发）；
- 计算量大，须进**任务队列**逐物料（或分批）**异步**执行，不阻塞在线业务；
- 结果**离线缓存**，不直接改主数据。

### 7.8.2 预测拟合：滚动回测算法

对每个物料取历史干净需求 `D[1..n]`，遍历「方法 × 参数」组合做滚动回测：

```
对每个 (method, params) 组合：
  errors = []
  for k in [k_min .. n-1]:              # k_min 为最小训练窗口（如 12）
    train = D[1..k]
    pred = method.forecast(train, params)   # 用前 k 期预测第 k+1 期
    if D[k+1] > 0:
      errors.append( |pred − D[k+1]| / ((|pred| + D[k+1]) / 2) )   # sMAPE，需求为 0 的期跳过
  error = mean(errors)
选 error 最小的组合 → 预测拟合结果
```

`k` 从 `k_min` 滚到 `n-1`，模拟「每月只用当月为止的历史预测下月」的真实场景，误差是所有滚动步 sMAPE 的平均。用 **sMAPE**（对称 MAPE）替代 MAPE：既避免需求为 0 时除零，也消除 MAPE「高估无上限、低估最多 100%」的系统性偏低倾向，对长尾品种更稳健。

### 7.8.3 库存拟合：库存推移模拟回测

用历史干净需求回放库存推移，评估库存参数组合（与预测拟合解耦）：

```
给定（服务系数 → C，组批窗口 → B；最低 A 由生产+物流时间算出）：
  库存 = 期初库存
  for t in [warmup+1 .. n]:            # warmup 预热期不计入统计
    库存 −= D[t]                        # 实际干净需求消耗
    if 库存 < 0:    缺货量 += −库存; 库存 = 0   # 记录缺货量，非仅缺货次数
    elif 库存 < A:  触发最低补库
    elif 库存 < A+C: 触发安全补库
    if 触发补库: 补货量 = B − 当前库存（补到组批水位 B，假设产能富余）; 切线次数++; 记录 L 期后入库
    库存 += 本期末到期的补货入库
    记录当期库存
  满足率 = 1 − 缺货量 / 总需求；平均库存 = mean(库存序列)；库存天数 = 平均库存/日均需求
```

这是第 6 章库存推移表的「历史回放版」——同一套补库触发逻辑（<0 / <A / <A+C），把「未来」换成「已发生的历史」去回测。两点关键：**warmup 预热期**（长度 = 一个组批窗口对应的期数）先让库存到稳态、再统计，避免期初库存初始化污染指标；**缺货记量不记次**，满足率按「满足的需求量 / 总需求量」计算，与第 1 章「准时交付率 / 满足率」口径一致。

### 7.8.4 参数选择：约束优化

在 `满足率 ≥ 目标（如 95%）` 的候选组合中，选「库存持有成本 + 切线成本」最小者。成本折算：

```
库存持有成本 = 平均库存 × 单位货值 × 年持有费率
             = 库存天数 × 日均需求 × 单位货值 × 年持有费率
切线成本     = 切线次数 × (12 ÷ 回测月数) × 每次切线成本
```

其中单位货值、每次切线成本来自物料主数据，年持有费率来自策略配置。

### 7.8.5 结果存储与回填

| 字段 | 说明 |
|---|---|
| 物料号 | 主键 |
| 拟合版本 | 月度（如 2026-08） |
| 预测方法 / 参数 | 最优组合 |
| sMAPE | 预测误差 |
| 服务系数 / 安全水位 / 组批窗口 | 最优库存参数 |
| 满足率 / 库存天数 / 切线次数 | 回测指标 |
| 状态 | 待复核 / 已生效 / 已否决 |

- 拟合结果先落**拟合结果表**，人工复核通过后置「已生效」，才回填物料主数据（基线方法 / 参数 / 水位 / 组批窗口）；
- 参数相对上月**跳变过大**时自动标记异常，强制人工确认；
- 参数回填**带版本记录**（拟合版本 + 生效时间），支持**回滚**到上一版参数——若新参数导致缺货 / 超储恶化，可快速退回。
