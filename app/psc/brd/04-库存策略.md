# 第4章 管理体系详述——库存策略

销售预测天然不可能准确。库存策略的作用，是用合理的水位设置去弥补销售预测的不准确性，在不显著抬高成本的前提下守住客户服务水平。本章给出三层库存结构、品种分层设定、参数公式、字段设计与验证方法。

## 4.1 定位与原则

库存策略回答一个核心问题：**为每个物料「存多少、什么时候补」**。它由三层库存构成，各自对应一个独立的不确定源：

| 层 | 目的 | 应对的问题 |
|---|---|---|
| 最低库存（A） | 覆盖响应缺口，防断货 | 客户需求提前期不足 |
| 安全库存（C） | 覆盖需求波动 | 客户需求波动性 |
| 组批库存（B） | 摊薄切换成本 | 频繁切线造成的效率损失 |

三层驱动因素相互独立，设定与诊断时必须分列，不能混为一谈。

## 4.2 三层库存结构

### 4.2.1 最低库存（A）

**本质**：覆盖「生产 + 物流响应时间」超出「客户自有缓冲」的那段缺口。客户只放几天线边库存、且调拨提前期很短时，这段缺口必须由我方库存兜底。

```
A = 日需求 × max(0, 生产时间 + 物流时间 − 可用缓冲天数)
```

- **可用缓冲天数**：未进入当前库存扣减的外部缓冲（如 OEM 线边库存）；寄售仓已计入当前库存，不重复计入缓冲。**默认设为 0**。
- 默认不抵扣的考虑：客户线边缓冲不可控、不透明，作为默认不扣减，让最低库存覆盖完整的「生产时间 + 物流时间」；仅在与客户有明确、稳定的缓冲协议时才扣减该天数。

### 4.2.2 安全库存（C）

**本质**：覆盖响应窗口内的需求波动。需求有随机波动，仅按均值备货必然缺货，安全库存以一定服务水平兜住波动。

```
C = 服务系数 × 响应窗口内需求波动（标准差）
```

- **服务系数**按满足率目标确定，常用取值：

| 满足率目标 | 服务系数 |
|---|---|
| 90% | 1.28 |
| 95% | 1.65 |
| 98% | 2.05 |
| 99% | 2.33 |

- 波动口径是「响应窗口内的需求标准差」，不是月度总量；低库存轨道（速度对冲）由产能吸收波动，C 可很小甚至为零。

**响应窗口内需求波动（标准差）的计算**：

- 响应窗口 `L = 生产时间 + 物流时间`，折算为与历史需求一致的期数（通常为月）；
- 方法一（经典公式，假设各期独立）：`σ_L = σ × √L`，σ 为单期需求标准差；
- 方法二（滚动累计，推荐）：构造连续 L 期的累计需求序列 `S_i = D_i + … + D_{i+L-1}`，`σ_L = std(S)`——直接测量响应窗口内累计需求的波动，不依赖「各期独立」假设，能正确捕捉需求自相关，而 `√L` 在需求存在持续趋势 / 季节时易失真。

其中 σ 采用近 N 期（如 12 个月）**干净需求**（剔除一次性脉冲事件）的样本标准差：`σ = √( Σ(x_i − x̄)² / (n−1) )`。

### 4.2.3 组批库存（B）

**本质**：按经济批量组织生产，减少切线次数，摊薄切换成本。**组批库存是库存水位的上限，而不是要补到的目标量**——它界定了「因组批最多允许额外持有多少库存」，超过即超储。

```
B = 日需求 × 组批窗口天数
```

- **日需求**：近 N 期历史干净需求的日均值。
- **组批窗口**的确定分三层：

| 层次 | 方法 | 说明 |
|---|---|---|
| 理论 | 经济批量模型 | `T = √(2S / (h·d))`，S=切线成本、h=单位日持有成本、d=日需求 |
| 经验 | 按需求频次起步 | 高频走量 2~4 周、一般件 4~8 周、长尾 12~16 周甚至更长、临近 EOP 强制缩短；频次按日需求量排序，前 20% 为高频、中间 30% 为一般、后 50% 为长尾 |
| 最优 | 库存推移表回测 | 模拟不同窗口，权衡库存天数 / 满足率 / 切线次数（§4.7） |

其中 `h = 单位货值 × 年持有费率 / 365`。经济批量模型的直觉：切线成本越高、持有成本越低，组批窗口越长；但其结果往往偏大（假设需求确定、无减值风险、无资金约束），故落地以经验值起步、回测收敛，理论值仅作窗口上限参考。

**窗口的核心驱动是需求频次**：切线频率 = 365 / 窗口（天），与日需求无关——品种越多、固定窗口下切线越多。长尾品种日需求小，拉长窗口的持有成本增量小、摊薄切线成本最划算，故窗口应显著长于走量件；「价值 / 风险 / EOP」只作修正因素（高价值压缩、低价值低风险可再拉长、临近 EOP 强制缩短清尾）。
- 组批库存 = 周转库存 + 预期库存：**淡季**优先组批建储、形成缓冲；**旺季**消耗缓冲、减少当期切线、保护产能；产能紧张时排不上是**正常机制**，不是异常。
- 组批制造只在有富余产能时执行，且按经济批量生产、**封顶于组批水位**，不会无限补。

## 4.3 库存水位：一个「水位带」而非一个点

三层库存共同构成一个**水位带**，而不是一个单一目标水位：

```
下限（补货触发线） = A（最低） + C（安全）
上限（组批封顶线） = A + C + B（组批）
```

- **下限**：库存低于「最低 + 安全」即触发补货（最低补货、安全补货，对应需求池优先级 2、3）；
- **上限**：组批制造最多把库存推到「最低 + 安全 + 组批」，超过即超储，不再组批、并触发降储预警。

三层分列的意义在于诊断：库存偏高时，能分清是「组批策略造成的」（正常）还是「风险缓冲失控」（异常）；否则库存推移表会失去诊断能力。日常口头统称「安全库存」无妨，但落到系统字段务必分层。

## 4.4 品种分层设定

核心主张：**并非所有品种都设齐三层库存**。不同物料用不同工具对冲需求不确定性——低价值物料用库存对冲，高价值、生产周期短的物料用速度对冲。

| 品种类型 | 对冲工具 | 策略 |
|---|---|---|
| 低价值、低变更风险 | 库存 | 高库存、月度及以上组批生产，省下切线成本 |
| 高价值、生产周期短 | 速度（快速响应生产） | 低库存甚至不设安全库存，按调拨需求生产 |

**不设安全库存的硬条件**：

```
生产时间 + 物流时间 ≤ 客户线边库存天数 + 调拨提前期
```

「生产周期短」正是该条件的关键变量，应做成判定规则按品种量化核对，而非价值高就自动豁免。

**不备库存 ≠ 没有成本**：用速度对冲，意味着拿**产能弹性**吸收波动（留富余产能、接受加班、允许插单）。产线满负荷时，这类零库存物料会直接演变成停线。做方案时须把「库存持有成本 vs 产能弹性成本」两笔账摆出来，哪个便宜用哪个。

### 4.4.1 分层设定规则

| 物料特征 | 设定 |
|---|---|
| 低价值、低变更风险、切线成本高、离 EOP 远 | 设组批库存，安全库存可适度从宽 |
| 高价值、生产周期短 | 可不设安全/组批库存，用速度应对 |
| 近 EOP / 高变更风险 | 组批窗口强制收缩、清尾，防减值 |

### 4.4.2 三层与品种的衔接

- **高库存品种**（低价值、低变更风险）：B + A + C 三层都有，B 是大头；
- **低库存品种**（高价值、短周期）：只有 A（+C），B = 0 不组批。

## 4.5 盲区与例外

分层规则存在两个未覆盖的象限和一个对称面，需单独给处理策略：

| 象限 | 困境 | 对策 |
|---|---|---|
| 高价值 + 生产周期长 | 既囤不起又追不上 | 往前端要时间：推客户延长预测冻结期；在半成品/通用前工序备通用件（延迟差异化）；协商最低库存 |
| 低价值 + 高变更风险 | 持有成本低但会呆滞 | 库存下沉到原材料/半成品形态，或小批高频，不囤成品 |
| EOP / 车型换代 | 与备货决策对称 | 清尾管理：按剩余生命周期需求倒推最后一批产量，宁欠勿超 |

## 4.6 参数设定与字段设计

库存策略按物料设定参数，字段如下：

| 字段 | 来源 / 说明 | 规则 |
|---|---|---|
| 物料号 | 物料主数据 | 维度 |
| 品种分类 | 物料主数据 | 价值、变更风险、切线成本、离 EOP |
| 对冲工具 | 系统判定 | 库存 / 速度 |
| 生产时间 | 物料主数据 | 生产周期 |
| 物流时间 | 物料主数据 | 物流周期 |
| 可用缓冲天数 | 客户/项目数据 | OEM 线边等外部缓冲，默认设为 0 |
| 最低库存水位 | 计算 | `日需求 × max(0, 生产+物流 − 缓冲)` |
| 服务系数 | 满足率目标 | 按目标取标准正态系数 |
| 响应窗口需求波动 | 历史数据 | 响应窗口内需求标准差 |
| 安全库存水位 | 计算 | `服务系数 × 响应窗口波动` |
| 组批窗口 | 物料主数据 | 按品类设定 |
| 组批库存水位 | 计算 | `日需求 × 组批窗口` |
| 设定依据 | 备注 | 参数来源与依据 |

> 参数最优值不必一次定死——初始给默认值，之后由第 7 章「模型拟合」用库存推移表回测，为每个物料确定最优组批窗口与水位，回填到物料主数据。

## 4.7 验证方法：库存推移表回测

「组批按月还是按几周」「水位设多少」不靠辩论，用历史调拨单直接回测：

1. 对每个 SKU，模拟不同组批窗口（周度、月度、6 周等）与不同库存水位；
2. 输出三个核心指标：**库存天数**、**满足率**与**切线次数**；
3. 把「组批窗口」和「安全库存」变成按 SKU 定参数的数据化决策，而非一刀切的固定规则。

## 4.8 主数据及字段

库存策略所需的主数据，均从外部系统（ERP、PLM、CRM 等）**冗余（同步副本）到本地**，本系统只读引用、不维护源数据。各类主数据必须提供的字段如下（标注单位与字典值）：

### 4.8.1 物料主数据

| 字段 | 单位 / 字典值 | 用途 |
|---|---|---|
| 物料号 | — | 唯一标识 |
| 状态 | 字典：正常 / EOP / 停用（外部维护） | 物料生命周期状态，来自主数据接口，本系统只读，不联动 EOP |
| 单位货值 | 元 / 件 | 组批窗口经济批量（持有成本 h） |
| 价值分类 | 字典：高 / 低（人工分类） | 品种分层（库存 / 速度对冲） |
| 切线成本 | 元 / 次 | 组批窗口经济批量（切线成本 S） |
| 生产时间 | 天 | 最低库存 A 计算 |
| 物流时间 | 天 | 最低库存 A 计算 |
| 变更风险等级 | 字典：高 / 低 | 品种分层 |
| 满足率目标 | 百分比（如 95%） | 安全库存服务系数 |
| 组批窗口 | 天（存储）/ 周（展示） | 组批库存 B 上限计算 |

### 4.8.2 项目台账

| 字段 | 单位 / 字典值 | 用途 |
|---|---|---|
| 项目号 | — | 关联项目 |
| 阶段 | 字典：进行中 / SOP / EOP | 生命周期阶段 |
| SOP 时间 | 日期 YYYY-MM-DD | 阶跃检测、爬坡期 |
| EOP 时间 | 日期 YYYY-MM-DD | 判断离 EOP、清尾管理 |

### 4.8.3 客户数据（线边信息）

| 字段 | 单位 / 字典值 | 用途 |
|---|---|---|
| 客户编码 | — | 关联客户 |
| 线边库存天数 | 天（默认 0） | 可用缓冲 |
| 调拨提前期 | 天 | 最低库存 / 不设安全库存硬条件 |

### 4.8.4 物料销售历史

| 字段 | 单位 / 字典值 | 用途 |
|---|---|---|
| 物料号 | — | 关联物料 |
| 期间 | 月度 YYYY-MM | 时间维度 |
| 数量（干净需求） | 件 | 日需求、响应窗口内需求波动 |

> 物料销售历史属历史数据而非严格主数据，但其字段同为体系运行所必需，故一并列出。

## 4.9 公式参数取值来源

本章各公式的参数，取值来源归纳为四类：物料主数据、客户数据、物料销售历史（计算派生）、策略配置。逐个公式映射如下：

| 公式 | 参数 | 取值来源 |
|---|---|---|
| 最低库存 `A = 日需求 × max(0, 生产+物流−缓冲)` | 日需求 | 物料销售历史：近 N 期月均干净需求 ÷ 30（自然日） |
| | 生产时间 | 物料主数据 |
| | 物流时间 | 物料主数据 |
| | 可用缓冲天数 | 客户数据：线边库存天数（默认 0） |
| 安全库存 `C = 服务系数 × 响应窗口内波动` | 服务系数 | 满足率目标 → 查标准正态表 |
| | 响应窗口内波动 | 物料销售历史：近 N 期干净需求滚动 L 期累计标准差（L = 生产+物流） |
| 组批库存 `B = 日需求 × 组批窗口` | 日需求 | 物料销售历史 |
| | 组批窗口 | 物料主数据（经验值）或经济批量模型计算 |
| 组批窗口 `T = √(2S / (h·d))` | S 切线成本 | 物料主数据 |
| | h 单位日持有成本 | 单位货值（物料主数据）× 年持有费率（策略配置）÷ 365 |
| | d 日需求 | 物料销售历史 |
| 硬条件 `生产+物流 ≤ 线边+调拨提前期` | 生产 / 物流 | 物料主数据 |
| | 线边 / 调拨提前期 | 客户数据 |

其中几类「非主数据」参数：

- **满足率目标**：按品类的服务水平目标（如 A 类 98%、B 类 95%），存物料主数据（§4.8.1）；
- **年持有费率**：资金成本 + 仓储费率 + 减值风险费率，来自财务 / 策略配置，非主数据；
- **N（历史窗口期数）**：日需求、σ、响应窗口波动均取「近 N 期」（建议 12 个月），属策略配置参数；
- **日需求、响应窗口内波动、σ**：均为**计算派生值**，源数据是物料销售历史（月度干净需求），非直接冗余字段。口径：`日需求 = 近 N 期月均干净需求 ÷ 30`（月均取简单算术平均）；`L(月) = (生产时间 + 物流时间) ÷ 30`（自然日，与历史需求的「月」对齐）；
- **服务系数**：由满足率目标查标准正态分布表得到（95% → 1.65），亦为派生值。
