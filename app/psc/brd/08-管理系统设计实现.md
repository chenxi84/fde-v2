# 第8章 管理系统设计实现

前七章定义了产销协同的管理体系，本章把它落到系统层面：划清系统边界、拆解模块、梳理数据模型、定义与 ERP 的集成方式与运行节奏。

## 8.1 系统定位与边界

本系统是产销协同的**执行载体**，承载「预测 → 库存策略 → 毛需求/净需求 → 主计划 → 需求池 → 拟合」的主链路。

**系统边界**（明确不做与依赖）：

| 项 | 处理方式 |
|---|---|
| 产能平衡 | 在线下完成，结果作为主计划导回系统（第 5 章） |
| 绩效指标统计 | 由 ERP / BI 承担，本系统不重复实现 |
| 主数据 | 从 ERP 冗余副本到本地，只读引用、不维护源 |
| 库存 / 在途 / 未发订单 | 从 ERP 同步，作为净需求与推移表输入 |

## 8.2 系统模块划分

| 模块 | 对应章节 | 职责 |
|---|---|---|
| 主数据管理 | 第 3、4 章 | ERP 主数据冗余同步、断点/替换关系维护 |
| 销售预测 | 第 3 章 | 预测清单 → 处理 → 汇总，四种方法，异常/最终预测决策 |
| 库存策略 | 第 4 章 | 三层水位（最低/安全/组批）计算、品种分层 |
| 毛需求与净需求运算 | 第 5 章 | 毛需求合成、净需求公式运算 |
| 主计划维护 | 第 5 章 | 线下产能平衡结果导回、版本管理 |
| 需求池管理 | 第 6 章 | 库存推移表逐日推演、三类补库生成 |
| 策略拟合 | 第 7 章 | 按物料滚动回测，每月拟合最优参数并回填 |

## 8.3 整体数据流

```
ERP（主数据 / 库存 / 在途 / 未发订单）
        │ 同步到本地
        ▼
客户预测 ──→ 销售预测 ─┐
                        ├─→ 毛需求 ─→ 净需求 ─→ 主计划（线下产能平衡导回）
历史数据 ──→ 库存策略 ─┘                          │
                                                 ▼
                                   库存推移表 ──→ 需求池
                                                 │
                                    主计划 + 需求池 ──→ 生产计划
                                                 ▲
                    模型拟合（每月）──回填参数─────┘
```

## 8.4 数据模型

### 8.4.1 基础数据表

#### 主数据（冗余到本地，引用不维护）

| 表 | 字段 |
|---|---|
| 客户主数据 | 客户编码、客户名称、结算模式、线边库存天数、调拨提前期 |
| 物料主数据 | 物料号、物料名称、状态、单位货值、价值分类、切线成本、生产时间、物流时间、变更风险等级、满足率目标、组批窗口、基线方法、基线参数 |
| 项目台账 | 项目号、阶段、SOP 时间、EOP 时间、责任销售 |
| 项目—零件映射 | 项目号、物料号、车型、单车用量、份额 |
| 断点基础数据 | 客户、原物料号、新物料号、切换时间、变更单号 |
| 替换关系表 | 原物料号、替换物料号 |
| 月度版本主数据 | 版本号、锚定期间、opening 日、锁定状态 |
| 模板 / 类比库 | 参考物料号、借用特征（趋势 / 季节 / 生命周期曲线） |

#### 历史 / 派生数据

| 表 | 字段 |
|---|---|
| 物料销售历史 | 物料号、客户、期间、数量（干净需求） |
| 客户达成率 / 置信度 | 客户、物料、MAPE、bias（ERP 统计后冗余回，派生） |

#### ERP 同步执行数据

| 表 | 字段 |
|---|---|
| 当前库存 | 物料号、仓库类型（自有 / 寄售）、库存量 |
| 在途工单 | 物料号、工单号、在制 / 在途数量、预计入库日期 |
| 客户订单 / 调拨单 | 物料号、客户、数量、要求发货日期、状态（已发 / 未发） |

#### 客户输入

| 表 | 字段 |
|---|---|
| 客户滚动预测 | 客户、物料号、期间（N+1/N+2/N+3）、预测量 |

### 8.4.2 业务单据

| 单据 | 节奏 | 关键字段 |
|---|---|---|
| 销售预测清单 / 处理表 / 汇总表 | 月度 | 物料 × 客户 × 版本 × 滚动月度、最终预测量 |
| 库存策略表 | 月度 | 物料、最低 / 安全 / 组批水位、参数 |
| 毛需求表 | 月度 | 物料 × 版本 × 滚动月度、销售预测 + 库存策略 |
| 净需求运算表 | 月度 | 毛需求 + 未发 − 库存 − 在途 |
| 主计划表 | 月度 | 物料、计划版本号、需求量、最迟入库日期 |
| 库存推移表 | 日度 | 物料 × 日期、预计入库 / 出库、库存余额 |
| 需求池 | 周度 / 日度 | 补库单号、补库类型、补库数量、要求/承诺入库时间、状态 |

## 8.5 外部接口

系统需要对接四类外部接口：

### 8.5.1 ERP 接口（核心，双向）

| 数据域 | 方向 | 内容 | 节奏 |
|---|---|---|---|
| 主数据 | 入 | 客户主数据、物料主数据、项目台账、项目—零件映射 | 增量 / 日度 |
| 库存 | 入 | 当前库存（自有仓 + 寄售仓） | 每日 0 点 |
| 在途工单 | 入 | 在制 / 在途数量、预计入库日期 | 日度 |
| 未发订单 / 调拨单 | 入 | 已接收未发运订单 | 日度 |
| 达成率 | 入 | MAPE / bias（ERP 统计后冗余回） | 月度 |
| 生产计划 | 出 | 主计划 + 需求池下发到 ERP 生产 / 排程 | 日度 / 周度 |
| 工单状态 | 入 | 已下达工单的开工 / 完工状态回传 | 日度 |
| 入库 | 入 | 补库单 / 工单的入库回传 | 日度 |

### 8.5.2 PLM / 工程变更接口（入）

| 数据域 | 内容 | 节奏 |
|---|---|---|
| 断点 / 替换关系 | 断点基础数据、替换关系表、项目—零件映射 | 变更增量同步 |

### 8.5.3 客户接口（入）

| 数据域 | 内容 | 节奏 | 方式 |
|---|---|---|---|
| 客户滚动预测 | 客户 N+1~N+3 预测量 | 月度 | EDI / 客户门户 / 手工导入 |

### 8.5.4 产能平衡接口（线下，双向）

| 数据域 | 方向 | 内容 | 节奏 |
|---|---|---|---|
| 净需求导出 | 出 | 净需求 → 线下产能平衡工具 | 月度 |
| 主计划导入 | 入 | 平衡后的主计划导回系统 | 月度 |

> **同步方式与质量**：主数据、库存、在途、未发订单均以**冗余副本**同步到本地，本系统只读引用。其中 ERP 库存同步（每日 0 点）是库存推移表的锚点，时效与准确性最为关键——漏扣库存 → 多下单、漏扣在途 → 重复下单。

## 8.6 关键实现要点

1. **预测计算引擎**：实现四种预测方法（移动平均 / 指数平滑 / 阶跃检测 / 借用参考），参数以 JSON 存储、可扩展；
2. **库存推移推演**：每日 0 点以 ERP 库存为锚点，逐日滚动推演未来 3 个月，产出缺货 / 击穿水位信号；
3. **净需求运算引擎**：按物料 × 期间执行 `毛需求 + 未发 − 库存 − 在途` 的公式，支持分层拆解、各层非负；
4. **策略拟合**：按物料滚动回测，计算量大，需**批量 / 异步**执行，结果离线缓存、人工复核后生效；
5. **版本与追溯**：主计划版本号（变更 +1）、月度版本冻结，保证计划可追溯、可回滚。

## 8.7 运行节奏

| 节奏 | 动作 |
|---|---|
| 月度 | 销售预测、库存策略、毛需求发布、净需求运算、主计划维护、策略拟合 |
| 周度 / 日度 | 库存推移表刷新、需求池执行 |
| 每日 0 点 | 从 ERP 取最新库存总额，刷新推移表起始库存 |

## 8.8 可配置参数清单

下表汇总全书各章的运行时参数，实现时统一做成配置项：

| 参数 | 默认 / 建议值 | 用途 | 章节 | 状态 |
|---|---|---|---|---|
| MAPE 阈值 | 20% | 判定客户预测可信 / 不可信 | 第 3 章 §3.7 | 待定默认值 |
| 偏离 / 误差阈值 | 5% | 异常标记、最终预测决策 | 第 3 章 §3.7 | 待定默认值 |
| 满足率目标 | 按品类（如 A 98%、B 95%） | 服务系数、安全库存、拟合约束 | 第 4 章 §4.2.2 | 按品类定 |
| 服务系数映射 | 90%→1.28、95%→1.65、98%→2.05、99%→2.33 | 安全库存计算 | 第 4 章 §4.2.2 | 固定（标准正态表） |
| N 历史窗口（库存策略） | 12 个月 | 日需求、σ、响应窗口波动 | 第 4 章 §4.9 | 待定默认值 |
| 年持有费率 | 资金 + 仓储 + 减值（财务定） | 经济批量 h、拟合成本折算 | 第 4 章 §4.2.3 | 财务定 |
| 可用缓冲天数 | 0 | 最低库存 A | 第 4 章 §4.2.1 | 已确认 |
| 组批窗口分档 | 高频 2~4 周 / 一般 4~8 周 / 长尾 12~16 周 | 组批库存 B | 第 4 章 §4.2.3 | 待定默认值 |
| 频次分档比例 | 前 20% 高频 / 中间 30% 一般 / 后 50% 长尾 | 组批窗口经验值分档 | 第 4 章 §4.2.3 | 已确认 |
| 拟合历史窗口 N | 24 个月 | 拟合数据准备 | 第 7 章 §7.6 | 待定默认值 |
| 最小训练窗口 k_min | 12 个月 | 滚动回测 | 第 7 章 §7.8.2 | 待定默认值 |
| warmup 预热期 | 一个组批窗口期 | 库存拟合模拟 | 第 7 章 §7.8.3 | 已确认 |
| 参数突变阈值 | 建议 30% | 拟合结果异常标记 | 第 7 章 §7.8.5 | 待定默认值 |

> 「已确认」为本书已定的业务规则；「待定默认值」建议实现时做成配置项，上线后按实际运行效果调优。「服务系数映射」为标准正态分布表，属固定映射，非可调参数。
