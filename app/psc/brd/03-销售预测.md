# 第3章 管理体系详述——销售预测

销售预测是整个产销协同体系的需求起点，其输出经加工发布后构成毛需求的销售预测部分。本章给出销售预测的工作机制、表结构、四种预测方法与参数、以及异常与最终预测的决策规则。

## 3.1 预测工作机制

销售预测按四步推进：

1. **收集客户预测**：收集客户针对各物料的滚动预测，结合客户的历史置信度（MAPE）与普遍性偏离方向（bias），决定如何调整客户原始预测；
2. **自主预测形成基线**：基于历史干净需求，为物料选择合适的预测模型（移动平均、指数平滑、阶跃检测、借用参考），计算得到预测基线；
3. **对比双源**：对比「调整后的客户预测值」与「基线预测值」；
4. **事件调整**：分析物料相关的独立事件，结合事件影响对预测值做相应调整。

## 3.2 数据流程总览

预测数据分三层递进：

```
销售预测清单（物料 × 客户）  →  销售预测处理表（逐行加工）  →  物料预测汇总表（按物料合计）
```

- **清单**：枚举所有需要预测的「物料 × 客户」组合；
- **处理表**：对每个组合逐行完成「客户预测调整、基线计算、事件调整、异常判定、最终预测」；
- **汇总表**：将同一物料下所有客户的最终预测量合计，得到物料级预测，作为毛需求发布的输入。

## 3.3 销售预测清单

清单用于枚举预测范围，字段如下：

| 字段 | 来源 |
|---|---|
| 物料号 | 物料主数据中所有处于正常状态的物料 |
| 客户 | 该物料历史发生过采购行为的所有客户 |

对上述条件做笛卡尔组合，即得到所有「物料号 × 客户」行。每个组合在指定月度版本下，按滚动月度拆成 N+1、N+2、N+3 三行进入处理表。

## 3.4 销售预测处理表

处理表是对清单逐行加工的工作表，字段分四组。

### 3.4.1 维度与客户预测字段

| 字段 | 来源 / 说明 | 规则 |
|---|---|---|
| 物料号 | 清单 | 维度 |
| 客户 | 清单 | 维度 |
| 月度版本 | 月度版本主数据（如 2026 年 8 月） | 维度 |
| 滚动月度 | 数据字典 | N+1 / N+2 / N+3 |
| 原始需求数量 | 客户填报 | 客户不填报时为空 |
| 平均绝对百分比误差 MAPE | 客户置信度（客户 × 物料，派生指标） | 基于该品种历史达成率滚动测算 |
| 预测偏差 bias | 客户置信度（客户 × 物料，派生指标） | 基于该品种历史达成率滚动测算 |
| 调整后需求数量 | 系统自动修正，人工可调 | `原始需求数量 × (1 − bias)` |

> **MAPE 与 bias 的定位**：两者都是「客户 × 物料」粒度的**派生指标**，由历史达成率统计滚动更新，不属于静态主数据。MAPE 衡量预测的**幅度准确性**（越小越准）；bias 衡量预测的**方向性偏差**（一贯多报为正、少报为负），用于修正原始预测。
>
> **bias 口径**：`bias = (历史预测合计 − 历史实际合计) ÷ 历史实际合计`，多报为正、少报为负。据此修正：`调整后需求 = 原始需求 × (1 − bias)`（客户一贯多报 10% 时 bias = +10%，调整后 = 原始 × 0.9）。

### 3.4.2 基线计算字段

| 字段 | 来源 / 说明 | 规则 |
|---|---|---|
| 基线方法 | 物料主数据 | 移动平均 / 指数平滑 / 阶跃检测 / 借用参考 |
| 基线参数 | 物料主数据（JSON 字符串） | 各方法的参数，见 §3.5 |
| 基线数量 | 计算 | 方法 + 参数 作用于历史干净需求的结果 |
| 事件分析 | 该物料存在的关键事件 | 促销、SOP、断点等 |
| 事件调整量 | 事件带来的调整量 | 只作用于归属期，不外推 |
| 基线和事件合计量 | 计算 | `基线数量 + 事件调整量` |

### 3.4.3 断点字段

| 字段 | 来源 |
|---|---|
| 断点物料号 | 断点基础数据 |
| 切换时间 | 断点基础数据 |

断点字段用于提示该物料正处于新旧件切换期，供人工调整参考，并驱动断点追溯（§3.6）。

### 3.4.4 决策字段

| 字段 | 说明 |
|---|---|
| 异常标记 | 标记双源分歧、需要人工介入的行 |
| 最终预测量 | 该行最终的预测值（异常行不自动填写） |

决策规则详见 §3.7。

## 3.5 四种预测方法及参数

每种方法统一输出「基线数量」，参数以 JSON 存于物料主数据。

### 3.5.1 移动平均（MA）

取过去 n 期历史需求的算术平均作为基线。最稳健的平稳需求预测法。

`F = (D_t + D_{t-1} + … + D_{t-n+1}) / n`

| 参数 | 含义 | 取值范围 | 默认 |
|---|---|---|---|
| `window` | 平滑窗口期数 | 3 ~ 12（月） | 6 |

**JSON**：`{"window": 6}`　　**适用**：需求平稳、无趋势、无季节；要求历史 ≥ n 期。

### 3.5.2 指数平滑（ES）

对历史做指数加权平均，越近的数据权重越高（权重按 `1−α` 衰减），可扩展趋势/季节项。

`F_{t+1} = α·D_t + (1−α)·F_t`，初始值 `F₀` 取训练窗口内历史需求均值。

| 参数 | 含义 | 取值范围 | 默认 |
|---|---|---|---|
| `alpha` | 水平平滑系数 | 0 ~ 1 | 0.3 |
| `trend` | 是否启用线性趋势项 | true / false | false |
| `beta` | 趋势平滑系数（trend=true 时生效） | 0 ~ 1 | 0.1 |
| `seasonal` | 是否启用季节项 | true / false | false |
| `gamma` | 季节平滑系数（seasonal=true 时生效） | 0 ~ 1 | 0.1 |
| `period` | 季节周期（seasonal=true 时生效） | 如 12 | 12 |

**JSON**：`{"alpha":0.3,"trend":false}`　　**适用**：有趋势、近期数据更重要的物料。

### 3.5.3 阶跃检测（Step Detection）

识别需求序列中的**永久性水平跳变**（阶跃），并基于跳变后的新水平外推。用于新车型 SOP、产能切换等「水平一次性抬高并维持」的场景——此类场景移动平均会严重滞后。

**逻辑**：回溯 `lookback` 期估计当前水平 → 检测相邻期**相对变化率** `(D_t − D_{t-1}) ÷ D_{t-1}` 是否超 `threshold` → 持续 `confirm_periods` 期才认定永久阶跃（防把脉冲误判为阶跃）→ 基线切换到阶跃后水平。

| 参数 | 含义 | 取值范围 | 默认 |
|---|---|---|---|
| `threshold` | 阶跃判定阈值（相对变化率） | 0 ~ 1 | 0.3 |
| `confirm_periods` | 阶跃需持续确认期数 | 1 ~ 3 | 2 |
| `lookback` | 阶跃前水平回溯窗口 | 3 ~ 12 | 6 |

**JSON**：`{"threshold":0.3,"confirm_periods":2,"lookback":6}`　　**适用**：SOP、产能切换、水平永久变化。

### 3.5.4 借用参考（Reference / Analogy）

物料自身历史不足时，借用相似物料的需求特征（趋势 / 季节 / 生命周期曲线）作为参考基线。

| 参数 | 含义 | 取值范围 | 默认 |
|---|---|---|---|
| `ref_material` | 参考物料号 | 物料主数据 | 必填 |
| `scale` | 缩放系数（参考物料与本物料的量比） | > 0 | 1.0 |
| `mode` | 借用模式 | trend / season / lifecycle | trend |
| `offset` | 偏移量（叠加修正） | 实数 | 0 |

**JSON**：`{"ref_material":"M12345","scale":1.0,"mode":"trend"}`　　**适用**：新品、历史数据不足、断点新件。

### 3.5.5 方法选择速查

| 场景 | 推荐方法 |
|---|---|
| 需求平稳 | 移动平均 |
| 有趋势、近期更重要 | 指数平滑 |
| SOP / 产能切换 / 水平跳变 | 阶跃检测 |
| 新品 / 历史不足 / 断点新件 | 借用参考 |

> 参数最优值不必一次定死——初始给默认值，之后由第 7 章「模型拟合」用历史数据回测，为每个物料挑出最优方法与参数，回填到物料主数据。

## 3.6 断点追溯规则

在运行历史数据、生成基线**之前**，先做断点追溯：

> 若物料是断点后的「新物料号」，沿断点基础数据向上追溯「原物料号」，将【原件历史】+【新件历史】按时间拼接成一条连续序列，再送入预测方法。

它与「借用参考」的区别：

- **断点前后 = 同一零件** → 历史**直接拼接**，量比固定 1.0，在数据准备阶段做；
- **借用参考 = 相似但不同的零件** → 借用**参考曲线**，量比可调，在预测阶段做。

## 3.7 异常标记与最终预测决策规则

设：

- `客户值 = 客户调整后需求数量`
- `基线值 = 基线和事件合计量`
- `偏离率 = |基线值 − 客户值| ÷ 客户值`（客户值为 0 时按绝对值判定）

**MAPE 阈值**（可配置参数，建议 20%）：`MAPE ≤ 阈值` 视为「小」（客户可信），`> 阈值` 视为「大」（客户不可信）。

### 3.7.1 异常标记

| 条件 | 结果 |
|---|---|
| MAPE 小 且 偏离率 > 5% | 标记异常 |
| MAPE 大 且 偏离率 > 5% | 标记异常 |
| MAPE 不存在 | 不标记 |
| 其余（偏离率 ≤ 5%） | 不标记 |

标记异常的行，【最终预测量】不自动填写，交由人工判断。

### 3.7.2 最终预测量

| 条件 | 结果 |
|---|---|
| MAPE 小 且 偏离率 ≤ 5% | 取【客户调整后需求数量】 |
| MAPE 大 且 偏离率 ≤ 5% | 取【基线和事件合计量】 |
| MAPE 不存在 | 取【基线和事件合计量】（默认信基线） |
| 标记异常（偏离率 > 5%） | 不自动填写，人工填 |

> 偏离/误差阈值（5%）与 MAPE 阈值（20%）均应做成**可配置参数**，避免写死后调优需改代码。
> 两套规则互补：偏离 ≤ 5% 自动取值，> 5% 标记异常人工介入，覆盖完整无遗漏。

## 3.8 物料预测汇总表

将处理表中同一「物料号 × 月度版本 × 滚动月度」下所有客户的【最终预测量】合计，得到物料级预测：

| 字段 | 来源 |
|---|---|
| 物料号 | 收集数据 |
| 月度版本 | 月度版本主数据 |
| 滚动月度 | 数据字典（N+1 / N+2 / N+3） |
| 最终预测量 | 该物料所有客户最终预测量合计 |

汇总表是销售预测的最终输出，作为毛需求（销售预测部分）的输入进入毛需求发布与净需求运算环节（详见第 5 章）。

## 3.9 基础数据

销售预测所需的基础数据，均从外部系统（ERP、PLM、CRM 等）**冗余（同步副本）到本地**，本系统只读引用、不维护源数据：

| 数据 | 主要字段 | 源头 |
|---|---|---|
| 断点基础数据 | 客户、原物料号、新物料号、切换时间、变更单号 | 冗余到本地（上游无此数据时本地录入） |
| 客户主数据 | 客户信息、结算模式 | 冗余到本地 |
| 物料主数据 | 物料信息、基线方法、基线参数 | 冗余到本地 |
| 物料销售历史 | 物料历史干净需求 | 冗余到本地（供基线计算） |
| 月度版本主数据 | 版本号（自然月）、锚定期间、锁定状态 | 本系统定义 |

> 其中 MAPE、bias 作为派生指标，由历史达成率统计滚动更新，其来源为物料销售历史与客户实际要货的比对（该达成率统计在 ERP 中完成，作为派生指标冗余到本地）。
