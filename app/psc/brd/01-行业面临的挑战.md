# 第1章 行业面临的挑战

## 1.1 产销协同的管理目标

汽车零部件企业的产销协同，本质上是在客户服务与运营成本之间寻求平衡。它由四个管理目标构成：

1. **客户服务水平高**——准时交付率（OTD）越高越好；
2. **库存占用少**——库存周转率越高越好；
3. **库存损失小**——库存减值与呆滞越低越好；
4. **生产成本低**——计划变更导致的切线（换型/换线切换）等异常情况越少越好。

这四项目标并不能同时各自最大化，彼此之间存在张力：要保证高准时交付，往往需要抬高安全库存；要压低库存减值，就需要控制长尾品种的批量，而这又会增加切线次数、推高切换成本。产销协同管理的意义，正在于在这些相互牵制的目标之间做出取舍与平衡。

## 1.2 下游市场发生的变化

近年来，下游整车市场发生了几点显著变化：

1. **车型数量急剧增多**：国内整车进入新能源时代后，市场竞争加剧，车型数量急剧增多，直接造成零部件种类急剧放大；
2. **产品生命周期缩短**：整车产品迭代周期加快，零部件产品生命周期随之急剧缩短；
3. **销量波动性激增**：激烈的市场竞争导致整车销售的波动性激增；
4. **传统燃油车件快速衰退**：传统燃油车零部件快速进入衰退周期；
5. **需求信号质量下降**：主机厂自身的需求计划质量下降，需求信号沿供应链逐级传递时被进一步放大（即牛鞭效应），零部件企业拿到的需求信息失真加剧；
6. **成本传导压力加大**：主机厂通过年降、竞价等方式将成本压力向供应链传导，持续挤压零部件企业的利润空间。

## 1.3 由此带来的新挑战

上述市场变化，使零部件企业的产销协同开始面临一些全新的挑战。

### 挑战一：销售预测难度急剧增加

1. 车型数量多、销量波动大，导致零部件需求的波动性急剧增加；
2. 产品生命周期短，导致支撑预测的历史数据往往不足；
3. 产品生命周期短，导致放大安全库存的风险增加——历史波动特征难以代表未来，安全库存的设定依据被削弱；
4. 需求信号在供应链中被逐级放大（牛鞭效应），进一步放大了预测误差。

### 挑战二：库存策略的重要性增加

1. 波动性增加，导致安全库存水位需要提升；
2. 长尾品种数量大幅度增加，显著提高了切线成本，需要通过组批库存来摊薄切换成本；
3. 产品生命周期缩短，导致呆滞与库存减值风险上升。

## 1.4 结论

这些挑战使零部件企业需要以更高的运营成本才能达成以往的客户服务水平；而在主机厂年降持续挤压利润的背景下，这种"以成本换服务"的空间越来越小——这正在成为汽车零部件行业目前面临的共性问题。

并且，规模越小、产品越分散的零部件企业面临的挑战越大。头部零部件企业往往生产高价值、品种相对集中的物料，而中小企业产品品种更加分散、长尾更为严重，因此预测难度更高、切线成本更高、库存更难摊薄，受到的冲击也更大。
