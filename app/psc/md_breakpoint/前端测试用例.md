## §1 本页渲染（防粘滞）

- **VT-ROUTE-01 路由渲染**
  - 页面：`psc:md_breakpoint`
  - 前置造数：无（纯渲染，未造数前列表允许为空态）
  - 操作：登录 admin → `location.hash = '#/md_breakpoint'`（或经菜单进入后 `pg.reload()` 强制刷新回初始态，pitfalls #6）
  - 断言：`main .card` 数 > 0；列表三段式（工具栏 / 表格 `.tbl` / 分页条）存在；**非看板页 `.kpi` 数 == 0**（防挂载粘滞假过，pitfalls #2）

## §2 造数后列表有数据

- **VT-LIST-01 列表含所造断点**
  - 前置造数：C001 / M3 / M4 → `md_breakpoint.create` 造 BP1（返回 `bp1`）
  - 操作：进入 `#/md_breakpoint`（或 `pg.reload()`）
  - 断言：列表含 `bp1`（`.b-link` 精确定位 `has_text`，不假设顺序，pitfalls #17）；该行含 customer_no=C001、old_material_no=M3、new_material_no=M4、switch_time=2026-09-01、ecn_no=ECN-001；表头无「状态」列（后端固定 disabled=0 过滤，无状态筛选维度）
  - 选择器注意：多单号时不取 `.first`，用精确 `bp1` 定位（pitfalls #17）

- **VT-LIST-02 搜索抽样（customer_no 精确匹配）**
  - 前置造数：复用 BP1
  - 操作：客户 autocomplete 选中 C001 → 触发精确过滤（重置回第 1 页）
  - 断言：结果集收敛，含 `bp1`（has_text）；不出现其他客户行
  - 选择器注意：autocomplete 选中后按「编号+名称」双行显示，确认回填 `customer_no` 再断言

- **VT-LIST-03 无匹配空态**
  - 前置造数：复用 BP1（其原物料为 M3）
  - 操作：原物料号 autocomplete 选中 M4（M4 仅作新物料，无「原=M4」的断点）
  - 断言：列表显示空态文案「无符合条件的断点记录」；不抛错（0 报错统计继续有效）
  - 选择器注意：空态文案按 `has_text` 定位，勿与「暂无断点基础数据」混淆（后者为无任何数据时的初始空态）

## §3 模态全字段

- **VT-MODAL-01 详情模态含全部业务字段**
  - 前置造数：复用 BP1
  - 操作：点 `bp1` 的 `.b-link` 开模态 → `wait_modal()` 轮询 `.modal-mask:visible .loadbox` 消失（pitfalls #16）
  - 断言：`.modal-bd.first` 内 KV 含 7 字段标签全集 `bp_id / disabled / customer_no / old_material_no / new_material_no / switch_time / ecn_no`，值含 C001 / M3 / M4 / 2026-09-01 / ECN-001；头带含 `bp_id` 与「正常」停用徽章（disabled=0 → 绿）；「原始数据」折叠区可展开（含 get 返回全量 JSON）；页脚 `.modal-ft` 含【编辑】【停用】【关闭】按钮
  - 选择器注意：一个模态存在多个 `.modal-bd`（详情 + 内嵌编辑区），读 KV 用 `.modal-bd.first`（pitfalls #15）；页脚按钮文案读整个 `.modal-mask:visible`

## §4 表单落库回显 / 校验 / 停用

- **VT-FORM-01 创建成功落库回显**
  - 前置造数：C001 / M3 / M4（已存在）；本用例经表单新建 BP2
  - 操作：点「+ 新建断点」→ 客户 autocomplete 选 C001、原物料号选 M3、新物料号选 M4、切换时间 date 填 2026-10-01、折叠区「更多字段 ▾」展开填 ecn_no=ECN-FORM → 点「保存」
  - 断言：toast「断点创建成功」；模态关闭；列表回第 1 页重载后含新记录（按 ecn_no=ECN-FORM 的 `has_text` 定位，`bp_id` 记为 `bp2`）；该行 6 列齐全（bp_id/customer_no/old_material_no/new_material_no/switch_time/ecn_no）
  - 选择器注意：折叠区「更多字段 ▾」先展开再填 ecn_no；date input 用真实日期格式 YYYY-MM-DD

- **VT-FORM-02 必填校验（空值拦截，不发请求）**
  - 前置造数：C001 / M3 / M4
  - 操作：点「+ 新建断点」→ 不填任何字段直接点「保存」
  - 断言：toast 警告（必填未填提示）；模态不关闭；列表无新增记录（仅前端拦截，未发 create 请求）
  - 选择器注意：断言「无新增记录」以列表行数不变为准，勿依赖网络面板

- **VT-FORM-03 old=new 校验（前端提示 + 后端兜底）**
  - 前置造数：C001 / M3 / M4
  - 操作：点「+ 新建断点」→ 客户选 C001、原物料号选 M3、新物料号选 M3、切换时间填 2026-11-01 → 点「保存」
  - 断言：toast 提示「原物料号与新物料号不能相同」（前端本地提示，最终后端 BR-02 兜底）；不产生新记录
  - 选择器注意：原/新物料号各一个独立 autocomplete 实例，确认两次均选中 M3 再提交

- **VT-FORM-04 组合唯一（后端 FdeError）**
  - 前置造数：BP1（C001+M3+M4+2026-09-01 已存在）
  - 操作：点「+ 新建断点」→ 客户 C001、原 M3、新 M4、切换时间 2026-09-01（与 BP1 完全相同）→ 点「保存」
  - 断言：错误 toast「该断点组合已存在」（后端 BR-01 校验，经 api.js 以 FdeError 呈现）；列表无新增重复行
  - 选择器注意：提交后等待错误 toast 出现，不要因模态被 api.js 处理而误判

- **VT-FORM-05 编辑态回显（bp_id 只读 + ecn_no 变更）**
  - 前置造数：复用 BP2（VT-FORM-01 产物）
  - 操作：定位 `bp2` 行 → 点【编辑】→ 断言 bp_id 输入 `:disabled`（只读展示、不可改，且表单无 disabled 选择器）→ 改 ecn_no=ECN-EDIT → 点「保存」
  - 断言：toast「断点更新成功」；刷新当前页后 `bp2` 行 ecn_no 回显 ECN-EDIT（旧值 ECN-FORM 不再出现）；switch_time 仍为 2026-10-01
  - 选择器注意：bp_id 只读用 `:disabled` 断言；编辑态定位用精确 `bp2`（has_text，pitfalls #17）

- **VT-FORM-06 停用（disable 软失效）**
  - 前置造数：复用 BP2
  - 操作：定位 `bp2` 行 → 点【停用】→ 二次确认弹窗「确认停用该断点？停用后不再参与断点追溯（trace）与列表默认展示」→ 确认
  - 断言：toast「断点已停用」；`bp2` 行从列表消失（后端 disabled=0 过滤）；随后 fetch `/api/apps/md_breakpoint/call/get` `{bp_id: bp2}` 返回 `disabled=1`（软失效，非物理删除）
  - 选择器注意：二次确认弹窗按 `:visible` 限定；已停用记录因列表过滤不可再触达，重复停用幂等拦截「该断点已停用」为后端行为，前端列表不可复现（见 §7）
