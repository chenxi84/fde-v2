# 断点基础数据 前端详设
> 来源：app/psc/_contracts.md（冻结契约）+ app/psc/md_breakpoint/应用详设.md
> 落位：`app/psc/md_breakpoint/view.js` + `view.html`（与 `md_breakpoint.py` 同文件夹，落盘即进启动清单与授权清单，零接线）

## 1. 页面元数据 PAGE_META

| 字段 | 值 | 说明 |
|---|---|---|
| key | `md_breakpoint` | = 应用文件夹名，page_id 为 `psc:md_breakpoint` |
| name | 断点基础数据 | 侧栏菜单名 |
| ic | ⏱ | 图标字 |
| title | 断点基础数据 | 主区页面头标题 |
| crumb | 主数据 · 新旧件断点切换关系 | 副题·要点 |
| order | 60 | 升序即菜单序 |

- 数据来源类型：独立创建（PLM 冗余同步，上游无此数据时本地录入）→ 页面保留「+ 新建」按钮。
- 页面零鉴权：无任何权限判断；菜单按页面授权渲染在 shell，数据范围由后端闸门执法，401 由 api.js 自动跳登录。停用（disable）按 应用详设 §5 为「总部计划」专属，页面不硬编码判断，仅做页面授权清单建议（见 §6.6）。
- 本应用**无状态机**（断点关系为事实记录，`disabled` 仅软失效布尔标记）；`trace` 为跨应用服务（供 sales_forecast 断点追溯），**前端不主动调**。

## 2. 区块构成

### 2.1 列表区（查）—— 三段式：工具栏 / 表格 / 分页条

**用途**：断点关系全量浏览 + 条件检索 + 新建入口。本页为非看板页，不设 KPI 指标带（验收断言无 `.kpi`）。

**过滤控件（与 `md_breakpoint.list(customer_no, old_material_no, new_material_no, page, size)` 可过滤参数一一对应；契约无 keyword / status 参数 → 不设关键字框、不设状态 chips，禁止前端假过滤）**：

| 控件 | 对应参数 | 形态 |
|---|---|---|
| 客户 autocomplete | `customer_no` | 主数据下拉（来源 md_customer，见 §4），选中即精确匹配 |
| 原物料号 autocomplete | `old_material_no` | 主数据下拉（来源 md_material，见 §4），选中即精确匹配 |
| 新物料号 autocomplete | `new_material_no` | 主数据下拉（来源 md_material，见 §4），选中即精确匹配 |
| 分页条 | `page` / `size` | `pageable()`（后端参数名为 `size`） |

**工具栏**：「查询」「+ 新建断点」（打开 2.3 创建模态）。

**表格列（`.tbl.tight` + `.scroll-x`；全部为详情字段子集）**：

| 列 | 字段 | 渲染 |
|---|---|---|
| 断点标识 | `bp_id` | 编号正文（**默认隐藏**，`PAGE_META.col_default_hidden`，可经列设置开启） |
| 客户 | `customer_no` | 编号正文 + customerMap 命中时附名称小字 |
| 原物料号 | `old_material_no` | 编号正文 + materialMap 命中时附名称小字 |
| 新物料号 | `new_material_no` | `.b-link`，点击打开详情模态 + materialMap 名称小字 |
| 切换时间 | `switch_time` | 文本（日期），空值 `dash()` |
| 变更单号 | `ecn_no` | 文本，空值 `dash()` |
| 操作 | — | 每行【编辑】【停用】（无状态机，行恒为未停用，见下） |

- 列表由后端固定 `disabled = 0` 过滤（默认不含已停用记录，无状态筛选维度），故**不设状态列**，所有行均可编辑 / 停用。
- **详情入口**：`bp_id` 为内部自增主键、业务价值低，默认隐藏；详情改由可见的「新物料号」`.b-link` 打开。
- **交互**：任一过滤变化 → 重置回第 1 页重载；停用成功刷新当前页（停用行从列表消失）；空结果显示空态文案。

### 2.2 详情模态（查全）—— 三段式：墨青头带 / KV 分组体 / 操作页脚

**用途**：点 `bp_id` 弹出，展示 `md_breakpoint.get` 返回的**全部**字段（含 `disabled`，共 7 字段）。

| 分组（`.sec`） | 字段 | 渲染 |
|---|---|---|
| 头带 | `bp_id` + 停用徽章 | 墨青头带；`disabled` 徽章（正常=绿 / 已停用=灰） |
| 基本信息 | `bp_id` / `disabled` | `.kv`；`bp_id` 注明「系统自增主键 · 全局唯一」 |
| 断点关系 | `customer_no` / `old_material_no` / `new_material_no` | `.kv`；注明「引用 md_customer / md_material · 创建/变更时校验物料存在」，customerMap / materialMap 命中附名称 |
| 切换信息 | `switch_time` / `ecn_no` | `.kv`；空值 `dash()` |
| 原始数据 | get 返回全量 JSON | 底部折叠（默认收起） |

- 本页**无 `*_json` 快照字段**（无 `tryParse()`）；`switch_time` 为日期文本（非时间戳，不 `fmtTime()`）。
- **页脚 `.modal-ft`**：【编辑】（打开编辑表单）+ 【停用】+ 【关闭】。

### 2.3 创建 / 编辑表单（增/改）—— 模态表单

**用途**：覆盖 `md_breakpoint.create` / `md_breakpoint.update` 接受的业务参数。

| 字段 | 控件 | 必填 | create 可见 | update 可见 | 约束来源 |
|---|---|---|---|---|---|
| `bp_id` | 只读展示 | — | 否 | 是（只读） | 主键，系统生成，创建后不可变 |
| `customer_no` | 客户 autocomplete（见 §4） | ★ 必填 | 是 | 是 | BR-04；引用 md_customer |
| `old_material_no` | 物料 autocomplete（见 §4） | ★ 必填 | 是 | 是 | BR-05；后端跨应用调 md_material.get 校验 |
| `new_material_no` | 物料 autocomplete（见 §4） | ★ 必填 | 是 | 是 | BR-05；不得等于 old_material_no（BR-02） |
| `switch_time` | date input | ★ 必填 | 是 | 是 | BR-03（切换时间不能为空） |
| `ecn_no` | input，maxlength=50 | 选填 | 是 | 是 | 变更单号（ECN），最大 50 字符 |

- **create 模式**：必填 4 项（customer_no / old_material_no / new_material_no / switch_time）；`ecn_no` 选填；`bp_id` / `disabled` 由后端生成（`disabled` 默认 0），不进表单。
- **update 模式**：`bp_id` 回填展示但不可修改（定位键）；5 个业务字段均可修改，按 应用详设 §4.3.1.3，`switch_time` / `ecn_no` 为**主要编辑目标**（修正切换时间 / 变更单号），`customer_no` / `old_material_no` / `new_material_no` 作为事实记录一般不改，但契约 update 接受（涉及修改时后端重新校验物料引用 + 组合唯一）。
- 布局：必填先行——客户 autocomplete、原物料号 autocomplete、新物料号 autocomplete、切换时间 date；折叠区「更多字段 ▾」：`ecn_no`；底部右对齐「取消」「保存」。
- 前端仅做必填校验（空值 → toast 警告、不提交）+ 可选前端提示 `old_material_no === new_material_no`（「原物料号与新物料号不能相同」，最终由后端 BR-02 校验兜底）；物料引用 / 组合唯一（BR-01）由后端校验，`FdeError` 经 api.js 以错误 toast 呈现。
- 提交成功：toast 成功消息 → 关闭模态 → 重置过滤重载列表（create）/ 刷新当前页（update）。

### 2.4 停用操作（disable）

**用途**：未停用行显示【停用】按钮，调 `md_breakpoint.disable`（软失效，事实记录不可物理删除）。

- 行内操作列 + 详情模态页脚：均显示【停用】（无状态机，行恒未停用）。
- 点击 → 弹出确认提示「确认停用该断点？停用后不再参与断点追溯（trace）与列表默认展示」。
- 确认后调用 `svc("md_breakpoint","disable")` `{bp_id}`。
- 成功后 toast「断点已停用」→ 刷新列表（该行因 `disabled=1` 从列表消失）+ 若模态打开则关闭。
- 已停用记录再停用 → 后端 `FdeError`「该断点已停用」（幂等拦截），前端 toast 呈现。

## 3. svc 字面量清单（授权派生依据——必须字面量 svc("应用","服务")）

| 区块 | 调用（应用.服务） | 参数 | quiet | 说明 |
|---|---|---|---|---|
| 列表区 | `svc("md_breakpoint","list")` | `{customer_no, old_material_no, new_material_no, page, size}` | — | 分页查询，默认不含已停用 |
| 客户下拉 | `svc("md_customer","list")` | `{page:1, size:200}` | true | 客户 autocomplete 数据源，quiet 探测；**跨应用调用，字面量产生 psc:md_breakpoint → md_customer.list 派生边** |
| 物料下拉 | `svc("md_material","list")` | `{page:1, size:500}` | true | 原/新物料 autocomplete 数据源，quiet 探测；**跨应用调用，字面量产生 psc:md_breakpoint → md_material.list 派生边** |
| 详情模态 | `svc("md_breakpoint","get")` | `{bp_id}` | — | 全字段详情（含已停用） |
| 创建表单 | `svc("md_breakpoint","create")` | `{customer_no, old_material_no, new_material_no, switch_time, ecn_no}` | — | 跨应用物料存在性校验 + 组合唯一校验 |
| 编辑表单 | `svc("md_breakpoint","update")` | `{bp_id, customer_no, old_material_no, new_material_no, switch_time, ecn_no}` | — | 更新（重新校验物料引用 / 原≠新 / 组合唯一） |
| 停用 | `svc("md_breakpoint","disable")` | `{bp_id}` | — | 软失效，不再参与 trace 与列表展示 |

> 以上 **7 处**必须在 view.js 中以字面量逐项书写（可包在闭包里），**勿用变量拼名**——这是页面授权隐式放行派生扫描的唯一来源。
> `trace`（跨应用，供 sales_forecast.calc_baseline 调用）**不在清单内**：前端不主动调用，亦不在 view.js 书写。

## 4. 数据来源与下拉

**客户 autocomplete（过滤条 + 创建/编辑表单共用一份 customerOptions / customerMap）**：
- 页面初始化一次性 `svc("md_customer","list")` `{page:1, size:200}`，`quiet:true` 探测：失败不喷 toast；零值兜底 → 下拉显示「暂无可选客户」禁用项。
- 由返回项构建 `customerOptions` **扁平数组**（字段 `customer_no, customer_name`），autocomplete 显示「customer_no + customer_name」双行，选中后表单/过滤存 `customer_no`；`customerMap = {customer_no: customer_name}` 供列表「客户」列与详情模态名称回显，未命中则原样展示 customer_no。

**物料 autocomplete（原/新物料号共用一份 materialOptions / materialMap）**：
- 页面初始化一次性 `svc("md_material","list")` `{page:1, size:500}`，`quiet:true` 探测：失败不喷 toast；零值兜底 → 下拉显示「暂无可选物料」禁用项。
- 由返回项构建 `materialOptions` **扁平数组**（字段 `material_no, material_name`），autocomplete 显示「material_no + material_name」双行，选中后回填 `material_no`；`materialMap = {material_no: material_name}` 供列表「原/新物料号」列与详情模态名称回显。
- `old_material_no` 与 `new_material_no` 各一个独立 autocomplete 实例，共用同一份 `materialOptions`。

**切换时间 / 变更单号**：`switch_time` 为日期（date input，无下拉）；`ecn_no` 为自由文本（无下拉）；均来自本地录入 / PLM 同步。

**本页无枚举下拉**：`disabled` 为布尔标记（非状态机），不进表单、不下拉，仅详情/头带展示。

**契约 payload → 区块字段映射**：

| 契约 | 载荷字段 | 映射区块 |
|---|---|---|
| `md_breakpoint.list` 返回项 | `bp_id, customer_no, old_material_no, new_material_no, switch_time, ecn_no, disabled` | 2.1 列表列（disabled 恒 0，不单独成列） |
| `md_breakpoint.get` 返回 | 同上（全量，含 disabled） | 2.2 详情模态 kv + 原始数据 |
| `md_breakpoint.create` 入参 | `customer_no, old_material_no, new_material_no, switch_time, ecn_no` | 2.3 创建表单 |
| `md_breakpoint.update` 入参 | `bp_id, customer_no, old_material_no, new_material_no, switch_time, ecn_no` | 2.3 编辑表单（bp_id 只读） |
| `md_breakpoint.disable` 入参 | `bp_id` | 2.4 停用 |
| `md_customer.list` 项 | `customer_no, customer_name` | 客户 autocomplete 选项 |
| `md_material.list` 项 | `material_no, material_name` | 物料 autocomplete 选项 |

> 快照/系统字段说明：`bp_id`（自增主键）与 `disabled`（软失效标记）由后端生成，仅详情展示，不进表单；本应用无审计字段（created_at/updated_at）暴露。

## 5. 交互要点

1. **加载**：首载正常拉取 `md_breakpoint.list`（非看板页，失败走 api.js 统一通道）+ quiet 拉取 `md_customer.list` / `md_material.list` 构建主数据下拉（失败静默降级为空数组，零值兜底）。
2. **过滤**：客户 / 原物料 / 新物料三个 autocomplete 选中即查（精确匹配，重置 `page=1`），「查询」按钮触发重载；翻页仅改 `page/size`，不清过滤条件；无状态 chips、无关键字框（契约无对应参数）。
3. **主数据 autocomplete**：客户一个、原/新物料各一个（共用 materialOptions）；`@click.stop` 展开 + `@input` 实时过滤（同时匹配代号与名称）+ `@click.away` 关闭；选中后回填编码；列表项「代号 + 名称」双行。
4. **无状态机 / 停用即软失效**：所有行与详情页脚恒显【编辑】【停用】（行恒未停用）；停用成功 → 行从列表消失（后端 `disabled=0` 过滤）。编辑表单不暴露 `disabled`，停用仅经 disable 操作。
5. **微交互**：表格行 hover 高亮；`bp_id` `.b-link` hover 下划线；「保存」按钮提交期 loading 防重复点击；【停用】点击后二次确认弹窗。
6. **成功流**：create 成功 → 关闭模态并清空表单 → toast「断点创建成功」→ 列表回第 1 页重载；update 成功 → toast「断点更新成功」→ 刷新当前页；disable 成功 → toast「断点已停用」→ 刷新当前页。
7. **错误流**：重复组合「该断点组合已存在」、old=new「原物料号与新物料号不能相同」、switch_time 空「切换时间不能为空」、物料不存在「物料不存在」、重复停用「该断点已停用」等后端 `FdeError` → toast 错误信息；old=new 前端可先本地提示（后端兜底）。
8. **空态**：无任何断点时「暂无断点基础数据 —— 点『新建断点』创建」；过滤无命中时「无符合条件的断点记录」。
9. **折叠「更多字段 ▾」**：仅 `ecn_no` 一个选填字段。
10. **展示工具**：`dash()`（switch_time / ecn_no 空值）、`hue()`（disabled 停用徽章）；无金额字段无需 `fmt()`、无时间戳字段无需 `fmtTime()`、无 `*_json` 字段无需 `tryParse()`。

## 6. 验收关注点（供第⑧步）

1. **路由渲染**：`#/md_breakpoint` 挂载出列表三段式（工具栏 + 表格 + 分页条），**断言无 `.kpi`**（非看板页防挂载粘滞假过）；菜单「⏱ 断点基础数据」按 order=60 定位。
2. **造数后列表有数据**：先造 customer（CUS001）+ material（OLD001 / NEW001）→ 经 `md_breakpoint.create` 造断点 → 列表 1 行，bp_id / customer_no / old_material_no / new_material_no / switch_time / ecn_no 列齐全，无状态列。
3. **过滤一一对应**：customer_no=CUS001 仅该客户行；old_material_no=OLD001；new_material_no=NEW001；三条件组合（AND）；无匹配显示空态且不抛错。
4. **模态全字段**：点 bp_id 开模态，断言 7 字段（bp_id / customer_no / old_material_no / new_material_no / switch_time / ecn_no / disabled）全部可见 + 「原始数据」可展开。
5. **表单落库**：create 表单填必填 4 项（customer_no / old_material_no / new_material_no / switch_time）+「更多字段」ecn_no → 提交 → 列表出现新记录；空必填字段提交 → toast 警告且不发请求；重复组合（US-01-AC2）→ 后端 toast「该断点组合已存在」；old=new（US-01-AC3）→ 「原物料号与新物料号不能相同」；物料不存在（US-01-AC4）→ 「物料不存在」。
6. **写操作真实回显**：update 改 ecn_no 后刷新列表值已变更（US-03-AC1）；disable 确认后该行从列表消失，且 get(bp_id) 的 disabled=1（US-04-AC1）；已停用再停用 → 后端 toast「该断点已停用」。
7. **编辑不暴露 bp_id / disabled**：编辑表单 bp_id 只读、无 disabled 选择器，确保停用仅经 disable 操作。
8. **主数据 autocomplete**：客户 / 原物料 / 新物料下拉含已建主数据选项，选中后正确回填编码。
9. **trace 不出现**：页面源码不含 `svc("md_breakpoint","trace")` 字面量（跨应用服务，前端不调）。
10. **受限角色页面授权清单建议**：停用（disable）建议仅授「总部计划」，一线销售不授（应用详设 §5）；页面自身不做任何鉴权判断。
11. **干净控制台**：全程 0 console error / 0 pageerror / 0 HTTP>=400（受限会话 403 属预期执法单独豁免）。
