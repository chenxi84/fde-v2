# sales_history · 前端详设（历史台账）

## 1. PAGE_META
key=sales_history / name=历史台账 / ic=📒 / order=170（尾插，保持组级菜单断言 `names[:16]` 不受影响）。

## 2. 区块
- **列表三段式**：过滤区（物料号/客户号 输入 + 期间 `input[type=month]` + 查询/重置/批量导入）/ 表格（期间/物料号(+名称)/客户号(+名称)/数量/原始预测）/ 分页条。
- **无新建按钮、无操作列**（数据源=导入/ERP，参照 attainment「自动参考创建」）。
- 名称回显：quiet 加载 `md_material.list`/`md_customer.list` 建 materialMap/customerMap，命中附小字。

## 3. 导入模态
- 粘贴 CSV/TSV 或选文件（表头自动跳过）；模板 `material_no,customer_no,period,qty`。
- `svc("sales_history","import_batch",{rows})` → toast 成功/失败 + 结果摘要（共/成功/失败 + 错误行表）→ 关闭刷新列表。

## 4. 展示工具
`dash`/`fmt` 须挂组件作用域（`fmt` 非 window 全局）。空态文案：「暂无历史台账数据 —— 由 ERP 经 import_batch / upsert 冗余回写」。

## 5. svc 字面量（授权派生依据）
`svc("sales_history","list")` / `svc("sales_history","import_batch")` / quiet `md_material.list` / `md_customer.list`。
