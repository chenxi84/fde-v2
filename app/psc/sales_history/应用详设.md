## 1. 聚合根
- 类 `SalesHistory`，应用 `sales_history`，库 `sales_history.db`。
- 取代架构决策 D1 的「物料销售历史不建聚合、纯 stub」：现落地为本地冗余聚合（ERP 经 import_batch/upsert 回写）。

## 2. 数据
表 `sales_history`：
| 字段 | 类型 | 说明 |
|---|---|---|
| material_no | TEXT | 物料号（PK 之一） |
| customer_no | TEXT | 客户编码（PK 之一） |
| period | TEXT | 期间 YYYY-MM（PK 之一） |
| qty | REAL | 干净需求（≥0） |
| forecast_qty | REAL | 对应期间 N+1 原始预测（可空）；upsert 自动拉取 / attach_forecast 推送 / sync_forecast 回填 |

PK `(material_no, customer_no, period)`；索引 period、customer_no。平台自动追加审计列。

> ⚠ `forecast_qty` 有**三条写入路径**（见 BR-08/09/10），分属三条不同的调用链 ——
> 这是本应用最容易被漏掉的地方：改其中一条不会影响另外两条。

## 3. 业务场景

### 3.1 业务流程描述

1. **入库**：ERP / 外部接口经 `import_batch`（批量，逐行校验不阻断）或 `upsert`（单条，幂等覆盖）写入 `qty`；
   外部接口未配置时 `sync_external_history` **报错**而不是静默导入 0 行。
2. **期间对齐**：以 `period`（`YYYY-MM`）为键而非位置 —— 断点链跨物料按期求和，消费端看到的是连续月份序列。
3. **出库（投影）**：三个读服务供消费方 —— `history_sequence`（纯数值序列）、
   `history_series`（带期间标签，供拟合回测横轴）、`purchasing_customers` / `main_customer`（客户维度）。

### 3.2 业务规则

> **三要素（`依赖输入` / `输出` / `生效点`）** —— 格式与用途见 `design-plus/应用设计.md`
> 的「三要素与载体格式无关」；本文件同本组其余详设，用**编号小节载体**。

#### 3.2.1 `BR-01` 三键与取值校验
- **规则描述**: `material_no` / `customer_no` 非空；`period` 须 `YYYY-MM`；`qty` 为数值且 ≥ 0。
- **适用场景**: `upsert` / `import_batch`（单行失败入 `errors`，不阻断其余行）。
- **示例**: `period=2026-13` 或 `qty=-5` → 该行被拒。
- **依赖输入**: `material_no` / `customer_no` / `period` / `qty`（**入参**；外部同步经 `_map_external_row` 映射产生）
- **输出**: 无（拒绝：抛 `FdeError`；`import_batch` 则把该行记进返回的 `errors`）
- **生效点**: `sales_history.upsert` / `sales_history.import_batch` → `_require` / `_period` / `_qty`

#### 3.2.2 `BR-02` upsert 幂等：同主键覆盖 qty
- **规则描述**: 同 `(物料, 客户, 期间)` 存在则覆盖 `qty`（与 `forecast_qty`），不存在则插入。
- **适用场景**: ERP 重导 / 补数。
- **示例**: 同键写两次 qty=1000、500 → 库里只剩 500。
- **依赖输入**: 主键三键（**入参**）；本表既有行（**本表**：`upsert` 产生）
- **输出**: `sales_history.qty`
- **生效点**: `sales_history.upsert`

#### 3.2.3 `BR-03` import_batch 逐行校验、失败行不阻断
- **规则描述**: 逐行校验，合法行入库、失败行返回错误明细，**不**因单行失败中断整批。
- **适用场景**: ERP 批量回写。
- **示例**: 4 行里 1 行 `qty` 为负 → `success=3, fail=1`。
- **依赖输入**: 行列表（**入参**）；主数据是否存在**不在此校验**（本应用是台账，不做物料/客户引用校验）
- **输出**: `sales_history.qty`（成功行）+ 返回 `success` / `fail` / `errors`
- **生效点**: `sales_history.import_batch` → `sales_history.upsert`

#### 3.2.4 `BR-04` history_sequence：按期聚合、缺口补 0
- **规则描述**: `material_nos` 支持单物料（`str`）或断点链（`list` 旧→新）；链内各物料按 `period`
  `SUM`；期间缺口补 0（保证消费方期间连续）；`limit` 取末尾 N 期；返回**纯数值列表**。
- **适用场景**: 预测基线 / 库存水位取历史。
- **示例**: M3=[100,120,110]、M4=[40,·,80] → 链序列 `[100,120,150,0,80]`。
- **依赖输入**: 本表 `qty`（**本表**：`upsert` / `import_batch` 产生）；断点链（**上游**：`md_material.history_chain` 产生）
- **输出**: 中间量（数值列表，**不落库**）
- **生效点**: `sales_history.history_sequence`；消费方 `sales_forecast.calc_baseline`、`inventory_strategy.calc` 的 `_load_sales_history`

#### 3.2.5 `BR-05` history_series：同口径 + 期间标签
- **规则描述**: 与 `history_sequence` 同口径，但返回 `[{period, qty}]`（含期间标签）。
- **为什么单列一条**: `history_sequence` 只给数量、**丢期间** —— 拟合回测的横轴需要期间语义。
- **示例**: 同上 → `[{2026-01,100},{2026-02,120},{2026-03,150},{2026-04,0},{2026-05,80}]`。
- **依赖输入**: 本表 `qty`（**本表**）；断点链（**上游**：`md_material.history_chain` 产生）
- **输出**: 中间量（带期间的序列，**不落库**）
- **生效点**: `sales_history.history_series`；消费方 `strategy_fitting` 的 `_load_sales_history`

#### 3.2.6 `BR-06` purchasing_customers：历史采购客户集
- **规则描述**: 去重升序，可按物料收窄。
- **适用场景**: 销售预测清单的客户维度（按物料收窄，避免 300 客户 × 3 月铺满）。
- **示例**: `purchasing_customers(M1)` → `["C001"]`。
- **依赖输入**: 本表 `customer_no`（**本表**：`upsert` / `import_batch` 产生）
- **输出**: 中间量（客户号列表，**不落库**）
- **生效点**: `sales_history.purchasing_customers`；消费方 `sales_forecast.open_version`

#### 3.2.7 `BR-07` main_customer：出货量最大的客户
- **规则描述**: 按 `material_no` 分组对 `qty` 求和，取**出货量最大**的客户；无历史返回 `None`。
- **为什么有它**: 库存策略的对冲判定（`BR-11/12`）右边是**客户**给的缓冲（线边库存天数 + 调拨提前期），
  批算水位时逐物料取它，比让调用方自己传客户现实。
- **示例**: 同物料两客户 100 / 10 → 返回量大者。
- **依赖输入**: 本表 `qty`（**本表**）
- **输出**: 中间量（单个客户号或 `None`，**不落库**）
- **生效点**: `sales_history.main_customer`；消费方 `inventory_strategy.calc` / `calc_batch`

#### 3.2.8 `BR-08` attach_forecast：仅当实际行已存在时推送预测
- **规则描述**: 把 N+1 原始预测写入对应台账行的 `forecast_qty`；**该行不存在则跳过**（返回 `attached=false`），
  不新建行 —— 实际值到了会在 `upsert` 时自动拉取兜底（BR-10）。
- **适用场景**: 销售预测填客户数（`fill_customer`）时顺带推送。
- **示例**: 台账里没有 2026-11 的实际行 → `attached=False`，不留半行。
- **依赖输入**: 预测值（**上游**：`sales_forecast.fill_customer` 产生）；本表既有行（**本表**）
- **输出**: `sales_history.forecast_qty`
- **生效点**: `sales_history.attach_forecast` ← 被 `sales_forecast.fill_customer` 调用（跨应用）

#### 3.2.9 `BR-09` sync_forecast：按期对齐批量回填
- **规则描述**: 按 `(物料, 客户)` 拉其 N+1 原始预测投影，按期对齐，回填存量台账行的 `forecast_qty`。
- **适用场景**: 补历史（达成率口径 A 的取数前置）。
- **示例**: 18 期台账里 3 期有对应预测 → `updated=3`。
- **依赖输入**: 各 `(物料,客户)` 的预测投影（**上游**：`sales_forecast.customer_forecast_history` 产生）
- **输出**: `sales_history.forecast_qty`（存量行的批量回填）
- **生效点**: `sales_history.sync_forecast` → `sales_forecast.customer_forecast_history`

#### 3.2.10 `BR-10` upsert 时自动拉取预测
- **规则描述**: `upsert` 写入实际值的同时，拉取该 `(物料, 客户, 期间)` 的 N+1 原始预测一并落库
  （拉不到 / 调用失败即写 `None`，不阻断入库）。
- **为什么**: 实际行先到时预测可能还没推送（BR-08 会跳过），这条是**兜底**。
- **示例**: 先 `import_batch` 实际值、后填预测 → 下一条同键 upsert 会把 `forecast_qty` 补上。
- **依赖输入**: 该期间的原始预测（**上游**：`sales_forecast.customer_forecast_history` 产生）
- **输出**: `sales_history.forecast_qty`
- **生效点**: `sales_history.upsert` → `_pull_forecast` → `sales_forecast.customer_forecast_history`

#### 3.2.11 `BR-11` 外部同步未配置即报错（fail-closed）
- **规则描述**: `sync_external_history` 在端点未配置 / 未填 URL 时**报错**并说明去哪配；
  启用 Mock 时返回 `status=mock` 跳过真实调用。**不得**静默导入 0 行。
- **适用场景**: API 定时任务（ERP → 台账）。
- **示例**: 未配置端点 → 抛「外部历史台账接口未配置（请先到 /integration 配置目标 URL）」。
- **依赖输入**: 集成端点配置（**外部适配器**：`integration.get_endpoint("psc/sales_history", "_http_fetch_sales_history")`）
- **输出**: 无（拒绝：抛 `FdeError`；Mock 启用时返回 `status=mock`）
- **生效点**: `sales_history.sync_external_history` → `_http_fetch_sales_history`（外部适配器）

## 4. 设计决策
- 期间对齐以 `YYYY-MM` 为键（非位置），断点链跨物料按期求和——消费端窗口数学看到的是连续月份序列。
- 无 create/delete/update：数据源=ERP/导入，重导/upsert 覆盖。
- 消费端保留空兜底：台账为空或调用失败 → `[]`，与 V1 行为一致（零回归）。

## 5. 消费端改造（仅适配器体）
- `sales_forecast._load_sales_history`：物料/链均空→purchasing_customers；否则→history_sequence；`except FdeError→[]`。
- `inventory_strategy._load_sales_history`：history_sequence(limit=months)；`except→[]`。
- `strategy_fitting._load_sales_history`：history_series(limit=periods)，返回 `[{period, qty}]` 供回测横轴；`except→[]`。
