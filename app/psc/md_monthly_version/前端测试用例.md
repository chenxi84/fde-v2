## §4 表单落库回显 + 状态机（发布/冻结）

### 4.1 状态机流转（publish / freeze，按状态 x-show）

- **VT-STATE-01 草稿 → 发布（锁定）**
  - 页面：psc:md_monthly_version
  - 前置造数：V202608 为草稿（活跃）
  - 操作：在列表 202608 行内点【发布】（x-show=lock_status==草稿）；成功后点该行 `.b-link` 开模态
  - 断言：toast 含「版本发布成功，预测已锁定」；该行 lock_status 徽章变「发布（锁定）」；行内【发布】消失、【冻结】出现；模态页脚【冻结】可见、【发布】不可见（同一 x-show 判定）
  - 选择器注意：行内/页脚按钮 `button:visible` 限定（pitfalls #14）

- **VT-STATE-02 发布（锁定） → 冻结**
  - 页面：psc:md_monthly_version
  - 前置造数：VT-STATE-01 完成后 V202608 为「发布（锁定）」
  - 操作：在列表 202608 行内点【冻结】（x-show=lock_status==发布（锁定））
  - 断言：toast 含「版本冻结成功」；该行 lock_status 徽章变「冻结」；行内无任何操作按钮（终态）
  - 选择器注意：`:visible` 限定

- **VT-STATE-03 冻结终态行内无按钮**
  - 页面：psc:md_monthly_version
  - 前置造数：VT-STATE-02 完成后 V202608 已冻结（此时 202607/202608 均冻结，全库无活跃版本）
  - 操作：检查列表 202608 行与 202607 行
  - 断言：两冻结行操作列均无【发布】/【冻结】按钮（冻结不可逆）
  - 选择器注意：`:visible` 限定（隐藏按钮仍在 DOM，须限定可见）

### 4.2 创建表单落库与校验

- **VT-FORM-01 空必填被拒**
  - 页面：psc:md_monthly_version
  - 前置造数：无（纯前端校验，不发请求）
  - 操作：点「+ 新建版本」→ version_no 留空 → 提交
  - 断言：toast 警告必填；不发 create 请求；模态保持打开
  - 选择器注意：toast 选择器

- **VT-FORM-02 重复版本号被拒**
  - 页面：psc:md_monthly_version
  - 前置造数：全库无活跃版本（202607/202608 已冻结），已存在 202607
  - 操作：点「+ 新建版本」→ 填 version_no=202607（已存在）→ 提交
  - 断言：后端 FdeError toast 含「该版本号已存在」；列表不新增行
  - 选择器注意：错误 toast 选择器

- **VT-FORM-03 创建落库**
  - 页面：psc:md_monthly_version
  - 前置造数：全库无活跃版本（满足 BR-06）
  - 操作：点「+ 新建版本」→ 填 version_no=202609、anchor_period=2026-09、opening_date=2026-09-01 → 提交
  - 断言：toast 含「月度版本创建成功」；模态关闭；列表刷新后含 202609 行且 lock_status=草稿（US-01-AC1）
  - 选择器注意：`:visible` 限定表单控件

- **VT-FORM-04 活跃版本冲突**
  - 页面：psc:md_monthly_version
  - 前置造数：V202609 已创建（草稿·活跃）
  - 操作：点「+ 新建版本」→ 填 version_no=202610、anchor_period、opening_date → 提交
  - 断言：后端 FdeError toast 含「已存在活跃版本」；列表不新增 202610 行（US-01-AC4）
  - 选择器注意：错误 toast 选择器
