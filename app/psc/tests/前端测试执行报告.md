### 3.2 脚本/用例翻译错（case_calibration，已修脚本）

| # | 脚本 | 问题 | 修复 |
|---|------|------|------|
| S1 | md_customer/md_material/md_project | `input[placeholder]` strict mode 撞车（过滤框+隐藏表单框 2 元素） | 加 `.first` |
| S2 | sales_forecast | step 文案含 Unicode `−`（GBK 控制台报错） | `−`→`-` |
| S3 | md_breakpoint/demand 等 | 造数后重新设同 hash 不触发 SPA 重建（pitfalls #6） | 造数后 `page.reload()` |
| S4 | md_material | base_params 是 textarea，fill_labeled 定位错 input | `tags=("textarea",)` |
| S5 | 组级/demand/demand_pool/inventory_projection/master_plan | 漏预置 `password_changed=1`（登录被强制改密页挡住） | 补 sqlite 更新（admin + limited_psc） |
| S6 | inventory_projection/组级 | SEED 用短名路径 `/api/apps/<app>`（psc 与 forecast 同名应用歧义 404） | 改组限定 `/api/apps/psc/<app>` |
| S7 | demand | md_material.create 缺库存参数 → calc 报「满足率目标不能为空」 | 补 service_level/batch_window/prod_days/logistics_days |
| S8 | demand | chips 过滤断言时机过早（列表异步刷新） | 加 wait_for_timeout |
| S9 | strategy_fitting | autocomplete 用 fill/press（触发 @input 清空） | 改 click-only（照 md_project_part PASS 范式） |
