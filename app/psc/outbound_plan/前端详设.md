> 数据来源类型：手工参考创建 —— 提供新建 / 编辑 / 删除入口

## 2. 区块构成

### 2.1 列表区（查）—— 三段式：过滤条 / 表格 / 分页条
- **过滤条**：物料 autocomplete（md_material.list quiet，代号+名称双匹配）+ 客户下拉（md_customer.list quiet）+ 状态 chips（全部 / 待出库 / 已关闭）+ 查询 / 重置 + 【+ 新建出库计划】。过滤参数与 `list(material_no, customer_no, status, page, size)` 一一对应；契约无 keyword，不设关键字搜索框。
- **表格列**：计划号（b-link → 详情）/ 客户（编码+名称小字）/ 物料（编码+名称小字）/ 数量（右对齐 mono）/ 计划出库日期 / 实际出库单号（空显示 —）/ 状态徽章（待出库=green，已关闭=slate，本页局部 STATUS_HUES）/ 操作（编辑；仅待出库显示删除）。
- **分页条**：共 N 条 + 上一页 / 页码 / 下一页。
- 到期自动关闭由后端在 list 读取时惰性结算，前端无定时器、无二次过滤。

### 2.2 详情模态（查全）—— 三段式：墨青头带 + 状态徽章 / KV 体 / 页脚
- 头带：`出库计划 · {plan_no}` + 状态徽章。
- KV 分组「计划信息」：计划号（注明系统生成主键）/ 客户（编码+名称）/ 物料（编码+名称）/ 数量 / 计划出库日期（注明到期自动关闭、延期恢复规则）/ 实际出库单号（注明执行后回填）。
- 原始数据折叠（get 全量 JSON）。
- 页脚：【编辑】（关详情开表单）/【关闭】。

### 2.3 新建 / 编辑表单模态（create / update 共用）
- 字段：客户下拉（必填）/ 物料 autocomplete（必填）/ 数量 number（必填 >0）/ 计划出库日期 date（必填，默认今日；注明早于今日直接记已关闭）/ 实际出库单号（可选）。
- 提交前前端轻量校验（客户/物料/日期必填、数量 >0）；主数据不存在、日期非法等由后端 FdeError 经 api.js 统一 toast，表单保持打开便于重试。
- 编辑已关闭计划即「延期」：日期改为今日及以后，保存后状态自动恢复待出库（后端重算，前端 toast 提示规则）。
- 删除：行内【删除】（仅待出库显示），confirm 二次确认，已关闭由后端拦截。

## 3. svc 字面量清单（授权派生依据——必须字面量 svc("应用","服务")）

| 调用 | 用途 |
|---|---|
| `svc("outbound_plan","list")` | 列表（过滤+分页） |
| `svc("outbound_plan","get")` | 详情查全 |
| `svc("outbound_plan","create")` | 新建 |
| `svc("outbound_plan","update")` | 编辑 / 延期 / 回填实际出库单号 |
| `svc("outbound_plan","delete")` | 删除（仅待出库） |
| `svc("md_material","list")` | 物料 autocomplete 数据源（quiet） |
| `svc("md_customer","list")` | 客户下拉数据源（quiet） |

## 4. 数据来源与下拉
- 物料：`md_material.list(page=1,size=200)` quiet → 扁平 `matOptions` + `matMap`（禁止嵌套对象存储）；过滤条与表单共用一份数据源，`acShow` 标记当前展开位置（filter / form）。
- 客户：`md_customer.list(page=1,size=200)` quiet → `custOptions` + `custMap`；失败零值兜底（下拉仅「全部 / 请选择客户」）。

## 5. 交互要点
- list 实例须在 tpl 赋值前同步建好（items:[]），避免模板求值 list.* 为 null。
- 本地日期用 `localToday()`（不用 toISOString 的 UTC，避免时差跨日）。
- 状态徽章为本页局部映射（不动公共 HUES）。
- 新建成功回第 1 页；编辑/删除成功停留当前页。

## 6. 验收关注点（供第⑧步前端测试用例）
1. 路由渲染：#/outbound_plan 出卡片，非看板页 .kpi==0 防粘滞。
2. 造数后列表回显：计划号/客户/物料/数量/日期/状态徽章。
3. 新建弹窗字段齐全 + 提交 toast + 落库回显。
4. 编辑（延期）保存后状态按日期重算回显。
5. 删除仅待出库可见；confirm 后消失。
6. 详情模态全字段 + 原始数据折叠。
7. 全程 0 console error / 0 pageerror / 0 HTTP>=400。
