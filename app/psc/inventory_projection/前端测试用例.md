# 应用组 `psc` · 库存推移表 前端测试用例（库存推移表）

> 产出技能：前端测试用例生成（第⑧步，规格 design-plus/前端测试.md）。
> 页面：`psc:inventory_projection`（本文件全部用例针对本页）。输入：本应用前端详设 + app/psc/_contracts.md。
> 执行：第⑨步翻译成 app/psc/tests/verify_view_psc_inventory_projection.py（自包含：隔离→起平台→登录→造数→断言→0 报错）。

## §0 测试数据字典（冻结 · 本脚本自足）

| 别名 | 类型 | 造数服务 | 关键参数 |
|---|---|---|---|
| M1 | 物料主数据（跨应用前置） | md_material.create | material_no="M1", material_name="测试物料A", status="正常" |
| IP-M1 | 库存推移表记录（本页主数据 · 自动参考创建） | inventory_projection.refresh | material_no="M1", biz_date="2026-08-15", opening_stock=0 |

- 造数走真实 REST（浏览器内 fetch，带会话 Cookie，pitfalls #18）：先 `POST /api/apps/md_material/call/create` 造 M1，再 `POST /api/apps/inventory_projection/call/refresh` 推演。
- `refresh` 返回 `{material_no, biz_date, version_no, opening_stock, generated, rows}`，`generated=90`（未来 3 个月逐日落盘）。`opening_stock=0` 显式锚定起始库存（不依赖 ERP stub `_load_inventory` 返回 0）。
- 无 master_plan / inventory_strategy 数据时，`inbound_qty=0`、`outbound_qty=0`、`balance=0`、`alert_type="无"`（`_classify_alert` 无水位线即回「无」）。biz_date="2026-08-15" ≥ 今日，90 行全部不被 BR-11 前端隐藏。
- 本应用无 `create / update / delete / set_* / import_batch` 服务（自动参考创建）→ 无业务单据表单，仅三个计算触发按钮（refresh / refresh_batch / scan_alert）+ 列表 + 详情。

> 预警六态 hue 徽章（本页 `alertHue` 局部映射，BR-09 枚举）：缺货/击穿最低/击穿安全 = `st-red`（击穿警示），呆滞/超储 = `st-amber`（降储治理），无 = `st-slate`（中性）。本脚本最小造数只产生「无」，六态枚举覆盖由 chips 渲染断言（VT-ROUTE-02）承载；逐态颜色回填需另造 inventory_strategy + master_plan 数据，不纳入最小造数。
