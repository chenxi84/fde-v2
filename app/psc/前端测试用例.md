### VT-DASH-01 看板页渲染

- **页面**: `psc:dashboard`
- **前置造数**: 无（空库即渲染；KPI / 管道 / 待办零值兜底，pitfalls #10）
- **操作**: 登录 admin → `GET /view/psc/`（默认落地页即 dashboard）或 `location.hash = '#/dashboard'` → 轮询 `.loadbox` 消失（`x-show="loading"` 结束）再断言
- **断言**:
  - **KPI 指标带**存在：`.kpi` 数 > 0（== 6，六张 KPI 卡恒渲染）
  - **主链管道**存在：`「主链管道」` overline + 7 段 `.pipe-col`（①销售预测…⑦策略拟合）
  - **待办队列**存在：`「待办队列」` overline + 3 行 `.pipe-col`（需求池待下达 / 拟合待复核 / 月度版本草稿）
- **选择器注意**: 看板页**有** `.kpi`（与逐应用页 `.kpi`==0 防挂载粘滞断言互为镜像，pitfalls #2/#36）；先等 loading 结束（`.loadbox` 的 `x-show` 由 `loading` 驱动，探测完成后 `loading=false`）再断言区块，避免抢跑。

## §5 受限用户菜单收敛

> 受限角色授权清单（逐字，第⑨步逐字搬进脚本）：
> `limited_role` → `["psc:dashboard", "psc:md_customer", "psc:md_monthly_version", "_platform:agent"]`
> 受限用户：`limited_psc`（密码 `Limited@123`），经 `fde_platform.users` 模块播种。
> 看板对受限用户恒显（`psc:dashboard` 在授权清单内），直访无授权路由回落菜单首项（dashboard）。

### VT-PERM-01 菜单收敛

- **页面**: `psc:dashboard`（受限会话落地页）
- **前置造数**: 播种 `limited_role`（授权清单逐字如上）+ `limited_user`（平台子进程启动前经 `fde_platform.users`）；§0 C001 客户
- **操作**: 新会话登录 `limited_psc` → `GET /view/psc/` → 等待 `.rail` 菜单渲染
- **断言**: 菜单项集合（`.nav-item` 的 `name` 序列）== `[产销协同看板, 客户主数据, 月度版本, Agent]`（顺序即菜单序）
- **选择器注意**: `Agent` 是平台页（`_platform:agent` 授权），排在业务页之后；未授权页（如 `物料主数据` / `销售预测`）不得出现在菜单。

### VT-PERM-02 直访无授权 hash 路由回落

- **页面**: `psc:dashboard`（回落目标 = 菜单首项）
- **前置造数**: 同 VT-PERM-01
- **操作**: 受限会话内 `location.hash = '#/sales_forecast'` → 等待重渲染（约 1200ms）
- **断言**: 回落渲染菜单首项「产销协同看板」——`header.top h1` 文本 == `产销协同看板`；`sales_forecast` 不在授权清单 → `syncRoute` 回落到 `menu[0]`（dashboard，order=10 最小）
- **选择器注意**: shell 的 `syncRoute` 渲染回落页但**不回写 `location.hash`**，故断言渲染内容（header 标题）而非 hash（照 verify_view_e2e.py 范式）。

### VT-PERM-03 隐式放行有数据

- **页面**: `psc:md_customer`
- **前置造数**: §0 C001（`md_customer.create`，经浏览器 fetch 走真实 REST，pitfalls #18）
- **操作**: 受限会话内 `location.hash = '#/md_customer'` → 等待列表渲染（`table.tbl` / 行含 C001）
- **断言**: md_customer 页列表有数据——列表含 `C001`（`button.b-link.mono` 客户编码列，`has_text` 精确定位，不假设顺序，pitfalls #17）；证明 `psc:md_customer` 页经 `X-Fde-Page` 派生隐式放行 `md_customer.list` 生效
- **选择器注意**: 受限会话 403 属预期执法，豁免报错统计（§6）。
