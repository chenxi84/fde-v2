# 替换关系 前端详设
> 来源：app/psc/_contracts.md（冻结契约）+ app/psc/md_part_replace/应用详设.md；产出供第⑦步前端编码 / 第⑧步前端测试用例。
> 落位：`app/psc/md_part_replace/view.js` + `view.html`（与 `md_part_replace.py` 同文件夹，落盘即进启动清单与授权清单，零接线）；import 一律绝对路径 `/view/lib/*`；模板经 `new URL("view.html", import.meta.url)` 抓取；工厂 `export default function pageMdPartReplace()`（保留专名）

## 1. 页面元数据 PAGE_META

| 字段 | 值 | 说明 |
|---|---|---|
| key | `md_part_replace` | = 应用文件夹名，page_id 为 `psc:md_part_replace` |
| name | 替换关系 | 侧栏菜单名 |
| ic | 🔁 | 菜单图标字 |
| title | 替换关系 | 主区页面头标题 |
| crumb | 主数据 · 零件替换关系(原件→替换件) | 头部副题 |
| order | 70 | 已按业务序预分配，升序即菜单序 |

- 页面零鉴权：无任何权限判断；菜单按页面授权渲染在 shell，数据范围（责任销售只读、计划员全量）由后端闸门执法，401 由 api.js 自动跳登录。
- 数据来源类型：**独立创建**（PLM 冗余同步 + 本地录入）→ 保留「新建」按钮；本应用无 `delete`（有效期管理经 `disable` 实现），无 `import_batch`。

## 2. 区块构成

### 2.1 列表区（查）—— 三段式：过滤条 / 表格 / 分页条

**用途**：替换关系台账，按原/替换物料（模糊）与状态（精确）筛选，承载行内「设为失效」状态流转动作。本页为非看板页，不设 KPI 指标带（验收断言无 `.kpi`）。

**过滤控件（与 `md_part_replace.list(old_material_no, new_material_no, status, page, size)` 可过滤参数一一对应；契约无 keyword 参数 → 不设关键字搜索框，禁止前端假过滤）**：

| 控件 | 对应参数 | 选项 / 说明 |
|---|---|---|
| 原物料号输入框 | `old_material_no` | placeholder「原物料号」，Enter 或「查询」按钮触发（后端 LIKE 模糊匹配） |
| 替换物料号输入框 | `new_material_no` | placeholder「替换物料号」，Enter 或「查询」按钮触发（后端 LIKE 模糊匹配） |
| 状态 chips | `status` | 全部 / 生效 / 失效（BR-06 枚举，原值传参，精确匹配） |
| 分页 | `page` / `size` | `pageable()` 分页条（契约签名 string 型，照传即可） |

**工具栏**：「查询」「+ 新建替换关系」（打开 2.3 创建模态）。

**表格列（`.tbl.tight` + `.scroll-x`；全部为详情字段子集）**：

| 列 | 字段 | 渲染 |
|---|---|---|
| 关系号 | `rel_no` | 编号正文（**默认隐藏**，`PAGE_META.col_default_hidden`，可经列设置开启） |
| 原物料号 | `old_material_no` | 编号正文 + materialMap 命中时附物料名称小字 |
| 替换物料号 | `new_material_no` | `.b-link`，点击打开详情模态 + materialMap 名称小字 |
| ECN 依据 | `ecn_no` | 文本，空值 `dash()` |
| 状态 | `status` | `hue()` 徽章（生效=绿 / 失效=灰） |
| 操作 | — | 按 `status` 行内动作：生效行 → 【编辑】【设为失效】；失效行 → 【编辑】（终态无失效按钮） |

**交互**：任一过滤变化 → 重置回第 1 页重载；编辑/失效操作成功后刷新当前页；空结果显示空态文案（不喷 toast）。
- **详情入口**：`rel_no` 为系统生成内部主键、业务价值低，默认隐藏；详情改由可见的「替换物料号」`.b-link` 打开。

### 2.2 详情模态（查全）—— 三段式：墨青头带 + 状态徽章 / KV 分组体 / 状态操作页脚

**用途**：点 `rel_no` 弹出，展示 `md_part_replace.get` 返回的**全部**业务字段。

| 分组（`.sec`） | 字段 | 渲染 |
|---|---|---|
| 头带 | `rel_no` + `status` 徽章 | 墨青头带，徽章 `hue()` |
| 基本信息 | `rel_no` / `status` | `.kv`；`rel_no` 注明「系统生成 · 全局唯一」；`status` 注明「生效 / 失效，失效关系在替换件合并中被排除」 |
| 零件关系 | `old_material_no` / `new_material_no` | `.kv`，materialMap 命中附物料名称；注明「引用 md_material · 创建/变更时经 md_material.get 校验存在」 |
| 变更依据 | `ecn_no` | `.kv`，空值 `dash()`，注明「最大 50 字符」 |
| 原始数据 | get 返回全量 JSON | 底部折叠（默认收起） |

**页脚 `.modal-ft`**：【编辑】（打开编辑表单）+ 按 `status` 的【设为失效】按钮（仅 `status=生效` 时可见）+ 【关闭】。

### 2.3 创建 / 编辑表单（增/改）—— 模态表单

**用途**：覆盖 `md_part_replace.create` / `md_part_replace.update` 接受的**全部**可写业务参数（old_material_no / new_material_no / ecn_no）。

| 字段 | 控件 | 必填 | create 可见 | update 可见 | 约束来源 |
|---|---|---|---|---|---|
| `old_material_no` | 物料 autocomplete（见 §4） | ★ 必填 | 是 | 是（可改） | BR-03/BR-04；后端经 md_material.get 校验存在 |
| `new_material_no` | 物料 autocomplete（见 §4） | ★ 必填 | 是 | 是（可改） | BR-03/BR-05；后端经 md_material.get 校验存在 |
| `ecn_no` | input，maxlength=50 | 选填 | 是 | 是（可改） | BR-03；ECN 依据 |
| `rel_no` | （系统生成） | — | 否（保存后生成） | 否（只读展示，主键锁定） | 系统生成 · 全局唯一 |
| `status` | （系统默认） | — | 否（自动=生效） | 否 | create 自动「生效」；update 不通过此表单修改 status |

- **create 模式**：必填 2 项（old_material_no / new_material_no）；`rel_no` 由后端自动生成、`status` 由后端默认「生效」，均不进表单。
- **update 模式**：`rel_no` 回填展示但不可修改（主键）；`old_material_no` / `new_material_no` / `ecn_no` 可修改（须重新校验物料引用、原≠替换、组合唯一）。若需将 status 设为失效，应使用行内/模态页脚【设为失效】操作而非编辑表单。
- 布局：必填先行——第一行（old_material_no autocomplete）、第二行（new_material_no autocomplete）；折叠区「更多字段 ▾」：ecn_no；底部右对齐「取消」「保存」。
- 前端仅做必填校验（old/new 空值 → toast 警告、不提交）；原=替换、组合唯一、物料引用校验均由后端执行，`FdeError` 经 api.js 以错误 toast 呈现。
- 提交成功：toast 成功消息（create 带出新 `rel_no`）→ 关闭模态 → 重置过滤重载列表（create）/ 刷新当前页（update）。

### 2.4 设为失效操作（改状态）

**用途**：生效行显示【设为失效】按钮，调 `md_part_replace.disable`。

- 行内操作列或详情模态页脚：`x-show="status==='生效'"` 时显示【设为失效】。
- 点击 → 弹出确认提示「确认将替换关系设为失效？失效后毛需求替换件合并中将排除此关系」。
- 确认后调用 `svc("md_part_replace","disable")` `{rel_no}`。
- 成功后 toast「替换关系已设为失效」→ 刷新列表 + 若模态打开则原地更新 status。
- 已失效行再点失效 → 后端幂等直接返回（status 保持「失效」），无副作用。

## 3. svc 字面量清单（授权派生依据——必须字面量 svc("应用","服务")）

| 区块 | 调用（应用.服务） | 参数 | quiet | 说明 |
|---|---|---|---|---|
| 列表区 | `svc("md_part_replace","list")` | `{old_material_no, new_material_no, status, page, size}` | — | 分页查询；空条件传 undefined 不带 |
| 物料下拉 | `svc("md_material","list")` | `{page:1, size:500}` | true | quiet 探测；**跨应用调用，字面量产生 psc:md_part_replace → md_material.list 派生边** |
| 详情模态 | `svc("md_part_replace","get")` | `{rel_no}` | — | 全字段详情 |
| 创建表单 | `svc("md_part_replace","create")` | `{old_material_no, new_material_no, ecn_no}` | — | 后端跨应用双校验物料存在；返回含 rel_no 记录 |
| 编辑表单 | `svc("md_part_replace","update")` | `{rel_no, old_material_no, new_material_no, ecn_no}` | — | 更新（rel_no 定位键，old/new 重新校验） |
| 设为失效 | `svc("md_part_replace","disable")` | `{rel_no}` | — | 生效→失效单向操作（幂等） |

> 以上 6 处必须在 view.js 中以字面量逐项书写（可包在闭包里），**勿用变量拼名**——这是页面授权隐式放行派生扫描的唯一来源。

## 4. 数据来源与下拉

**物料 autocomplete（原/替换物料号，共用一份 materialOptions / materialMap）**：
- 页面初始化一次性 `svc("md_material","list")` `{page:1, size:500}`，`quiet:true` 探测：失败不喷 toast；零值兜底 → autocomplete 显示「暂无可选物料」禁用项（提交时再 toast 提示）。
- 由返回项构建 `materialOptions` 扁平数组（字段 `material_no` / `material_name`），autocomplete 显示「material_no + material_name」双行，选中后表单存 `material_no`。
- 由返回项构建 `materialMap = {material_no: material_name}`，供列表「原物料号」「替换物料号」列与详情模态物料名称回显；未命中则原样展示 material_no。
- material 列表项字段以 md_material 契约为准，本页仅用 `material_no` / `material_name`（status / value_class 等不展示）。

**状态下拉 / 状态 chips**：静态枚举（生效 / 失效），来源：BR-06 / 建表 `VALID_STATUSES`（`("生效", "失效")`）。

**契约 payload → 区块字段映射**：

| 来源 | payload 字段 | 去向 |
|---|---|---|
| `md_part_replace.list` 项 | rel_no, old_material_no, new_material_no, ecn_no, status | 列表区表格列（1:1） |
| `md_part_replace.get` | 同上（全量，5 字段） | 详情模态全部 KV 分组 + 原始数据折叠 |
| `md_part_replace.create` 入参 | old_material_no, new_material_no, ecn_no | 2.3 创建表单 |
| `md_part_replace.create` 返回 | 记录对象（含 rel_no，status=生效） | toast 展示 rel_no → 列表重载 |
| `md_part_replace.update` 入参 | rel_no, old_material_no, new_material_no, ecn_no | 2.3 编辑表单（rel_no 只读） |
| `md_part_replace.disable` 入参/返回 | rel_no / 记录对象（status=失效） | 2.4 设为失效；原地更新已开模态 + 列表行 |
| `md_material.list` 项 | material_no, material_name | 物料 autocomplete 选项 + materialMap |

> 本页无 `*_json` 快照字段（无需 `tryParse()`）；无金额字段（无需 `fmt()`）；无时间字段（无需 `fmtTime()`）。字段序统一：单号（rel_no）→ 状态（status）→ 归属（old/new_material_no）→ 变更依据（ecn_no）。

## 5. 交互要点

1. **按状态的行内动作（状态机：生效→失效，行操作列与模态页脚共用判定）**：
   - `status=生效` → 【编辑】【设为失效】；
   - `status=失效` → 终态，仅【编辑】（无失效按钮，V1 不支持反向激活）。
   - 动作成功：toast + 刷新列表；对失效行再点失效由后端幂等返回，前端 toast 呈现；非法流转由后端 FdeError 经 api.js 统一 toast，页面不硬编状态机校验。
2. **模态**：统一三段式；加载态等待消失后再断言内容；头带墨青 + `hue()` 状态徽章。
3. **物料 autocomplete**：old_material_no 和 new_material_no 各独立 autocomplete（`@click.stop` 切换 + `@input` 实时过滤 + `@click.away` 关闭），共用同一份 `materialOptions`，过滤逻辑同时匹配 material_no 和 material_name，选中后回填对应编码。
4. **过滤**：原/替换物料号输入框（模糊）Enter 或「查询」触发并重置 `page=1`；状态 chips 点击即查并重置 `page=1`；翻页仅改 `page/size`，不清过滤条件。
5. **折叠「更多字段 ▾」**：仅 `ecn_no` 一个选填字段。
6. **quiet 探测性加载**：物料下拉 quiet + 零值兜底，失败不喷 toast；替换关系列表本身正常加载，错误走 api.js 统一通道。
7. **展示工具**：`hue()`（status 徽章）、`dash()`（空 ecn_no）；本页无 `*_json` / 金额 / 时间字段，无需 `tryParse()` / `fmt()` / `fmtTime()`。
8. **toast**：创建成功 / 更新成功 / 设为失效成功 / 必填未填警告；其余错误（组合已存在、物料不存在、原=替换、ECN 超长）一律由 api.js 统一呈现。

## 6. 验收关注点（供第⑧步前端测试用例）

1. **路由渲染**：`#/md_part_replace` 挂载出列表三段式（过滤条 + 表格 + 分页条），**断言无 `.kpi`**（非看板页防挂载粘滞假过）；菜单「🔁 替换关系」按 order=70 定位。
2. **造数后列表有数据**：先造 material（M10001 / M10002）→ `create` 造替换关系（old=M10001, new=M10002）→ 列表行数正确，rel_no / old_material_no / new_material_no / ecn_no / status=生效 列非空。
3. **过滤一一对应**：old_material_no=10001 模糊匹配仅命中含 10001 的行；new_material_no 同理；status=生效 chips 仅生效行；三条件组合（AND）；无匹配显示空态且不抛错。
4. **模态全字段**：点 rel_no 开模态，断言 rel_no / old_material_no / new_material_no / ecn_no / status 全部可见 + 「原始数据」可展开；失效记录的模态页脚无【设为失效】按钮。
5. **表单落库**：create 表单经 autocomplete 选原/替换物料 +「更多字段」ecn_no → 提交 → 列表出现新记录且 status=生效（US-01-AC1）；空必填字段提交 → toast 警告且不发请求；重复原+替换组合 → 后端 FdeError toast（US-01-AC2）。
6. **引用与约束拦截**：原=替换 → 后端 toast「原物料号与替换物料号不能相同」（US-01-AC3）；引用不存在物料 → 后端 toast「原物料号不存在 / 替换物料号不存在」（US-01-AC4/AC5）。
7. **设为失效**：生效行点【设为失效】→ 确认后 status 变为失效 → 行内不再显示【设为失效】按钮（US-05-AC1）；已失效行再点 → 幂等无副作用（US-05-AC2）。
8. **编辑不暴露 status**：编辑表单无 status 选择器，rel_no 只读，确保状态仅通过 disable 变更；编辑改 ecn_no 后保存 → 列表回显新 ecn_no（US-04-AC1）。
9. **物料 autocomplete**：old/new 下拉含已创建物料选项（material_no + material_name 双行），选中后正确回填编码；无物料时显示「暂无可选物料」禁用项。
10. **干净控制台**：全程 0 console error / 0 pageerror / 0 HTTP≥400（受限会话 403 属预期执法单独豁免；责任销售角色下菜单收敛为「看板 + 授权应用 + 平台页」，页面不做任何判断）。
