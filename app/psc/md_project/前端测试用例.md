# 应用组 `psc` · md_project 前端测试用例（项目台账）

> 产出技能：前端测试用例生成（第⑧步，规格 design-plus/前端测试.md）。
> 页面：`psc:md_project`（本文件全部用例针对本页，条目内页面省写）。
> 输入：app/psc/md_project/前端详设.md（主输入）+ app/psc/_contracts.md（冻结契约）。
> 执行：第⑨步翻译成 app/psc/tests/verify_view_psc_md_project.py（自包含：隔离→起平台→登录→造数→断言→0 报错）。

## §0 测试数据字典（冻结 · 本脚本自足）

| 别名 | 类型 | 造数服务 | 关键参数 |
|---|---|---|---|
| PRJ-1 | 项目台账（进行中·含日期） | md_project.create | project_no=PRJ-1, project_name=项目1, owner=S001, sop_date=2026-01-01, eop_date=2027-12-31（stage 默认进行中） |
| PRJ-2 | 项目台账（进行中·无日期，供推进） | md_project.create | project_no=PRJ-2, project_name=项目2, owner=S002（stage 默认进行中，无 sop/eop_date） |
| PRJ-SOP | 项目台账（SOP） | md_project.create + md_project.update | create(project_no=PRJ-SOP, project_name=项目SOP, owner=S003) → update(project_no=PRJ-SOP, stage=SOP, sop_date=2026-06-01) |
| PRJ-EOP | 项目台账（EOP 终态） | md_project.create + md_project.update×2 | create(project_no=PRJ-EOP, project_name=项目EOP, owner=S004) → update(stage=SOP, sop_date=2026-06-01) → update(stage=EOP, eop_date=2029-12-31) |

> 造数服务签名以 `_contracts.md` 为准：`md_project.create(project_no*, project_name*, owner*, stage=None, sop_date=None, eop_date=None)`；`md_project.update(project_no*, project_name=None, stage=None, sop_date=None, eop_date=None, owner=None)`。
> 说明：`create` 的后端 `_validate_transition(None, stage)` 仅允许初始阶段为「进行中」，新建直接传 SOP/EOP 会被拒——故 PRJ-SOP / PRJ-EOP 一律先 `create` 再经 `update` 按状态机单向推进得到（进行中→SOP→EOP）。
> 本页无跨应用前置（owner 为纯文本字段，无用户主数据下拉），字典自足。

## §1 本页渲染（防粘滞）

- **VT-ROUTE-01 路由渲染**
  - 操作: admin 登录 → `location.hash = '#/md_project'`（必要时 `pg.reload()` 刷新注册表 mtime 缓存）
  - 断言: `main .card` 数 > 0；列表三段式（工具栏「+ 新建项目」「批量导入」按钮 + `.tbl` 表格 + 分页条）可见；**非看板页 `.kpi` 数 == 0**（防挂载粘滞假过，pitfalls #2）
  - 选择器注意: 用 `:visible` 限定（x-show 隐藏元素仍在 DOM，pitfalls #14）

## §2 造数后列表有数据

- **VT-LIST-01 列表含所造单号**
  - 前置造数: 浏览器内 `fetch POST /api/apps/md_project/call/create` 造 PRJ-1、PRJ-2、PRJ-SOP、PRJ-EOP（带会话 Cookie，走真实 REST，pitfalls #18；PRJ-SOP/PRJ-EOP 另经 `/call/update` 推进）
  - 操作: 进入 `#/md_project`（或 `pg.reload()`）
  - 断言: `table.tbl tr.data` 行数 >= 4；列表含 PRJ-1 单号（精确 `has_text` 定位，不假设顺序，#17）；PRJ-1 行 project_name=项目1、stage 徽章「进行中」、owner=S001 非空
  - 选择器注意: 用精确 `has_text("PRJ-1")` 定位行而非 `.first`（#17）

- **VT-LIST-02 阶段 chips 过滤（精确匹配）**
  - 前置造数: 同 VT-LIST-01
  - 操作: 点阶段 chips「SOP」
  - 断言: 结果收敛为仅 PRJ-SOP 行（含 PRJ-SOP，不含 PRJ-1 / PRJ-2 / PRJ-EOP）
  - 选择器注意: chips 点击后等待列表刷新（`.loadbox` 消失）

- **VT-LIST-03 项目号模糊搜索**
  - 操作: project_no 输入框填「PRJ-」→ 点「查询」
  - 断言: 命中 PRJ-1 / PRJ-2 / PRJ-SOP / PRJ-EOP 全部（后端 LIKE %PRJ-%）
  - 选择器注意: Enter 或「查询」按钮触发；输入框 `:visible`

- **VT-LIST-04 项目名称模糊搜索 + 空态**
  - 操作: project_name 输入框填「项目1」→ 点「查询」
  - 断言: 仅含 PRJ-1 行；再改填「不存在XYZ」→ 查询 → 空态文案「无符合条件的项目」（不喷 toast）
  - 选择器注意: 空态文案用 `.tbl .empty` 定位

## §3 模态全字段

- **VT-MODAL-01 详情模态全字段 + 进行中页脚推进按钮**
  - 前置造数: PRJ-1（进行中）
  - 操作: 点 PRJ-1 单号 `.b-link` → `wait_modal()`（轮询 `.modal-mask:visible .loadbox` 消失，#16）
  - 断言: `.modal-bd.first` 含字段标签全集：项目号 / 项目名称 / 阶段 / SOP 时间 / EOP 时间 / 责任销售；值含 PRJ-1 / 项目1 / 进行中 / 2026-01-01 / 2027-12-31 / S001；「原始数据」details 可展开；页脚 `.modal-ft` 含【推进至 SOP】+【编辑】+【关闭】（进行中态）
  - 选择器注意: 多 `.modal-bd` 用 `.first`（#15）；页脚按钮文案读整个 `.modal-mask:visible .modal-ft`；`:visible` 限定

- **VT-MODAL-02 页脚按钮按状态可见性（SOP / EOP）**
  - 前置造数: PRJ-SOP、PRJ-EOP
  - 操作: 点 PRJ-SOP 单号 → `wait_modal()` → 读页脚；关闭 → 点 PRJ-EOP 单号 → `wait_modal()` → 读页脚
  - 断言: PRJ-SOP 页脚含【推进至 EOP】+【编辑】+【关闭】（无【推进至 SOP】）；PRJ-EOP 页脚含「EOP 终态 · 阶段不可推进」文案 +【编辑】+【关闭】（无任何推进按钮）
  - 选择器注意: `:visible` 限定（隐藏按钮仍在 DOM，#14）；EOP 态推进按钮 `count() == 0` 而非「不存在」

## §4 表单落库回显

- **VT-FORM-01 创建落库（stage=进行中）**
  - 操作: 点「+ 新建项目」→ 填 project_no=PRJ-NEW、project_name=项目新建、owner=S009 → 展开「更多字段 ▾」填 sop_date=2026-10-01 → 点「创建」
  - 断言: toast 含「项目台账创建成功」；列表回显 PRJ-NEW 且 stage=进行中、sop_date=2026-10-01
  - 选择器注意: 表单模态 `.modal-mask:visible` 内控件 `:visible` 限定；创建态 stage 为只读「进行中」

- **VT-FORM-02 空必填字段被拒（前端校验）**
  - 操作: 点「+ 新建项目」→ project_no 留空 → 点「创建」
  - 断言: toast 警告「项目号必填」且不发请求（列表无新增行）；模态保持打开
  - 选择器注意: toast 选择器；断言模态仍 `:visible`

- **VT-FORM-03 重复 project_no 后端拒绝（BR-01）**
  - 前置造数: PRJ-1 已存在
  - 操作: 点「+ 新建项目」→ project_no=PRJ-1、project_name=任意、owner=任意 → 点「创建」
  - 断言: toast 错误「该项目号已存在」；模态保持打开；列表仍仅 1 条 PRJ-1
  - 选择器注意: 错误 toast 经 api.js 呈现；模态保持打开便于修改

- **VT-FORM-04 编辑态 project_no 只读 + 字段更新回显 + stage 选项单向**
  - 前置造数: PRJ-1（进行中）
  - 操作: 点 PRJ-1 行【编辑】→ 断言 project_no input `:disabled` 且回填 PRJ-1 → 断言 stage select 选项 == [进行中, SOP]（无回退/跳级选项）→ 修改 project_name=项目1-改、owner=S011 → 点「保存修改」
  - 断言: toast 含「项目台账更新成功」；列表 PRJ-1 行 project_name=项目1-改、owner=S011
  - 选择器注意: 编辑态 project_no input `:disabled`（主键不可改）；stage select 选项集合等于 `editStageOptions()` 的 [当前, 下一阶段]

- **VT-FORM-05 阶段推进（进行中 → SOP）**
  - 前置造数: PRJ-2（进行中，无日期）
  - 操作: 点 PRJ-2 行【推进至 SOP】→ 断言表单标题「阶段推进 · PRJ-2 → SOP」且 stage 只读锁定 SOP、sop_date 标红星必填 → 填 sop_date=2026-09-30 → 点「确认推进」
  - 断言: toast 含「已推进至 SOP · PRJ-2」；列表 PRJ-2 行 stage=SOP、sop_date=2026-09-30
  - 选择器注意: 阶段推进态 stage 为只读 input（`:disabled`）；「确认推进」按钮 `:visible`

- **VT-FORM-06 阶段推进（SOP → EOP）+ 推进日期必填前端校验**
  - 前置造数: PRJ-SOP（SOP，已填 sop_date=2026-06-01）
  - 操作: 点 PRJ-SOP 行【推进至 EOP】→ 不填 eop_date → 点「确认推进」→ 断言 toast 警告「推进到 EOP 阶段须填写 EOP 时间」（不发请求）；再填 eop_date=2029-12-31 → 点「确认推进」
  - 断言: 先 toast 警告且列表 PRJ-SOP 仍 stage=SOP；后 toast 含「已推进至 EOP · PRJ-SOP」；列表 PRJ-SOP 行 stage=EOP、eop_date=2029-12-31
  - 选择器注意: `:visible` 限定；EOP 推进态 eop_date 标红星必填

- **VT-FORM-07 日期先后后端校验（BR-05）**
  - 操作: 点「+ 新建项目」→ 填 project_no=PRJ-DATE、project_name=日期项目、owner=S013 → 展开「更多字段 ▾」填 sop_date=2026-09-30、eop_date=2026-08-31 → 点「创建」
  - 断言: toast 错误「EOP 时间须晚于 SOP 时间」；模态保持打开；列表无 PRJ-DATE
  - 选择器注意: 后端 FdeError 经 api.js toast；模态保持打开便于修改

- **VT-FORM-08 批量导入（新增 + 冲突 upsert + 失败明细）**
  - 前置造数: PRJ-1 已存在
  - 操作: 点「批量导入」→ 在「或直接粘贴 CSV」textarea 粘贴 3 行数据：
    `project_no,project_name,stage,sop_date,eop_date,owner` 表头 + `PRJ-IMP-1,导入项目1,进行中,,,S010` + `PRJ-1,项目1导入改,进行中,,,S001` + `PRJ-IMP-BAD,,进行中,,,S012` → 点「导入」
  - 断言: toast 含「导入完成 · 成功 2 条 / 失败 1 条」；结果摘要 total=3、success=2、fail=1、created=1、updated=1；错误明细表含「项目名称不能为空」；列表回显 PRJ-IMP-1、PRJ-1 的 project_name 变为「项目1导入改」
  - 选择器注意: 粘贴 CSV 走真实 `svc("md_project","import_batch")`；结果摘要读 `.modal-mask:visible .kv`

## §7 待确认

- 前端详设 §6 验收关注点 6 提到「非法回退（编辑表单选回进行中）由后端拦截」，但 `view.js` 的 `editStageOptions()` 编辑态 stage select 仅提供 [当前阶段, 下一阶段]（SOP 项目仅 [SOP, EOP]、EOP 项目仅 [EOP]），**前端无回退/跳级入口**——故「非法回退/跳级」无法经 UI 触发，其拦截由后端用例（第④⑤步 verify_chain）覆盖；本文件仅以 VT-FORM-04 断言 select 选项单向性，不回测后端拦截 toast。
