# 达成率与置信度 前端详设
> 来源：app/psc/_contracts.md（冻结契约）+ app/psc/attainment/应用详设.md
> 落位：`app/psc/attainment/view.js` + `view.html`（与 `attainment.py` 同文件夹，落盘即进启动清单与授权清单，零接线）

## 1. 页面元数据 PAGE_META

| 字段 | 值 | 说明 |
|---|---|---|
| key | `attainment` | = 应用文件夹名，page_id 为 `psc:attainment` |
| name | 达成率与置信度 | 侧栏菜单名 |
| ic | 📊 | 菜单图标字 |
| title | 达成率与置信度 | 主区页面头 |
| crumb | 派生指标 · 客户×物料 MAPE/bias | 头部副题 |
| order | 90 | 已按业务序预分配，直接用；升序即菜单序 |

- 页面零鉴权：无任何权限判断；菜单按页面授权渲染在 shell，数据范围由后端闸门执法，401 由 api.js 自动跳登录。
- **数据来源类型 = 自动参考创建**：MAPE/bias 由 ERP 统计后经 `_load_attainment` 适配器冗余回写 `upsert`，前端**禁止创建/编辑/删除入口**（BR-05）。
- 本应用契约**无 create / update / set_* / import_batch / delete**；`upsert` 是 ERP 回写服务（系统回写，非用户触发），前端不提供 upsert 入口。

## 2. 区块构成

### 2.1 列表区（查）—— 三段式：过滤条 / 表格 / 分页条

**用途**：达成率与置信度台账，按客户 / 物料维度筛选，供计划员月度复盘只读查看。本页为非看板页，不设 KPI 指标带（验收断言无 `.kpi`）。

**过滤控件（与 `attainment.list(customer_no, material_no, page, size)` 可过滤参数一一对应；契约无 keyword 参数 → 不设关键字搜索框，禁止前端假过滤）**：

| 控件 | 对应参数 | 选项 |
|---|---|---|
| 客户 autocomplete | `customer_no` | 内联 autocomplete（主数据选择控件铁律），选项来自 `md_customer.list` quiet 加载；选中回填 `customer_no`（精确匹配） |
| 物料 autocomplete | `material_no` | 内联 autocomplete，选项来自 `md_material.list` quiet 加载；选中回填 `material_no`（精确匹配） |
| 分页 | `page` / `size` | `pageable()` 分页条（契约签名 integer 型，照传即可） |

**表格列（`.tbl.tight` + `.scroll-x`；全部为详情字段子集，字段序与详情一致）**：

| 列 | 字段 | 渲染 |
|---|---|---|
| 客户编码 | `customer_no` | `.b-link`，点击开详情模态；custMap 命中时附客户名小字 |
| 物料号 | `material_no` | 编号正文 + matMap 命中时附物料名小字 |
| 平均绝对百分比误差 | `mape` | 百分比 `fmt()`（0.12 → 12%），空值 `dash()` |
| 预测偏差 | `bias` | 带符号百分比 `fmt()`（+8% / −5%），正负着色（多报/少报），空值 `dash()` |
| 操作 | — | 无行内操作（只读派生数据，无状态机、无编辑/删除） |

**交互**：任一过滤变化 → 重置回第 1 页重载；空结果显示空态文案（不喷 toast）。

### 2.2 详情模态（查全）—— 三段式：墨青头带 / KV 分组体 / 页脚

**用途**：点 `customer_no` 弹出，展示 `attainment.get(customer_no, material_no)` 返回的**全部**业务字段。

| 分组（`.sec`） | 字段 | 渲染 |
|---|---|---|
| 头带 | `customer_no` + `material_no` | 墨青头带 |
| 标识信息 | `customer_no` / `material_no` | `.kv`；注明「联合主键 · 客户+物料唯一」（BR-01） |
| 主数据回显 | 客户名称 / 物料名称 | `.kv`；custMap / matMap 命中时附名称，未命中 `dash()`；注明「弱引用主数据，来源 md_customer / md_material」（BR-02） |
| 达成率指标 | `mape` | `.kv` 百分比展示，注明「平均绝对百分比误差 · 越小越准 · 非负」（BR-04） |
| 置信度指标 | `bias` | `.kv` 带符号百分比展示，注明「多报为正、少报为负 · ERP 统计回写，本应用只存储不计算」（BR-03） |
| 原始数据 | get 返回全量 JSON | 底部折叠（默认收起） |

**页脚 `.modal-ft`**：仅「关闭」按钮（无写操作、无状态机动作可放）。

### 2.3 创建 / 编辑表单

**豁免，理由**：数据来源类型为「自动参考创建」（ERP 统计回写），本应用契约无 `create` / `update` / `set_*` / `import_batch` 写服务；`upsert` 为 ERP 回写服务（`_load_attainment` 适配器驱动，非用户触发）。前端仅提供列表 + 详情只读展示，无任何新建 / 编辑 / 删除入口（BR-05）。

## 3. svc 字面量清单（授权派生依据——必须字面量 svc("应用","服务")）

| 区块 | 调用（应用.服务） | 参数 | quiet | 说明 |
|---|---|---|---|---|
| 列表区 | `svc("attainment","list")` | `{customer_no, material_no, page, size}` | — | 分页查询，AND 筛选；空条件传 undefined 不带 |
| 详情模态 | `svc("attainment","get")` | `{customer_no, material_no}` | — | 全字段详情（未命中返回 None，展示空态） |
| 过滤条 / 客户名称回显 | `svc("md_customer","list")` | `{page:1, page_size:200}` | true | quiet 探测，构建 `custMap`；**跨应用调用，字面量产生 psc:attainment → md_customer.list 派生边** |
| 过滤条 / 物料名称回显 | `svc("md_material","list")` | `{page:1, page_size:200}` | true | quiet 探测，构建 `matMap`；**跨应用调用，字面量产生 psc:attainment → md_material.list 派生边** |

> 以上 4 处必须在 view.js 中以字面量逐项书写（可包在闭包里），**勿用变量拼名**——这是页面授权隐式放行派生扫描的唯一来源。`upsert` 为 ERP 系统回写，前端不调用，**不进 svc 清单**。

## 4. 数据来源与下拉

**客户 autocomplete（过滤条 + 名称回显共用一份 custList / custMap）**：
- 页面初始化一次性 `svc("md_customer","list")` `{page:1, page_size:200}`，`quiet:true` 探测：失败不喷 toast；零值兜底 → 过滤 autocomplete 空选项、列表与详情客户名回显降级为纯 customer_no。
- 由返回项构建 `custMap = {customer_no: customer_name}`，供列表「客户编码」列与详情模态姓名回显；未命中则原样展示 customer_no。
- md_customer 列表项字段以 md_customer 契约为准，本页仅用 `customer_no` / `customer_name`（settle_mode 等不展示）。

**物料 autocomplete（过滤条 + 名称回显共用一份 matList / matMap）**：
- 同客户下拉，一次性 `svc("md_material","list")` `{page:1, page_size:200}`，`quiet:true`；构建 `matMap = {material_no: material_name}`。
- 本页仅用 `material_no` / `material_name`（status / unit_value 等不展示）。

**主数据选择控件实现要点**（主数据引用铁律）：客户/物料过滤必须用内联 autocomplete（点击输入框弹出匹配列表、输入关键字过滤、选中回填代号），禁止普通 `<select>`；为每个主数据源单独声明扁平数组 `custOptions` / `matOptions`（禁止嵌套对象 `autoOptions[field]`）；`@click.stop` 展开 + `@input` 实时过滤（同时匹配代号和名称）+ `@click.away` 关闭；列表项双行「代号 + 名称」，选中后表单/过滤存代号。

**契约 payload → 区块字段映射**：

| 来源 | payload 字段 | 去向 |
|---|---|---|
| `attainment.list` 项 | customer_no, material_no, mape, bias | 列表区表格列（1:1） |
| `attainment.get` | 同上（全量） | 详情模态全部 KV 分组 + 原始数据折叠 |
| `md_customer.list` 项 | customer_no, customer_name | 客户 autocomplete 选项 + custMap |
| `md_material.list` 项 | material_no, material_name | 物料 autocomplete 选项 + matMap |

- 本应用无 `*_json` 快照字段，无需 `tryParse()`；无时间字段，无需 `fmtTime()`；无审计字段（created_at 等），详情以原始数据折叠兜底。
- `mape` / `bias` 为小数（如 0.12、0.08 / −0.05），前端用 `fmt()` 格式化为百分比展示；空值 `dash()`。

## 5. 交互要点

1. **加载**：首载正常拉取 `attainment.list`（非看板页，失败走 api.js 统一通道）+ quiet 拉取 `md_customer.list` / `md_material.list` 构建名称映射与 autocomplete 选项。
2. **过滤**：客户/物料 autocomplete 选中即查并重置 `page=1`；翻页仅改 `page/size`，不清过滤条件；两条件为 AND 关系，均空返回全部（分页）。
3. **只读页面**：列表无新建 / 编辑 / 删除按钮，行内无操作列；详情模态页脚仅「关闭」。数据来源类型为「自动参考创建」，`upsert` 无前端入口（BR-05）。
4. **quiet 探测性加载**：客户 / 物料主数据下拉 quiet + 零值兜底，失败不喷 toast；达成率列表本身正常加载，错误走 api.js 统一通道。
5. **bias 方向着色**：bias 为正（多报）暖色、为负（少报）冷色、0 中性，`fmt()` 带符号百分比展示；无后端阈值可据此高亮（本页不做 MAPE 阈值判定——阈值判定在 sales_forecast 消费侧，不臆造前端阈值）。
6. **微交互**：表格行 hover 高亮；`customer_no` `.b-link` hover 下划线；空结果显示空态文案（不喷 toast）。
7. **展示工具**：`fmt()`（mape/bias 百分比）、`dash()`（空值 / 未命中主数据名）；本页无 `*_json`（无需 `tryParse()`）、无时间字段（无需 `fmtTime()`）、无金额字段、无 `hue()` 徽章（无状态字段）。
8. **toast**：本页无写操作、无必填校验，仅错误由 api.js 统一呈现。

## 6. 验收关注点（供第⑧步前端测试用例）

1. **路由渲染**：`#/attainment` 挂载出列表三段式（过滤条 + 表格 + 分页条），**断言无 `.kpi`**（非看板页防挂载粘滞假过）；菜单「📊 达成率与置信度」按 order=90 定位。
2. **无创建入口**：页面工具栏无「新建」按钮，列表无行内编辑 / 删除操作，详情页脚仅「关闭」（BR-05 / US 全部）。
3. **造数后列表有数据**：经 `upsert`（ERP 回写口径，REST 直调）造多条（覆盖不同客户 × 物料、mape/bias 正负值）→ 列表行数正确，customer_no / material_no / mape / bias 列非空。
4. **过滤一一对应**：客户=C001 仅该客户行；物料=M001 仅该物料行；两条件组合（AND）；无匹配显示空态且不抛错（US-03-AC1/AC2/AC3）。
5. **模态全字段**：点 customer_no 开模态，断言 customer_no / material_no / mape / bias 全部可见 + 主数据名称回显 + 「原始数据」可展开；页脚无操作按钮。
6. **主数据名称回显**：列表客户/物料列与详情模态在 custMap / matMap 命中时附名称小字；未命中时原样展示代号、不抛错。
7. **clean 控制台**：全程 0 console error / 0 pageerror / 0 HTTP≥400（受限会话 403 属预期执法单独豁免；计划员角色下页面只读，无任何写入动作）。
