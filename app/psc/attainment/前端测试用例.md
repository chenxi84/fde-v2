# 应用组 `psc` · attainment 前端测试用例（达成率与置信度）

> 产出技能：前端测试用例生成（第⑧步，规格 design-plus/前端测试.md）。
> 页面：`psc:attainment`（本文件全部用例针对本页）。输入：本应用前端详设 + app/psc/_contracts.md。
> 执行：第⑨步翻译成 app/psc/tests/verify_view_psc_attainment.py（自包含：隔离→起平台→登录→造数→断言→0 报错）。
> 数据来源类型 = 自动参考创建（ERP 统计回写 upsert），本页为只读页，§4 豁免（理由见 §4）。

## §0 测试数据字典（冻结 · 本脚本自足）

| 别名 | 类型 | 造数服务 | 关键参数 |
|---|---|---|---|
| C001 | 客户（跨应用前置 · 名称回显） | md_customer.create | customer_no=C001, customer_name=客户A |
| C002 | 客户（过滤测试用） | md_customer.create | customer_no=C002, customer_name=客户B |
| M1 | 物料（跨应用前置 · 名称回显） | md_material.create | material_no=M1, material_name=物料A |
| M2 | 物料（过滤测试用） | md_material.create | material_no=M2, material_name=物料B |
| ATTN1 | 达成率主数据（多报为正） | attainment.upsert | customer_no=C001, material_no=M1, mape=0.12, bias=0.08 |
| ATTN2 | 达成率主数据（少报为负） | attainment.upsert | customer_no=C001, material_no=M2, mape=0.05, bias=-0.03 |
| ATTN3 | 达成率主数据（第二客户） | attainment.upsert | customer_no=C002, material_no=M1, mape=0.20, bias=0.10 |

> 说明：`attainment` 契约无 create/update/delete，数据经 `attainment.upsert`（ERP 回写口径）REST 直调造入（pitfalls #18）。C001/M1 供列表与详情模态主数据名称回显；C002/M2 供过滤断言区分行。
> 造数顺序：先 C001/C002/M1/M2（主数据，跨应用前置），再 ATTN1/ATTN2/ATTN3（依赖主数据）。

## §1 本页渲染（防粘滞）

- **VT-ROUTE-01 路由渲染有内容**
  - 页面：psc:attainment
  - 操作：登录 admin → location.hash = '#/attainment'
  - 断言：`main .card` 数 > 0；列表三段式（过滤条 + 表格 + 分页条）可见；**非看板页 `.kpi` 数 == 0**（防挂载粘滞，pitfalls #2）；工具栏**无「新建」按钮**、列表**无行内操作列**（只读，BR-05）
  - 选择器注意：`:visible` 限定（隐藏页签元素仍在 DOM，pitfalls #14）

## §2 造数后列表有数据

- **VT-LIST-01 列表含所造数据（C001×M1）**
  - 前置造数：经 REST 依次调用 §0 全部服务（C001/C002/M1/M2 → ATTN1/ATTN2/ATTN3）
  - 操作：进入 `#/attainment`（或 `pg.reload()` 重载回初始态，pitfalls #6）
  - 断言：`table.tbl tr.data` 行数 == 3；含 ATTN1 的 `customer_no=C001` 与 `material_no=M1`（精确 `has_text` 定位，不假设顺序，pitfalls #17）；该行 mape/bias 列非空且渲染为百分比（`12%` / `+8%`）
  - 选择器注意：列表按新到旧排，用 `has_text` 精确单号定位而非 `.first`（pitfalls #17）

- **VT-LIST-02 客户过滤（customer_no 抽样）**
  - 前置造数：同 VT-LIST-01
  - 操作：客户 autocomplete 输入/选中 C001 → 过滤触发（重置 page=1）
  - 断言：结果收敛为 2 行（ATTN1 + ATTN2）；不含 `customer_no=C002`
  - 选择器注意：autocomplete 用内联匹配列表，选中回填代号；等列表刷新后再断言

- **VT-LIST-03 物料过滤（material_no 抽样）**
  - 前置造数：同 VT-LIST-01
  - 操作：物料 autocomplete 输入/选中 M1
  - 断言：结果收敛为 2 行（ATTN1 + ATTN3）；不含 `material_no=M2`

- **VT-LIST-04 组合过滤（AND）与空态**
  - 前置造数：同 VT-LIST-01
  - 操作：客户=C001 且 物料=M1 → 断言结果 1 行（仅 ATTN1）；再改 客户=C002 且 物料=M2 → 断言空结果显示空态文案、不抛错（US-03-AC3）
  - 断言：组合 AND 精确收敛；空态文案可见且无 toast 错误

- **VT-LIST-05 主数据名称回显**
  - 前置造数：同 VT-LIST-01（custMap/matMap 由 quiet 拉取构建）
  - 操作：检查 C001×M1 行
  - 断言：`customer_no` 列附客户名小字「客户A」，`material_no` 列附物料名小字「物料A」
  - 选择器注意：未命中主数据名时原样展示代号、不抛错（BR-02）

## §3 模态全字段

- **VT-MODAL-01 详情模态全字段**
  - 前置造数：同 VT-LIST-01
  - 操作：点 ATTN1 行 `customer_no=C001` 的 `.b-link` → `wait_modal()` 轮询 `.modal-mask:visible .loadbox` 消失（pitfalls #16）
  - 断言：`.modal-bd.first` 含业务字段全集：`customer_no=C001` / `material_no=M1` / `mape=12%` / `bias=+8%`（全部 KV 标签可见）；主数据回显「客户名称=客户A」「物料名称=物料A」；「原始数据」折叠区可展开；页脚 `.modal-ft` 仅「关闭」按钮，无任何写操作按钮
  - 选择器注意：多 `.modal-bd` 用 `.first`（pitfalls #15）；读页脚读 `.modal-mask:visible`；`:visible` 限定

- **VT-MODAL-02 少报负值渲染**
  - 前置造数：同 VT-LIST-01
  - 操作：点 ATTN2 行（C001×M2）`.b-link` → `wait_modal()`
  - 断言：模态 `bias` 显示带符号百分比 `-3%`（少报为负，BR-03）；`mape` 显示 `5%`（越小越准 · 非负，BR-04）

## §4 表单落库回显 —— 豁免

- **豁免，理由**：数据来源类型为「自动参考创建」——MAPE/bias 由 ERP 统计后经 `_load_attainment` 适配器冗余回写 `attainment.upsert`（系统回写，非用户触发）。本应用契约无 `create` / `update` / `set_*` / `import_batch` / `delete` 写服务，前端不提供 upsert 入口。故本页无创建/编辑表单，**无 §4 表单落库回显用例**（BR-05）。
- 只读约束的正面断言（无创建入口）已并入 §1 VT-ROUTE-01 与 §3 VT-MODAL-01（页脚仅「关闭」）。
