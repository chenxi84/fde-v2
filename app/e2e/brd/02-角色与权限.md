# 第2章 角色与权限

## 2.1 角色清单

| 角色 | 是谁 | 在业务里干什么 |
|---|---|---|
| `admin`（管理员 / 成员管理员） | 团队管理者 | 建成员名单；建任务并指派；查看**全部**任务；推进**任意**任务的状态 |
| `member`（普通成员） | 团队成员 | 查看**指派给自己的**任务、推进其状态；查看成员名单（为了知道任务能指派给谁） |
| 系统服务（`task` 应用） | 另一个业务应用 | 建任务时向成员名单要一次「这个人存在吗」 |
| 未认证调用方 | 任何未登录的请求 | **一律禁止**，不得访问任何服务 |

## 2.2 成员名单的权限

| # | 角色 | 可做的操作 | 判定 |
|---|---|---|---|
| PERM-1 | `admin` | 创建成员 | 允许 |
| PERM-2 | `admin` | 查成员详情 | 允许 |
| PERM-3 | `admin` | 查成员列表 | 允许 |
| PERM-4 | `member` | 查成员详情 | 允许（协作需要知道成员是谁） |
| PERM-5 | `member` | 查成员列表 | 允许（要选任务指派对象） |
| PERM-6 | `member` | 创建成员 | **禁止** |
| PERM-7 | 系统服务（`task` 应用） | 查成员详情 | 允许（存在性校验） |
| PERM-8 | 系统服务（`task` 应用） | 查成员列表 | 允许（指派对象选择场景） |
| PERM-9 | 未认证调用方 | 全部功能 | **禁止** |

## 2.3 任务的权限

| # | 角色 | 可做的操作 | 数据范围 |
|---|---|---|---|
| PERM-1 | `admin` | 创建任务 | 全部成员可被指派 |
| PERM-2 | `admin` | 查任务详情 | 全部任务 |
| PERM-3 | `admin` | 查任务列表 | 全部任务 |
| PERM-4 | `admin` | 启动 / 完成 / 退回 | 全部任务 |
| PERM-5 | `member` | 查任务详情 | **仅**指派给自己的任务 |
| PERM-6 | `member` | 查任务列表 | **仅**指派给自己的任务 |
| PERM-7 | `member` | 启动 / 完成 / 退回 | **仅**指派给自己的任务 |
| PERM-8 | 未认证调用方 | 全部服务 | 禁止 |

> ⚠ **数据范围的执法位置**：权限判定与范围过滤由**平台**按「用户 → 角色 → 页面/服务」的授权链执行，
> 业务应用**自身不写鉴权代码**（符合平台约定）。上表是**业务上要求的效果**，
> 不是让应用去 `if role == "admin"`。
>
> 页面侧的表现：普通成员登录后，侧栏里看不到「任务管理」等未授权页；即使手输地址直访，
> 也会**回落到菜单首项**而不是渲染出数据。管理员则能看到全部页面。
