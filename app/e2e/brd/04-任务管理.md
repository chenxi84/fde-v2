# 第4章 任务管理

## 4.1 业务定位

任务单是**事务单据**：一件事从「指派」到「做完」的全过程记录在它身上。
它引用成员编号（不复制成员信息），并用**状态**表达这件事走到哪一步了。

## 4.2 单据与字段

**单据名：任务（`task`）**　标识：`task_no`

| 字段 | 含义 | 业务要求 |
|---|---|---|
| `task_no` | 任务编号 | 系统生成、全局唯一；业务方**不手填** |
| `title` | 任务标题 | 必填、去空白后不得为空、长度 ≤ 200 |
| `description` | 任务描述 | 可选；有值时长度 ≤ 2000 |
| `assignee_member_no` | 指派给谁 | 必填；**必须是名单里存在的成员编号** |
| `priority` | 优先级 | 必填，取值只能是 `low` 或 `high` |
| `status` | 状态 | 系统按状态机写入，业务方不直接改 |
| `created_at` / `updated_at` | 创建时间 / 更新时间 | 系统写入；**每次状态流转都必须刷新 `updated_at`**（用于判断"这事最近有动静吗"） |

## 4.3 业务流程

### 4.3.1 建任务并指派（管理员）

1. 管理员填标题、描述、指派成员编号、优先级。
2. 系统校验字段规则（`R4.1`~`R4.5`）。
3. 系统**向成员名单要一次「这个编号存在吗」**：不存在 → **拒绝创建**（`R4.6`）。
4. 通过 → 生成任务编号、写入记录，**初始状态固定为「待办」**。

> 第 3 步是**先校验再落库**：不允许"先把任务建出来、再提示指派无效"——
> 那样库里会出现指向不存在成员的任务单，事后再没人能判断它该不该存在。

### 4.3.2 任务状态流转

```
待办 --start--> 进行中
进行中 --complete--> 已完成
进行中 --reopen--> 待办
已完成 --start/complete/reopen--> 拒绝（终态）
```

| 动作 | 允许的前置状态 | 结果状态 |
|---|---|---|
| `start`（启动） | 待办 | 进行中 |
| `complete`（完成） | 进行中 | 已完成 |
| `reopen`（退回） | 进行中 | 待办 |

**要点**：
- 每条流转都**只看当前状态**：状态不对就拒绝，且**任务状态保持不变**（不留半截状态）。
- 「已完成」是**终态**：不允许再启动、重复完成或退回。
- 「待办」任务**不能直接完成**，也**不能退回**（它已经是待办）——必须先启动。

### 4.3.3 查询任务

- 按任务编号查详情：查不到即报错。
- 查列表：可按**状态 / 指派成员 / 优先级**筛选，三者可组合（取交集）；无匹配返回空列表。
- 列表需支持**分页**（页码 + 每页条数），并同时给出**切片前的总条数** ——
  「这一页有几条」和「一共几条」是两件事，少一个就画不出翻页控件。

## 4.4 业务规则

> 编号带章节前缀 `R4.x`（理由见第 3 章 §3.4 的说明：不与《应用详设》的 `BR-n` 撞名）。

| 需求条目 | 规则 | 违反时 |
|---|---|---|
| R4.1 | `title` 必填（去空白后非空） | 拒绝 |
| R4.2 | `title` 长度 ≤ 200 | 拒绝 |
| R4.3 | `description` 可选；有值时长度 ≤ 2000 | 拒绝 |
| R4.4 | `priority` 必须在 `low` / `high` 之内 | 拒绝 |
| R4.5 | `assignee_member_no` 必填 | 拒绝 |
| R4.6 | 指派成员**必须存在于成员名单** | 拒绝（跨应用校验） |
| R4.7 | 新建任务初始状态 = 待办 | —— |
| R4.8 | `start` 仅允许从「待办」启动 | 拒绝 |
| R4.9 | `complete` 仅允许从「进行中」完成 | 拒绝 |
| R4.10 | `reopen` 仅允许从「进行中」退回 | 拒绝 |
| R4.11 | 「已完成」任务禁止任何状态流转 | 拒绝 |
| R4.12 | 任务不存在（查/启动/完成/退回） | 拒绝 |
| R4.13 | 状态更新必须刷新 `updated_at` | —— |
| R4.14 | 列表筛选的 `status` / `priority` 必须为合法枚举 | 拒绝 |
| R4.15 | 任务创建后不开放修改正文与删除 | 系统不提供这些操作 |
| R4.16 | 任务编号冲突时以"能生成出唯一编号"为准 | ——（实现细节） |

## 4.5 与其他模块的关系

| 方向 | 关系 |
|---|---|
| 任务 → 成员 | **仅一处**：建任务时校验指派成员存在（`R4.6`）。查询与流转**不再回查成员** |
| 任务 → 其他 | 无 |
