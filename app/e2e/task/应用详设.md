# 任务管理应用（task）— 用户需求规格说明书

| 项目 | 内容 |
|---|---|
| 应用名 | `task` |
| 类名 | `Task` |
| 实体标识 | `task_no` |
| 聚合根卡来源 | 《架构设计：成员任务管理（e2e）》§2.2 `task` / `Task` |
| 单据性质 | 事务单据 |
| 一句话职责 | 管理任务创建、指派、查询与状态流转 |

---

## §1 需求概览

### 1.1 基本信息

| 项目 | 内容 |
|---|---|
| 需求名称 | 成员任务管理—任务事务管理 |
| 所属模块 | `e2e / task` |
| 优先级 | P0 |
| 依赖应用 | `member` |
| 被调服务 | `member.get` |

### 1.2 需求背景

成员任务管理业务需要维护任务单据，支持将任务指派给已存在的成员，并围绕任务状态进行流转管理。`task` 应用作为任务事务单据的聚合根，负责任务的创建、查询、列表检索，以及从“待办”到“进行中”、从“进行中”到“已完成”或退回“待办”的状态推进。

任务创建时必须确保指派成员真实存在，因此 `task.create` 需要跨应用调用 `member.get` 进行成员存在性校验。`member` 作为主数据应用独立维护，`task` 仅通过 `assignee_member_no` 弱引用成员主数据。

### 1.3 需求范围

#### 包含

1. 创建任务。
2. 按任务编号查询任务。
3. 按状态、指派成员、优先级查询任务列表。
4. 启动任务：`待办 -> 进行中`。
5. 完成任务：`进行中 -> 已完成`。
6. 退回任务：`进行中 -> 待办`。
7. 任务状态机约束。
8. 任务创建时调用 `member.get` 校验指派成员是否存在。
9. 任务表字段定义，字段表可直接作为 `_init_db` 建表依据。
10. 业务规则校验，违反规则时抛出 `FdeError`。

#### 不包含

1. 成员主数据创建、修改、删除、查询。
2. 用户认证、登录、会话管理。
3. 权限判定与鉴权执行；权限仅作为需求描述，由平台实现。
4. 任务内容修改、任务删除。
5. 任务评论、附件、标签、子任务、工时记录。
6. 任务批量操作。
7. 任务提醒、通知、消息推送。
8. 报表统计与看板视图。
9. 独立变更单或逆向单据应用。

### 1.4 涉及角色

| 角色 | 说明 |
|---|---|
| `admin` | 管理员，可管理任务并查看全部任务。 |
| `member` | 普通成员，可处理指派给自己的任务，并查看本人相关任务。 |

## §2 用户故事

### US-1 创建任务

**故事描述**：作为管理员，我希望创建一条任务并指派给已存在的成员，以便后续跟踪该成员的工作进展。

**独立测试**：调用 `task.create` 创建任务后，调用 `task.get` 能查询到该任务，且任务初始状态为 `待办`。

**前置条件**：

1. 被指派成员已存在于 `member` 应用。
2. 调用者具备创建任务权限。
3. 标题、优先级、指派成员编号满足业务规则。

**后置条件**：

1. 系统生成全局唯一的 `task_no`。
2. 任务持久化成功。
3. 任务状态为 `待办`。
4. `created_at` 与 `updated_at` 已写入。

#### US-1-AC1 成功创建任务

- **Given** 成员 `M001` 已存在，且调用者具备创建任务权限
- **When** 调用 `create(title="实现登录功能", description="完成账号密码登录", assignee_member_no="M001", priority="high")`
- **Then** 返回任务对象，`task_no` 非空，`status="待办"`，`assignee_member_no="M001"`，`priority="high"`

#### US-1-AC2 标题为空时创建失败

- **Given** 成员 `M001` 已存在
- **When** 调用 `create(title="   ", description="任意描述", assignee_member_no="M001", priority="low")`
- **Then** 抛出 `FdeError`，任务未持久化

#### US-1-AC3 指派成员不存在时创建失败

- **Given** 成员 `M999` 不存在
- **When** 调用 `create(title="实现登录功能", description="完成账号密码登录", assignee_member_no="M999", priority="low")`
- **Then** 抛出 `FdeError`，任务未持久化

#### US-1-AC4 优先级非法时创建失败

- **Given** 成员 `M001` 已存在
- **When** 调用 `create(title="实现登录功能", description="完成账号密码登录", assignee_member_no="M001", priority="urgent")`
- **Then** 抛出 `FdeError`，任务未持久化

### US-2 查询任务

**故事描述**：作为管理员或任务负责人，我希望按任务编号查询任务详情，以便了解任务内容与当前状态。

**独立测试**：先创建任务，再使用返回的 `task_no` 调用 `task.get`，应返回完整任务对象。

**前置条件**：

1. 任务已存在。
2. 调用者具备查询该任务的权限。

**后置条件**：

1. 查询成功时返回任务详情。
2. 查询失败时抛出 `FdeError`。

#### US-2-AC1 成功查询任务

- **Given** 存在任务 `T001`
- **When** 调用 `get(task_no="T001")`
- **Then** 返回任务对象，包含 `task_no`、`title`、`description`、`assignee_member_no`、`priority`、`status`

#### US-2-AC2 查询不存在任务失败

- **Given** 不存在任务 `T999`
- **When** 调用 `get(task_no="T999")`
- **Then** 抛出 `FdeError`

### US-3 查询任务列表

**故事描述**：作为管理员或普通成员，我希望按状态、负责人、优先级筛选任务列表，以便快速找到需要处理的任务。

**独立测试**：准备多条不同状态、负责人、优先级的任务，调用 `task.list` 按条件筛选，返回结果应满足筛选条件。

**前置条件**：

1. 系统中存在任务数据。
2. 调用者具备列表查询权限。
3. 若传入筛选条件，枚举值必须合法。

**后置条件**：

1. 查询成功时返回任务列表。
2. 无匹配数据时返回空列表，不抛错。

#### US-3-AC1 按状态查询

- **Given** 存在状态为 `待办` 和 `进行中` 的任务
- **When** 调用 `list(status="待办")`
- **Then** 返回的所有任务 `status="待办"`

#### US-3-AC2 按指派成员查询

- **Given** 存在指派给 `M001` 和 `M002` 的任务
- **When** 调用 `list(assignee_member_no="M001")`
- **Then** 返回的所有任务 `assignee_member_no="M001"`

#### US-3-AC3 按优先级查询

- **Given** 存在 `low` 和 `high` 优先级任务
- **When** 调用 `list(priority="high")`
- **Then** 返回的所有任务 `priority="high"`

#### US-3-AC4 组合条件查询

- **Given** 存在多条任务
- **When** 调用 `list(status="进行中", assignee_member_no="M001", priority="high")`
- **Then** 返回的所有任务同时满足 `status="进行中"`、`assignee_member_no="M001"`、`priority="high"`

#### US-3-AC5 无匹配数据

- **Given** 不存在满足条件的任务
- **When** 调用 `list(status="已完成", assignee_member_no="M001")`
- **Then** 返回空列表，不抛出 `FdeError`

## §3 业务场景

### 3.1 业务流程描述

1. 管理员创建任务，填写任务标题、描述、指派成员编号与优先级。
2. 系统校验标题、优先级、指派成员编号等业务规则。
3. 系统调用 `member.get` 校验 `assignee_member_no` 对应成员是否存在。
4. 校验通过后，系统生成全局唯一 `task_no`，并将任务初始状态置为 `待办`。
5. 任务负责人或管理员查询任务详情或任务列表。
6. 对 `待办` 任务执行 `start`，状态流转到 `进行中`。
7. 对 `进行中` 任务执行 `complete`，状态流转到 `已完成`。
8. 对 `进行中` 任务执行 `reopen`，状态退回 `待办`。
9. `已完成` 任务禁止再执行任何状态流转操作。

### 3.2 状态机

```text
待办 --start--> 进行中
进行中 --complete--> 已完成
进行中 --reopen--> 待办
已完成 --禁止 start/complete/reopen--> 已完成
```

### 3.3 业务规则

| 编号 | 规则 | 校验点 | 违反处理 |
|---|---|---|---|
| BR-1 | `title` 必填 | `title.strip()` 后长度必须大于 0 | 抛 `FdeError` |
| BR-2 | `title` 长度受限 | `title` 长度不得超过 200 | 抛 `FdeError` |
| BR-3 | `description` 可选但长度受限 | `description` 为空允许；非空时长度不得超过 2000 | 抛 `FdeError` |
| BR-4 | `priority` 枚举合法 | 取值必须为 `low` 或 `high` | 抛 `FdeError` |
| BR-5 | `assignee_member_no` 必填 | `assignee_member_no.strip()` 后长度必须大于 0 | 抛 `FdeError` |
| BR-6 | 指派成员必须存在 | `task.create` 调用 `self.fde.call('member.get', member_no=assignee_member_no)`，返回结果必须存在 | 抛 `FdeError` |
| BR-7 | `task_no` 全局唯一 | 系统生成任务编号，落库前唯一性校验；冲突时重新生成或失败 | 抛 `FdeError` |
| BR-8 | 任务初始状态固定 | `task.create` 成功后 `status` 必须为 `待办` | 抛 `FdeError` |
| BR-9 | `status` 枚举合法 | 取值必须为 `待办`、`进行中`、`已完成` | 抛 `FdeError` |
| BR-10 | `start` 仅允许从待办启动 | 执行 `start` 前，任务当前状态必须为 `待办` | 抛 `FdeError` |
| BR-11 | `complete` 仅允许从进行中完成 | 执行 `complete` 前，任务当前状态必须为 `进行中` | 抛 `FdeError` |
| BR-12 | `reopen` 仅允许从进行中退回 | 执行 `reopen` 前，任务当前状态必须为 `进行中` | 抛 `FdeError` |
| BR-13 | 已完成任务禁止状态流转 | `status="已完成"` 时禁止 `start`、`complete`、`reopen` | 抛 `FdeError` |
| BR-14 | 状态操作前任务必须存在 | `get`、`start`、`complete`、`reopen` 传入的 `task_no` 必须存在 | 抛 `FdeError` |
| BR-15 | 状态变更必须更新时间 | `start`、`complete`、`reopen` 成功后必须更新 `updated_at` | 抛 `FdeError` |
| BR-16 | 列表筛选枚举合法 | `list` 传入 `status` 时必须为合法状态；传入 `priority` 时必须为合法优先级 | 抛 `FdeError` |

## §4 功能清单 + 字段表

### 4.1 功能清单

| 功能编号 | 功能 | 服务 | 说明 |
|---|---|---|---|
| FUNC-1 | 创建任务 | `create` | 创建任务，初始状态为 `待办` |
| FUNC-2 | 查询任务详情 | `get` | 按 `task_no` 查询任务 |
| FUNC-3 | 查询任务列表 | `list` | 按状态、负责人、优先级筛选任务 |
| FUNC-4 | 启动任务 | `start` | `待办 -> 进行中` |
| FUNC-5 | 完成任务 | `complete` | `进行中 -> 已完成` |
| FUNC-6 | 退回任务 | `reopen` | `进行中 -> 待办` |

### 4.2 实体字段表

> 本表直接作为 `_init_db` 建表依据。

| 实体 | 表名 | 主键 | 单据性质 |
|---|---|---|---|
| `Task` | `task` | `task_no` | 事务单据 |

| 字段名 | 类型 | 约束 | 说明 |
|---|---|---|---|
| `task_no` | TEXT | PRIMARY KEY, NOT NULL, UNIQUE | 任务编号，系统生成，全局唯一 |
| `title` | TEXT | NOT NULL, LENGTH >= 1, LENGTH <= 200 | 任务标题 |
| `description` | TEXT | NULLABLE, LENGTH <= 2000 | 任务描述，可选 |
| `assignee_member_no` | TEXT | NOT NULL, INDEX | 指派成员编号，逻辑引用 `member.member_no`，不建物理外键 |
| `priority` | TEXT | NOT NULL, CHECK (`priority` IN ('low','high')) | 优先级，取值 `low` / `high` |
| `status` | TEXT | NOT NULL, DEFAULT '待办', CHECK (`status` IN ('待办','进行中','已完成')) | 任务状态 |
| `created_at` | DATETIME | NOT NULL, DEFAULT CURRENT_TIMESTAMP | 创建时间，创建时写入 |
| `updated_at` | DATETIME | NOT NULL, DEFAULT CURRENT_TIMESTAMP | 更新时间，状态变更时由应用刷新 |

### 4.3 索引需求

| 索引名 | 字段 | 用途 |
|---|---|---|
| `idx_task_assignee_member_no` | `assignee_member_no` | 按指派成员查询任务 |
| `idx_task_status` | `status` | 按状态查询任务 |
| `idx_task_priority` | `priority` | 按优先级查询任务 |
| `idx_task_status_assignee` | `status`, `assignee_member_no` | 按状态与负责人组合查询 |

### 4.4 对外服务签名

| 服务 | 签名 | 返回 | 说明 |
|---|---|---|---|
| `create` | `create(title: str, description: str | None, assignee_member_no: str, priority: str) -> dict` | 任务对象 | 创建任务；初始状态为 `待办` |
| `get` | `get(task_no: str) -> dict` | 任务对象 | 按任务编号查询任务 |
| `list` | `list(status: str | None = None, assignee_member_no: str | None = None, priority: str | None = None) -> list[dict]` | 任务对象列表 | 按条件查询任务列表 |
| `start` | `start(task_no: str) -> dict` | 任务对象 | 将任务从 `待办` 推进到 `进行中` |
| `complete` | `complete(task_no: str) -> dict` | 任务对象 | 将任务从 `进行中` 推进到 `已完成` |
| `reopen` | `reopen(task_no: str) -> dict` | 任务对象 | 将任务从 `进行中` 退回到 `待办` |

### 4.5 返回对象字段

任务对象至少包含以下字段：

| 字段 | 类型 | 说明 |
|---|---|---|
| `task_no` | str | 任务编号 |
| `title` | str | 任务标题 |
| `description` | str / None | 任务描述 |
| `assignee_member_no` | str | 指派成员编号 |
| `priority` | str | 优先级 |
| `status` | str | 任务状态 |
| `created_at` | datetime | 创建时间 |
| `updated_at` | datetime | 更新时间 |

### 4.6 跨应用依赖

| 本应用服务 | 被调应用.服务 | 调用方式 | 用途 | 失败处理 |
|---|---|---|---|---|
| `task.create` | `member.get` | `self.fde.call('member.get', member_no=assignee_member_no)` | 校验指派成员是否存在 | 成员不存在或调用失败时抛 `FdeError` |
