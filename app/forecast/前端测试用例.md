## §5 壳启动与菜单序

- **VT-SHELL-01 壳启动渲染**
  - 页面：`forecast:dashboard`
  - 前置造数：无（壳基于 `/api/view_boot` 动态装配）
  - 操作：admin 登录 → 进入 `/view/forecast/`
  - 断言：侧栏品牌区可见「FDE·FORECAST」；菜单项含「📊 首页看板」+ 全部应用页（按 order 升序）；主区默认渲染 dashboard
  - 选择器注意：侧栏 `.side` 内菜单项按 order 排序

- **VT-SHELL-02 菜单序验证**
  - 页面：`forecast:dashboard`
  - 操作：检查侧栏菜单项顺序
  - 断言：菜单顺序 = 首页看板(order=10) → 预测快照(20) → 统计基线(30) → 预测加工(40) → 零件级处理(50) → 毛需求发布(60) → 主数据段(110-170)
  - 选择器注意：`.side nav a` 按 DOM 序 = order 升序

## §7 受限用户菜单收敛

- **VT-PERM-01 受限角色仅授权看板+1应用**
  - 页面：受限会话
  - 前置造数：管理页创建角色 `limited_role`，授权页面 `forecast:dashboard` + `forecast:forecast_snapshot` + `_platform:agent`
  - 操作：受限用户登录 → 进入 `/view/forecast/`
  - 断言：菜单仅含「📊 首页看板」「📷 预测快照」「🤖 Agent」三项；主区默认渲染 dashboard
  - 选择器注意：受限用户菜单收敛 = 仅授权页 + 平台页

- **VT-PERM-02 直访无授权路由回落菜单首项**
  - 页面：受限会话
  - 前置造数：同上
  - 操作：受限用户直访 `#/forecast_baseline`（未授权页）
  - 断言：页面回落至 `#/dashboard`（菜单首项）；无 403 toast（403 属预期执法豁免）
  - 选择器注意：hash 变化后检查主区内容是否回到看板

- **VT-PERM-03 授权页隐式放行有数据**
  - 页面：受限会话 → `forecast:forecast_snapshot`
  - 前置造数：admin 先经 `forecast_snapshot.open_version` + `fill` 造数
  - 操作：受限用户进入 `#/forecast_snapshot`
  - 断言：列表有数据（svc 经 X-Fde-Page 隐式放行成功）；无 403 error
  - 选择器注意：`page.wait_for_selector("table.tbl tr.data")`

## §8 Dashboard 页渲染

- **VT-DASH-01 看板渲染有 .kpi**
  - 页面：`forecast:dashboard`
  - 前置造数：admin 造完整业务链数据（快照+基线+加工）
  - 操作：admin 进入 `#/dashboard`
  - 断言：页面含 `.kpi` 元素（KPI 卡片）；KPI 卡片数 >= 4；管道卡片含表格行；待办卡片含按钮
  - 选择器注意：看板页有 .kpi（与非看板页相反）

- **VT-DASH-02 看板 quiet 探测零值兜底**
  - 页面：`forecast:dashboard`（空库）
  - 前置造数：无（首次进入）
  - 操作：admin 进入 `#/dashboard`
  - 断言：页面渲染不报错；KPI 卡片显示"—"或"暂无数据"；管道卡片显示空态
  - 选择器注意：无数据时不喷 toast（quiet 模式）

## §9 组级会话 0 报错

- **VT-ERR-01 admin 全流程 0 报错**
  - 页面：admin 会话（壳 + 各页切换）
  - 操作：admin 登录 → dashboard → forecast_snapshot → forecast_baseline → forecast_processing → part_level_adj → demand_release → 逐主数据页
  - 断言：全程 0 console error / 0 pageerror / 0 HTTP≥400（favicon 除外）
  - 选择器注意：`page.on("console")` 收集 error 级别；`page.on("pageerror")` 收集未捕获异常

- **VT-ERR-02 受限会话 0 报错（403 豁免）**
  - 页面：受限会话
  - 操作：受限用户登录 → dashboard → 授权页
  - 断言：0 console error / 0 pageerror；HTTP 403 属预期执法豁免
  - 选择器注意：受限用户的 403 不纳入报错统计（pitfalls #38）
