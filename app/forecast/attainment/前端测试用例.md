# attainment 前端测试用例

> 页面：forecast:attainment

## §0 测试数据字典（本页自足）

| 标识 | 造数服务 | 参数 |
|------|---------|------|
| C1 | md_customer.create | oem_code=OEM-A, plant_code=PLT-A1, oem_name=主机厂A, plant_name=一工厂, settle_mode=寄售 |
| M1 | md_material.create | part_no=8210001, part_name=前保险杠总成, uom=件, mat_type=成品 |
| PRJ | md_project.create | project_no=PRJ-001, project_name=车型A, stage=进行中, oem_code=OEM-A, plant_code=PLT-A1 |
| PP | md_project_part.create | project_no=PRJ-001, part_no=8210001, usage=1, share=1.0 |
| VER | md_fcst_version.create | fcst_version=202608, base_period=2026-08, periods=["2026-09","2026-10","2026-11"] |
| SNAP | forecast_snapshot.open_version | fcst_version=202608 |
| ATTN | attainment.compute_batch | fcst_version=202608 |
> 注：attainment 数据由 compute_batch 自动生成，前端无创建入口。compute_batch 依赖 forecast_snapshot.open_version 生成的快照数据。

## §1 渲染

- **VT-RENDER-01 路由渲染有内容**
  - 页面：forecast:attainment
  - 操作：admin 进入 `#/attainment`
  - 断言：`.card` > 0；列表三段式（过滤条 + 表格 + 分页区域）可见；**无 `.kpi`**（防粘滞）；**无「新建」按钮**（前端禁止创建入口）
  - 选择器注意：`:visible` 限定

## §2 造数后列表有数据

- **VT-LIST-01 compute_batch 后列表有数据**
  - 前置造数：经 REST 依次调用 C1+M1+PRJ+PP → VER → SNAP → ATTN
  - 操作：刷新页面 `#/attainment`
  - 断言：`table.tbl tr.data` 行数 >= 1；含 oem_code=OEM-A / period=2026-09 / horizon 徽章 / snap_qty / settle_qty / attain_rate / conf_factor / gen_batch 齐全
  - 选择器注意：精确 `has_text("OEM-A")` 定位行

- **VT-LIST-02 过滤生效**
  - 前置造数：同 VT-LIST-01
  - 操作：horizon chips 选「H1」
  - 断言：仅显示 horizon=H1 的行
  - 选择器注意：chips 点击后等待列表刷新

- **VT-LIST-03 客户名称回显**
  - 操作：检查 OEM-A 行
  - 断言：oem_code 列附客户名称小字「主机厂A」（custMap quiet 拉取回显）

## §3 模态全字段

- **VT-MODAL-01 详情模态全字段**
  - 前置造数：同 VT-LIST-01
  - 操作：点击 oem_code=OEM-A 的 `.b-link` → `wait_modal()` 等 `.loadbox` 消失
  - 断言：模态含 H1/H2/H3 三行子表各字段 snap_qty / settle_qty / attain_rate / conf_factor；头带含 oem_code + period；原始数据可展开；页脚仅「关闭」按钮，无任何写操作按钮
  - 选择器注意：多 `.modal-bd` 用 `.first`；`:visible` 限定

## §4 无创建入口

- **VT-NO-CREATE-01 无创建入口确认**
  - 操作：检查页面工具栏
  - 断言：无「新建」/「+ 创建」按钮；列表行内无编辑/删除操作列；详情模态页脚仅「关闭」
  - 说明：数据来源类型为「自动参考创建」——达成率/置信度由月度闭环 compute_batch 自动生成

- **VT-COMPUTE-01 批量计算触发**
  - 前置造数：C1+M1+PRJ+PP+VER+SNAP 存在
  - 操作：点击工具栏「批量计算」→ 输入 fcst_version=202608 → 确认
  - 断言：loading 期间按钮不可点击；toast 含『批量计算完成』及处理摘要（N 条记录 / M 个客户）；列表刷新有数据
  - 选择器注意：确认弹窗 `:visible` 限定

## §6 0 报错

- **VT-ERR-01 本会话 0 报错**
  - 操作：完成上述全部测试步骤
  - 断言：本脚本会话全程 0 console error / 0 pageerror / 0 HTTP>=400（favicon 除外）
