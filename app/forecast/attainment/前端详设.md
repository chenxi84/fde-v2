# 达成率与置信度 前端详设
> 来源：app/forecast/_contracts.md（冻结契约）+ app/forecast/attainment/应用详设.md
> 落位：`app/forecast/attainment/view.js` + `view.html`

## 1. 页面元数据 PAGE_META

| 字段 | 值 | 说明 |
|---|---|---|
| key | `attainment` | = 应用文件夹名，page_id 为 `forecast:attainment` |
| name | 达成率置信度 | 侧栏菜单名 |
| ic | 🎯 | 图标字 |
| title | 达成率与置信度 | 主区页面头标题 |
| crumb | 月度闭环自动生成·分horizon | 副题·要点 |
| order | 170 | 升序即菜单序 |

页面零鉴权：无任何权限判断；菜单按页面授权渲染在 shell，数据范围由后端闸门执法，401 由 api.js 自动跳登录。

**数据来源类型：自动参考创建**——达成率/置信度由月度闭环的 `compute_batch` 自动生成，**前端禁止创建入口**。页面仅提供列表查询 + 批量计算触发 + 置信系数展示。

## 2. 区块构成

### 2.1 列表区（查）—— 三段式：工具栏 / 表格 / 分页条

**用途**：达成率与置信度数据浏览 + 条件筛选 + 批量计算触发。本页为非看板页，不设 KPI 指标带（验收断言无 `.kpi`）。

**过滤控件（与 `attainment.list(oem_code, period, horizon, page, page_size)` 可过滤参数一一对应）**：

| 控件 | 对应参数 | 形态 |
|---|---|---|
| 客户编码输入框 | `oem_code` | placeholder「客户编码」，Enter 或「查询」按钮触发（后端 LIKE 模糊匹配） |
| 期间输入框 | `period` | placeholder「如 2026-09」，Enter 或「查询」按钮触发（精确匹配） |
| horizon chips | `horizon` | 全部 / H1 / H2 / H3，单选互斥，点击即查（精确匹配） |
| 分页条 | `page` / `page_size` | `pageable()`，integer 传参 |

**工具栏**：「查询」「批量计算」（打开触发确认模态，见 §2.4）。

**表格列（`.tbl.tight` + `.scroll-x`；全部为详情字段子集）**：

| 列 | 字段 | 渲染 |
|---|---|---|
| 客户编码 | `oem_code` | `.b-link`，点击打开详情模态 |
| 期间 | `period` | 文本 |
| 预测提前期 | `horizon` | `hue()` 徽章（H1=蓝 / H2=黄 / H3=灰） |
| 快照原始量 | `snap_qty` | `fmt()` 数字 |
| 结算实际量 | `settle_qty` | `fmt()` 数字，0 值 `dash()` |
| 达成率 | `attain_rate` | 百分比 `fmt()`；<0.9 行高亮（越阈提示）；0 值 `dash()` |
| 置信系数 | `conf_factor` | `fmt()` 小数；[0.8, 1.2] 区间；默认 1.0 |
| 生成批次 | `gen_batch` | 文本，空值 `dash()` |
| 操作 | — | 无行内操作（只读数据，无编辑/删除） |

**交互**：任一过滤变化 → 重置回第 1 页重载；批量计算完成后刷新列表；空结果显示空态文案。**无新建/编辑/删除入口**。

### 2.2 详情模态（查全）—— 三段式：墨青头带 / KV 分组体 / 操作页脚

**用途**：点 `oem_code` 弹出，展示 `attainment.get` 返回的全部字段（同一客户+期间的全部 horizon 记录）。

| 分组（`.sec`） | 字段 | 渲染 |
|---|---|---|
| 头带 | `oem_code` + `period` | 墨青头带 |
| H1 达成率 | H1 行：`snap_qty` / `settle_qty` / `attain_rate` / `conf_factor` | 子表格行（或 `.kv` 分组），`hue()` horizon 标记 |
| H2 达成率 | H2 行：同上 | 子表格行 |
| H3 达成率 | H3 行：同上 | 子表格行 |
| 元数据 | `gen_batch` | `.kv`，空值 `dash()` |
| 原始数据 | get 返回全量 JSON | 底部折叠（默认收起） |

**页脚 `.modal-ft`**：仅「关闭」按钮（无写操作可放）。

### 2.3 创建 / 编辑

**无**。数据来源类型为「自动参考创建」——达成率/置信度由月度闭环的 `compute_batch` 自动生成，前端不提供创建/编辑/删除入口。

### 2.4 批量计算触发（compute_batch）

**用途**：工具栏「批量计算」按钮 → 弹出确认模态 → 调 `attainment.compute_batch`。

- 点击「批量计算」→ 弹出输入框让用户填写 `fcst_version`（如 202608），附带说明文字「此操作将触发月度闭环计算：遍历指定版本下所有有快照数据的客户，分 horizon 计算达成率与置信系数」
- 确认后调用 `svc("attainment","compute_batch")` `{fcst_version}`。
- 成功后 toast「批量计算完成，共处理 N 条记录，覆盖 M 个客户」→ 刷新列表。
- 此操作可能有较长耗时（遍历客户 x 期间），按钮提交期 loading + toast 提示「正在计算，请稍候...」。

## 3. svc 字面量清单（授权派生依据——必须字面量 svc("应用","服务")）

| 区块 | 调用（应用.服务） | 参数 | quiet | 说明 |
|---|---|---|---|---|
| 列表区 | `svc("attainment","list")` | `{oem_code, period, horizon, page, page_size}` | — | 分页查询，按 oem_code/period/horizon 排序 |
| 客户下拉 | `svc("md_customer","list")` | `{page:1, page_size:200}` | true | quiet 探测，用于列表客户名称回显（`custMap`） |
| 详情模态 | `svc("attainment","get")` | `{oem_code, period}` | — | 全字段详情，返回至多 3 条 H1/H2/H3 |
| 批量计算 | `svc("attainment","compute_batch")` | `{fcst_version}` | — | 月度闭环触发；按钮提交 |
| 置信系数（系统内部） | `svc("attainment","get_conf_factor")` | `{oem_code, period}` | — | 供加工表跨应用调用，非页面功能；返回值默认为 1.0 |

> 以上 5 处必须在 view.js 中以字面量逐项书写，**勿用变量拼名**。

## 4. 数据来源与下拉

**客户名称回显（列表区）**：
- 页面初始化一次性 `svc("md_customer","list")` `{page:1, page_size:200}`，`quiet:true` 探测：失败不喷 toast。
- 由返回项构建 `custMap = {oem_code: {oem_name, plant_code}}`，供列表「客户编码」列附客户名小字回显。

**horizon 下拉**：静态枚举（H1 / H2 / H3），来源：建表 CHECK。

**契约 payload → 区块字段映射**：

| 契约 | 载荷字段 | 映射区块 |
|---|---|---|
| `attainment.list` 返回项 | `oem_code, period, horizon, snap_qty, settle_qty, attain_rate, conf_factor, gen_batch` | 2.1 列表列 |
| `attainment.get` 返回 | 同上（H1/H2/H3 各一条） | 2.2 详情模态三 horizon 子表 + 原始数据 |
| `attainment.compute_batch` 入参 | `fcst_version` | 2.4 批量计算触发 |
| `md_customer.list` 项 | `oem_code, oem_name` | 列表客户名称回显（custMap） |

- `attaining_rate` 和 `conf_factor` 为小数（如 0.974、0.85），前端用 `fmt()` 格式化为百分比展示；0 值用 `dash()`。
- `snap_qty` / `settle_qty` 为实数，用 `fmt()` 千分位格式化。

## 5. 交互要点

1. **加载**：首载正常拉取 list（非看板页，失败走 api.js 统一通道）+ quiet 拉取 md_customer.list 构建客户名称映射。
2. **过滤**：horizon chips 点击即查并重置 `page=1`；oem_code / period 输入后 Enter 或「查询」触发；翻页仅改 `page/page_size`，不清过滤条件。
3. **只读页面**：列表无新建/编辑/删除按钮，行内无操作列；详情模态页脚仅「关闭」。数据来源类型为「自动参考创建」。
4. **批量计算触发**：工具栏「批量计算」→ 输入 fcst_version → 确认 → loading → toast 结果摘要 → 刷新列表。
5. **越阈高亮**：达成率 `attain_rate < 0.9` 的行高亮（如浅红色背景），供月度复盘快速定位。
6. **微交互**：表格行 hover 高亮；oem_code `.b-link` hover 下划线；horizon 徽章 `hue()` 着色；attain_rate 百分比 `fmt()` 格式化显示。
7. **成功流**：compute_batch 成功 → toast「批量计算完成」→ 列表刷新。
8. **错误流**：compute_batch 失败（如取快照数据失败）→ 后端 `FdeError` toast。
9. **空态**：无任何达成率数据时「暂无达成率数据 —— 点击『批量计算』触发月度闭环计算生成」；过滤无命中时「无符合条件的达成率记录」。
10. **展示工具**：`hue()`（horizon 徽章）、`fmt()`（snap_qty / settle_qty / attain_rate / conf_factor）、`dash()`（0 值 / 空值）、不需要 `tryParse()`（无 `*_json` 字段）、不需要 `fmtTime()`（无时间字段）。

## 6. 验收关注点（供第⑧步）

1. **路由渲染**：`#/attainment` 挂载出列表三段式（工具栏 + 表格 + 分页条），**断言无 `.kpi`**（非看板页防挂载粘滞假过）。**断言无「新建」按钮**（BR-06 前端禁止创建入口）。
2. **造数后列表有数据**：通过 REST 直接插入 attainment 记录（或调 compute_batch 触发生成）→ 列表有数据，oem_code / period / horizon 徽章 / snap_qty / settle_qty / attain_rate / conf_factor / gen_batch 齐全。
3. **过滤一一对应**：horizon=H1 chips 仅 H1 行；oem_code=OEM 模糊匹配；period=2026-09 精确匹配；组合条件；无匹配显示空态且不抛错。
4. **模态全字段**：点 oem_code 开模态，断言 H1/H2/H3 三行子表各字段齐全 + 「原始数据」可展开；页脚仅「关闭」，无任何操作按钮。
5. **无创建入口**：页面工具栏无「新建」按钮；列表无行内编辑/删除操作。
6. **批量计算**：工具栏「批量计算」→ 输入 fcst_version → 确认 → toast 摘要 → 列表刷新有数据。
7. **越阈高亮**：attain_rate < 0.9 的行有视觉高亮。
8. **客户名称回显**：oem_code 列表列附客户名称小字（custMap 命中时）。
9. **干净控制台**：全程 0 console error / 0 pageerror / 0 HTTP>=400（受限会话 403 属预期执法单独豁免）。
