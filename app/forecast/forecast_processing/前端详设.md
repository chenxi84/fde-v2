## 2. 区块构成

### 2.1 列表区（批次列表）
**过滤控件**：
| 控件 | 参数 | 选项 |
|------|------|------|
| 版本下拉 | fcst_version | md_fcst_version.list quiet |
| 状态 chips | status | 全部 / 进行中 / 全部核定 / 已锁定 |
| 分页 | page/page_size | pageable() |

**批次表格列**：
| 列 | 字段 | 渲染 |
|----|------|------|
| 批次号 | prc_batch | `.b-link` 点击进入明细视图 |
| 基线批次 | base_batch | 正文 |
| 版本 | fcst_version | 正文 |
| 状态 | status | hue() 徽章 |
| 负责人 | owner | 正文 |
| 创建时间 | created_at | fmtTime() |
| 操作 | — | x-show=status!=='已锁定' → 【核定】【锁定】 |

### 2.2 明细视图（点击批次号进入）
**过滤控件**：
| 控件 | 参数 |
|------|------|
| 客户下拉 | oem_code |
| 零件搜索 | part_no |
| 核定状态 chips | chk_result（全部/通过/退回/未核定） |
| 分页 | page/page_size |

**明细表格列**（宽表 `.scroll-x`）：
| 列 | 字段 | 渲染 |
|----|------|------|
| 客户 | oem_code+plant_code | 双行 |
| 物料 | part_no | `.b-link` 开编辑模态 |
| 期间 | period | 正文 |
| 基线值 | base_qty | fmt() |
| 客户预测 | cust_qty | fmt() |
| 置信度调整 | conf_adj | fmt() 带符号 |
| 趋势调整 | trend_adj | fmt() 带符号 |
| 一次性调整 | onetime_adj | fmt() 带符号 + onetime_tag 小标签 |
| 独立需求 | indep_qty | **fmt() 加粗** |
| 核定 | chk_result | hue() 徽章（通过=绿/退回=红/空=灰） |
| 操作 | — | x-show=status!=='已锁定' → 【填调整】【核定】 |

### 2.3 编辑模态（填调整）
打开为模态内表单：
| 字段 | 控件 | 必填 | 说明 |
|------|------|------|------|
| conf_adj | input number | — | 置信度调整 delta |
| conf_reason | input text | 条件 | conf_adj 不为0时必填 |
| trend_adj | input number | — | 趋势调整 delta |
| trend_reason | input text | 条件 | trend_adj 不为0时必填 |
| onetime_adj | input number | — | 一次性调整 delta |
| onetime_reason | input text | 条件 | onetime_adj 不为0时必填 |
| onetime_tag | select | — | 一次性/大一次性/断点 |

**只读展示**：base_qty / cust_qty / indep_qty（系统强制加和，不可手工改）
**indep_qty 实时预览**：= base_qty + conf_adj + trend_adj + onetime_adj

### 2.4 创建批次
列表顶部【创建加工批次】按钮 → 输入 base_batch + fcst_version → 调 create_batch

### 2.5 一次性行附加
批次详情页【附加一次性行】→ 输入 oem_code/plant_code/part_no/period + onetime_adj/onetime_reason/onetime_tag

## 3. svc 字面量清单

| 区块 | 调用 | 参数 |
|------|------|------|
| 批次列表 | `svc("forecast_processing","list_batches")` | `{fcst_version, status, page, page_size}` |
| 版本下拉 | `svc("md_fcst_version","list")` | `{page:1, page_size:50}` quiet |
| 明细列表 | `svc("forecast_processing","list_lines")` | `{prc_batch, oem_code, part_no, chk_result, page, page_size}` |
| 客户下拉 | `svc("md_customer","list")` | `{page:1, page_size:200}` quiet |
| 批次详情 | `svc("forecast_processing","get")` | `{prc_batch}` |
| 创建批次 | `svc("forecast_processing","create_batch")` | `{base_batch, fcst_version}` |
| 填调整 | `svc("forecast_processing","fill_line")` | `{prc_batch, oem_code, plant_code, part_no, period, conf_adj, conf_reason, trend_adj, trend_reason, onetime_adj, onetime_reason, onetime_tag}` |
| 核定 | `svc("forecast_processing","review_line")` | `{prc_batch, oem_code, plant_code, part_no, period, chk_result, chk_comment}` |
| 锁定 | `svc("forecast_processing","finalize")` | `{prc_batch}` |
| 附加一次性 | `svc("forecast_processing","add_onetime_line")` | `{prc_batch, oem_code, plant_code, part_no, period, onetime_adj, onetime_reason, onetime_tag}` |

## 4. 数据来源
- 版本下拉：md_fcst_version.list
- 客户下拉：md_customer.list
- 基线批次：从 forecast_baseline 列表取

## 5. 交互要点
1. indep_qty 实时预览：表单内调整量变化时自动计算显示
2. 核定退回须附理由：chk_result=退回时弹出 chk_comment 必填
3. 锁定确认：全部行通过才可锁定，否则 toast 错误
4. 退回行红底高亮

## 6. 验收关注点
1. 渲染：批次列表 + 点击进入明细视图
2. 创建批次后列表有数据
3. 填调整落库：indep_qty 自动计算正确
4. 核定→锁定 全流程
5. 未全部核定锁定被拒：FdeError toast
6. 0 报错
