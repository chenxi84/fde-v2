# forecast_processing 前端测试用例
> 页面：forecast:forecast_processing

## §0 测试数据字典
依赖 forecast_baseline §0 字典全部 + PRC1=加工批次号（从 create_batch 返回值捕获）

## §1 渲染
- **VT-RENDER-01** 路由 `#/forecast_processing` 批次列表三段式，**无 `.kpi`**

## §2 列表
- **VT-LIST-01** 经 REST `forecast_processing.create_batch(base_batch=B202608, fcst_version=202608)` 造数 → 批次列表含新批次，status=进行中
- **VT-LIST-02** 点击批次号进入明细视图 → 明细表格含 base_qty/cust_qty/conf_adj/indep_qty 列

## §3 模态
- **VT-MODAL-01** 明细视图点击 part_no → 模态含 base_qty/cust_qty/conf_adj/trend_adj/onetime_adj/indep_qty/chk_result（indep_qty = 加和显示）
- **VT-MODAL-02** 页脚按 status 显示核定/锁定按钮

## §4 表单
- **VT-FORM-01** 填调整：conf_adj=10, conf_reason=达成率97.5% → 提交 → indep_qty 自动更新为 base_qty+10
- **VT-FORM-02** 填一次性：onetime_adj=180, onetime_reason=客户加库存, onetime_tag=大一次性 → indep_qty = base_qty+10+180
- **VT-FORM-03** 核定通过 → chk_result=通过 徽章绿
- **VT-FORM-04** 退回须理由：chk_result=退回 无理由 → toast 含『必须附理由』
- **VT-FORM-05** 全部核定→锁定：全部行 chk_result=通过 → finalize → status=已锁定
- **VT-FORM-06** 未全核定锁定被拒 → FdeError toast 含『未通过核定』

## §6 0 报错
- **VT-ERR-01** 本会话 0 console error / 0 pageerror / 0 HTTP≥400
