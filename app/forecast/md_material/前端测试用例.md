# md_material 前端测试用例

> 页面：forecast:md_material

## §0 测试数据字典（本页自足）

| 标识 | 造数服务 | 参数 |
|------|---------|------|
| M1 | md_material.create | part_no=8210001, part_name=前保险杠总成, uom=件, mat_type=成品 |
| M2 | md_material.create | part_no=8210002, part_name=后保险杠总成, uom=件, mat_type=半成品 |

## §1 渲染

- **VT-RENDER-01 路由渲染有内容**
  - 页面：forecast:md_material
  - 操作：admin 进入 `#/md_material`
  - 断言：`.card` > 0；列表三段式（过滤条 + 表格 + 分页区域）可见；**无 `.kpi`**（防粘滞）
  - 选择器注意：`:visible` 限定

## §2 造数后列表有数据

- **VT-LIST-01 造数后列表有数据**
  - 前置造数：经 REST 调用 `md_material.create` 创建 M1、M2
  - 操作：刷新页面 `#/md_material`
  - 断言：`table.tbl tr.data` 行数 >= 2；含 part_no=8210001 且 mat_type 徽章显示「成品」
  - 选择器注意：精确 `has_text("8210001")` 定位行

- **VT-LIST-02 过滤生效**
  - 前置造数：同 VT-LIST-01
  - 操作：mat_type chips 选「成品」
  - 断言：仅显示成品行（8210001）；8210002 不可见
  - 选择器注意：chips 点击后等待列表刷新

- **VT-LIST-03 模糊搜索生效**
  - 操作：part_name 输入框填入「保险杠」→ 点击「查询」
  - 断言：M1 和 M2 均可见（模糊匹配命中）

## §3 模态全字段

- **VT-MODAL-01 详情模态全字段**
  - 前置造数：同 VT-LIST-01
  - 操作：点击 part_no=8210001 的 `.b-link` → `wait_modal()` 等 `.loadbox` 消失
  - 断言：模态含字段 part_no / part_name / uom / mat_type；头带含 mat_type 徽章；原始数据可展开
  - 选择器注意：多 `.modal-bd` 用 `.first`；`:visible` 限定

## §4 表单落库回显

- **VT-FORM-01 创建落库**
  - 操作：点击「+ 新建物料」→ 填写 part_no=8210003, part_name=侧围外板, uom=件, mat_type=成品 → 提交
  - 断言：toast 含『物料主数据创建成功』；列表刷新后含 8210003 行
  - 选择器注意：`:visible` 限定表单控件

- **VT-FORM-02 空必填字段被拒**
  - 操作：点击「+ 新建物料」→ part_no 留空 → 提交
  - 断言：toast 警告『必填』且不发请求；模态保持打开
  - 选择器注意：toast 选择器

- **VT-FORM-03 mat_type 选填入库**
  - 操作：点击「+ 新建物料」→ 填写 part_no=8210004, part_name=标准件, uom=件 → mat_type 留空 → 提交
  - 断言：toast 成功；列表刷新后 8210004 行 mat_type 列显示 `dash()`
  - 选择器注意：列表列空值渲染为 dash

- **VT-FORM-04 编辑回显**
  - 前置造数：M1 存在
  - 操作：点击 M1 行【编辑】→ 断言 part_no 只读不可改 → 修改 part_name=前保险杠总成-改 → 提交
  - 断言：toast 含『物料主数据更新成功』；列表刷新后 part_name=前保险杠总成-改
  - 选择器注意：edit 表单中 part_no input 为 readonly

- **VT-FORM-05 批量导入**
  - 操作：点击「批量导入」→ 上传含有效行的 Excel → 确认
  - 断言：toast 含摘要（成功 N 条 / 失败 M 条）；列表刷新含新行

## §6 0 报错

- **VT-ERR-01 本会话 0 报错**
  - 操作：完成上述全部测试步骤
  - 断言：本脚本会话全程 0 console error / 0 pageerror / 0 HTTP>=400（favicon 除外）
