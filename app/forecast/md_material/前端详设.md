# 物料主数据 前端详设
> 来源：app/forecast/_contracts.md（冻结契约）+ app/forecast/md_material/应用详设.md
> 落位：`app/forecast/md_material/view.js` + `view.html`

## 1. 页面元数据 PAGE_META

| 字段 | 值 | 说明 |
|---|---|---|
| key | `md_material` | = 应用文件夹名，page_id 为 `forecast:md_material` |
| name | 物料主数据 | 侧栏菜单名 |
| ic | 📦 | 图标字 |
| title | 物料主数据 | 主区页面头标题 |
| crumb | 零件号·名称·单位 | 副题·要点 |
| order | 120 | 升序即菜单序 |

页面零鉴权：无任何权限判断；菜单按页面授权渲染在 shell，数据范围由后端闸门执法，401 由 api.js 自动跳登录。

## 2. 区块构成

### 2.1 列表区（查）—— 三段式：工具栏 / 表格 / 分页条

**用途**：物料主数据全量浏览 + 条件检索 + 新建/批量导入入口。本页为非看板页，不设 KPI 指标带（验收断言无 `.kpi`）。

**过滤控件（与 `md_material.list(part_no, part_name, mat_type, page, page_size)` 可过滤参数一一对应）**：

| 控件 | 对应参数 | 形态 |
|---|---|---|
| 零件号输入框 | `part_no` | placeholder「零件号」，Enter 或「查询」按钮触发（后端 LIKE 模糊匹配） |
| 零件名称输入框 | `part_name` | placeholder「零件名称」，Enter 或「查询」按钮触发（后端 LIKE 模糊匹配） |
| 物料类型 chips | `mat_type` | 全部 / 成品 / 半成品，单选互斥，点击即查（精确匹配） |
| 分页条 | `page` / `page_size` | `pageable()`，integer 传参 |

**工具栏**：「查询」「+ 新建物料」（打开 2.3 创建模态）「批量导入」（打开文件选择模态）。

**表格列（`.tbl.tight` + `.scroll-x`；全部为详情字段子集）**：

| 列 | 字段 | 渲染 |
|---|---|---|
| 零件号 | `part_no` | `.b-link`，点击打开详情模态 |
| 零件名称 | `part_name` | 文本 |
| 单位 | `uom` | 文本 |
| 物料类型 | `mat_type` | `hue()` 徽章（成品=蓝 / 半成品=灰），空值 `dash()` |
| 操作 | — | 【编辑】按钮（开编辑表单） |

**交互**：任一过滤变化 → 重置回第 1 页重载；编辑保存成功后刷新当前页；空结果显示空态文案。

### 2.2 详情模态（查全）—— 三段式：墨青头带 / KV 分组体 / 操作页脚

**用途**：点 `part_no` 弹出，展示 `md_material.get` 返回的全部字段。

| 分组（`.sec`） | 字段 | 渲染 |
|---|---|---|
| 头带 | `part_no` + `mat_type` 徽章 | 墨青头带，徽章 `hue()` |
| 基本信息 | `part_no` / `part_name` | `.kv`；part_no 注明「全局唯一主键 · 创建后不可变更」 |
| 计量信息 | `uom` / `mat_type` | `.kv`；mat_type 空值 `dash()`，注明「选填参考字段」 |
| 原始数据 | get 返回全量 JSON | 底部折叠（默认收起） |

**页脚 `.modal-ft`**：【编辑】（打开编辑表单）【关闭】。

### 2.3 创建 / 编辑表单（增/改）—— 模态表单

**用途**：覆盖 `md_material.create` / `md_material.update` 接受的业务参数。

| 字段 | 控件 | 必填 | create 可见 | update 可见 | 约束来源 |
|---|---|---|---|---|---|
| `part_no` | input，maxlength=50 | ★ 必填 | 是 | 否（只读展示） | BR-01 主键，创建后不可变 |
| `part_name` | input，maxlength=100 | ★ 必填 | 是 | 是 | BR-02 |
| `uom` | input，maxlength=20 | ★ 必填 | 是 | 是 | BR-02；默认「件」 |
| `mat_type` | select：成品 / 半成品 / （空） | 选填 | 是 | 是 | BR-03 枚举约束；可选 |

- create 模式：全部 4 字段可填写；uom 默认「件」。
- update 模式：`part_no` 回填展示但不可修改（主键）；`part_name` / `uom` / `mat_type` 可修改。
- 布局：必填先行、frow 语义分组——第一行（part_no）、第二行（part_name + uom）、第三行（mat_type）；底部右对齐「取消」「保存」。
- 前端仅做必填校验（空值 → toast 警告、不提交）；枚举值合法性、主键唯一性由后端校验，`FdeError` 经 api.js 以错误 toast 呈现。
- 提交成功：toast 成功消息 → 关闭模态 → 重置过滤重载列表（create）/ 刷新当前页（update）。

### 2.4 批量导入

**用途**：点击「批量导入」按钮，弹出文件上传模态，调 `md_material.import_batch`。

- 提供模板下载链接（表头：part_no, part_name, uom, mat_type）。
- 上传 Excel → 后端逐行校验 + upsert（已存在主键 → 更新，新增 → 创建）。
- 返回摘要：成功数 / 失败数 / 错误明细列表。
- 导入完成后刷新列表。

## 3. svc 字面量清单（授权派生依据——必须字面量 svc("应用","服务")）

| 区块 | 调用（应用.服务） | 参数 | quiet | 说明 |
|---|---|---|---|---|
| 列表区 | `svc("md_material","list")` | `{part_no, part_name, mat_type, page, page_size}` | — | 分页查询；空条件传 undefined 不带 |
| 详情模态 | `svc("md_material","get")` | `{part_no}` | — | 全字段详情 |
| 创建表单 | `svc("md_material","create")` | `{part_no, part_name, uom, mat_type}` | — | 新建物料主数据 |
| 编辑表单 | `svc("md_material","update")` | `{part_no, part_name, uom, mat_type}` | — | 更新（仅传有变更字段） |
| 批量导入 | `svc("md_material","import_batch")` | `{rows: [...]}` | — | Excel 逐行校验 + upsert |

> 以上 5 处必须在 view.js 中以字面量逐项书写，**勿用变量拼名**。

## 4. 数据来源与下拉

- **无跨应用主数据下拉**：`md_material` 不主动外调，物料类型为静态枚举（成品 / 半成品），来源：应用详设 BR-03 / 建表 DEFAULT。
- **契约 payload → 区块字段映射**：

| 契约 | 载荷字段 | 映射区块 |
|---|---|---|
| `md_material.list` 返回项 | `part_no, part_name, uom, mat_type` | 2.1 列表列 |
| `md_material.get` 返回 | `part_no, part_name, uom, mat_type` | 2.2 详情模态 kv + 原始数据 |
| `md_material.create` 入参 | `part_no, part_name, uom, mat_type` | 2.3 创建表单 |
| `md_material.update` 入参 | `part_no, part_name, uom, mat_type` | 2.3 编辑表单（part_no 只读） |
| `md_material.import_batch` 入参 | `rows: [{part_no, part_name, uom, mat_type}]` | 2.4 批量导入 |

## 5. 交互要点

1. **加载**：首载正常拉取 list（非看板页，失败走 api.js 统一通道）；列表重载期间显示加载态。
2. **过滤**：物料类型 chips 点击即查并重置 `page=1`；part_no / part_name 输入后 Enter 或「查询」触发；翻页仅改 `page/page_size`，不清过滤条件。
3. **微交互**：表格行 hover 高亮；part_no `.b-link` hover 下划线；mat_type 徽章 `hue()` 着色；「保存」按钮提交期 loading 防重复点击。
4. **成功流**：create 成功 → 关闭模态并清空表单 → toast「物料主数据创建成功」→ 列表回第 1 页重载；update 成功 → 关闭模态 → toast「物料主数据更新成功」→ 刷新当前页。
5. **错误流**：重复 part_no / 枚举非法等后端 `FdeError` → toast 错误信息，模态保持打开便于修改后重试。
6. **空态**：无任何物料时「暂无物料 —— 点『新建物料』创建」；过滤无命中时「无符合条件的物料」。
7. **批量导入**：文件选择后上传 → 导入过程 loading → 完成弹摘要（成功 N 条，失败 M 条，错误明细列表）→ 关闭后刷新列表。
8. **原始数据**折叠默认收起。
9. **展示工具**：`hue()`（mat_type 徽章）、`dash()`（空 mat_type）、无金额字段无需 `fmt()`、无时间字段无需 `fmtTime()`、无 `*_json` 字段无需 `tryParse()`。

## 6. 验收关注点（供第⑧步）

1. **路由渲染**：`#/md_material` 挂载出列表三段式（工具栏 + 表格 + 分页条），**断言无 `.kpi`**（非看板页防挂载粘滞假过）。
2. **造数后列表有数据**：REST 创建 8210001 某零件 件 成品 → 列表 1 行，part_no / part_name / uom / mat_type 徽章齐全。
3. **过滤一一对应**：mat_type=成品 chips 仅成品行；part_no=8210 模糊匹配；part_name=螺栓 模糊匹配；组合条件；无匹配显示空态且不抛错。
4. **模态全字段**：点 part_no 开模态，断言 part_no / part_name / uom / mat_type 全部可见 + 「原始数据」可展开。
5. **表单落库**：create 表单填 part_no + part_name + uom（★）+ mat_type（选填）→ 提交 → 列表出现新记录；空必填字段提交 → toast 警告且不发请求；重复 part_no 创建 → 后端 FdeError toast。
6. **update 回显**：编辑模态 part_no 只读不可改；修改 part_name 保存后列表和详情均反映新值。
7. **mat_type 可选**：创建时 mat_type 留空 → 成功入库，列表该列显示 `dash()`。
8. **批量导入**：上传合法 Excel → 列表新增行；含冲突行 → 摘要正确展示成功/失败数。
9. **干净控制台**：全程 0 console error / 0 pageerror / 0 HTTP>=400（受限会话 403 属预期执法单独豁免）。
