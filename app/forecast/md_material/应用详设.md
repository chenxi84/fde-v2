## 1. 需求概览

### 1.1 基本信息
- **需求名称**: 物料主数据管理
- **需求编号**: REQ-FCST-MDM-001
- **所属模块**: 销售预测-主数据层
- **需求来源**: 业务方（销售/计划）
- **创建日期**: 2026-08-12
- **优先级**: P0

### 1.2 需求背景
#### 1.2.1 为什么需要这个需求？
零件号（part_no）是预测快照、基线、加工、零件级处理、发布等全部业务链的核心键，被6个业务聚合引用。必须有一条统一的物料主数据作为零件号的权威来源，确保各行校验与全程一致性。

#### 1.2.2 期望达到什么目标？
建立零件号的基础信息台账（零件号/名称/单位/物料类型），为全链提供物料键校验能力。

### 1.3 需求范围
#### 1.3.1 包含哪些功能？
物料主数据的创建、列表查询、更新、批量导入/更新。

#### 1.3.2 不包含哪些功能？
- 不做物料 BOM/工艺路线/库存属性管理（不在预测域范围）
- 不做 ERP 物料同步接口（V1 以 Excel 导入起步）

> **数据来源类型**: 独立创建 —— 数据由用户在本应用内独立录入，前端保留"新建"按钮。

### 1.4 涉及角色
**谁会使用这个功能？**

- **一线销售**: 新建/维护物料基础信息（预测录入需要零件号作为键）
- **总部计划**: 查看物料列表、管理物料类型分类

## 2. 用户故事

### 2.1 核心用户故事

#### 2.1.1 `US-01` 用户故事 — 创建物料主数据（优先级：P1）

- **故事描述**: 作为一线销售/总部计划，我想要创建物料主数据记录，以便于后续预测快照录入时选择零件号
- **为何赋予此优先级**：物料主数据是全部6个业务聚合的零件键来源，无物料则全链无法运作
- **独立测试**：可通过进入物料主数据页面，点击"新建"，填写必填字段后保存并验证记录已入库来独立测试
- **前置条件**: 用户已登录，拥有物料主数据创建权限
- **后置条件**: 系统生成一条新的物料主数据记录，part_no 全局唯一

**验收场景**：

1. `US-01-AC1` **场景**: 合法参数创建成功
   - **Given** 系统中不存在 part_no=8210001 的记录，**When** 填写 part_no=8210001, part_name=某零件, uom=件, mat_type=成品 后点击保存，**Then** 记录创建成功，可通过 get(8210001) 查询到完整记录

2. `US-01-AC2` **场景**: 重复零件号被拒绝
   - **Given** 系统中已存在 part_no=8210001，**When** 再次创建 part_no=8210001，**Then** 系统拒绝保存并提示"该零件号已存在"

3. `US-01-AC3` **场景**: 必填字段为空被拒绝
   - **Given** 用户在新建表单中，**When** part_no 或 part_name 或 uom 为空提交，**Then** 系统拒绝保存并提示具体缺失字段

---

#### 2.1.2 `US-02` 用户故事 — 查看物料主数据列表（优先级：P1）

- **故事描述**: 作为一线销售/总部计划，我想要按条件筛选查看物料主数据列表，以便于快速定位目标零件
- **为何赋予此优先级**：列表查询是最基础的数据浏览入口，是更新/维护的前置操作
- **独立测试**：可通过进入物料列表页，使用不同筛选条件查询并验证结果来独立测试
- **前置条件**: 系统中已有物料主数据记录
- **后置条件**: 返回符合条件的物料列表，支持分页

**验收场景**：

1. `US-02-AC1` **场景**: 按零件号模糊查询
   - **Given** 系统中存在多条物料记录，**When** 输入 part_no=8210 后查询，**Then** 列表展示所有 part_no 包含"8210"的物料

2. `US-02-AC2` **场景**: 按物料类型筛选
   - **Given** 系统中存在成品和半成品物料，**When** 筛选 mat_type=成品 后查询，**Then** 列表仅展示物料类型为成品的记录

3. `US-02-AC3` **场景**: 按零件名称模糊查询
   - **Given** 系统中存在多条物料记录，**When** 输入 part_name=螺栓 后查询，**Then** 列表展示所有 part_name 包含"螺栓"的物料

---

#### 2.1.3 `US-03` 用户故事 — 更新物料主数据（优先级：P2）

- **故事描述**: 作为总部计划，我想要修改物料主数据的名称、单位、物料类型，以便于保持主数据与工程变更一致
- **为何赋予此优先级**：物料主数据相对静态，但名称/单位/类型随工程变更可能需要更新
- **独立测试**：可通过查询一条已有记录，修改其 part_name 后保存并验证生效来独立测试
- **前置条件**: 目标记录已存在
- **后置条件**: 记录更新成功

**验收场景**：

1. `US-03-AC1` **场景**: 更新零件名称成功
   - **Given** 存在物料 part_no=8210001 part_name=旧名称，**When** 修改 part_name 为"新名称"后保存，**Then** 更新成功，重新查询 part_name 为"新名称"

2. `US-03-AC2` **场景**: 更新不存在的记录被拒绝
   - **Given** 系统中不存在 part_no=NOTEXIST，**When** 尝试更新该零件号，**Then** 系统拒绝并提示"物料记录不存在"

---

#### 2.1.4 `US-04` 用户故事 — 批量导入物料主数据（优先级：P2）

- **故事描述**: 作为总部计划，我想要通过 Excel 批量导入物料主数据，以便于系统初始化或新零件集中上线时高效建账
- **为何赋予此优先级**：V1 主数据以 Excel 导入起步，批量导入是初始化阶段的核心入口
- **独立测试**：可通过准备合法的 Excel 文件，执行导入并验证所有行均已入库来独立测试
- **前置条件**: 导入文件格式符合规范（列：part_no, part_name, uom, mat_type）
- **后置条件**: 导入成功的行入库，失败的行返回错误明细

**验收场景**：

1. `US-04-AC1` **场景**: 全部合法行导入成功
   - **Given** 导入文件含5条合法物料记录且无主键冲突，**When** 执行导入，**Then** 5条均入库，返回成功计数

2. `US-04-AC2` **场景**: 部分行冲突—冲突行更新
   - **Given** 导入文件含5条，其中2条 part_no 与已有记录冲突，**When** 执行导入，**Then** 3条新增入库，2条已有记录的 part_name/uom/mat_type 被更新（upsert）

3. `US-04-AC3` **场景**: 必填缺失—该行失败
   - **Given** 导入文件某行 part_no 为空，**When** 执行导入，**Then** 该行导入失败，错误明细提示"零件号不能为空"，其他合法行正常导入

## 3. 业务场景

### 3.1 业务流程描述

#### 3.1.1 场景1: 新建物料主数据
1. 用户进入"物料主数据"页面，点击"新建"
2. 系统展示物料主数据表单（part_no, part_name, uom, mat_type）
3. 用户填写必填字段：part_no, part_name, uom
4. 用户点击"保存"
5. 系统校验 part_no 唯一性
6. 校验通过，记录入库；校验不通过，提示冲突

#### 3.1.2 场景2: 批量导入物料主数据
1. 用户进入"物料主数据"页面，点击"批量导入"
2. 系统弹出文件上传对话框
3. 用户选择符合模板的 Excel 并上传
4. 系统逐行校验：part_no 非空唯一、part_name 非空、uom 非空
5. 已存在主键行 → 更新（upsert），新行 → 新增
6. 系统返回导入结果摘要（成功数、失败数、错误明细）

### 3.2 业务规则

#### 3.2.1 `BR-01` 零件号全局唯一
- **规则描述**: part_no 全局唯一，为单字段主键
- **适用场景**: 创建、导入
- **示例**: part_no=8210001 已存在，则不可再建 part_no=8210001

#### 3.2.2 `BR-02` 必填字段校验
- **规则描述**: part_no, part_name, uom 为必填，不可为空字符串；mat_type 可选
- **适用场景**: 创建、导入、更新
- **示例**: 创建时 part_name 为空 → 拒绝保存，提示"零件名称不能为空"

#### 3.2.3 `BR-03` 物料类型枚举约束
- **规则描述**: mat_type 有值时仅限"成品"或"半成品"
- **适用场景**: 创建、导入、更新
- **示例**: mat_type=原材料 → 拒绝保存，提示"物料类型仅支持成品/半成品"

### 3.3 业务数据

#### 3.3.1 数据1: 零件号 part_no
- **数据描述**: 零件的唯一编码，全局主键，被全部业务聚合作为物料键
- **数据类型**: 文本
- **数据来源**: 用户录入 / Excel 导入
- **示例值**: 8210001

#### 3.3.2 数据2: 零件名称 part_name
- **数据描述**: 零件的中文名称
- **数据类型**: 文本
- **数据来源**: 用户录入 / Excel 导入
- **示例值**: 某零件

#### 3.3.3 数据3: 单位 uom
- **数据描述**: 计量单位
- **数据类型**: 文本
- **数据来源**: 用户录入 / Excel 导入
- **示例值**: 件 / 套 / kg

#### 3.3.4 数据4: 物料类型 mat_type
- **数据描述**: 物料类型分类（成品/半成品），可选参考字段
- **数据类型**: 枚举值
- **数据来源**: 用户录入 / Excel 导入
- **示例值**: 成品 / 半成品

### 3.4 状态机
无状态机。物料主数据为静态基础数据，无生命周期状态流转。

### 4.3 功能详细说明

#### 4.3.1 F01-02 物料主数据

##### 4.3.1.1 FUNC-01 创建物料主数据

**功能描述**:
提供物料主数据的创建表单，用户录入零件号/名称/单位/物料类型后保存。此功能为独立创建——前端保留"新建"按钮。

**用户操作流程**:
1. 用户进入"物料主数据"列表页，点击"新建"按钮
2. 系统展示创建表单（part_no, part_name, uom, mat_type）
3. 用户填写 part_no（必填）、part_name（必填）、uom（必填）、mat_type（选填）
4. 用户点击"保存"
5. 系统校验 part_no 唯一性
6. 校验通过 → 记录入库，提示保存成功；校验不通过 → 提示"该零件号已存在"

**输入数据**:
- part_no: 零件号 - 必填，最大50字符 - 示例：8210001
- part_name: 零件名称 - 必填，最大100字符 - 示例：某零件
- uom: 单位 - 必填，最大20字符 - 示例：件
- mat_type: 物料类型 - 选填，枚举（成品\|半成品） - 示例：成品

**输出数据**:
- 成功消息: "物料主数据创建成功"
- 错误消息: "该零件号已存在" / "XX字段不能为空" / "物料类型仅支持成品/半成品"

**业务规则**:
- BR-01: part_no 全局唯一
- BR-02: part_no, part_name, uom 必填
- BR-03: mat_type 有值时仅限"成品"或"半成品"

**特殊处理**:
- 无

**业务实体**:
- **MdMaterial**: 零件号/名称/单位/物料类型基础信息，标识为 part_no

**MdMaterial 字段**

| 字段名称 | 字段类型 | 是否必填 | 默认值 | 业务逻辑 |
|---|---|---|---|---|
| part_no | 文本 | 是 | - | 零件号，PK，全局唯一，最大50字符 |
| part_name | 文本 | 是 | - | 零件名称，最大100字符 |
| uom | 文本 | 是 | - | 单位（件/套/kg等），最大20字符 |
| mat_type | 枚举值 | 否 | - | 成品\|半成品，可选参考字段；来源：用户选择 |

##### 4.3.1.2 FUNC-02 物料主数据列表查询

**功能描述**:
提供物料主数据的分页列表，支持按零件号、零件名称、物料类型等条件筛选。

**用户操作流程**:
1. 用户进入"物料主数据"列表页
2. 用户可选填写筛选条件：part_no（模糊匹配）、part_name（模糊匹配）、mat_type（精确匹配）
3. 用户点击"查询"
4. 系统返回符合条件的物料列表（分页）

**输入数据**:
- part_no: 零件号 - 选填，模糊匹配 - 示例：8210
- part_name: 零件名称 - 选填，模糊匹配 - 示例：螺栓
- mat_type: 物料类型 - 选填，精确匹配 - 示例：成品
- page: 页码 - 默认1
- size: 每页条数 - 默认20

**输出数据**:
- 列表字段: part_no, part_name, uom, mat_type
- 分页信息: total, page, size

**业务规则**:
- 筛选条件均为可选，条件之间 AND 关系
- part_no / part_name 支持模糊匹配（LIKE %value%）

**特殊处理**:
- 默认按 part_no 升序排列

**业务实体**:
- **MdMaterial**: 同上 FUNC-01

**MdMaterial 列表展示字段**

| 展示字段 | 字段来源 | 可筛选 | 说明 |
|---|---|---|---|
| 零件号 | part_no | 是（模糊） | PK |
| 零件名称 | part_name | 是（模糊） | 显示用 |
| 单位 | uom | 否 | 显示用 |
| 物料类型 | mat_type | 是（精确） | 成品/半成品 |

##### 4.3.1.3 FUNC-03 更新物料主数据

**功能描述**:
对已有物料主数据记录修改 part_name, uom, mat_type。part_no 作为主键不允许修改。

**用户操作流程**:
1. 用户在列表页点击目标行 → 进入编辑模式
2. 系统回填当前值到表单
3. 用户修改 part_name / uom / mat_type
4. 用户点击"保存"
5. 系统校验 mat_type 枚举值
6. 校验通过 → 更新入库

**输入数据**:
- part_no: 零件号 - 不可修改，仅作为定位键
- part_name: 零件名称 - 可修改，最大100字符
- uom: 单位 - 可修改，最大20字符
- mat_type: 物料类型 - 可修改，枚举（成品\|半成品）

**输出数据**:
- 成功消息: "物料主数据更新成功"
- 错误消息: "物料记录不存在" / "物料类型仅支持成品/半成品"

**业务规则**:
- BR-01: part_no 不可修改（主键不可变）
- BR-02: part_name, uom 不能更新为空
- BR-03: mat_type 有值时仅限"成品"或"半成品"

**特殊处理**:
- 无

---

##### 4.3.1.4 FUNC-04 批量导入物料主数据

**功能描述**:
通过上传 Excel 文件（列：part_no, part_name, uom, mat_type），系统逐行校验入库。已存在的主键行执行更新（upsert），不存在的新增。

**用户操作流程**:
1. 用户点击"批量导入"按钮
2. 系统弹出文件上传对话框，附带模板下载链接
3. 用户选择符合格式的 Excel 文件上传
4. 系统逐行校验（必填、枚举值）
5. 导入完成 → 系统返回摘要（成功数、失败数、错误明细列表）

**输入数据**:
- Excel 文件，列：part_no, part_name, uom, mat_type

**输出数据**:
- 导入摘要: { total: N, success: N, fail: N, errors: [{ row, field, message }] }

**业务规则**:
- BR-01: 主键已存在行 → 更新 part_name/uom/mat_type（upsert），非冲突拒绝
- BR-02: 必填字段为空行 → 失败，记录错误明细
- BR-03: mat_type 不在枚举范围内 → 失败，记录错误明细（空值 OK）

**特殊处理**:
- Upsert 策略：已存在主键 → 更新 part_name, uom, mat_type
- 提供模板下载：含表头行（part_no, part_name, uom, mat_type）的空白 Excel

#### 6.1.1 标准1: 物料主数据 CRUD 完整闭环

- **关联业务规则**: BR-01, BR-02, BR-03
- **验证方式**: 依次执行创建→查询→更新→再查询
- **测试数据**: part_no=8210001, part_name=某零件, uom=件, mat_type=成品
- **预期结果**: 创建成功并通过 list/get 可查询；更新 part_name 后再次查询值已变更

#### 6.1.2 标准2: 零件号唯一性校验
- **关联用户故事**: US-01
- **关联业务规则**: BR-01
- **验证方式**: 创建两条 part_no 完全相同的记录
- **测试数据**: 重复创建 part_no=8210001
- **预期结果**: 第二条创建被拒绝，提示"该零件号已存在"

#### 6.1.3 标准3: 批量导入正常+异常混合场景
- **关联用户故事**: US-04
- **关联业务规则**: BR-01, BR-02, BR-03
- **验证方式**: 导入含5行数据（3行合法新记录、1行已有主键、1行缺必填字段）
- **测试数据**: 合法新记录3条 + 已有主键1条 + 缺 part_name 行1条
- **预期结果**: 3条新增入库，已有主键行被更新，缺必填行失败并返回错误明细

#### 6.1.4 标准4: 物料类型枚举约束
- **关联用户故事**: US-01, US-03
- **关联业务规则**: BR-03
- **验证方式**: 创建/更新时 mat_type 传入非法值（如"原材料"）
- **测试数据**: mat_type=原材料
- **预期结果**: 保存被拒绝，提示"物料类型仅支持成品/半成品"；空 mat_type 合法

### 6.2 非功能验收标准
**性能要求**: 列表查询（5000条以内）页面加载时间<2秒
**安全性要求**: 无敏感加密需求（基础数据）
**兼容性要求**: 支持 Chrome、Edge 浏览器

### 6.3 已知问题或限制
- V1 无 ERP 物料同步接口，主数据以 Excel 导入起步；同步接口在实施设计阶段补
- 物料删除功能暂不提供（V1 只增不改删，避免预测链级联问题）
- mat_type 为可选字段，V1 仅作分类参考，不参与业务规则判断
