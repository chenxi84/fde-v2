## 2. 区块构成

### 2.1 列表区
**过滤控件**：
| 控件 | 参数 | 选项 |
|------|------|------|
| 版本下拉 | fcst_version | md_fcst_version.list quiet |
| 功能类型 chips | func_type | 全部 / 通用件合并 / 替换件合并 / 断点处理 |
| 零件搜索 | part_no | 输入框 |
| 分页 | page/page_size | pageable() |

**表格列**：
| 列 | 字段 | 渲染 |
|----|------|------|
| 处理单号 | adj_no | `.b-link` 开详情 |
| 功能 | func_type | hue() 徽章 |
| 物料 | part_no | 正文 |
| 期间 | period | 正文 |
| 调整量 | adj_qty | fmt() 带符号（正=绿/负=红） |
| 依据 | basis | 小字省略 |
| 配对号 | pair_no | 断点行显示 |
| 处理人 | owner | 正文 |
| 时间 | created_at | fmtTime() |

### 2.2 详情模态
墨青头带（adj_no + func_type 徽章）。KV 分组：
- 处理信息：adj_no / func_type / part_no / fcst_version / period
- 调整数据：adj_qty / basis
- 断点信息：pair_no（如有）
- 元数据：owner / created_at

### 2.3 创建表单（三种功能入口）
列表顶部三个按钮：
- **通用件合并** → 表单：fcst_version / period / part_no / adj_qty / basis
- **替换件合并** → 表单：fcst_version / period / part_no / adj_qty / basis
- **断点处理** → 表单：fcst_version / period / old_part / new_part / old_adj / new_adj / ecn_no

### 2.4 汇总视图
【查看汇总】按钮 → 调 summarize → 展示按物料×期间聚合的 delta 表

## 3. svc 字面量清单

| 区块 | 调用 | 参数 |
|------|------|------|
| 列表 | `svc("part_level_adj","list")` | `{fcst_version, func_type, part_no, period, page, page_size}` |
| 版本下拉 | `svc("md_fcst_version","list")` | `{page:1, page_size:50}` quiet |
| 详情 | `svc("part_level_adj","get")` | `{adj_no}` |
| 通用件合并 | `svc("part_level_adj","create_generic_merge")` | `{fcst_version, period, part_no, adj_qty, basis}` |
| 替换件合并 | `svc("part_level_adj","create_replace_merge")` | `{fcst_version, period, part_no, adj_qty, basis}` |
| 断点处理 | `svc("part_level_adj","create_breakpoint_adj")` | `{fcst_version, period, old_part, new_part, old_adj, new_adj, ecn_no}` |
| 汇总 | `svc("part_level_adj","summarize")` | `{fcst_version}` |

## 4. 数据来源
- 版本下拉：md_fcst_version.list
- 替换关系：md_part_replace.list（断点处理时可查 ECN 列表）

## 5. 交互要点
1. 断点处理创建后返回两条（old+new），toast 显示 pair_no
2. 通用件标识：系统自动识别 ≥2 客户的零件
3. 执行顺序提示：通用→替换→断点

## 6. 验收关注点
1. 渲染：列表三段式，无 `.kpi`
2. 创建通用件合并后列表有数据
3. 断点成对：创建后列表出现两条 adj_no 且 pair_no 相同
4. 汇总视图数据正确
5. 0 报错
