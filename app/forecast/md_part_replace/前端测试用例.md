# md_part_replace 前端测试用例

> 页面：forecast:md_part_replace

## §0 测试数据字典（本页自足）

| 标识 | 造数服务 | 参数 |
|------|---------|------|
| M1 | md_material.create | part_no=8210001, part_name=前保险杠总成, uom=件, mat_type=成品 |
| M2 | md_material.create | part_no=8210001-B, part_name=前保险杠总成B版, uom=件, mat_type=成品 |
| M3 | md_material.create | part_no=8210002, part_name=后保险杠总成, uom=件, mat_type=半成品 |
| REL1 | md_part_replace.create | rel_no=REL-001, rel_type=替换, old_part=8210001, new_part=8210001-B, ecn_no=ECN-A-001 |
| REL2 | md_part_replace.create | rel_no=REL-002, rel_type=替代, old_part=8210001, new_part=8210002, switch_date=2026-09-01 |

## §1 渲染

- **VT-RENDER-01 路由渲染有内容**
  - 页面：forecast:md_part_replace
  - 操作：admin 进入 `#/md_part_replace`
  - 断言：`.card` > 0；列表三段式（过滤条 + 表格 + 分页区域）可见；**无 `.kpi`**（防粘滞）
  - 选择器注意：`:visible` 限定

## §2 造数后列表有数据

- **VT-LIST-01 造数后列表有数据**
  - 前置造数：经 REST 依次调用 M1+M2+M3 → REL1+REL2
  - 操作：刷新页面 `#/md_part_replace`
  - 断言：`table.tbl tr.data` 行数 >= 2；含 rel_no=REL-001 且 rel_type 徽章显示「替换」、status 徽章显示「生效」
  - 选择器注意：精确 `has_text("REL-001")` 定位行

- **VT-LIST-02 过滤生效**
  - 前置造数：同 VT-LIST-01
  - 操作：rel_type chips 选「替换」
  - 断言：仅显示 REL-001（替换）；REL-002 不可见
  - 选择器注意：chips 点击后等待列表刷新

- **VT-LIST-03 状态过滤生效**
  - 操作：status chips 选「生效」
  - 断言：REL1 和 REL2 均可见（创建默认生效）

## §3 模态全字段

- **VT-MODAL-01 详情模态全字段**
  - 前置造数：同 VT-LIST-01
  - 操作：点击 rel_no=REL-001 的 `.b-link` → `wait_modal()` 等 `.loadbox` 消失
  - 断言：模态含字段 rel_no / rel_type / old_part / new_part / switch_date / ecn_no / status；头带含 rel_type + status 徽章；原始数据可展开
  - 选择器注意：多 `.modal-bd` 用 `.first`；`:visible` 限定

## §4 表单落库回显

- **VT-FORM-01 创建落库**
  - 前置造数：M1+M2 存在
  - 操作：点击「+ 新建替换关系」→ 填写 rel_no=REL-003 → rel_type select 选「替换」→ old_part autocomplete 选 8210001 → new_part autocomplete 选 8210001-B → 提交
  - 断言：toast 含『替换关系创建成功』；列表刷新后含 REL-003 行且 status=生效
  - 选择器注意：`:visible` 限定表单控件；autocomplete 下拉项可点击

- **VT-FORM-02 空必填字段被拒**
  - 操作：点击「+ 新建替换关系」→ rel_no 留空 → 提交
  - 断言：toast 警告『必填』且不发请求；模态保持打开
  - 选择器注意：toast 选择器

- **VT-FORM-03 物料 autocomplete**
  - 操作：点击「+ 新建替换关系」→ 点击 old_part autocomplete → 断言下拉含 M1+M2+M3（来自 quiet 拉取）→ 选中后正确回填
  - 选择器注意：autocomplete 下拉 `:visible` 限定

- **VT-FORM-04 编辑回显**
  - 前置造数：REL1 存在
  - 操作：点击 REL1 行【编辑】→ 断言 rel_no 只读不可改 → 断言表单无 status 选择器 → 修改 ecn_no=ECN-A-002 → 提交
  - 断言：toast 含『替换关系更新成功』；列表刷新后 ecn_no=ECN-A-002
  - 选择器注意：edit 表单中 rel_no input 为 readonly；确认无 status 字段

- **VT-FORM-05 设为失效**
  - 前置造数：REL1（status=生效）存在
  - 操作：点击 REL1 行【设为失效】→ 确认弹窗 → 确认
  - 断言：toast 含『替换关系已设为失效』；列表刷新后 REL1 status=失效；行内不再显示【设为失效】按钮
  - 选择器注意：确认弹窗按钮 `:visible` 限定

- **VT-FORM-06 重复失效被拒**
  - 前置造数：REL1 已设为失效
  - 操作：再次点击 REL1 行【设为失效】（如按钮仍可见）→ 确认
  - 断言：后端 toast「替换关系已失效」（幂等拦截）

## §6 0 报错

- **VT-ERR-01 本会话 0 报错**
  - 操作：完成上述全部测试步骤
  - 断言：本脚本会话全程 0 console error / 0 pageerror / 0 HTTP>=400（favicon 除外）
