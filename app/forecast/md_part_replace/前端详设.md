## 2. 区块构成

### 2.1 列表区（查）—— 三段式：工具栏 / 表格 / 分页条

**用途**：替换关系全量浏览 + 条件检索 + 新建入口。本页为非看板页，不设 KPI 指标带（验收断言无 `.kpi`）。

**过滤控件（与 `md_part_replace.list(rel_type, old_part, new_part, status, page, page_size)` 可过滤参数一一对应）**：

| 控件 | 对应参数 | 形态 |
|---|---|---|
| 关系类型 chips | `rel_type` | 全部 / 替换 / 替代，单选互斥，点击即查（精确匹配） |
| 旧件号输入框 | `old_part` | placeholder「旧件号」，Enter 或「查询」按钮触发（后端 LIKE 模糊匹配） |
| 新件号输入框 | `new_part` | placeholder「新件号」，Enter 或「查询」按钮触发（后端 LIKE 模糊匹配） |
| 状态 chips | `status` | 全部 / 生效 / 失效，单选互斥，点击即查（精确匹配） |
| 分页条 | `page` / `page_size` | `pageable()`，integer 传参 |

**工具栏**：「查询」「+ 新建替换关系」（打开 2.3 创建模态）。

**表格列（`.tbl.tight` + `.scroll-x`；全部为详情字段子集）**：

| 列 | 字段 | 渲染 |
|---|---|---|
| 关系号 | `rel_no` | `.b-link`，点击打开详情模态 |
| 关系类型 | `rel_type` | `hue()` 徽章（替换=橙 / 替代=蓝） |
| 旧件号 | `old_part` | 文本 |
| 新件号 | `new_part` | 文本 |
| 切换时点 | `switch_date` | 文本，空值 `dash()` |
| ECN号 | `ecn_no` | 文本，空值 `dash()` |
| 状态 | `status` | `hue()` 徽章（生效=绿 / 失效=灰） |
| 操作 | — | 按 `status` 行内动作：生效行 → 【编辑】【设为失效】；失效行 → 【编辑】 |

**交互**：任一过滤变化 → 重置回第 1 页重载；编辑/失效操作成功后刷新当前页；空结果显示空态文案。

### 2.2 详情模态（查全）—— 三段式：墨青头带 / KV 分组体 / 操作页脚

**用途**：点 `rel_no` 弹出，展示 `md_part_replace.get` 返回的全部字段。

| 分组（`.sec`） | 字段 | 渲染 |
|---|---|---|
| 头带 | `rel_no` + `status` 徽章 + `rel_type` 徽章 | 墨青头带 |
| 基本信息 | `rel_no` / `rel_type` / `status` | `.kv`；rel_no 注明「全局唯一主键 · 创建后不可变更」 |
| 零件关系 | `old_part` / `new_part` | `.kv`，注明「引用 md_material · 创建/变更时校验物料存在」 |
| 变更依据 | `switch_date` / `ecn_no` | `.kv`；空值 `dash()` |
| 原始数据 | get 返回全量 JSON | 底部折叠（默认收起） |

**页脚 `.modal-ft`**：【编辑】（打开编辑表单）+ 按 `status` 的【设为失效】按钮（仅 status=生效 时可见）+ 【关闭】。

### 2.3 创建 / 编辑表单（增/改）—— 模态表单

**用途**：覆盖 `md_part_replace.create` / `md_part_replace.update` 接受的业务参数。

| 字段 | 控件 | 必填 | create 可见 | update 可见 | 约束来源 |
|---|---|---|---|---|---|
| `rel_no` | input，maxlength=50 | ★ 必填 | 是 | 否（只读展示） | BR-01 主键，创建后不可变 |
| `rel_type` | select：替换 / 替代 | ★ 必填 | 是 | 是 | BR-03 枚举约束 |
| `old_part` | 物料 autocomplete（见 §4） | ★ 必填 | 是 | 是 | BR-05；后端 cross-app 调 md_material.get 校验 |
| `new_part` | 物料 autocomplete（见 §4） | ★ 必填 | 是 | 是 | BR-06；后端 cross-app 调 md_material.get 校验 |
| `switch_date` | date input | 选填 | 是 | 是 | 切换时点 |
| `ecn_no` | input，maxlength=50 | 选填 | 是 | 是 | ECN 号 |
| `status` | (系统默认) | — | 否（自动=生效） | 否 | create 自动「生效」，不可选；update 不通过此表单修改 status |

- create 模式：必填 4 项（rel_no, rel_type, old_part, new_part）；status 由后端自动设为「生效」，不可见也不可选。
- update 模式：`rel_no` 回填展示但不可修改（主键）；`rel_type` / `old_part` / `new_part` / `switch_date` / `ecn_no` 可修改。若需将 status 设为失效，应使用行内【设为失效】操作而非编辑表单。
- 布局：必填先行——第一行（rel_no）、第二行（rel_type）、第三行（old_part autocomplete + new_part autocomplete）；折叠区「更多字段 ▾」：switch_date / ecn_no；底部右对齐「取消」「保存」。
- 前端仅做必填校验（空值 → toast 警告、不提交）；枚举值、替换类型新旧件相同检查、物料引用校验由后端执行，`FdeError` 经 api.js 以错误 toast 呈现。
- 提交成功：toast 成功消息 → 关闭模态 → 重置过滤重载列表（create）/ 刷新当前页（update）。

### 2.4 设为失效操作

**用途**：生效行显示【设为失效】按钮，调 `md_part_replace.disable`。

- 行内操作列或详情模态页脚：`x-show="status==='生效'"` 时显示【设为失效】。
- 点击 → 弹出确认提示「确认将替换关系设为失效？失效后零件级处理中将排除此关系」。
- 确认后调用 `svc("md_part_replace","disable")` `{rel_no}`。
- 成功后 toast「替换关系已设为失效」→ 刷新列表 + 若模态打开则原地更新 status。
- 已失效行再点失效 → 后端返回「替换关系已失效」（幂等拦截），前端 toast 呈现即可。

## 3. svc 字面量清单（授权派生依据——必须字面量 svc("应用","服务")）

| 区块 | 调用（应用.服务） | 参数 | quiet | 说明 |
|---|---|---|---|---|
| 列表区 | `svc("md_part_replace","list")` | `{rel_type, old_part, new_part, status, page, page_size}` | — | 分页查询 |
| 物料下拉 | `svc("md_material","list")` | `{page:1, page_size:500}` | true | quiet 探测；零值兜底 |
| 详情模态 | `svc("md_part_replace","get")` | `{rel_no}` | — | 全字段详情 |
| 创建表单 | `svc("md_part_replace","create")` | `{rel_no, rel_type, old_part, new_part, switch_date, ecn_no}` | — | 跨应用双校验 |
| 编辑表单 | `svc("md_part_replace","update")` | `{rel_no, rel_type, old_part, new_part, switch_date, ecn_no}` | — | 更新（仅传有变更字段） |
| 设为失效 | `svc("md_part_replace","disable")` | `{rel_no}` | — | 生效→失效单向操作 |

> 以上 6 处必须在 view.js 中以字面量逐项书写，**勿用变量拼名**。

## 4. 数据来源与下拉

**物料下拉（旧件/新件 autocomplete，共用一份 partOptions/partMap）**：
- 页面初始化一次性 `svc("md_material","list")` `{page:1, page_size:500}`，`quiet:true` 探测：失败不喷 toast；零值兜底 → 下拉显示「暂无可选物料」禁用项。
- 由返回项构建 `partOptions` 扁平数组（字段 `part_no, part_name`），autocomplete 显示「part_no - part_name」，选中后回填 part_no。
- 列表「旧件号」「新件号」列通过 `partMap` 显示物料名称辅助信息。

**关系类型下拉**：静态枚举（替换 / 替代），来源：应用详设 BR-03 / 建表 CHECK。

**状态下拉**：静态枚举（生效 / 失效），来源：BR-07 / 建表 CHECK。

**契约 payload → 区块字段映射**：

| 契约 | 载荷字段 | 映射区块 |
|---|---|---|
| `md_part_replace.list` 返回项 | `rel_no, rel_type, old_part, new_part, switch_date, ecn_no, status` | 2.1 列表列 |
| `md_part_replace.get` 返回 | 同上（全量） | 2.2 详情模态 kv + 原始数据 |
| `md_part_replace.create` 入参 | `rel_no, rel_type, old_part, new_part, switch_date, ecn_no` | 2.3 创建表单 |
| `md_part_replace.update` 入参 | `rel_no, rel_type, old_part, new_part, switch_date, ecn_no` | 2.3 编辑表单（rel_no 只读） |
| `md_part_replace.disable` 入参 | `rel_no` | 2.4 设为失效 |
| `md_material.list` 项 | `part_no, part_name` | 物料 autocomplete 选项 |

## 5. 交互要点

1. **加载**：首载正常拉取 list（非看板页，失败走 api.js 统一通道）+ quiet 拉取 md_material.list 构建物料下拉。
2. **过滤**：关系类型 chips / 状态 chips 点击即查并重置 `page=1`；old_part / new_part 输入后 Enter 或「查询」触发；翻页仅改 `page/page_size`，不清过滤条件。
3. **物料 autocomplete**：old_part 和 new_part 各独立 autocomplete（@click.stop / @click.away / @input），共用同一份 `partOptions`，选中后回填对应编码。
4. **状态机（生效→失效）**：仅 status=生效 的行显示【设为失效】按钮（行内操作列 + 详情模态页脚）；失效为终态，不再显示失效按钮。编辑表单不暴露 status 选择器，状态变更仅通过 disable 操作。
5. **微交互**：表格行 hover 高亮；rel_no `.b-link` hover 下划线；rel_type 和 status 徽章 `hue()` 着色；「保存」按钮提交期 loading 防重复点击；【设为失效】点击后二次确认弹窗。
6. **成功流**：create 成功 → 关闭模态并清空表单 → toast「替换关系创建成功」→ 列表回第 1 页重载；update 成功 → toast「替换关系更新成功」→ 刷新当前页；disable 成功 → toast「替换关系已设为失效」→ 刷新当前页。
7. **错误流**：重复 rel_no / 物料不存在 / 替换类型新旧件相同 / 重复失效等后端 `FdeError` → toast 错误信息。
8. **空态**：无任何替换关系时「暂无替换关系 —— 点『新建替换关系』创建」；过滤无命中时「无符合条件的替换关系」。
9. **折叠「更多字段 ▾」**：switch_date / ecn_no 共 2 个选填字段。
10. **展示工具**：`hue()`（rel_type / status 徽章）、`dash()`（空值字段）、无金额字段无需 `fmt()`、无时间字段无需 `fmtTime()`、无 `*_json` 字段无需 `tryParse()`。

## 6. 验收关注点（供第⑧步）

1. **路由渲染**：`#/md_part_replace` 挂载出列表三段式（工具栏 + 表格 + 分页条），**断言无 `.kpi`**（非看板页防挂载粘滞假过）。
2. **造数后列表有数据**：先造 material（2条）→ 创建替换关系 REL-001 替换 旧件→新件 → 列表 1 行，rel_no / rel_type 徽章 / old_part / new_part / status=生效 齐全。
3. **过滤一一对应**：rel_type=替换 chips 仅替换行；status=生效 chips 仅生效行；old_part=8210 模糊匹配；组合条件；无匹配显示空态且不抛错。
4. **模态全字段**：点 rel_no 开模态，断言全部 7 字段可见 + 「原始数据」可展开。
5. **表单落库**：create 表单填必填 4 项 → 提交 → 列表出现新记录且 status=生效；空必填字段提交 → toast 警告且不发请求；重复 rel_no → 后端 FdeError toast。
6. **替换新旧件相同拦截**：rel_type=替换 + old_part == new_part → 后端 toast「替换关系中旧件号与新件号不能相同」。
7. **设为失效**：生效行点【设为失效】→ 确认后 status 变为 失效 → 行内不再显示【设为失效】按钮；已失效行再点击 → 后端 toast「替换关系已失效」。
8. **编辑不暴露 status**：编辑表单无 status 选择器，确保状态仅通过 disable 变更。
9. **物料 autocomplete**：old_part / new_part 下拉含已创建物料选项，选中后正确回填。
10. **干净控制台**：全程 0 console error / 0 pageerror / 0 HTTP>=400（受限会话 403 属预期执法单独豁免）。
