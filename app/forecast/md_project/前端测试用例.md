# md_project 前端测试用例

> 页面：forecast:md_project

## §0 测试数据字典（本页自足）

| 标识 | 造数服务 | 参数 |
|------|---------|------|
| C1 | md_customer.create | oem_code=OEM-A, plant_code=PLT-A1, oem_name=主机厂A, plant_name=一工厂, settle_mode=寄售 |
| PRJ1 | md_project.create | project_no=PRJ-001, project_name=车型A, stage=待定点, oem_code=OEM-A, plant_code=PLT-A1 |
| PRJ2 | md_project.create | project_no=PRJ-002, project_name=车型B, stage=进行中, oem_code=OEM-A, plant_code=PLT-A1, veh_model=SUV, sop=2026-01, eop=2030-12, owner=张三 |

## §1 渲染

- **VT-RENDER-01 路由渲染有内容**
  - 页面：forecast:md_project
  - 操作：admin 进入 `#/md_project`
  - 断言：`.card` > 0；列表三段式（过滤条 + 表格 + 分页区域）可见；**无 `.kpi`**（防粘滞）
  - 选择器注意：`:visible` 限定

## §2 造数后列表有数据

- **VT-LIST-01 造数后列表有数据**
  - 前置造数：经 REST 调用 `md_customer.create` 创建 C1 → `md_project.create` 创建 PRJ1、PRJ2
  - 操作：刷新页面 `#/md_project`
  - 断言：`table.tbl tr.data` 行数 >= 2；含 project_no=PRJ-001 且 stage 徽章显示「待定点」
  - 选择器注意：精确 `has_text("PRJ-001")` 定位行

- **VT-LIST-02 过滤生效**
  - 前置造数：同 VT-LIST-01
  - 操作：stage chips 选「进行中」
  - 断言：仅显示进行中行（PRJ-002）；PRJ-001 不可见
  - 选择器注意：chips 点击后等待列表刷新

- **VT-LIST-03 模糊搜索生效**
  - 操作：project_no 输入框填入「PRJ」→ 点击「查询」
  - 断言：PRJ1 和 PRJ2 均可见（模糊匹配命中）

## §3 模态全字段

- **VT-MODAL-01 详情模态全字段**
  - 前置造数：同 VT-LIST-01
  - 操作：点击 project_no=PRJ-002 的 `.b-link` → `wait_modal()` 等 `.loadbox` 消失
  - 断言：模态含字段 project_no / project_name / stage / oem_code / plant_code / veh_model / platform / sop / eop / owner；头带含 stage 徽章；原始数据可展开
  - 选择器注意：多 `.modal-bd` 用 `.first`；`:visible` 限定

## §4 表单落库回显

- **VT-FORM-01 创建落库**
  - 前置造数：C1 存在
  - 操作：点击「+ 新建项目」→ 填写 project_no=PRJ-003, project_name=车型C, stage=待定点 → oem_code autocomplete 选 OEM-A（联动回填 plant_code=PLT-A1）→ 展开「更多字段」填 veh_model=轿车 → 提交
  - 断言：toast 含『项目台账创建成功』；列表刷新后含 PRJ-003 行且 stage=待定点
  - 选择器注意：`:visible` 限定表单控件；autocomplete 下拉项可点击

- **VT-FORM-02 空必填字段被拒**
  - 操作：点击「+ 新建项目」→ project_no 留空 → 提交
  - 断言：toast 警告『必填』且不发请求；模态保持打开
  - 选择器注意：toast 选择器

- **VT-FORM-03 客户 autocomplete 联动**
  - 操作：点击「+ 新建项目」→ 点击 oem_code autocomplete → 断言下拉含 OEM-A（来自 C1 quiet 拉取）→ 选中 OEM-A → 断言 oem_code 和 plant_code 同时回填
  - 选择器注意：autocomplete 下拉 `:visible` 限定

- **VT-FORM-04 编辑回显**
  - 前置造数：PRJ1 存在
  - 操作：点击 PRJ1 行【编辑】→ 断言 project_no 只读不可改 → 修改 project_name=车型A-改 → 提交
  - 断言：toast 含『项目台账更新成功』；列表刷新后 project_name=车型A-改
  - 选择器注意：edit 表单中 project_no input 为 readonly

- **VT-FORM-05 状态机校验**
  - 前置造数：PRJ2（stage=进行中）存在
  - 操作：点击 PRJ2 行【编辑】→ stage 改为 EOP关闭 → 提交 → 成功（正向流转合法）
  - 然后：再次编辑 PRJ2 → stage 改回进行中 → 提交
  - 断言：后端 FdeError toast「EOP关闭项目不可回退」
  - 选择器注意：错误 toast 选择器

## §6 0 报错

- **VT-ERR-01 本会话 0 报错**
  - 操作：完成上述全部测试步骤
  - 断言：本脚本会话全程 0 console error / 0 pageerror / 0 HTTP>=400（favicon 除外）
