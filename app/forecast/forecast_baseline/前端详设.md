> 落位：`app/forecast/forecast_baseline/view.js` + `view.html`

## 1. 页面元数据 PAGE_META
key=forecast_baseline / name=统计基线 / ic=📈 / title=统计基线 / crumb=客观统计锚 · 系统预计算+计划确认 / order=30

## 2. 区块构成

### 2.1 列表区
**过滤控件**：
| 控件 | 参数 | 选项 |
|------|------|------|
| 批次下拉 | base_batch | 来自 list 不重复批次号 |
| 客户下拉 | oem_code | md_customer.list quiet |
| 零件搜索 | part_no | 输入框 |
| 状态 chips | status | 全部 / 预计算 / 已确认 |
| 路径 chips | base_path | 全部 / 时序外推 / 借用 |
| 分页 | page/page_size | pageable() |

**表格列**：
| 列 | 字段 | 渲染 |
|----|------|------|
| 批次 | base_batch | 正文 |
| 客户 | oem_code+plant_code | 双行 |
| 物料 | part_no | `.b-link` 开模态 |
| 期间 | period | 正文 |
| 基线值 | base_qty | fmt() |
| 路径 | base_path | hue() 徽章 |
| 方法 | base_method | 小字省略 |
| 状态 | status | hue() 徽章 |
| 操作 | — | x-show=status==='预计算' → 【确认】 |

### 2.2 详情模态
墨青头带（base_batch + status 徽章）。KV 分组：
- 基本信息：base_batch / fcst_version / oem_code+plant_code / part_no / period
- 基线数据：base_qty / base_path / base_method / cross_chk
- 参考信息：project_no / veh_model
- 元数据：generator / status

页脚：x-show=status==='预计算' → 【确认】/【调整方法】

### 2.3 操作
- **生成基线**：列表顶部按钮 → 输入 base_batch + fcst_version → 调 generate
- **确认整批**：批次操作 → 调 confirm_batch
- **调整方法**：单行操作 → 弹输入框填 base_method（须登记依据）

## 3. svc 字面量清单

| 区块 | 调用 | 参数 | quiet |
|------|------|------|-------|
| 列表 | `svc("forecast_baseline","list")` | `{base_batch, oem_code, part_no, status, base_path, page, page_size}` | — |
| 客户下拉 | `svc("md_customer","list")` | `{page:1, page_size:200}` | true |
| 详情 | `svc("forecast_baseline","get")` | `{base_batch, oem_code, plant_code, part_no, period}` | — |
| 生成 | `svc("forecast_baseline","generate")` | `{base_batch, fcst_version}` | — |
| 确认 | `svc("forecast_baseline","confirm")` | `{base_batch, oem_code, plant_code, part_no, period}` | — |
| 确认整批 | `svc("forecast_baseline","confirm_batch")` | `{base_batch}` | — |
| 调整方法 | `svc("forecast_baseline","update_method")` | `{base_batch, oem_code, plant_code, part_no, period, base_method}` | — |

## 4. 数据来源
- 客户下拉：md_customer.list → custOptions[]
- 基线只读：销售只读基线，不认可意见走加工表调整层

## 5. 交互要点
1. 生成基线时需先确认 fcst_version 对应快照数据已就绪
2. 销售只读提示：行内无编辑控件，仅计划角色可确认/调方法
3. 借用路径行高亮提示

## 6. 验收关注点
1. 渲染：`#/forecast_baseline` 列表三段式，无 `.kpi`
2. 生成基线后列表有数据
3. 确认后 status 变为 已确认
4. 0 报错
