## §1 渲染
- **VT-RENDER-01** 路由 `#/forecast_baseline` 渲染列表三段式，**无 `.kpi`**

## §2 列表
- **VT-LIST-01** 经 REST `forecast_baseline.generate(base_batch=B202608, fcst_version=202608)` 造数 → 列表含 part_no=8210001 行，base_path 列非空

## §3 模态
- **VT-MODAL-01** 点击 part_no → `wait_modal()` → 断言 base_batch/base_qty/base_path/base_method/status 字段可见

## §4 表单
- **VT-FORM-01** 点击【生成基线】→ 输入 base_batch+fcst_version → submit → toast 含 created → 列表有数据
- **VT-FORM-02** 预计算行【确认】→ status 变为「已确认」
