## §1 渲染

- **VT-RENDER-01 路由渲染有内容**
  - 页面：forecast:forecast_snapshot
  - 操作：admin 进入 `#/forecast_snapshot`
  - 断言：`.card` > 0；列表三段式（过滤条 + 表格 + 分页区域）可见；**无 `.kpi`**（防粘滞）
  - 选择器注意：`:visible` 限定

## §2 造数后列表有数据

- **VT-LIST-01 Opening 后列表有数据**
  - 前置造数：经 REST 调用 `forecast_snapshot.open_version(fcst_version=202608)`
  - 操作：刷新页面 `#/forecast_snapshot`
  - 断言：`table.tbl tr.data` 行数 >= 3（N+1~N+3 三行）；含 part_no=8210001
  - 选择器注意：精确 `has_text("8210001")` 定位

- **VT-LIST-02 fill 后数据标记变化**
  - 前置造数：`forecast_snapshot.fill(fcst_version=202608, oem_code=OEM-A, plant_code=PLT-A1, part_no=8210001, period=2026-09, orig_qty=1150, data_flag="正常")`
  - 操作：搜索 part_no=8210001
  - 断言：对应行 `data_flag=正常`, `orig_qty=1150`
  - 选择器注意：`has_text("8210001")` 行内含 "1150" 和 "正常"

## §3 模态全字段

- **VT-MODAL-01 详情模态全字段**
  - 前置造数：同 VT-LIST-02
  - 操作：点击 part_no=8210001 的 `.b-link` → `wait_modal()` 等 `.loadbox` 消失
  - 断言：模态含字段 fcst_version / oem_code / plant_code / part_no / period / offset / orig_qty / data_flag / source_channel；原始数据可展开
  - 选择器注意：多 `.modal-bd` 用 `.first`；`:visible` 限定

## §4 表单落库回显

- **VT-FORM-01 填预测落库**
  - 前置造数：含 data_flag="OEM未提供" 的行
  - 操作：点击该行【填预测】→ 输入 orig_qty=500 → 选择 data_flag=正常 → 提交
  - 断言：toast 含『已录入』；列表刷新后该行 data_flag=正常 / orig_qty=500
  - 选择器注意：`:visible` 限定表单控件

- **VT-FORM-02 重复填被拒**
  - 前置造数：已填过的行
  - 操作：再次 fill 该行
  - 断言：toast/FdeError 含『已录入，不可修改』
  - 选择器注意：错误 toast 选择器

## §6 0 报错

- **VT-ERR-01 本会话 0 报错**
  - 操作：完成上述全部测试步骤
  - 断言：本脚本会话全程 0 console error / 0 pageerror / 0 HTTP≥400（favicon 除外）
