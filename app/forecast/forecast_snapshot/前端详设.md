## 2. 区块构成

### 2.1 列表区
**过滤控件（与 list 参数对应）**：
| 控件 | 参数 | 选项 |
|------|------|------|
| 版本下拉 | fcst_version | 来自 md_fcst_version.list quiet |
| 客户下拉 | oem_code | 来自 md_customer.list quiet |
| 零件搜索 | part_no | 输入框，@keydown.enter |
| 期间 | period | 输入框 |
| 数据标记 chips | data_flag | 全部 / 正常 / OEM未提供 |
| 分页 | page/page_size | pageable() |

**表格列**：
| 列 | 字段 | 渲染 |
|----|------|------|
| 版本 | fcst_version | 正文 |
| 客户 | oem_code | oem_code+plant_code 双行 |
| 物料 | part_no | `.b-link`，点击开详情模态 |
| 期间 | period | 正文 |
| 偏移 | offset | M+1/M+2/M+3 标签 |
| 预测量 | orig_qty | fmt() 数字 |
| 标记 | data_flag | hue() 徽章（正常=绿/未提供=灰） |
| 来源 | source_channel | 小字 |
| 接收日期 | recv_date | fmtTime() |
| 操作 | — | x-show=data_flag==='OEM未提供' → 【填预测】 |

### 2.2 详情模态
墨青头带（fcst_version + data_flag 徽章），KV 分组：
- 基本信息：fcst_version / oem_code+plant_code / part_no / period / offset
- 预测数据：orig_qty / data_flag / source_channel
- 参考信息：project_no / veh_model（多值）
- 收集信息：recv_date / collector
- 原始数据 JSON 折叠

页脚：x-show=data_flag==='OEM未提供' → 【填预测】按钮→打开填预测子表单

### 2.3 填预测表单（内嵌于模态）
| 字段 | 控件 | 必填 |
|------|------|------|
| orig_qty | input number | ★ |
| data_flag | select: 正常/OEM未提供 | ★ |
| source_channel | select: EDI/OEM门户/邮件Excel/销售转录 | — |

**不进表单**：fcst_version/oem_code/plant_code/part_no/period（行键锁定，编辑态不可改）
**无创建入口**：快照行由 open_version 自动生成

### 2.4 月度 Opening 按钮
列表顶部【月度 Opening】按钮→弹窗：确认当前活跃版本 → 调用 `open_version`

## 3. svc 字面量清单

| 区块 | 调用 | 参数 | quiet |
|------|------|------|-------|
| 列表 | `svc("forecast_snapshot","list")` | `{fcst_version, oem_code, part_no, period, data_flag, page, page_size}` | — |
| 版本下拉 | `svc("md_fcst_version","list")` | `{page:1, page_size:50}` | true |
| 客户下拉 | `svc("md_customer","list")` | `{page:1, page_size:200}` | true |
| 详情 | `svc("forecast_snapshot","get")` | `{fcst_version, oem_code, plant_code, part_no, period}` | — |
| 填预测 | `svc("forecast_snapshot","fill")` | `{fcst_version, oem_code, plant_code, part_no, period, orig_qty, data_flag, source_channel}` | — |
| Opening | `svc("forecast_snapshot","open_version")` | `{fcst_version}` | — |
| 版本状态 | `svc("forecast_snapshot","get_version_status")` | `{fcst_version}` | true |

## 4. 数据来源与下拉
- 版本下拉：`md_fcst_version.list` → fcstVersionOptions[]
- 客户下拉：`md_customer.list` → custOptions[]（显示 oem_code+oem_name）

## 5. 交互要点
1. 行不可变提示：fill 成功后 toast「已录入，不可修改」
2. Opening 确认：弹窗显示活跃零件数预期，确认后执行
3. 未提供行高亮：data_flag=OEM未提供 的行灰底

## 6. 验收关注点
1. 渲染：`#/forecast_snapshot` 列表三段式，无 `.kpi`
2. 造数后列表有数据：经 fill 填入预测量 → 列表含该行且 data_flag=正常
3. 模态全字段：点 part_no → 模态含全部 KV 分组
4. 填预测落库：填 orig_qty → toast → 列表行刷新
5. 重复填被拒：对已正常行再 fill → FdeError toast
6. 0 报错
