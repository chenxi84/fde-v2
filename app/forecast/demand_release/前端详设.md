## 2. 区块构成

### 2.1 列表区（发布单列表）
**过滤控件**：
| 控件 | 参数 | 选项 |
|------|------|------|
| 版本下拉 | fcst_version | md_fcst_version.list quiet |
| 状态 chips | status | 全部 / 草稿 / 已发布 / 已替代 |
| 物料搜索 | part_no | 输入框 |
| 期间 | period | 输入框 |
| 分页 | page/page_size | pageable() |

**发布单表格列**：
| 列 | 字段 | 渲染 |
|----|------|------|
| 发布单号 | rel_no | `.b-link` 开详情 |
| 版本 | fcst_version | 正文 |
| 状态 | status | hue() 徽章（草稿=黄/已发布=绿/已替代=灰） |
| 发布人 | publisher | 正文 |
| 发布时间 | published_at | fmtTime() |
| 操作 | — | x-show=status==='草稿' → 【发布】；x-show=status==='已发布' → 【差异】 |

### 2.2 详情模态（发布单+明细行）
墨青头带（rel_no + status 徽章）。详情分两层：
- **单头信息**：rel_no / fcst_version / base_period / prev_rel_no / publisher / published_at
- **明细表格**（宽表 `.scroll-x`）：

| 列 | 字段 | 渲染 |
|----|------|------|
| 行号 | line_no | 正文 |
| 物料 | part_no | 正文 |
| 期间 | period | 正文 |
| 初步毛需求 | prelim_qty | fmt() |
| 零件级处理 | part_adj | JSON 展开为 [{功能, 原因, 量}] |
| 其中一次性 | onetime_items | JSON 展开 |
| **发布量** | rel_qty | **fmt() 加粗** |
| 主要依据 | basis | 小字 |
| 链路线索 | lineage | 可折叠 JSON |

页脚：x-show=status==='草稿' → 【发布】；x-show=status==='已发布' → 【附加一次性调整】

### 2.3 创建发布草稿
列表顶部【创建发布草稿】→ 输入 prc_batch → 调 create_draft

### 2.4 应用零件级处理
发布单详情页 → 【应用零件级处理】→ 输入 part_no/period/adj_qty/func_type/basis → rel_qty 自动更新

### 2.5 发布确认
【发布】按钮 → 确认对话框（显示联动锁定信息）→ 调 publish

### 2.6 差异视图
【查看差异】→ 调 get_diff → 表格展示变动行（物料/期间/当前量/上期量/差异）

### 2.7 月中附加一次性
已发布单 → 【附加一次性调整】→ 输入 part_no/period/onetime_adj/reason

## 3. svc 字面量清单

| 区块 | 调用 | 参数 |
|------|------|------|
| 发布单列表 | `svc("demand_release","list")` | `{fcst_version, part_no, period, status, page, page_size}` |
| 版本下拉 | `svc("md_fcst_version","list")` | `{page:1, page_size:50}` quiet |
| 详情 | `svc("demand_release","get")` | `{rel_no}` |
| 创建草稿 | `svc("demand_release","create_draft")` | `{prc_batch}` |
| 应用零件级 | `svc("demand_release","apply_part_adj")` | `{rel_no, part_no, period, adj_qty, func_type, basis}` |
| 发布 | `svc("demand_release","publish")` | `{rel_no}` |
| 差异 | `svc("demand_release","get_diff")` | `{rel_no}` |
| 附加一次性 | `svc("demand_release","add_onetime_item")` | `{rel_no, part_no, period, onetime_adj, reason}` |

## 4. 数据来源
- 版本下拉：md_fcst_version.list
- 加工批次：从 forecast_processing 列表取已锁定批次

## 5. 交互要点
1. rel_qty 系统强制加和提示：发布量 = 初步 + Σ零件级处理量
2. 发布确认对话框：提示「发布后将联动锁定快照版本与月度版本」
3. 已替代单灰底
4. 差异视图中正差异=绿/负差异=红

## 6. 验收关注点
1. 渲染：发布单列表三段式，无 `.kpi`
2. 创建草稿后列表出现草稿单
3. 应用零件级处理后 rel_qty 更新
4. 发布后 status=已发布 + 联动验证（快照锁定+版本锁定）
5. 差异视图正确
6. 0 报错
