# demand_release 前端测试用例
> 页面：forecast:demand_release

## §0 测试数据字典
依赖 forecast_processing §0 字典全部 + REL1_NO=发布单号（从 create_draft 返回值捕获）

## §1 渲染
- **VT-RENDER-01** 路由 `#/demand_release` 发布单列表三段式，**无 `.kpi`**

## §2 列表
- **VT-LIST-01** 经 REST `demand_release.create_draft(prc_batch=PRC1)` 造数 → 列表含新发布单，status=草稿
- **VT-LIST-02** status chips 筛选「已发布」→ 仅已发布单

## §3 模态
- **VT-MODAL-01** 点击 rel_no → 模态含单头（rel_no/fcst_version/status）+ 明细表格（part_no/period/prelim_qty/part_adj/rel_qty/basis）
- **VT-MODAL-02** rel_qty = prelim_qty + Σpart_adj（系统强制加和验证）
- **VT-MODAL-03** 页脚按 status：草稿=【发布】；已发布=【附加一次性】

## §4 表单
- **VT-FORM-01** 创建草稿：输入 prc_batch → submit → toast 含 REL- → 列表出现草稿单
- **VT-FORM-02** 应用零件级处理：apply_part_adj(part_no=STD-M6, period=2026-09, adj_qty=-1600, func_type=通用件合并) → rel_qty 更新
- **VT-FORM-03** 发布：点击【发布】→ 确认对话框 → status=已发布 → 联动验证（快照锁定+版本锁定）
- **VT-FORM-04** 已发布不可再发布 → FdeError toast 含『已发布』
- **VT-FORM-05** 未锁定批次不可创建发布 → FdeError 含『未锁定』
- **VT-FORM-06** 差异视图：【查看差异】→ 表格展示物料/期间/当前量/上期量/差异

## §6 0 报错
- **VT-ERR-01** 本会话 0 console error / 0 pageerror / 0 HTTP≥400
