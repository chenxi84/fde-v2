## §1 主数据准备

- **TC-DM-01 创建客户（寄售）**
  - 步骤: `md_customer.create(oem_code=C001.oem_code, oem_name=C001.oem_name, plant_code=C001.plant_code, plant_name=C001.plant_name, settle_mode=C001.settle_mode)`
  - 期望: 返回 `oem_code=OEM-A, settle_mode=寄售`

- **TC-DM-02 创建客户（非寄售）**
  - 步骤: `md_customer.create(oem_code=C002.oem_code, oem_name=C002.oem_name, plant_code=C002.plant_code, plant_name=C002.plant_name, settle_mode=C002.settle_mode)`
  - 期望: 返回 `oem_code=OEM-B, settle_mode=非寄售`

- **TC-DM-03 创建物料**
  - 步骤: `md_material.create(part_no=M001.part_no, part_name=M001.part_name, uom=M001.uom)` + `md_material.create(part_no=M002.part_no, ...)` + `md_material.create(part_no=M003.part_no, ...)`
  - 期望: 三条均创建成功

- **TC-DM-04 创建项目**
  - 步骤: `md_project.create(project_no=PRJ1.project_no, project_name=PRJ1.project_name, stage=PRJ1.stage, oem_code=PRJ1.oem_code, plant_code=PRJ1.plant_code)` + PRJ2
  - 期望: 两条均创建成功，stage=进行中

- **TC-DM-05 创建项目-零件映射**
  - 步骤: `md_project_part.create(project_no=PRJ1.project_no, part_no=8210001, usage=1, share=1.0)` + PP2 + PP3 + PP4
  - 期望: 四条映射均创建成功

- **TC-DM-06 创建替换关系**
  - 步骤: `md_part_replace.create(rel_no=REL1.rel_no, rel_type=REL1.rel_type, old_part=REL1.old_part, new_part=REL1.new_part, ecn_no=REL1.ecn_no)`
  - 期望: 返回 `rel_type=替换, status=生效`

- **TC-DM-07 创建月度版本**
  - 步骤: `md_fcst_version.create(fcst_version=VER1.fcst_version, base_period=VER1.base_period, periods=VER1.periods, opening_date=VER1.opening_date)`
  - 期望: 返回 `fcst_version=202608, status=活跃`

## §2 主业务链（Happy Path）

### §2.1 快照 Opening → 填预测

- **TC-SO-01 月度 Opening 自动生成快照行**
  - 数据: fcst_version=202608
  - 步骤: `forecast_snapshot.open_version(fcst_version=202608)`
  - 期望: 返回 `fcst_version=202608, created >= 12`（3物料×2项目×2客户，每个零件每个客户×3期间，扣除不匹配组合后 >= 12行）

- **TC-SO-02 填客户预测量**
  - 数据: fcst_version=202608, oem_code=OEM-A, plant_code=PLT-A1, part_no=8210001, period=2026-09, orig_qty=1150, data_flag=正常
  - 步骤: `forecast_snapshot.fill(fcst_version=202608, oem_code=OEM-A, plant_code=PLT-A1, part_no=8210001, period=2026-09, orig_qty=1150, data_flag=正常)`
  - 期望: 返回 `orig_qty=1150, data_flag=正常`

- **TC-SO-03 填更多预测行**
  - 步骤: 依次填 8210001/M+2=1100（正常）、8210001/M+3=1050（正常）、STD-M6/各期间/各客户
  - 期望: 全部填充成功

- **TC-SO-04 取版本状态**
  - 步骤: `forecast_snapshot.get_version_status(fcst_version=202608)`
  - 期望: 返回 `total_rows >= 12, unfilled_rows < total_rows`

### §2.2 基线生成与确认

- **TC-SO-05 生成基线**
  - 数据: base_batch=B202608, fcst_version=202608
  - 步骤: `forecast_baseline.generate(base_batch=B202608, fcst_version=202608)`
  - 期望: 返回 `base_batch=B202608, created >= 12`（基线与快照行集一一对应）
  - 注：V1 stub 寄售客户返回模拟历史数据（指数平滑 α=0.3），非寄售走借用路径

- **TC-SO-06 确认基线整批**
  - 步骤: `forecast_baseline.confirm_batch(base_batch=B202608)`
  - 期望: 返回 `confirmed >= 1`

- **TC-SO-07 验证基线状态**
  - 步骤: `forecast_baseline.get_batch_status(base_batch=B202608)`
  - 期望: detail 中含 `status=已确认`

### §2.3 加工表

- **TC-SO-08 创建加工批次**
  - 步骤: `forecast_processing.create_batch(base_batch=B202608, fcst_version=202608)`
  - 期望: 返回 `status=进行中, line_count >= 12`

- **TC-SO-09 填写调整（置信度）**
  - 数据: prc_batch=PRC-202608-001, oem_code=OEM-A, plant_code=PLT-A1, part_no=8210001, period=2026-09, conf_adj=10, conf_reason=达成率97.5%近直采
  - 步骤: `forecast_processing.fill_line(prc_batch=PRC1, oem_code=OEM-A, plant_code=PLT-A1, part_no=8210001, period=2026-09, conf_adj=10, conf_reason=达成率97.5%近直采)`
  - 期望: 返回 `conf_adj=10, indep_qty = base_qty + 10`

- **TC-SO-10 填写调整（一次性）**
  - 数据: onetime_adj=180, onetime_reason=客户加库存, onetime_tag=大一次性
  - 步骤: `forecast_processing.fill_line(prc_batch=PRC1, oem_code=OEM-A, plant_code=PLT-A1, part_no=8210001, period=2026-09, onetime_adj=180, onetime_reason=客户加库存, onetime_tag=大一次性)`
  - 期望: 返回 `onetime_adj=180, indep_qty = base_qty + 10 + 180`

- **TC-SO-11 核定全部行**
  - 步骤: 对每行调 `forecast_processing.review_line(prc_batch=PRC1, ..., chk_result=通过)`
  - 期望: 所有行 `chk_result=通过`

- **TC-SO-12 锁定加工批次**
  - 步骤: `forecast_processing.finalize(prc_batch=PRC1)`
  - 期望: 返回 `status=已锁定`

### §2.4 零件级处理

- **TC-SO-13 通用件合并**
  - 数据: fcst_version=202608, period=2026-09, part_no=STD-M6, adj_qty=-1600, basis=口头加码按历史系数0.65折减
  - 步骤: `part_level_adj.create_generic_merge(fcst_version=202608, period=2026-09, part_no=STD-M6, adj_qty=-1600, basis=口头加码按历史系数0.65折减)`
  - 期望: 返回 `func_type=通用件合并, adj_qty=-1600`

- **TC-SO-14 断点成对调整**
  - 数据: fcst_version=202608, period=2026-10, old_part=8210001, new_part=8210001-B, old_adj=-420, new_adj=400, ecn_no=ECN-A-118
  - 步骤: `part_level_adj.create_breakpoint_adj(fcst_version=202608, period=2026-10, old_part=8210001, new_part=8210001-B, old_adj=-420, new_adj=400, ecn_no=ECN-A-118)`
  - 期望: 返回含 `pair_no`，old `adj_qty=-420`, new `adj_qty=400`

- **TC-SO-15 汇总零件级处理**
  - 步骤: `part_level_adj.summarize(fcst_version=202608)`
  - 期望: 返回 list 含 STD-M6 通用件合并量和 8210001/8210001-B 断点量

### §2.5 毛需求发布

- **TC-SO-16 创建发布草稿**
  - 步骤: `demand_release.create_draft(prc_batch=PRC1)`
  - 期望: 返回 `status=草稿, line_count >= 2`（物料级汇总行数）

- **TC-SO-17 应用零件级处理量**
  - 步骤: `demand_release.apply_part_adj(rel_no=REL1_NO, part_no=STD-M6, period=2026-09, adj_qty=-1600, func_type=通用件合并, basis=口头加码折减)`
  - 期望: `rel_qty = prelim_qty - 1600`

- **TC-SO-18 发布**
  - 步骤: `demand_release.publish(rel_no=REL1_NO)`
  - 期望: 返回 `status=已发布`
  - 联动验证: `forecast_snapshot.get_version_status(fcst_version=202608)` → locked=true; `md_fcst_version.get(202608)` → `status=锁定`

- **TC-SO-19 验证发布单完整性**
  - 步骤: `demand_release.get(rel_no=REL1_NO)`
  - 期望: `status=已发布`, lines 含物料/期间/发布量/依据，`rel_qty = prelim_qty + Σ part_adj`

## §3 分支 / 异常用例

### §3.1 快照

- **TC-ERR-01 重复 Opening 被拒**
  - 步骤: `forecast_snapshot.open_version(fcst_version=202608)`
  - 期望: 抛 `FdeError` 含『已有快照数据』

- **TC-ERR-02 修改已录入快照行被拒**
  - 数据: 对已 fill 为 data_flag=正常的行再次 fill 不同 orig_qty
  - 步骤: `forecast_snapshot.fill(fcst_version=202608, oem_code=OEM-A, plant_code=PLT-A1, part_no=8210001, period=2026-09, orig_qty=9999)`
  - 期望: 抛 `FdeError` 含『已录入，不可修改』

- **TC-ERR-03 负需求量被拒**
  - 步骤: `forecast_snapshot.fill(..., orig_qty=-100)`
  - 期望: 抛 `FdeError` 含『不能为负』

- **TC-ERR-04 不存在的版本 Opening**
  - 步骤: `forecast_snapshot.open_version(fcst_version=209999)`
  - 期望: 抛 `FdeError` 含『不存在』

### §3.2 基线

- **TC-ERR-05 重复生成基线批次被拒**
  - 步骤: `forecast_baseline.generate(base_batch=B202608, fcst_version=202608)`
  - 期望: 抛 `FdeError` 含『已存在』

- **TC-ERR-06 零历史零件走借用路径**
  - 步骤: `forecast_baseline.list(base_batch=B202608, base_path=借用)`
  - 期望: 非寄售客户行 `base_path=借用, base_method` 含『借用』

### §3.3 加工

- **TC-ERR-07 未全部核定即锁定被拒**
  - 数据: 先创建新批次 PRC2，只核定部分行
  - 步骤: `forecast_processing.finalize(prc_batch=PRC2)`
  - 期望: 抛 `FdeError` 含『未通过核定』

- **TC-ERR-08 已锁定批次不可修改**
  - 步骤: `forecast_processing.fill_line(prc_batch=PRC1, ...)`
  - 期望: 抛 `FdeError` 含『已锁定』

- **TC-ERR-09 退回必须附理由**
  - 步骤: `forecast_processing.review_line(prc_batch=PRC1, ..., chk_result=退回)`
  - 期望: 抛 `FdeError` 含『必须附理由』

- **TC-ERR-10 indep_qty 系统强制加和**
  - 步骤: 填 conf_adj=10 后取行验证 indep_qty = base_qty + conf_adj + trend_adj + onetime_adj
  - 期望: indep_qty 自动计算正确（不可手工改总量）

### §3.4 零件级处理

- **TC-ERR-11 断点必须成对**
  - 步骤: 单独创建断点处理（仅 old_part 无 new_part）
  - 期望: `create_breakpoint_adj` 自动生成 old+new 两条，共享 pair_no

- **TC-ERR-12 ECN号必填**
  - 步骤: `part_level_adj.create_breakpoint_adj(ecn_no=空)`
  - 期望: 抛 `FdeError` 含『ECN号必填』

### §3.5 发布

- **TC-ERR-13 非锁定加工批次不可创建发布**
  - 步骤: 用未 finalize 的加工批次创建发布草稿
  - 步骤: `demand_release.create_draft(prc_batch=未锁定批次)`
  - 期望: 抛 `FdeError` 含『未锁定』

- **TC-ERR-14 已发布不可再次发布**
  - 步骤: `demand_release.publish(rel_no=REL1_NO)`
  - 期望: 抛 `FdeError` 含『已发布』

- **TC-ERR-15 已发布不可修改**
  - 步骤: `demand_release.apply_part_adj(rel_no=REL1_NO, ...)`
  - 期望: 抛 `FdeError` 含『已发布』

### §3.6 主数据

- **TC-ERR-16 重复客户被拒**
  - 步骤: `md_customer.create(oem_code=OEM-A, plant_code=PLT-A1, ...)`
  - 期望: 抛 `FdeError` 含『已存在』

- **TC-ERR-17 引用不存在的客户创建项目被拒**
  - 步骤: `md_project.create(oem_code=NOEXIST, plant_code=NOEXIST, ...)`
  - 期望: 抛 `FdeError` 含『不存在』

- **TC-ERR-18 替换关系新旧件相同被拒**
  - 步骤: `md_part_replace.create(rel_type=替换, old_part=8210001, new_part=8210001, ...)`
  - 期望: 抛 `FdeError` 含『不能相同』

### §3.7 月度版本

- **TC-ERR-19 同一时刻只能有一个活跃版本**
  - 步骤: 先创建 VER2（fcst_version=202609），再创建 VER3（fcst_version=202610）
  - 期望: VER3 创建成功（VER2 不同月），但 `md_fcst_version.create(fcst_version=202608)` → 抛 `FdeError` 含『已有活跃版本』
