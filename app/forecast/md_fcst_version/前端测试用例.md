# md_fcst_version 前端测试用例

> 页面：forecast:md_fcst_version

## §0 测试数据字典（本页自足）

| 标识 | 造数服务 | 参数 |
|------|---------|------|
| V1 | md_fcst_version.create | fcst_version=202608, base_period=2026-08, periods=["2026-09","2026-10","2026-11"], opening_date=2026-08-01 |
| V2 | md_fcst_version.create | fcst_version=202609, base_period=2026-09, periods=["2026-10","2026-11","2026-12"] |

## §1 渲染

- **VT-RENDER-01 路由渲染有内容**
  - 页面：forecast:md_fcst_version
  - 操作：admin 进入 `#/md_fcst_version`
  - 断言：`.card` > 0；列表三段式（工具栏 + 表格 + 分页区域）可见；**无 `.kpi`**（防粘滞）；**无业务过滤控件**（仅分页条，list 签名仅 page/page_size）
  - 选择器注意：`:visible` 限定

## §2 造数后列表有数据

- **VT-LIST-01 造数后列表有数据**
  - 前置造数：经 REST 调用 `md_fcst_version.create` 创建 V1、V2
  - 操作：刷新页面 `#/md_fcst_version`
  - 断言：`table.tbl tr.data` 行数 >= 2；含 fcst_version=202608 且 status=活跃；列表按 fcst_version 降序排列（202609 在前）；periods 列展示 M+1~M+3 三标签
  - 选择器注意：精确 `has_text("202608")` 定位行

- **VT-LIST-02 无编辑入口**
  - 操作：检查 V1 行
  - 断言：行内操作列仅【锁定】按钮（活跃行），无【编辑】按钮（本应用无 update 服务）
  - 选择器注意：`:visible` 限定

## §3 模态全字段

- **VT-MODAL-01 详情模态全字段**
  - 前置造数：同 VT-LIST-01
  - 操作：点击 fcst_version=202608 的 `.b-link` → `wait_modal()` 等 `.loadbox` 消失
  - 断言：模态含字段 fcst_version / base_period / periods（结构化展示 M+1~M+3）/ opening_date / status / linked_batch；头带含 status 徽章；原始数据可展开；页脚仅【锁定】+【关闭】，无【编辑】
  - 选择器注意：多 `.modal-bd` 用 `.first`；`:visible` 限定

## §4 表单落库回显

- **VT-FORM-01 创建落库**
  - 操作：点击「+ 新建版本」→ 填写 fcst_version=202610, base_period=2026-10 → 断言 periods 自动推算展示 2026-11/2026-12/2027-01 → 提交
  - 断言：toast 含『月度版本创建成功』；列表刷新后含 202610 行且 status=活跃
  - 选择器注意：`:visible` 限定表单控件

- **VT-FORM-02 空必填字段被拒**
  - 操作：点击「+ 新建版本」→ fcst_version 留空 → 提交
  - 断言：toast 警告『必填』且不发请求；模态保持打开
  - 选择器注意：toast 选择器

- **VT-FORM-03 periods 自动推算**
  - 操作：点击「+ 新建版本」→ base_period 填入 2026-08 → 断言 periods 只读展示区显示 2026-09 / 2026-10 / 2026-11 三个标签
  - 选择器注意：periods 为只读标签，非可编辑 input

- **VT-FORM-04 活跃版本冲突**
  - 前置造数：V1（status=活跃）存在
  - 操作：创建新版本 fcst_version=202699, base_period=2026-99 → 提交
  - 断言：后端 FdeError toast「当前已有活跃版本 202608」
  - 选择器注意：错误 toast 选择器

- **VT-FORM-05 锁定操作**
  - 前置造数：V2（status=活跃）存在
  - 操作：点击 V2 行【锁定】→ 弹窗输入 rel_no=REL-202609-001 → 确认
  - 断言：toast 含『版本已锁定』；列表刷新后 V2 status=锁定 / linked_batch=REL-202609-001；行内不再显示【锁定】按钮
  - 选择器注意：确认弹窗 `:visible` 限定

- **VT-FORM-06 重复锁定被拒**
  - 前置造数：V2 已锁定
  - 操作：检查 V2 行 → 断言无【锁定】按钮（已锁定行无操作）

## §6 0 报错

- **VT-ERR-01 本会话 0 报错**
  - 操作：完成上述全部测试步骤
  - 断言：本脚本会话全程 0 console error / 0 pageerror / 0 HTTP>=400（favicon 除外）
