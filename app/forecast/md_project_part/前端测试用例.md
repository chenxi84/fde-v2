# md_project_part 前端测试用例

> 页面：forecast:md_project_part

## §0 测试数据字典（本页自足）

| 标识 | 造数服务 | 参数 |
|------|---------|------|
| C1 | md_customer.create | oem_code=OEM-A, plant_code=PLT-A1, oem_name=主机厂A, plant_name=一工厂, settle_mode=寄售 |
| M1 | md_material.create | part_no=8210001, part_name=前保险杠总成, uom=件, mat_type=成品 |
| M2 | md_material.create | part_no=8210002, part_name=后保险杠总成, uom=件, mat_type=半成品 |
| PRJ1 | md_project.create | project_no=PRJ-001, project_name=车型A, stage=进行中, oem_code=OEM-A, plant_code=PLT-A1 |
| PP1 | md_project_part.create | project_no=PRJ-001, part_no=8210001, veh_model=SUV, usage=2, share=1.0 |
| PP2 | md_project_part.create | project_no=PRJ-001, part_no=8210002, usage=1, share=0.5, eff_from=2026-01, eff_to=2030-12 |

## §1 渲染

- **VT-RENDER-01 路由渲染有内容**
  - 页面：forecast:md_project_part
  - 操作：admin 进入 `#/md_project_part`
  - 断言：`.card` > 0；列表三段式（过滤条 + 表格 + 分页区域）可见；**无 `.kpi`**（防粘滞）
  - 选择器注意：`:visible` 限定

## §2 造数后列表有数据

- **VT-LIST-01 造数后列表有数据**
  - 前置造数：经 REST 依次调用 C1 → M1+M2 → PRJ1 → PP1+PP2
  - 操作：刷新页面 `#/md_project_part`
  - 断言：`table.tbl tr.data` 行数 >= 2；含 project_no=PRJ-001 / part_no=8210001 / share=100%（fmt 百分比格式化）
  - 选择器注意：精确 `has_text("PRJ-001")` 定位行

- **VT-LIST-02 过滤生效**
  - 前置造数：同 VT-LIST-01
  - 操作：project_no 输入框填入「PRJ-001」→ 点击「查询」
  - 断言：仅显示 PRJ-001 的行（PP1 + PP2）；共 2 行
  - 选择器注意：输入后 Enter 或点击查询按钮

- **VT-LIST-03 零件号模糊搜索**
  - 操作：part_no 输入框填入「8210」→ 点击「查询」
  - 断言：PP1 和 PP2 均可见（模糊匹配命中）

## §3 模态全字段

- **VT-MODAL-01 详情模态全字段**
  - 前置造数：同 VT-LIST-01
  - 操作：点击 project_no=PRJ-001 的 `.b-link` → `wait_modal()` 等 `.loadbox` 消失
  - 断言：模态含字段 project_no / part_no / veh_model / usage / share / eff_from / eff_to；头带含 project_no + part_no；原始数据可展开
  - 选择器注意：多 `.modal-bd` 用 `.first`；`:visible` 限定

## §4 表单落库回显

- **VT-FORM-01 创建落库**
  - 前置造数：C1 + M1 + PRJ1 存在
  - 操作：点击「+ 新建映射」→ project_no autocomplete 选 PRJ-001 → part_no autocomplete 选 8210001 → share 默认 1.0 → 提交
  - 断言：toast 含『项目-零件映射创建成功』；列表刷新后含新映射行
  - 选择器注意：`:visible` 限定表单控件；双 autocomplete 下拉项可点击

- **VT-FORM-02 空必填字段被拒**
  - 操作：点击「+ 新建映射」→ project_no 留空 → 提交
  - 断言：toast 警告『必填』且不发请求；模态保持打开
  - 选择器注意：toast 选择器

- **VT-FORM-03 双 autocomplete 联动**
  - 操作：点击「+ 新建映射」→ 点击 project_no autocomplete → 断言下拉含 PRJ-001（来自 quiet 拉取）→ 点击 part_no autocomplete → 断言下拉含 8210001 + 8210002（来自 quiet 拉取）
  - 选择器注意：autocomplete 下拉 `:visible` 限定

- **VT-FORM-04 编辑回显**
  - 前置造数：PP1 存在
  - 操作：点击 PP1 行【编辑】→ 断言 project_no / part_no 只读不可改 → 修改 share=0.8 → 提交
  - 断言：toast 含『映射更新成功』；列表刷新后 share=80%
  - 选择器注意：edit 表单中 project_no/part_no input 为 readonly

- **VT-FORM-05 share 范围校验**
  - 操作：点击「+ 新建映射」→ 填 project_no=PRJ-001, part_no=8210002 → share 填 1.5 → 提交
  - 断言：后端 FdeError toast「供应份额必须在 0~1 之间」
  - 选择器注意：错误 toast 选择器

## §6 0 报错

- **VT-ERR-01 本会话 0 报错**
  - 操作：完成上述全部测试步骤
  - 断言：本脚本会话全程 0 console error / 0 pageerror / 0 HTTP>=400（favicon 除外）
