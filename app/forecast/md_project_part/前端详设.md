## 1. 页面元数据 PAGE_META

| 字段 | 值 | 说明 |
|---|---|---|
| key | `md_project_part` | = 应用文件夹名，page_id 为 `forecast:md_project_part` |
| name | 项目-零件映射 | 侧栏菜单名 |
| ic | 🔗 | 图标字 |
| title | 项目-零件映射 | 主区页面头标题 |

## 2. 区块构成

### 2.1 列表区（查）—— 三段式：工具栏 / 表格 / 分页条

**用途**：项目-零件映射全量浏览 + 条件检索 + 新建入口。本页为非看板页，不设 KPI 指标带（验收断言无 `.kpi`）。

**过滤控件（与 `md_project_part.list(project_no, part_no, veh_model, page, page_size)` 可过滤参数一一对应）**：

| 控件 | 对应参数 | 形态 |
|---|---|---|
| 项目号输入框 | `project_no` | placeholder「项目号」，Enter 或「查询」按钮触发（后端 LIKE 模糊匹配） |
| 零件号输入框 | `part_no` | placeholder「零件号」，Enter 或「查询」按钮触发（后端 LIKE 模糊匹配） |
| 车型输入框 | `veh_model` | placeholder「车型」，Enter 或「查询」按钮触发（后端 LIKE 模糊匹配） |
| 分页条 | `page` / `page_size` | `pageable()`，integer 传参 |

**工具栏**：「查询」「+ 新建映射」（打开 2.3 创建模态）。

**表格列（`.tbl.tight` + `.scroll-x`；全部为详情字段子集）**：

| 列 | 字段 | 渲染 |
|---|---|---|
| 项目号 | `project_no` | `.b-link`，点击打开详情模态 |
| 零件号 | `part_no` | 文本 |
| 车型 | `veh_model` | 文本，空值 `dash()` |
| 单车用量 | `usage` | 数字，空值/0 `dash()` |
| 供应份额 | `share` | 百分比 `fmt()` |
| 生效起 | `eff_from` | 文本，空值 `dash()` |
| 生效止 | `eff_to` | 文本，空值 `dash()` |
| 操作 | — | 【编辑】（开编辑表单） |

**交互**：任一过滤变化 → 重置回第 1 页重载；编辑保存成功后刷新当前页；空结果显示空态文案。

### 2.2 详情模态（查全）—— 三段式：墨青头带 / KV 分组体 / 操作页脚

**用途**：点 `project_no` 弹出，展示 `md_project_part.get` 返回的全部字段。

| 分组（`.sec`） | 字段 | 渲染 |
|---|---|---|
| 头带 | `project_no` + `part_no` | 墨青头带 |
| 基本信息 | `project_no` / `part_no` | `.kv`；注明「联合主键 · project_no+part_no 创建后不可直接变更」 |
| 量纲信息 | `veh_model` / `usage` / `share` | `.kv`；share 标注「范围 [0, 1]」；空值 `dash()` |
| 生效期间 | `eff_from` / `eff_to` | `.kv`；空值 `dash()` |
| 原始数据 | get 返回全量 JSON | 底部折叠（默认收起） |

**页脚 `.modal-ft`**：【编辑】（打开编辑表单）【关闭】。

### 2.3 创建 / 编辑表单（增/改）—— 模态表单

**用途**：覆盖 `md_project_part.create` / `md_project_part.update` 接受的业务参数。

| 字段 | 控件 | 必填 | create 可见 | update 可见 | 约束来源 |
|---|---|---|---|---|---|
| `project_no` | 项目 autocomplete（见 §4） | ★ 必填 | 是 | 否（只读展示） | BR-02/BR-03；后端 cross-app 调 md_project.get 校验 |
| `part_no` | 物料 autocomplete（见 §4） | ★ 必填 | 是 | 否（只读展示） | BR-02/BR-04；后端 cross-app 调 md_material.get 校验 |
| `veh_model` | input，maxlength=50 | 选填 | 是 | 是 | — |
| `usage` | input number，min=0 | 选填 | 是 | 是 | 单车用量 |
| `share` | input number，min=0，max=1，step=0.01 | 选填 | 是 | 是 | BR-05 范围 [0, 1] |
| `eff_from` | date input | 选填 | 是 | 是 | 生效起 |
| `eff_to` | date input | 选填 | 是 | 是 | 生效止 |

- create 模式：全部字段可见，必填 2 项（project_no, part_no）；share 默认值 1.0。
- update 模式：`project_no` + `part_no` 回填展示但不可修改（联合主键）；`veh_model` / `usage` / `share` / `eff_from` / `eff_to` 可修改。如需变更 project_no 或 part_no，应删除旧映射后新建。
- 布局：必填先行——第一行（project_no autocomplete + part_no autocomplete）；折叠区「更多字段 ▾」：veh_model / usage / share / eff_from / eff_to；底部右对齐「取消」「保存」。
- 前端仅做必填校验（空值 → toast 警告、不提交）；share 范围、引用校验由后端执行，`FdeError` 经 api.js 以错误 toast 呈现。
- cross-app 校验：创建时后端调用 `self.fde.call("md_project","get", project_no)` + `self.fde.call("md_material","get", part_no)`，前端 autocomplete 已限定选项降低无效输入。
- 提交成功：toast 成功消息 → 关闭模态 → 重置过滤重载列表（create）/ 刷新当前页（update）。

| 区块 | 调用（应用.服务） | 参数 | quiet | 说明 |
|---|---|---|---|---|

| 编辑表单 | `svc("md_project_part","update")` | `{project_no, part_no, veh_model, usage, share, eff_from, eff_to}` | — | 更新（仅传有变更字段） |

> 以上 6 处必须在 view.js 中以字面量逐项书写，**勿用变量拼名**。

## 4. 数据来源与下拉

**项目下拉（创建表单 autocomplete）**：
- 页面初始化一次性 `svc("md_project","list")` `{page:1, page_size:200}`，`quiet:true` 探测：失败不喷 toast；零值兜底 → 下拉显示「暂无可选项目」禁用项。
- 由返回项构建 `projectOptions` 扁平数组（字段 `project_no, project_name`），autocomplete 显示「project_no - project_name」，选中后回填 project_no。

**物料下拉（创建表单 autocomplete）**：
- 页面初始化一次性 `svc("md_material","list")` `{page:1, page_size:500}`，`quiet:true` 探测：失败不喷 toast；零值兜底 → 下拉显示「暂无可选物料」禁用项。
- 由返回项构建 `partOptions` 扁平数组（字段 `part_no, part_name`），autocomplete 显示「part_no - part_name」，选中后回填 part_no。

**契约 payload → 区块字段映射**：

| 契约 | 载荷字段 | 映射区块 |
|---|---|---|
| `md_project_part.list` 返回项 | `project_no, part_no, veh_model, usage, share, eff_from, eff_to` | 2.1 列表列 |
| `md_project_part.get` 返回 | 同上（全量） | 2.2 详情模态 kv + 原始数据 |
| `md_project_part.create` 入参 | `project_no, part_no, veh_model, usage, share, eff_from, eff_to` | 2.3 创建表单 |
| `md_project_part.update` 入参 | `project_no, part_no, veh_model, usage, share, eff_from, eff_to` | 2.3 编辑表单（project_no/part_no 只读） |
| `md_project.list` 项 | `project_no, project_name` | 项目 autocomplete 选项 |
| `md_material.list` 项 | `part_no, part_name` | 物料 autocomplete 选项 |

## 5. 交互要点

1. **加载**：首载正常拉取 list（非看板页，失败走 api.js 统一通道）+ quiet 拉取 md_project.list + md_material.list 构建双下拉。
2. **过滤**：project_no / part_no / veh_model 输入后 Enter 或「查询」触发；翻页仅改 `page/page_size`，不清过滤条件。
3. **双 autocomplete**：project_no 和 part_no 各独立 autocomplete 下拉（@click.stop / @click.away / @input 实时过滤），选项存储为独立扁平数组（`projectOptions` / `partOptions`），列表项双行显示「编码 - 名称」，选中后回填对应编码。
4. **微交互**：表格行 hover 高亮；project_no `.b-link` hover 下划线；share 百分比格式化显示；「保存」按钮提交期 loading 防重复点击。
5. **成功流**：create 成功 → 关闭模态并清空表单 → toast「项目-零件映射创建成功」→ 列表回第 1 页重载；update 成功 → 关闭模态 → toast「映射更新成功」→ 刷新当前页。
6. **错误流**：重复映射 / 项目不存在 / 物料不存在 / share 超范围等后端 `FdeError` → toast 错误信息，模态保持打开。
7. **空态**：无任何映射时「暂无映射 —— 点『新建映射』创建」；过滤无命中时「无符合条件的映射」。
8. **折叠「更多字段 ▾」**：veh_model / usage / share / eff_from / eff_to 共 5 个选填字段。
9. **展示工具**：`fmt()`（share 百分比）、`dash()`（空值字段）、无金额字段、无时间字段、无 `*_json` 字段无需 `tryParse()`。

## 6. 验收关注点（供第⑧步）

1. **路由渲染**：`#/md_project_part` 挂载出列表三段式（工具栏 + 表格 + 分页条），**断言无 `.kpi`**（非看板页防挂载粘滞假过）。
2. **造数后列表有数据**：先造 project + material → 创建映射 → 列表 1 行，project_no / part_no / veh_model / usage / share / eff_from / eff_to 齐全。
3. **过滤一一对应**：project_no=PRJ 模糊匹配；part_no=8210 模糊匹配；veh_model=车型A 模糊匹配；组合条件；无匹配显示空态且不抛错。
4. **模态全字段**：点 project_no 开模态，断言全部 7 字段可见 + 「原始数据」可展开。
5. **表单落库**：create 表单选 project_no + part_no（★）→ 提交 → 列表出现新记录；空必填字段提交 → toast 警告且不发请求。
6. **双 autocomplete**：project_no 下拉含已创建项目；part_no 下拉含已创建物料；选中后正确回填。
7. **跨应用双校验**：project_no 选不存在项目 → 后端 toast「项目不存在」；part_no 选不存在物料 → 后端 toast「物料不存在」。
8. **share 范围**：输入 1.5 → 后端 toast「供应份额必须在 0~1 之间」。
9. **update 主键只读**：编辑模态 project_no + part_no 只读不可改；修改 share 保存后回显正确。
10. **干净控制台**：全程 0 console error / 0 pageerror / 0 HTTP>=400（受限会话 403 属预期执法单独豁免）。
