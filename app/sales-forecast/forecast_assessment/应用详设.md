# 应用详设：预测转单率考核表（forecast_assessment）

> **应用名**：`forecast_assessment` | **类名**：`ForecastAssessment`
> **对应聚合根卡**：architecture.md #11 | **对应 BRD**：§2.9 D12

---

## 1. 需求概览

- **需求名称**: 预测考核与闭环反哺
- **优先级**: P1（事后闭环，反哺激励与数据校准）
- **涉及角色**: 总部计划（归因认定）、销售管理（激励考核应用）、一线销售（查看/申诉）

### 1.2 需求背景
考核不是终点，反哺才是。两个任务：①让报数的人有动机报实（激励闭环）；②让系统每个周期变得更准（数据闭环：反哺信任折扣/策略/参数）。

### 1.3 指标体系（双口径）
- **消耗口径（结算量）**: 考核预测能力（达成率/FVA/准确率）
- **发运口径（转单量）**: 考核报数质量（转单率/呆滞）

---

## 2. 用户故事

#### `US-01` 考核计算与归因（优先级：P1）
- **故事描述**: 作为总部计划，我想要计算双口径指标并区分可控性归因，以便于公平考核与闭环反哺
- **验收场景**：
  1. `US-01-AC1` **转单率考核**: Given 预测1300/实际转单1050/归因"销售多报"，Then 转单率80.8%，考核结论=计入呆滞考核
  2. `US-01-AC2` **塌方免责**: Given 预测850/实际转单560/归因"OEM需求塌方"有减产证据，Then 考核结论=免责剔除
  3. `US-01-AC3` **FVA计算**: Given 基线误差30/核定误差250，Then FVA=−220（修正拉低准确率）

## 3.2 业务规则

| 编号 | 规则 |
|-----|------|
| BR-01 | 考核引用发布快照（R版）+实际结算快照，不引用实时值 |
| BR-02 | 可控性区分：销售多报计入考核，OEM塌方免责剔除 |
| BR-03 | 塌方认定须举证（外部减产/销量骤降/结算趋势/客户函件） |
| BR-04 | 容忍区间 ±10%，区间内不追责 |
| BR-05 | 通用件呆滞考核上移总量层，不下沉个人 |
| BR-06 | 事件履约单独核销，不混入消耗口径准确率 |
