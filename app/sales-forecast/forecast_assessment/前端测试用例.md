# forecast_assessment 前端测试用例

> 逐应用 · 第⑧步产出 | 对应前端详设 PAGE_META.key = forecast_assessment

## TC-FA-01 本页渲染
- 页面: `/view/sales-forecast/#forecast_assessment`
- 操作: admin 登录后访问
- 断言:
  1. 列表区 `.card .tbl` 存在（即使无数据也会有空提示行）
  2. **批量计算按钮存在**: `.tagline` 内可见 `批量计算` 按钮或 `b-pri` 含"批量计算"文本
  3. 搜索栏含结果 chips（计入考核/免责剔除/归因流程·策略）和搜索输入框
  4. 非看板页 `.kpi` 数量 == 0（防粘滞——确保不是 dashboard 残留）

## TC-FA-02 批量计算 —— 落库回显
- 前置: 列表已渲染
- 造数: 浏览器内 fetch POST `/api/apps/sales-forecast/forecast_assessment/call/calculate`，传入 period=2026-08
- 操作: 点击 `批量计算` → 选择或输入考核期间 period=2026-08 → 点击确认
- 断言:
  1. 计算过程有 loading 提示
  2. 计算完成后 toast 提示 "计算完成，共 N 条记录"
  3. 列表自动刷新，显示新计算的考核记录

## TC-FA-03 详情模态全字段
- 前置: 列表有数据
- 操作: 点击某考核记录的编号 `.b-link`
- 断言:
  1. 模态 `.modal-mask` 出现
  2. 等待 `.loadbox` 消失
  3. 单头 KV 含: fa_no, part_no, veh_model, period, result, attribution
  4. 双口径展示: fcst_qty（预测量）, actual_qty（实际量）, conv_rate（转化率）, dev_qty（偏差量）
  5. FVA 视图存在（预测价值分析，含各环节贡献度分解）

## TC-FA-04 结果筛选
- 前置: 列表已渲染
- 操作: 依次点击结果 chips（计入考核 / 免责剔除 / 归因流程·策略）
- 断言:
  1. 点击后 chip 高亮
  2. 列表仅刷新为对应考核结果的记录
  3. 再次点击已选中 chip 取消筛选

## TC-FA-05 归因详情查看
- 前置: 打开一个考核详情
- 操作: 查看 attribution（归因）字段和 FVA 视图
- 断言:
  1. attribution 显示归因类型（如 "归因流程·策略"）
  2. FVA 视图包含各环节（需求收集→加工→发布→...→考核）的贡献值
  3. 各环节贡献值合计与总偏差量 dev_qty 逻辑一致

## TC-FA-06 免责剔除记录
- 前置: 列表中有 result=免责剔除 的记录
- 操作: 点击打开详情
- 断言:
  1. 模态中 attribution 显示免责原因
  2. 相关字段（如 dev_qty）可能有特殊标记（如负值或 0）
  3. FVA 视图中免责环节有特殊标注
