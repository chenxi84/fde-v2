# 前端详设：车型—零件映射表（vehicle_part_mapping）

> PAGE_META.key = `vehicle_part_mapping` | order = `70`

## PAGE_META
- key: `vehicle_part_mapping`, name: `车型映射`, ic: `link`, title: `车型—零件映射管理`, crumb: `D02 量纲权威源`, order: `70`

## 区块构成

### 列表
- 列: part_no, veh_model, platform, usage, share, lc_stage, lc_shape, sop, eop, status, source
- 搜索: part_no（文本输入）, veh_model（文本输入）, lc_stage（多选枚举：爬坡/成熟/衰退/EOP临近）, status（多选枚举：生效/停用）
- 操作:
  - 生效 → [编辑] [量纲变更] [停用]
  - 停用 → [查看详情]

### 详情模态
- 字段分组:
  - 映射标识: part_no, veh_model, platform
  - 量纲（权威源）: usage, share
  - 生命周期: lc_stage, lc_shape, sop, eop
  - 状态与来源: status, source
- 子账本:
  - 量纲历史版本（子表）: effective_from, field_name（usage/share）, value, effective_to, change_basis
- 页脚操作:
  - 生效 → [编辑] [量纲变更] [停用]
  - 停用 → 只读

### 表单（创建/编辑）
- 可写字段:
  - 必填: part_no, veh_model, usage, share, lc_stage, sop, source
  - 可选: platform, lc_shape, eop
  - 折叠: —（无折叠字段，全显式填写）
- 必填项: part_no, veh_model, usage, share, lc_stage, sop, source
- 可选/折叠: platform, lc_shape（默认"传统"）, eop

### 量纲变更子表单（模态弹窗）
- 可写字段:
  - 必填: field_name（usage/share）, new_value（新用量/份额）, effective_date（生效日期）, change_basis（依据：设变通知号/商务函件）
  - 不可写: current_value（只读展示）, effective_from_display（当前生效起期）
- 必填项: field_name, new_value, effective_date, change_basis
- 可选/折叠: —（单一操作弹窗）

### 停用确认子表单
- 可写字段:
  - 必填: reason（停用原因）
  - 不可写: part_no, veh_model（只读展示）
- 必填项: reason

## svc 字面量清单
- svc("vehicle_part_mapping", "list") — 映射列表（按零件/车型/状态筛选）
- svc("vehicle_part_mapping", "get") — 映射详情（含量纲历史版本）
- svc("vehicle_part_mapping", "create") — 新建映射
- svc("vehicle_part_mapping", "update") — 更新映射属性
- svc("vehicle_part_mapping", "set_usage") — 变更单车用量（生成历史版本）
- svc("vehicle_part_mapping", "set_share") — 变更供应份额（生成历史版本）
- svc("vehicle_part_mapping", "get_usage_history") — 查询量纲历史版本
- svc("vehicle_part_mapping", "disable") — 停用映射（须填原因）

## 验收关注点
- 新建按钮存在
- 非看板页 .kpi==0
- 列表列 ⊆ 详情字段集（列表字段均在详情模态中出现）
- 搜索控件与 list 参数一一对应（part_no/veh_model/lc_stage/status）
- 表单字段 = 写服务接受参数（create/update 参数与表单字段一致）
- 量纲变更弹窗须填写 effective_date + change_basis
- 历史版本子表按 effective_from 倒序展示，含旧值保留区间
- lc_shape="上市高后下滑"时前端给出视觉提示（该形态基线须用衰减模型）
- 停用操作须填写停用原因
- 进行中项目零件无生效映射时前端告警提示
