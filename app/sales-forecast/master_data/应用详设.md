# 应用详设：通用主数据（master_data）

> **应用名**：`master_data` | **类名**：`MasterData`
> **对应聚合根卡**：architecture.md #12 | **对应 BRD**：§2.17

---

## 1. 需求概览

- **需求名称**: 通用主数据本地冗余
- **优先级**: P0（全部业务单据的基础校验依赖）
- **涉及角色**: 系统（同步）、总部计划（扩展属性维护）

### 1.2 需求背景
权威源在外部（MDM/ERP/HR），本域不维护主体、只引用。通过主数据接口同步到本地冗余，保证引用性能、离线可用与历史快照。五类实体：客户/物料/车型/用户/日历。

---

## 2. 用户故事

#### `US-01` 主数据查询（优先级：P1）
- **故事描述**: 作为业务应用，我想要查询客户/零件/车型/用户/日历数据，以便于校验单据录入
- **验收场景**：
  1. `US-01-AC1` **客户查询**: Given oem_code，When get_customer，Then 返回客户信息+结算模式+预测行为标签
  2. `US-01-AC2` **缺失阻断**: Given 零件不存在于本地冗余表，When 录入 D03 明细，Then 系统拒绝

#### `US-02` 主数据同步（优先级：P1）
- **故事描述**: 作为系统，我想要从权威源增量同步主数据，以便于本地冗余与权威源一致
- **验收场景**：
  1. `US-02-AC1` **增量同步**: Given 权威源新增一个客户，When sync_customers(data)，Then 客户写入 md_customer，主体字段更新
  2. `US-02-AC2` **冲突处理**: Given 权威源与本地扩展属性均被修改，Then 主体以权威源覆盖、扩展属性以本地为准

---

## 3.2 业务规则

| 编号 | 规则 |
|-----|------|
| BR-01 | 主体字段本地只读（同步覆盖），扩展属性本地可维护 |
| BR-02 | 缺失阻断：零件/客户/车型在本地冗余表不存在→阻断相应单据录入 |
| BR-03 | 同步以权威源覆盖主体；扩展属性以本地为准 |
| BR-04 | 接口失败降级：使用本地缓存并显示"同步时点"；超期未同步告警 |
| BR-05 | 月度与权威源对账并留快照 |
