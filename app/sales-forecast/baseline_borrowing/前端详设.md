# 前端详设：基线借用台账（baseline_borrowing）

## PAGE_META
- key: `baseline_borrowing`, name: `基线借用`, ic: `copy`, title: `基线借用台账`, crumb: `D05 历史不足零件的基线例外`, order: `100`

## 区块构成

### 列表
- 列: jy_no, part_no, veh_model, hist_months, borrow_method, borrow_source, status, reviewer, review_date
- 搜索: part_no（文本输入）, status（多选枚举：待审核/生效/已转自产/已关闭）, borrow_method（枚举多选：先导指标/类比/模板拟合/上移/池化）
- 操作:
  - 待审核 → [审核（通过/驳回）] [编辑]
  - 生效 → [早期校准] [关闭（转自产/不再使用）] [查看详情]
  - 已转自产 → [查看详情]
  - 已关闭 → [查看详情]

### 详情模态
- 字段分组:
  - 借用单标识: jy_no, part_no, veh_model, hist_months, status
  - 借用方法: borrow_method, borrow_source, source_params
  - 推导基线: derived_qty（JSON 展开：M0~M+N 各期值）
  - 校准与审核: calibration, reviewer, review_date
  - 关联信息: proc_batch（关联 D04 加工批次）
- 子账本:
  - derived_qty 各期展开表（期间 / 基线值）
- 页脚操作:
  - 待审核 → [审核通过] [审核驳回] [编辑]
  - 生效 → [早期校准] [关闭借用单]
  - 已转自产/已关闭 → 只读

### 表单（创建/编辑）
- 可写字段:
  - 必填: part_no, veh_model, hist_months, borrow_method, borrow_source, source_params, derived_qty
  - 可选: —
  - 折叠: derived_qty（JSON 编辑区，M0~M+N 各期值逐期填写）
- 必填项: part_no, veh_model, hist_months, borrow_method, borrow_source, source_params, derived_qty
- 可选/折叠: —（无折叠字段，全部必填）

### 审核子表单
- 可写字段:
  - 必填: approved（是/否）, comment（审核意见，驳回时必填理由）
  - 不可写: jy_no, part_no（只读展示）
- 必填项: approved
- 可选/折叠: comment（通过时可选，驳回时必填）

### 早期校准子表单
- 可写字段:
  - 必填: calibration_data（校准参数更新）
  - 不可写: jy_no（只读展示）
- 必填项: calibration_data
- 可选/折叠: —

### 关闭子表单
- 可写字段:
  - 必填: reason（关闭原因：转自产/不再使用）
  - 不可写: jy_no（只读展示）
- 必填项: reason

## svc 字面量清单
- svc("baseline_borrowing", "list") — 借用单列表（按零件/状态/方法筛选）
- svc("baseline_borrowing", "get") — 借用单详情（含推导基线各期值）
- svc("baseline_borrowing", "create") — 新建借用单（选借法+定来源+参数）
- svc("baseline_borrowing", "review") — 审核（通过/驳回）
- svc("baseline_borrowing", "calibrate") — 早期校准更新
- svc("baseline_borrowing", "close") — 关闭借用单（转自产/不再使用）
- svc("baseline_borrowing", "get_derived_baseline") — 获取推导基线值

## 验收关注点
- 新建按钮存在
- 非看板页 .kpi==0
- 列表列 ⊆ 详情字段集（列表字段均在详情模态中出现）
- 搜索控件与 list 参数一一对应（part_no/status/borrow_method）
- 表单字段 = 写服务接受参数（create 参数与表单字段一致）
- 有早期数据但未填写 calibration 时审核驳回提示
- derived_qty JSON 编辑区支持逐期填写 M0~M+N 各期值
- 审核驳回须填写驳回理由（comment 条件必填）
- 关闭须选择关闭原因（转自产/不再使用）
- hist_months > 12 时系统提示"历史充足，建议走 D10 策略拟合"
