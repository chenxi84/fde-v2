# 应用详设：基线借用台账（baseline_borrowing）

> **应用名**：`baseline_borrowing` | **类名**：`BaselineBorrowing`
> **对应聚合根卡**：architecture.md #5 | **对应 BRD**：§2.5 D05

---

## 1. 需求概览

- **需求名称**: 基线借用管理
- **优先级**: P1（历史不足零件的基线例外，保证锚不缺失）

### 1.2 需求背景
历史不足零件（<12个月或无完整季节周期）无法用时间序列外推基线。五种借法（先导指标/类比/模板拟合/上移/池化）提供替代的客观锚来源。与 D10 分工：历史充足→D10选策略；历史不足→D05借基线。

### 1.3 涉及角色
- **总部计划**：选借法、定参数、校准与审核
- **一线销售**：提供类比线索、客户预测可信度情报

---

## 2. 用户故事

#### `US-01` 借用单登记与审核（优先级：P1）
- **故事描述**: 作为总部计划，我想要为历史不足零件登记借用基线（选借法+定来源参数），以便于 D04 有可用的基线锚
- **验收场景**：
  1. `US-01-AC1` **类比+早期校准**: Given 新车型C有2个月早期数据，When 选类比法（相似车型A）+ 用首2月数据校准峰值/衰减率，Then 审核通过
  2. `US-01-AC2` **先导指标**: Given 未上市车型D零历史，When 选先导指标法（取OEM预测true_qty），Then 借用单生成，推导基线=OEM预测值
  3. `US-01-AC3` **无校准拒绝**: Given 有早期数据但未做校准，When 提交审核，Then 驳回并提示"有早期数据必须校准参数"

---

## 3.2 业务规则

| 编号 | 规则 |
|-----|------|
| BR-01 | 无登记不借用：历史不足零件未经借用登记不得产生基线 |
| BR-02 | 校准优先：有自身早期数据必须校准参数，纯照搬模板不予通过 |
| BR-03 | 自动退出：历史转充足后切换自产策略，防止"永久借用" |
| BR-04 | 锚纪律同等适用：借用基线同样不受脉冲/事件影响 |
| BR-05 | 先导指标须过拆解：取 true_qty，不取 orig_qty |

### 3.4 状态机

```
(新建) --提交--> 待审核 --通过--> 生效 --历史转充足--> 已转自产 → 已关闭
待审核 --驳回--> (修改重报)
生效 --不再使用--> 已关闭
```
