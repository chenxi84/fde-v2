# 前端详设：毛需求发布单（demand_release）

> PAGE_META.key = `demand_release` | order = `40`

## PAGE_META
- key: `demand_release`, name: `发布管理`, ic: `send`, title: `毛需求发布管理`, crumb: `D09 发布与口径冻结`, order: `40`

## 区块构成

### 列表
- 列: rel_no, rel_version, base_period, status, publisher, publish_date
- 搜索: rel_version（文本输入）, status（多选枚举：草稿/待发布/已发布/已替代）, base_period（日期选择）
- 操作:
  - 草稿 → [checklist校验] [发布] [版本修订]
  - 待发布 → [发布] [版本修订]
  - 已发布 → [查看详情] [版本比对] [版本修订]
  - 已替代 → [查看详情] [版本比对]

### 详情模态
- 字段分组:
  - 发布单头: rel_no, rel_version, base_period, prev_version, status, publisher, publish_date
  - 发布明细（子表 D09-D）: line_no, part_no, veh_model, period, cons_qty, event_items, rel_qty, split_qty, basis, lineage
  - 构成列示: cons_qty（消耗驱动量）+ event_items（事件加项列表，含 event_no + qty）→ rel_qty（发布量，系统强制 = cons_qty + Σ事件量）
- 子账本:
  - D09-D 发布明细（零件×期间 纵表，含链路线索）
- 页脚操作:
  - 草稿 → [checklist校验] [发布]
  - 待发布 → [发布]
  - 已发布/已替代 → [版本比对]

### 表单（版本修订）
- 可写字段:
  - 必填: reason（修订原因）
  - 可选: —（修订由系统根据上游最新数据重新汇总）
  - 折叠: —（无折叠字段，修订为单一操作按钮+原因输入）
- 必填项: reason
- 可选/折叠: —

## svc 字面量清单
- svc("demand_release", "list") — 发布单列表（按版本/状态/期间筛选）
- svc("demand_release", "get") — 发布单详情（含构成列示+明细+链路线索）
- svc("demand_release", "create_draft") — 生成发布草稿（系统汇总 D04/D06/D07/D08）
- svc("demand_release", "checklist_verify") — 发布前 checklist 五项校验
- svc("demand_release", "publish") — 正式发布（联动锁定 D04 批次 + D03 V版）
- svc("demand_release", "revise") — 版本修订（产生子版本）
- svc("demand_release", "version_diff") — 版本比对

## 验收关注点
- 新建按钮存在（生成草稿入口）
- 非看板页 .kpi==0
- 列表列 ⊆ 详情字段集（单头字段均在详情模态中出现）
- 搜索控件与 list 参数一一对应（rel_version/status/base_period）
- 表单字段 = 写服务接受参数（create_draft 参数 base_period；revise 参数 reason）
- 构成可加和前端校验（rel_qty = cons_qty + Σ事件量，不可手动改总量）
- checklist 五项校验结果前端展示（全部通过方可发布）
- 发布后联动锁定提示（D04 批次锁定 + D03 V版锁定确认弹窗）
- event_items 仅列示生效事件（待确认事件不出现）
