# 前端详设：策略仿真拟合表（strategy_simulation）

> PAGE_META.key = `strategy_simulation` | order = `130`

## PAGE_META
- key: `strategy_simulation`, name: `策略拟合`, ic: `target`, title: `策略仿真拟合`, crumb: `D10 基线方法军火库`, order: `130`

## 区块构成

### 列表
- 列: fit_no, part_no, veh_model, demand_shape, data_range, backtest_spec, status, fitter, fit_date
- 搜索: part_no（文本输入）, veh_model（文本输入）, demand_shape（枚举多选：稳定/波动/季节/短生命周期/断续）, status（多选枚举：拟合中/已选定/生效中/已替代）
- 操作:
  - 拟合中 → [添加候选] [执行回测] [查看详情]
  - 已选定 → [选定策略] [重拟合] [查看详情]
  - 生效中 → [重拟合] [查看详情]
  - 已替代 → [查看详情]

### 详情模态
- 字段分组:
  - 拟合单标识: fit_no, part_no, veh_model, demand_shape, status, fitter, fit_date
  - 回测规格: data_range（清洗后历史区间）, backtest_spec（训练窗口/验证步长/滚动次数）
  - 候选明细（子表）: cand_no（序号）, strategy（方法+参数）, inv_policy（配套库存策略）, mape, bias, service_level, inv_cost, score, rank（排名）, selected（选定标记）
- 子账本:
  - 候选策略明细表（按 rank 排序展示，selected 高亮）
- 页脚操作:
  - 拟合中 → [添加候选] [执行回测]
  - 已选定 → [选定策略] [重拟合]
  - 生效中 → [重拟合]
  - 已替代 → 只读

### 表单（创建/编辑）
- 可写字段:
  - 必填: part_no, veh_model, demand_shape, data_range, backtest_spec
  - 可选: —
  - 折叠: —（无折叠字段）
- 必填项: part_no, veh_model, demand_shape, data_range, backtest_spec
- 可选/折叠: —

### 添加候选子表单
- 可写字段:
  - 必填: strategy（方法+参数）, inv_policy（配套库存策略）
  - 可选: —
  - 折叠: —（单行添加，支持批量添加多个候选）
- 必填项: strategy, inv_policy

### 选定策略子表单
- 可写字段:
  - 必填: cand_no（选定候选序号）
  - 不可写: fit_no, 候选排名列表（只读展示）
- 必填项: cand_no
- 可选/折叠: —（从候选列表中单选）

### 重拟合子表单
- 可写字段:
  - 必填: —（触发重拟合，月度轻量/季度全量由系统决定）
  - 不可写: fit_no, part_no, veh_model（只读展示）
- 必填项: —
- 可选/折叠: —（单一操作按钮）

## svc 字面量清单
- svc("strategy_simulation", "list") — 拟合单列表（按零件/状态/形态筛选）
- svc("strategy_simulation", "get") — 拟合单详情（含候选+打分+排名）
- svc("strategy_simulation", "create") — 新建拟合任务（定形态+回测规格）
- svc("strategy_simulation", "add_candidate") — 添加候选策略
- svc("strategy_simulation", "run_backtest") — 执行滚动回测
- svc("strategy_simulation", "select_strategy") — 选定策略
- svc("strategy_simulation", "get_strategy") — 获取当前生效策略（供 D04 调用）
- svc("strategy_simulation", "refit") — 重拟合

## 验收关注点
- 新建按钮存在
- 非看板页 .kpi==0
- 列表列 ⊆ 详情字段集（列表字段均在详情模态中出现）
- 搜索控件与 list 参数一一对应（part_no/veh_model/demand_shape/status）
- 表单字段 = 写服务接受参数（create 参数与表单字段一致）
- 候选明细表按 rank（排名）排序，selected 高亮展示
- 回测结果各指标（MAPE/Bias/服务水平/库存代价/综合分）前端展示
- add_candidate 支持多次添加多个候选策略
- 最优候选综合分低于可接受线时前端提示"建议转借用基线 D05"
- 选定策略后 status 流转为"已选定"
- 重拟合前提示"新旧策略将影子并行1~2期"确认
