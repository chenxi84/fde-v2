# 前端详设：独立事件登记表（independent_event）

> PAGE_META.key = `independent_event` | order = `50`

## PAGE_META
- key: `independent_event`, name: `独立事件`, ic: `bolt`, title: `独立事件登记管理`, crumb: `D06 脉冲/断点/其他事件`, order: `50`

## 区块构成

### 列表
- 列: event_no, event_type, part_no, oem_code, veh_model, period, event_qty, status, creator, create_date
- 搜索: part_no（文本输入）, event_type（多选枚举：水位脉冲/断点·旧件截断/断点·新件启动/其他）, status（多选枚举：待确认/生效/持续中/已回落/已关闭/已取消）, period（日期范围）
- 操作:
  - 待确认 → [确认] [取消]
  - 生效 → [标记持续中] [标记回落] [关闭]
  - 持续中 → [标记回落] [关闭]
  - 已回落 → [关闭]
  - 已关闭/已取消 → [查看详情]

### 详情模态
- 字段分组:
  - 事件基础: event_no, event_type, part_no, oem_code, veh_model, period, event_qty, status
  - 系统常量（只读）: in_demand（恒"是"）, in_trend（恒"否"）
  - 断点信息（仅断点类）: bp_batch, bp_date
  - 来源与依据: source_basis, source_ref
  - 登记与关闭: creator, create_date, close_basis
- 子账本:
  - 断点成对关联（bp_batch 相同的事件卡片）
- 页脚操作:
  - 待确认 → [确认事件] [取消事件（误判）]
  - 生效 → [标记持续中] [标记回落] [关闭事件]
  - 持续中 → [标记回落] [关闭事件]
  - 已回落 → [关闭事件]
  - 已关闭/已取消 → 只读

### 表单（创建/编辑）
- 可写字段:
  - 必填: event_type, part_no, period, event_qty, source_basis
  - 条件必填: oem_code（脉冲类必填）, veh_model, bp_batch（断点类必填）, bp_date（断点类必填）, source_ref
  - 折叠: —（无折叠字段，全显式填写）
- 必填项: event_type, part_no, period, event_qty, source_basis
- 可选/折叠: oem_code（脉冲类必填）, veh_model, source_ref

### 表单（创建成对断点）
- 可写字段:
  - 旧件: old_part_no, bp_batch, bp_date, event_qty（截断量）, source_basis
  - 新件: new_part_no, bp_batch（同）, bp_date（同）, event_qty（启动量）, source_basis
- 必填项: old_part_no, new_part_no, bp_date, source_basis
- 可选/折叠: —（双卡片同时填写，联动保存）

## svc 字面量清单
- svc("independent_event", "list") — 事件列表（按类型/状态/零件/期间筛选）
- svc("independent_event", "get") — 事件详情
- svc("independent_event", "create") — 新建事件（人工登记须附依据）
- svc("independent_event", "create_bp_pair") — 创建成对断点（旧件+新件）
- svc("independent_event", "confirm") — 确认事件（待确认→生效）
- svc("independent_event", "mark_sustained") — 标记持续中
- svc("independent_event", "mark_subsided") — 标记已回落（须填 close_basis）
- svc("independent_event", "close") — 关闭事件（须填 close_basis）
- svc("independent_event", "cancel") — 取消事件（误判，须填 close_basis）

## 验收关注点
- 新建按钮存在（含"新建事件"和"成对断点"两个入口）
- 非看板页 .kpi==0
- 列表列 ⊆ 详情字段集（列表字段均在详情模态中出现）
- 搜索控件与 list 参数一一对应（part_no/event_type/status/period）
- 表单字段 = 写服务接受参数（create 参数与表单一致；create_bp_pair 参数与双卡片一致）
- in_demand/in_trend 字段前端只读展示，不可编辑（系统常量）
- 断点类 event_type 时 bp_batch/bp_date 条件必填
- 关闭/回落/取消操作均须填写 close_basis
- 成对断点保存后两条事件同时出现在列表中（bp_batch 相同）
- 待确认事件行样式区别于生效事件（如灰色/斜体）
