# 应用详设：系统配置（system_config）

> **应用名**：`system_config` | **类名**：`SystemConfig`
> **对应聚合根卡**：architecture.md #13 | **对应 BRD**：§2.15 + §2.16

---

## 1. 需求概览

- **需求名称**: 参数配置与知识沉淀
- **优先级**: P1（全部规则引用+经验积累）
- **涉及角色**: 总部计划（参数变更申请+沉淀库维护）、系统（自动生成信任折扣）

### 1.2 需求背景
让"逻辑与参数分离、经验可积累可回溯"。三部分：①参数配置表（全部可调阈值与规则）；②沉淀库（生命周期模板库/类比库/信任折扣库）；③外部数据源台账。参数变更须审批+校准依据，历史值版本化保留。

---

## 2. 用户故事

#### `US-01` 参数查询与变更（优先级：P1）
- **故事描述**: 作为 D04/D08 等应用，我想要获取当前生效的参数阈值，以便于校验规则正确执行
- **验收场景**：
  1. `US-01-AC1` **取参数**: Given param_code="θ_rev"，When get_param，Then 返回当前值20%+生效期间+校准依据
  2. `US-01-AC2` **参数变更留版本**: Given θ_rev从20%改为15%，When set_param(15%, "2026Q3回测结论", approver)，Then 旧值(20%)保留历史版本，新值(15%)生效

#### `US-02` 沉淀库管理（优先级：P2）
- **故事描述**: 作为总部计划，我想要维护模板库/类比库/信任折扣库，以便于经验复用
- **验收场景**：
  1. `US-02-AC1` **模板沉淀**: Given 车型A的衰减曲线效果良好，When 沉淀为模板 TPL-03，Then 供 D05 借用
  2. `US-02-AC2` **信任折扣自动生成**: Given D12 月度考核完成，When 系统计算达成率，Then 自动更新信任折扣系数

## 3.2 业务规则

| 编号 | 规则 |
|-----|------|
| BR-01 | 参数变更须审批+校准依据，历史值版本化保留 |
| BR-02 | 沉淀库条目须来源可溯 |
| BR-03 | 信任折扣自动生成为主，人工覆盖为辅（覆盖须理由） |
| BR-04 | 外部数据先登记后使用，未登记不得被消费 |
| BR-05 | 季度评审参数适用性+沉淀效果，低效条目降权或淘汰 |
