# 应用详设：项目信息台账（project_info）

> **应用名**：`project_info` | **类名**：`ProjectInfo`
> **对应聚合根卡**：architecture.md #1 | **对应 BRD**：§2.11 D01

---

## 1. 需求概览

- **需求名称**: 项目信息管理（主数据底座）
- **优先级**: P0（全部过程单据的项目维度参照）
- **涉及角色**: 销售（维护客户/阶段/责任人）、总部计划（维护产品/生命周期）

### 1.2 需求背景
项目是毛需求的载体，台账记录项目×零件的六维属性（客户/产品/车型/量纲/生命周期/责任人）。项目阶段决定需求去向：进行中→近端毛需求主线；待定点/定点中→长期产能规划输入。

---

## 2. 用户故事

#### `US-01` 项目台账维护（优先级：P1）
- **故事描述**: 作为销售/计划，我想要维护项目×零件的六维属性与阶段迁移，以便于下游单据准确引用
- **验收场景**：
  1. `US-01-AC1` **新建项目-零件**: Given PRJ-001·8210001·进行中，When 创建台账记录，Then 六维属性完整
  2. `US-01-AC2` **阶段迁移留痕**: Given 项目从"定点中"→"进行中"，When 执行 set_stage，Then 变更日志记录（旧阶段/新阶段/操作人/时点/原因）
  3. `US-01-AC3` **通用件关联多客户**: Given STD-M6·通用件，When 创建，Then 必须关联≥2客户或显式标记"单一客户通用"

---

## 3.2 业务规则

| 编号 | 规则 |
|-----|------|
| BR-01 | 项目×零件组合唯一 |
| BR-02 | 阶段迁移必须记录变更日志 |
| BR-03 | 通用件须关联≥2客户或标记"单一客户通用" |
| BR-04 | 量纲字段引用展示，权威源在 vehicle_part_mapping |
| BR-05 | 维护分工：销售维护客户/阶段/责任人，计划维护产品/生命周期，变更互通知 |

### 3.4 状态机

```
(新建) --定点立项--> 定点中 --获得定点--> 进行中 --EOP--> EOP关闭
待定点 --定点立项--> 定点中
任意阶段 --年型/改款--> 记录变更日志（阶段不变）
```
