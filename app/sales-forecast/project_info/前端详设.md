# 前端详设：项目信息台账（project_info）

> PAGE_META.key = `project_info` | order = `60`

## PAGE_META
- key: `project_info`, name: `项目台账`, ic: `folder`, title: `项目信息台账`, crumb: `D01 项目×零件主数据`, order: `60`

## 区块构成

### 列表
- 列: project_no, part_no, stage, oem_code, veh_model, platform, part_kind, usage, share, sop, eop, owner_sales
- 搜索: stage（多选枚举：待定点/定点中/进行中/EOP关闭）, oem_code（下拉选择）, owner_sales（用户下拉）, part_no（文本输入）, project_no（文本输入）
- 操作:
  - 任意阶段 → [查看详情] [编辑]
  - 待定点/定点中 → [阶段迁移]
  - 进行中 → [阶段迁移]
  - EOP关闭 → [查看详情]

### 详情模态
- 字段分组:
  - 基础标识: project_no, part_no, part_kind
  - 客户与车型: oem_code, plant_code, veh_model, platform
  - 项目阶段: stage, award_prob（待定点/定点中时展示）
  - 量纲（引用展示，权威源在 D02）: usage, share
  - 生命周期: sop, eop, lc_shape
  - 责任人: owner_sales
- 子账本:
  - 变更日志（子表）: seq, field_name, old_value, new_value, reason, operator, op_time
- 页脚操作:
  - 待定点 → [编辑] [定点立项（→定点中）]
  - 定点中 → [编辑] [获得定点（→进行中）] [EOP（→EOP关闭）]
  - 进行中 → [编辑] [EOP（→EOP关闭）]
  - EOP关闭 → 只读

### 表单（创建/编辑）
- 可写字段:
  - 必填: project_no, part_no, oem_code, plant_code, veh_model, part_kind, usage, share, sop, owner_sales
  - 可选: platform, award_prob, eop, lc_shape
  - 折叠: —（无折叠字段，全显式填写）
- 必填项: project_no, part_no, oem_code, plant_code, veh_model, part_kind, usage, share, sop, owner_sales
- 可选/折叠: platform, award_prob（阶段为待定点/定点中时显示）, eop, lc_shape

### 阶段迁移子表单（模态弹窗）
- 可写字段:
  - 必填: new_stage（目标阶段）, reason（迁移原因）
  - 不可写: current_stage（只读展示）
- 必填项: new_stage, reason
- 可选/折叠: —（单一操作弹窗，简单填写）

## svc 字面量清单
- svc("project_info", "list") — 台账列表（按阶段/客户/销售筛选）
- svc("project_info", "get") — 项目详情（含变更日志）
- svc("project_info", "create") — 新建项目-零件关联
- svc("project_info", "update") — 更新属性
- svc("project_info", "set_stage") — 阶段迁移（记录变更日志）

## 验收关注点
- 新建按钮存在
- 非看板页 .kpi==0
- 列表列 ⊆ 详情字段集（列表字段均在详情模态中出现）
- 搜索控件与 list 参数一一对应（stage/oem_code/owner_sales/part_no/project_no）
- 表单字段 = 写服务接受参数（create/update 参数与表单字段一致）
- usage/share 字段前端标注"引用展示，权威源在车型映射"
- 阶段迁移弹窗须填写迁移原因
- 通用件（part_kind=通用）创建时须提示"关联多客户或标记单一客户通用"
- 变更日志子表按时间倒序展示
