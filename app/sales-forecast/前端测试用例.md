## §G1 壳启动与菜单序

### TC-SHELL-01 模块壳正常启动
- 页面: `/view/sales-forecast/`
- 前置: 平台已启动，admin 已登录
- 操作: 访问模块 URL
- 断言: 页面加载完成，侧栏菜单可见，品牌为"FDE·SALES-FORECAST"，脚标含"sales-forecast 组"
- 选择器: `.side .brand`, `.side .foot`

### TC-SHELL-02 菜单顺序正确
- 页面: `/view/sales-forecast/`
- 断言: 菜单项按 order 升序排列：工作台(dashboard) → 需求收集 → 毛需求加工 → 发布管理 → 独立事件 → 项目台账 → 车型映射 → 主数据 → 系统配置 → 基线借用 → 通用件汇总 → 牛鞭修正 → 策略拟合 → 考核
- 选择器: `.side .menu a`

### TC-SHELL-03 默认路由为 dashboard
- 操作: 访问 `/view/sales-forecast/`（无 hash）
- 断言: 默认显示 dashboard 页，可见 KPI 指标带
- 选择器: `.kpi`

## §G2 Dashboard 页渲染

### TC-DASH-01 KPI 指标带渲染
- 页面: `/view/sales-forecast/#dashboard`
- 断言: `.kpi` 区域内至少有 4 个卡片，每个卡片含数值
- 注意: 首次加载 KPI 可能全为 0（无数据），但卡片结构必须存在

### TC-DASH-02 主链管道渲染
- 断言: 主链管道区域内可见"收集""加工""通用件汇总""牛鞭修正""发布"五个卡片

### TC-DASH-03 待办区渲染
- 断言: "销售待办"和"计划待办"两个卡片可见，含跳转按钮

### TC-DASH-04 0 console error
- 断言: dashboard 页加载完成后浏览器 console 无 error（favicon 除外）

## §G3 受限用户菜单收敛

### TC-LIMITED-01 受限用户仅见授权页面
- 前置: 创建受限角色 `limited_role`，仅授权 dashboard + demand_collection 两个页面；创建受限用户 userno=LIMITED_USER，绑定该角色
- 操作: 以受限用户登录，访问 `/view/sales-forecast/`
- 断言: 菜单仅含「工作台」「需求收集」+ 平台页；不含「毛需求加工」「发布管理」等未授权页

### TC-LIMITED-02 直访无授权路由回落
- 操作: 受限用户直接访问 `/view/sales-forecast/#demand_processing`
- 断言: 自动回落至 dashboard（首个授权页）

### TC-LIMITED-03 隐式放行有数据
- 操作: 受限用户在 demand_collection 页执行 list 操作
- 断言: svc 调用成功返回数据（不 403），因 `svc()` 字面量已由 view.js 源码扫描派生放行

## 逐应用测试用例

各应用前端测试用例独立成文件，放对应应用文件夹下：
- `app/sales-forecast/<应用>/前端测试用例.md`

共用断言模板：
1. **本页渲染**：列表加载后含至少一个 `<tr class="data">` 或无数据提示
2. **造数后列表有数据**：浏览器内 fetch 造数（调对应 create/add_lines 等服务），精确单号定位到新行
3. **模态全字段**：点击单号打开详情，wait modal loading 消失，断言关键字段（单号/状态/归属）含预期值
4. **表单落库回显**：填写创建表单→提交→列表确认新记录出现
5. **本会话 0 console error / 0 pageerror / 0 HTTP≥400**（favicon 除外）
