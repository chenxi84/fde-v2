# 前端详设：主机厂原始需求收集表（demand_collection）

> PAGE_META.key = `demand_collection` | order = `20`

## PAGE_META
- key: `demand_collection`, name: `需求收集`, ic: `inbox`, title: `主机厂原始需求收集`, crumb: `D03 收集与信号拆解`, order: `20`

## 区块构成

### 列表
- 列: collect_no, oem_code, plant_code, fcst_version, base_period, demand_type, source_channel, recv_date, collector, status
- 搜索: oem_code（下拉选择）, fcst_version（文本输入）, status（多选枚举：草稿/已拆解/已锁定/已替代）, recv_date（日期范围）
- 操作:
  - 草稿 → [录入明细] [拆解执行] [作废]
  - 已拆解 → [查看详情] [版本比对] [作废]
  - 已锁定 → [查看详情] [版本比对]
  - 已替代 → [查看详情] [版本比对]

### 详情模态
- 字段分组:
  - 收集单头: collect_no, oem_code, plant_code, fcst_version, base_period, demand_type, source_channel, recv_date, collector, status, prev_version, remark
  - 收集明细（子表）: line_no, part_no, project_no, veh_model, proj_stage, period, orig_qty, uom, data_flag
  - 拆解快照（子表，与明细1:1关联）: noise_adj, pulse_qty, true_qty, has_pulse, event_no, method, basis, decomposer, decompose_date
- 子账本:
  - D03-D 收集明细（纵表，零件×期间）
  - D03-S 拆解快照（四栏展开：原始量/噪声/脉冲/真实消耗）
- 页脚操作:
  - 草稿 → [录入明细] [拆解执行] [作废]
  - 已拆解 → [版本比对]
  - 已锁定/已替代 → [版本比对]

### 表单（创建/编辑）
- 可写字段:
  - 必填: oem_code, plant_code, fcst_version, base_period, demand_type, source_channel
  - 可选: recv_date（默认当天）, remark
  - 折叠: prev_version（系统自动带出）
- 必填项: oem_code, plant_code, fcst_version, base_period, demand_type, source_channel
- 可选/折叠: recv_date（默认当天可改）, remark, prev_version（自动带出不可改）

### 明细录入子表单（模态内嵌）
- 可写字段（逐行）: part_no, project_no, veh_model, period, orig_qty, uom, data_flag
- 必填项: part_no, project_no, veh_model, period, orig_qty, data_flag
- 支持批量录入（多行同时编辑）
- data_flag 为"OEM未提供"时 orig_qty 可留空

### 拆解执行子表单（模态内嵌）
- 展示: 预计算结果列表（逐行 orig_qty / noise_adj / pulse_qty / true_qty）
- 可写: noise_adj（可调）, pulse_qty（可调）, true_qty（系统计算，只读）, method, basis
- 恒等式强制校验: true_qty = orig_qty - pulse_qty - noise_adj
- 噪声守恒校验: 拆解窗口内 Σnoise_adj ≈ 0

## svc 字面量清单
- svc("demand_collection", "list") — 收集单列表（按客户/版本/状态筛选）
- svc("demand_collection", "get") — 收集单详情（含明细+拆解快照）
- svc("demand_collection", "create") — 新建收集单头
- svc("demand_collection", "add_lines") — 批量录入明细
- svc("demand_collection", "set_decomposition") — 记录拆解结果
- svc("demand_collection", "confirm_decomposition") — 拆解确认（草稿→已拆解）
- svc("demand_collection", "cancel") — 作废收集单（须填原因）
- svc("demand_collection", "supersede") — 版本替代
- svc("demand_collection", "version_diff") — 版本比对（V_n vs V_{n-1}）

## 验收关注点
- 新建按钮存在（`.btn-create`）
- 非看板页 .kpi==0
- 列表列 ⊆ 详情字段集（列表字段均在详情模态中出现）
- 搜索控件与 list 参数一一对应（oem_code/fcst_version/status/recv_date）
- 表单字段 = 写服务接受参数（create 参数与表单字段一致）
- 拆解恒等式前端同步校验（true_qty = orig_qty - pulse_qty - noise_adj）
- 明细录入后 orig_qty 不可编辑（快照不可变）
- "OEM未提供"期间不强制补0
