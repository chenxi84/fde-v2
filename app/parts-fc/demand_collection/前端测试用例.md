## §3 模态全字段

#### TC-VW-demand_collection-04 详情模态全字段+子表
- **页面**: parts-fc:demand_collection
- **前置造数**: 依赖 DC2（需先 add_lines 录入明细 + decompose 拆解）
- **操作**:
  1. 调 `demand_collection.add_lines(collect_no=DC2的collect_no, lines=[{part_no=DC-PART-001, project_no=DC-PRJ-001, veh_model=MODEL-A, period=2026-09, orig_qty=1000, uom=件, data_flag=正常}])`
  2. 调 `demand_collection.decompose(collect_no, line_no=1, period=2026-09, noise_adj=0, pulse_qty=0, method=免拆解, basis=无脉冲无噪声)` 
  3. 调 `demand_collection.confirm_decompose(collect_no)` → DC2 status=已拆解
  4. 进入页面，点击 DC2 的 collect_no `.b-link`
  5. `wait_modal()`
- **断言**:
  - 单头字段：collect_no / oem_code / plant_code / fcst_version / base_period / demand_type / source_channel / recv_date / collector / status / prev_version / remark / created_at
  - 明细子表（D03-D）：line_no / part_no / project_no / veh_model / period / orig_qty / data_flag
  - 拆解快照子表（D03-S）：noise_adj / pulse_qty / true_qty / method / basis
  - 「原始数据」可展开

## §4 表单落库回显

#### TC-VW-demand_collection-05 创建表单落库
- **页面**: parts-fc:demand_collection
- **前置造数**: 无
- **操作**:
  1. 点击【+ 新建收集单】→ 填 oem_code=OEM-A, plant_code=PLANT-1, fcst_version=V2026-10, base_period=2026-10
  2. 展开「更多字段」填 remark=测试备注
  3. 提交
- **断言**:
  - toast 含新 collect_no
  - 列表出现新记录，status=草稿

#### TC-VW-demand_collection-06 明细录入落库
- **页面**: parts-fc:demand_collection
- **前置造数**: 依赖 DC2（草稿状态）
- **操作**:
  1. DC2 行点击【录入明细】→ 填 part_no=DC-PART-001, project_no=DC-PRJ-001, veh_model=MODEL-A, period=2026-09, orig_qty=1000
  2. 批量提交
- **断言**:
  - toast 成功
  - 模态明细子表刷新显示新行

#### TC-VW-demand_collection-07 拆解确认与作废
- **页面**: parts-fc:demand_collection
- **前置造数**: 依赖 DC2（已录入明细）+ DC3（草稿）
- **操作（拆解确认）**:
  1. DC2 → 逐行拆解 → 填 noise_adj=0, pulse_qty=0, method=免拆解, basis=无异常
  2. 【拆解确认】
- **断言**:
  - status=已拆解
  - true_qty = orig_qty（恒等式验证）
- **操作（作废）**:
  1. DC3 → 【作废】→ 填 reason=测试作废
- **断言**:
  - status=已作废
