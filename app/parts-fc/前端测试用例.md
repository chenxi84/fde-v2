#### TC-VW-GROUP-01 壳启动与菜单序
- **页面**: parts-fc:shell
- **前置造数**: 无
- **操作**:
  1. 登录 admin → GET `/view/parts-fc/`
  2. 等待侧栏 `.rail` 或 `.menu` 或 `nav` 渲染（timeout 15s）
  3. 等待 `header.top h1` 出现
- **断言**:
  - 侧栏品牌含「FDE·PARTS-FC」（大小写不敏感）
  - 菜单项集合 == [首页看板, 项目信息台账, 车型零件映射, 需求收集, 需求加工, 基线借用, 独立事件, 策略拟合, 通用件汇总, 牛鞭修正, 需求发布, 预测考核]（12项）
  - 菜单顺序：首页看板 居首（order=10），其余按 PAGE_META.order 升序排列
  - 默认路由 `#/dashboard` 已挂载
- **选择器注意**: 菜单文案取侧栏 `.rail` 或 `nav` 的 `inner_text()`

#### TC-VW-GROUP-02 dashboard 页渲染（KPI + 主链管道 + 待办队列）
- **页面**: parts-fc:dashboard
- **前置造数**:
  - 调 `demand_collection.create(DASH-DC)` 草稿收集单
  - 调 `demand_processing.create_batch(DASH-DP)` 进行中批次
  - 调 `demand_release.create_draft(DASH-REL)`
  - 调 `demand_release.checklist_verify(rel_no)` → `publish(rel_no)` → status=已发布
  - 调 `independent_event.create` 一条 待确认 事件
  - 调 `independent_event.confirm(event_no)` → status=生效
- **操作**:
  1. location.hash = '#/dashboard'（若未在默认路由）
  2. 等待 KPI 区域 `.kpi` 出现（timeout 15s）
  3. 等待主链管道 `.pipeline-node` 或等效区块出现
- **断言**:
  - **看板页 `.kpi` 数 > 0**（与各应用页防粘滞断言互为镜像）
  - KPI 指标带：含「待收集」「待修正」「已发布 R 版」「生效事件」「生效映射」等磁贴，数字大字+标签小字
  - 主链管道区存在：D03收集→D04加工→D07通用件→D08牛鞭→D09发布 五节点
  - 待办队列区存在：销售待办与计划待办分组
  - 快捷入口区存在：项目台账/车型映射/基线借用/独立事件/策略拟合/预测考核 入口卡片
  - 所有 KPI/管道/待办的 svc 调用为 quiet 探测——quiet 失败时对应磁贴显示「—」而非 toast
- **选择器注意**: KPI 加载中显示「—」占位，需等待数据到达后断言数字

## §5 受限用户菜单收敛

**受限角色授权清单（逐字）**: `limited_role` → `["parts-fc:dashboard", "parts-fc:project_ledger", "parts-fc:vehicle_part_map", "_platform:agent"]`

> 授权页集：看板 + 项目信息台账 + 车型零件映射（主数据底座两页）+ Agent。未授权页（如 demand_collection）用于直访回落测试。
> **页面对齐规则（pitfalls #38）**: 新增/调整页面后本清单与回落断言必须同步改。

#### TC-VW-GROUP-04 菜单收敛
- **页面**: parts-fc:shell（受限会话）
- **前置造数**:
  - 经 `users` 模块（非浏览器 HTTP API）创建受限角色与用户：
    - `users.create_role("limited_role", "受限测试角色")`
    - `users.set_role_page_grants("limited_role", ["parts-fc:dashboard", "parts-fc:project_ledger", "parts-fc:vehicle_part_map", "_platform:agent"])`
    - `users.create_user("limited_pfc", "Limited@123", "limited_role", [], "U400", "D001")`
- **操作**:
  1. 新浏览器上下文 → 登录 `limited_pfc` / `Limited@123`
  2. GET `/view/parts-fc/`
  3. 等待侧栏渲染
- **断言**:
  - 菜单项集合 == [首页看板, 项目信息台账, 车型零件映射, Agent]（4项）
  - 未授权页（需求收集/需求加工/基线借用/独立事件/策略拟合/通用件汇总/牛鞭修正/需求发布/预测考核）**不在菜单中**
- **选择器注意**: 受限会话 403 为预期执法，豁免报错统计（state["limited"]=True 时 suppress 403）

#### TC-VW-GROUP-05 直访无授权路由回落
- **页面**: parts-fc:shell（受限会话）
- **前置造数**: 同 TC-VW-GROUP-04
- **操作**:
  1. 受限会话已登录 → `location.hash = '#/demand_collection'`（未授权页）
  2. 等待 1200ms（shell syncRoute 回落渲染）
- **断言**:
  - 渲染回落菜单首项：`header.top h1` 含「首页看板」（或「需求预测总览」）
  - 不渲染 demand_collection 页内容
- **选择器注意**: shell 的 syncRoute 渲染回落页但未必回写 location.hash，故断言 `h1` 文本而非 hash 值

#### TC-VW-GROUP-06 授权页隐式放行有数据
- **页面**: parts-fc:project_ledger（受限会话，经 X-Fde-Page 隐式放行）
- **前置造数**:
  - 受限用户授权含 `parts-fc:project_ledger`（见 TC-VW-GROUP-04）
  - 需在受限会话前（admin 会话）造好 project_ledger 数据：调 `project_ledger.create` 至少 1 条记录
- **操作**:
  1. 受限会话 → location.hash = '#/project_ledger'
  2. 等待列表加载（timeout 15s）
- **断言**:
  - 列表有数据（行数 >= 1）
  - project_no / part_no / stage 列非空
  - 全程无 console error（受限会话 403 已豁免）
- **选择器注意**: 受限会话内 svc 调用带 `X-Fde-Page` 头自动享受隐式放行；4xx 响应若为权限执法 403 属预期、豁免报错
