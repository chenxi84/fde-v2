## §3 模态全字段

#### TC-VW-demand_processing-04 详情模态全字段+四个子表
- **页面**: parts-fc:demand_processing
- **前置造数**: 依赖 DP1（先 generate_baseline + submit_adjustment + review 填数据）
- **操作**:
  1. 调 `demand_processing.generate_baseline(proc_batch=DP1.proc_batch)`
  2. 调 `demand_processing.submit_adjustment(proc_batch, part_no=DP-PART-001, veh_model=DP-MODEL-A, period=2026-09, adj_qty=1100, adj_reason_cat=客户侧情报, adj_evidence=客户确认函)`
  3. 调 `demand_processing.review(proc_batch, part_no=DP-PART-001, veh_model=DP-MODEL-A, period=2026-09, chk_result=通过, chk_reason=修正合理)`
  4. 进入页面，点击 DP1 proc_batch `.b-link`
  5. `wait_modal()`
- **断言**:
  - 批次头：proc_batch / oem_code / plant_code / fcst_version / status / start_time / finish_time
  - 基线子表（D04-B）：base_qty / base_path / base_method / causal_qty / deviation / generator / gen_time
  - 修正子表（D04-A）：adj_qty / adj_pct / adj_reason_cat / adj_evidence / submit_status
  - 核对子表（D04-C）：chk_result / chk_reason / approved_qty / chk_round
  - 调整日志子表（D04-L，默认折叠）：actor_role / before_qty / after_qty / reason_cat
  - 「原始数据」可展开
- **选择器注意**: 四个子表可分别折叠展开；多 `.modal-bd` 用 `.first`
