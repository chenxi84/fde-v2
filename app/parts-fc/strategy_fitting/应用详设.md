# 应用详设：策略仿真拟合（strategy_fitting）

> **应用名**：`strategy_fitting` | **类名**：`StrategyFitting`
> **对应聚合根卡**：architecture.md #10 | **对应 BRD**：§2.10 D10

---

## 1. 需求概览

### 1.1 基本信息

- **需求名称**: 策略仿真拟合（基线方法选取与重拟合）
- **所属模块**: parts-fc / 毛需求管理
- **优先级**: P1（历史充足零件的基线方法唯一来源，缺失则 D04 基线生成无法取策略）

### 1.2 需求背景

#### 1.2.1 为什么需要这个需求？

不同物料的需求形态不同（稳定 / 波动 / 季节 / 短生命周期 / 断续），单一预测方法难以通吃——移动平均适合稳态但跟不上趋势，指数平滑能跟随趋势但滞后拐点，季节分解需要完整周期历史，生命周期模板依赖形态先验。必须在历史数据上滚动回测，为每个物料选出拟合最优的策略（方法 + 参数 + 配套库存策略），并定期重拟合以适应需求形态演变。

#### 1.2.2 期望达到什么目标？

- 为每个历史充足的物料（可用清洗历史 >= 12 个月且覆盖完整季节周期）自动选出拟合最优的预测策略
- 策略包含完整配方：方法 + 参数 + 配套库存策略（安全库存天数 / 补货频率），供 D04 基线生成直接引用
- 评估不只看误差（MAPE），还综合 Bias 方向、服务水平、库存代价，非对称加权（断线损失远大于呆滞损失）
- 分段诊断（峰期 / 稳期 / 衰减期），防止"平均好、拐点差"
- 重拟合有节奏有纪律：月度轻量重估参数，季度全量重选方法；新旧策略影子并行防盲目切换
- 候选全集、得分、选定理由全留存，支撑复盘与 FVA 归因

### 1.3 需求范围

#### 1.3.1 包含哪些功能？

- 拟合单管理：新建拟合单（选定零件×车型、需求形态、历史数据区间、回测规格）
- 候选策略管理：系统枚举生成候选策略（方法 × 参数 × 配套库存策略），人工可增补
- 滚动回测执行：训练段拟合 → 验证段出预测 → 滚动推进，各候选打分排名
- 策略选定与生效：选定最优候选，登记生效
- 重拟合：月度轻量（参数重估）+ 季度全量（完整回测重选）+ 事件触发（形态变化 / D12 告警）
- 影子并行对比：新旧策略影子并行 1~2 期，对比指标防盲目切换
- 策略查询：供 D04 基线生成调用 get_strategy（取当前生效策略）
- 拟合结论反哺：生命周期模板与类比结论沉淀为模板库 / 类比库条目

#### 1.3.2 不包含哪些功能？

- 不直接产出基线数值（基线值在 D04 步骤2 生成，D10 只出方法+参数）
- 不负责历史不足物料的基线来源（归 D05 基线借用）
- 不负责历史数据的清洗执行（清洗由 D03 拆解 + D06 事件标记完成，D10 只消费清洗后的数据）
- 不负责策略效果的考核闭环（归 D12 预测转单率考核，考核结论触发 D10 重拟合）

### 1.4 涉及角色

| 角色 | 职责 |
|------|------|
| 总部计划 | 需求形态确认、候选策略审核、权重配置、选定确认、切换决策、影子对比结论判定 |
| 系统 | 形态分类建议、候选策略枚举、回测执行、综合打分排名、影子并行对比计算、重拟合触发建议 |
| D12 闭环（forecast_assessment） | 基线准确率 / Bias 持续恶化告警，触发重拟合（联动） |

## 2. 用户故事

### 2.1 核心用户故事

#### US-01 新建拟合单并配置候选策略（优先级：P1）

- **故事描述**: 作为总部计划，我想要为物料创建拟合单并配置候选策略列表，以便于系统执行回测选优
- **优先级**: P1
- **独立测试**: 可独立测试——创建一个拟合单，添加 3 个候选策略，验证候选策略已录入
- **前置条件**: 零件在 master_data 中存在，零件×车型在 vehicle_part_map 中存在生效映射，该物料历史数据已清洗且 >= 12 个月
- **后置条件**: 拟合单状态为"拟合中"，候选明细已录入
- **验收场景**:
  1. `US-01-AC1` **正常创建**: Given 零件 8210001、车型A、需求形态"稳定"、历史区间 2025-01~2026-06，When 总部计划新建拟合单并系统自动枚举 3 个候选策略，Then 拟合单创建成功，fit_no 格式为 D10-YYYYQN-NNN，状态为"拟合中"
  2. `US-01-AC2` **手动增补候选**: Given 拟合单已创建且有 3 个系统枚举候选，When 计划手动添加候选"指数平滑 α=0.3 + 安全库存 3 天"，Then 候选明细新增一条，cand_no 自动递增
  3. `US-01-AC3` **历史不足阻止**: Given 零件 8320001 的清洗后历史仅 6 个月，When 尝试新建拟合单，Then 系统提示"历史不足 12 个月，建议走 D05 基线借用"

#### US-02 执行滚动回测（优先级：P1）

- **故事描述**: 作为总部计划，我想要对拟合单执行滚动回测并查看各候选得分排名，以便于选优决策
- **优先级**: P1
- **独立测试**: 可独立测试——对已有候选的拟合单执行 run_backtest，验证各候选产生 mape/bias/service_level/inv_cost/score/rank
- **前置条件**: 拟合单状态为"拟合中"，候选明细 >= 2 条，历史数据已清洗
- **后置条件**: 各候选明细的 mape/bias/service_level/inv_cost/score/rank 已填写
- **验收场景**:
  1. `US-02-AC1` **回测选优**: Given 8210001·稳定形态·3 候选策略（移动平均 N=3、指数平滑 α=0.3、指数平滑 α=0.5），When 执行滚动回测，Then 排名1=指数平滑 α=0.3（MAPE 9%/Bias +1%/服务 96%），排名2=移动平均 N=3（MAPE 12%/Bias +2%/服务 95%），排名3=指数平滑 α=0.5（MAPE 11%/Bias +3%/服务 94%）
  2. `US-02-AC2` **防泄漏校验**: Given 回测区间 2025-01~2026-06、验证步长 1 个月，When 验证 2026-01 的预测，Then 模型训练数据仅到 2025-12，未使用 2026-01 及其之后的数据
  3. `US-02-AC3` **分段诊断**: Given 波动形态·生命周期含峰期/稳期/衰减期，When 执行回测，Then 各段分别输出 MAPE/Bias，拐点误差单独标注
  4. `US-02-AC4` **综合分不达标**: Given 回测完成且最优候选综合分低于可接受线（θ_accept），When 系统评估，Then 标记"无可接受候选"并提示转 D05 借用基线或人工判断

#### US-03 选定策略并生效（优先级：P1）

- **故事描述**: 作为总部计划，我想要从候选列表选定最优策略并使其生效，以便于 D04 基线生成可引用
- **优先级**: P1
- **独立测试**: 可独立测试——对已完成回测的拟合单执行 select，验证 selected 标记和状态变更
- **前置条件**: 拟合单状态为"拟合中"且回测已完成（各候选有 score/rank）
- **后置条件**: 选定候选的 selected=True，拟合单状态→"已选定"→"生效中"
- **验收场景**:
  1. `US-03-AC1` **选定生效**: Given 拟合单 D10-2026Q3-017 回测完成排名1=指数平滑 α=0.3，When 计划确认选定 rank=1 的候选，Then 该候选 selected=True，状态→"已选定"，确认后→"生效中"
  2. `US-03-AC2` **不可接受候选不选定**: Given 最优候选综合分低于可接受线，When 计划尝试选定，Then 系统警告并建议转 D05

#### US-04 重拟合（优先级：P2）

- **故事描述**: 作为总部计划，我想要对已生效策略执行重拟合（月度轻量 / 季度全量 / 事件触发），以便于策略随数据积累与形态演变持续优化
- **优先级**: P2
- **独立测试**: 可独立测试——对已生效拟合单执行 refit，生成新拟合单并对比结果
- **前置条件**: 已存在生效中的拟合单，新数据已到达
- **后置条件**: 新拟合单生成，旧单状态→"已替代"（若策略变更）
- **验收场景**:
  1. `US-04-AC1` **月度轻量**: Given 生效中策略"指数平滑 α=0.3"，新一个月数据到达，When 月度轻量重拟合（参数重估、不换方法），Then 新拟合单参数更新为 α=0.28，方法不变
  2. `US-04-AC2` **季度全量重选**: Given 策略已生效 3 个月，When 季度全量回测重选，Then 完整重跑候选枚举+回测+打分，若最优方法改变则生成新单替代旧单
  3. `US-04-AC3` **形态变化触发**: Given 零件进入衰退期（lc_stage 变更），When 系统检测到需求形态变化，Then 自动触发重拟合建议
  4. `US-04-AC4` **D12 告警触发**: Given D12 闭环检测到连续 3 期基线准确率恶化，When 系统告警，Then 触发即时重拟合

#### US-05 影子并行对比（优先级：P2）

- **故事描述**: 作为总部计划，我想要让新旧策略影子并行运行 1~2 期，对比实际表现后再切换，以便于防盲目切换导致恶化
- **优先级**: P2
- **独立测试**: 可独立测试——执行 shadow_compare，验证新旧策略指标对比报告
- **前置条件**: 新拟合单已完成回测且排名结果优于旧策略，旧策略仍在生效中
- **后置条件**: 影子对比报告生成，含新旧策略各指标对比与切换建议
- **验收场景**:
  1. `US-05-AC1` **影子并行验证通过**: Given 旧策略"移动平均 N=3"生效中、新策略"指数平滑 α=0.3"回测更优，When 影子并行 2 期后，Then 新策略实际 MAPE 仍优于旧策略，建议正式切换
  2. `US-05-AC2` **影子并行验证不通过**: Given 新旧策略影子并行 2 期，When 新策略实际表现不如回测预期（MAPE 反高于旧策略），Then 系统标记异常，暂不切换并建议复核回测数据

## 3. 业务场景

### 3.1 业务流程描述

#### 场景1：首次拟合（历史转充足 → 回测选优 → 供给基线）

1. 系统检测某物料可用清洗历史 >= 12 个月且覆盖完整季节周期，标记为"历史充足"
2. 总部计划创建拟合单：选定零件×车型，系统建议需求形态（基于 vehicle_part_map 的 lc_shape + 历史数据特征分析），计划确认或调整
3. 系统自动枚举候选策略：根据需求形态从方法库（移动平均、指数平滑、季节分解、生命周期模板、类比）生成方法×参数×配套库存策略的候选组合
4. 总部计划审核候选列表，可增补或删减候选
5. 系统执行滚动回测：按回测规格（训练窗口 / 验证步长 / 滚动次数），取清洗后历史数据，训练段拟合 → 验证段出预测 → 滚动推进 → 综合打分排名
6. 总部计划查看回测结果，选定最优候选（或标记"无可接受候选"转 D05）
7. 策略生效：状态→"已选定"→"生效中"，fit_no 可供 D04 引用
8. 拟合结论（含模板参数 / 类比关系）沉淀为模板库 / 类比库条目，供 D05 反哺使用

#### 场景2：定期重拟合（月度轻量 + 季度全量）

**月度轻量**：
1. 月初系统自动触发已生效策略的参数重估：取最新一个月数据，重新估计参数（如 α、N 等）
2. 若参数变化在容忍范围内（如 α 变化 < 0.05），保持原参数不变
3. 若参数变化超出容忍范围，记录新参数并建议切换，触发影子并行对比

**季度全量**：
1. 每季度初系统自动触发完整重拟合：重新枚举候选策略（方法库可能有新增方法），完整回测重选
2. 若最优方法与当前生效方法不同，生成新拟合单，触发影子并行对比
3. 影子并行 1~2 期后，若新策略确实更优，正式切换（旧单→"已替代"）

#### 场景3：事件触发重拟合

1. 触发源：①需求形态变化（零件进入衰退期 / 新形态）；②D12 闭环告警（基线准确率连续 N 期恶化）
2. 系统自动创建新拟合单，执行完整回测重选
3. 流程同"季度全量"
4. 生命周期转折点单独考核（拐点预测能力作为选优的关键指标）

### 3.2 业务规则

#### 核心不变量

| 编号 | 规则描述 | 适用场景 |
|------|---------|---------|
| BR-01 | **干净输入纪律**：回测数据必须清洗（脉冲/断点/异常已标记剔除），否则方法学到噪声。清洗状态由 D03 拆解 + D06 事件标记联合保证，D10 只消费已清洗数据 | 创建拟合单、执行回测 |
| BR-02 | **防未来信息泄漏**：滚动回测严格按时间序，验证段只用当时点可见信息。训练窗口的截止时间 <= 验证窗口的起始时间 | 执行回测 |
| BR-03 | **不强行选定**：最优候选综合分低于可接受线（θ_accept）→ 不强行选定，转借用基线（D05）或人工判断 | 选定策略 |
| BR-04 | **全留痕**：候选全集、各候选得分、选定理由、拟合人全数留存，支持复盘与 FVA 归因 | 全生命周期 |
| BR-05 | **边界分工**：D10 出"方法+参数"，D04 步骤2 出基线值；基线偏差归因在 D12 中区分"方法失准（归 D10）"与"数据污染（归拆解）" | 被 D04 调用、D12 归因 |

#### 字段级校验规则

| 编号 | 规则描述 | 字段 |
|------|---------|------|
| BR-06 | fit_no 编码格式：`D10-YYYYQN-NNN`（D10-年份+Q+季度号-三位流水号），系统自动生成，不可手动修改 | fit_no |
| BR-07 | part_no + veh_model 必须在 vehicle_part_map 中存在生效映射行，否则阻断创建 | part_no, veh_model |
| BR-08 | 需求形态枚举值：稳定 / 波动 / 季节 / 短生命周期 / 断续；系统建议 + 人工确认 | demand_shape |
| BR-09 | 历史数据区间须覆盖 >= 12 个月且覆盖完整季节周期，否则提示走 D05 | data_range |
| BR-10 | 回测规格必填：含训练窗口长度（月）、验证步长（月）、滚动次数 | backtest_spec |
| BR-11 | 候选明细至少 2 条方可执行回测（单一候选无比较意义） | 候选明细 |
| BR-12 | strategy 字段格式：方法名 + 参数键值对，如"指数平滑 α=0.3" | strategy |
| BR-13 | inv_policy 字段格式：安全库存天数 + 补货频率，如"安全库存 3 天 / 周补货" | inv_policy |
| BR-14 | score 为综合加权分 = w1*MAPE_score + w2*Bias_score + w3*ServiceLevel_score + w4*InvCost_score，权重可配置 | score |
| BR-15 | Bias 评分非对称：正向偏差（高报）扣分权重 < 负向偏差（低报）扣分权重（断线损失远大于呆滞损失） | score, bias |
| BR-16 | 分段诊断：峰期 / 稳期 / 衰减期分别输出各段指标，综合分含分段加权 | mape, bias, score |
| BR-17 | 策略切换必须登记依据（shadow_compare 对比报告或人工判定理由）；未登记依据不可切换 | 状态变更 |
| BR-18 | 影子并行期间旧策略仍为"生效中"，新单状态为"拟合中"→ 影子验证通过后才可选定生效 | status |
| BR-19 | 重拟合产生的新拟合单号独立于旧单；旧单状态→"已替代"，历史数据保留不删除 | refit |

#### 重拟合规则

| 编号 | 规则描述 |
|------|---------|
| BR-20 | 月度轻量重拟合：仅参数重估（新数据输入，重跑同方法的参数估计），不换方法、不重选 |
| BR-21 | 季度全量重拟合：完整候选枚举 + 回测 + 重选，方法可能变更 |
| BR-22 | 形态变化触发：当 vehicle_part_map 中 lc_stage 或 lc_shape 发生变化时，系统自动建议重拟合 |
| BR-23 | D12 告警触发：当 forecast_assessment 检测到同一策略连续 N 期（默认 3 期）基线准确率恶化超过阈值时，触发即时重拟合 |

### 3.3 业务数据

| 数据 | 描述 | 来源 |
|------|------|------|
| 拟合单号 (fit_no) | 唯一标识一次拟合任务，格式 D10-YYYYQN-NNN | 系统自动生成 |
| 清洗后历史数据 | 扣除脉冲/断点/异常期间后的真实消耗序列（true_qty） | D03 拆解 + D06 事件标记 |
| 需求形态 (demand_shape) | 物料的需求特征分类，决定候选策略枚举范围与分段评估方式 | vehicle_part_map.lc_shape + 历史数据特征分析 |
| 候选策略 (strategy + inv_policy) | 方法（移动平均/指数平滑/季节分解/生命周期模板/类比）+ 参数 + 配套库存策略 | 系统枚举 + 人工增补 |
| 回测指标 | MAPE / Bias / 服务水平 / 库存代价 | 系统回测计算 |
| 综合分 (score) | 加权（误差、Bias、服务水平、库存代价），非对称损失函数 | 系统计算，权重可配置 |
| 选定策略 | 当前生效的策略配方，供 D04 基线生成引用 | D10 选定结果 |

```
拟合中 ──回测完成+选定──► 已选定 ──确认生效──► 生效中 ──重拟合(新单)──► 已替代
  │                       │                    │
  │                       │                    │
  └─无可接受候选──────────┼────────────────────┘
  (转 D05 借用基线)        │
                          
                          影子并行期：新单"拟合中" + 旧单"生效中"
                          验证通过 → 新单"已选定"→"生效中" + 旧单"已替代"
                          验证不通过 → 新单保留"拟合中"，不切换
```

| 当前状态 | 目标状态 | 触发动作 | 前置条件 | 后置动作 |
|---------|---------|---------|---------|---------|
| (新建) | 拟合中 | 创建拟合单 | part_no+veh_model 存在生效映射；历史数据 >= 12 个月 | 候选明细已录入 |
| 拟合中 | 拟合中 | 添加候选 | fit_no 存在 | 新增候选明细行 |
| 拟合中 | 拟合中 | 执行回测 | 候选明细 >= 2 条；回测数据已清洗 | 各候选 score/rank 已填写 |
| 拟合中 | 已选定 | 选定策略 | 回测已完成；指定候选综合分 >= θ_accept | selected=True；记录选定理由 |
| 拟合中 | (转 D05) | 无接受候选 | 最优候选综合分 < θ_accept | 系统提示转 D05，拟合单保留"拟合中" |
| 已选定 | 生效中 | 确认生效 | 计划确认 | fit_no 可供外部引用 |
| 已选定 / 生效中 | (旧单)已替代 | 重拟合生成新单 | 新拟合单已选定生效 | 旧单状态→"已替代"，历史数据保留 |
| 生效中 | (新单)拟合中 | 影子并行开始 | 重拟合新单已创建 | 新旧策略并行运行 |

### 4.3 功能详细说明

#### FUNC-01 拟合单列表

**功能描述**: 展示全部拟合单，支持按零件号、需求形态、状态、拟合人等条件筛选，按拟合日期倒序排列

**用户流程**:
1. 总部计划进入拟合单列表页
2. 可通过筛选条件（part_no / veh_model / demand_shape / status / fitter / fit_date 范围）缩小列表
3. 列表展示关键字段：fit_no、part_no、veh_model、demand_shape、data_range、status、fitter、fit_date
4. 点击某行进入拟合单详情页（FUNC-03）

**输入数据**:
- 筛选条件（均为可选）：part_no、veh_model、demand_shape、status、fitter、fit_date 起止

**输出数据**:
- 拟合单列表，含：fit_no、part_no、veh_model、demand_shape、status、fitter、fit_date

**业务规则**:
- 按 fit_date 倒序排列
- 状态筛选支持多选

#### FUNC-02 新建拟合单 (create)

**功能描述**: 总部计划为物料创建拟合单，选定零件×车型、确认需求形态、设置历史数据区间与回测规格，系统自动生成候选策略列表

**用户流程**:
1. 总部计划点击"新建拟合单"
2. 输入 part_no 和 veh_model（系统自动校验 vehicle_part_map 中存在生效映射，BR-07）
3. 系统自动计算可用清洗历史区间（取 D03 true_qty 序列中未标记脉冲/断点的连续月数）并建议需求形态（基于 vehicle_part_map.lc_shape）
4. 若历史 < 12 个月或不覆盖完整季节周期，系统提示"历史不足，建议走 D05"但不硬阻（若计划坚持可继续，US-01-AC3）
5. 计划确认或调整 demand_shape、data_range、backtest_spec
6. 提交后系统自动枚举候选策略（FUNC-04），状态"拟合中"

**输入数据**:

| 字段名称 | 字段类型 | 是否必填 | 默认值 | 业务逻辑 |
|---------|---------|---------|-------|---------|
| part_no | 文本 | 是 | — | 引用物料主数据；须在 vehicle_part_map 中有生效映射 (BR-07) |
| veh_model | 文本 | 是 | — | 引用车型主数据；须在 vehicle_part_map 中有生效映射 (BR-07) |
| demand_shape | 枚举 | 是 | 系统建议 | 稳定/波动/季节/短生命周期/断续；系统建议+人工确认 (BR-08) |
| data_range | 文本 | 是 | 系统计算 | 清洗后可用的历史区间，格式"YYYY-MM~YYYY-MM" (BR-09) |
| backtest_spec | 文本 | 是 | 系统默认 | 训练窗口/验证步长/滚动次数 (BR-10) |

**输出数据**:
- 拟合单头 + 系统枚举的候选明细列表

**业务规则**:
- BR-07: part_no+veh_model 映射校验
- BR-09: 历史区间 >= 12 个月校验，不满足提示走 D05
- BR-06: fit_no 系统自动生成
- 系统自动建议 demand_shape：参考 vehicle_part_map.lc_shape + 历史数据变异系数/季节性指数

#### FUNC-03 拟合单详情 (get)

**功能描述**: 展示拟合单完整信息：单头 + 候选明细列表（含回测指标）+ 分段诊断结果 + 选定记录 + 操作历史

**用户流程**:
1. 从列表页点击进入详情页
2. 单头区域展示基本信息
3. 候选明细 Tab：展示全部候选策略及其回测指标，排名高亮
4. 分段诊断 Tab：展示峰期/稳期/衰减期各段指标
5. 操作历史 Tab：展示拟合单全生命周期操作日志

**输出数据**:
- 拟合单头全部字段
- 候选明细列表（含 mape/bias/service_level/inv_cost/score/rank/selected）
- 分段诊断指标
- 操作日志（创建/添加候选/回测/选定/生效/重拟合/影子对比）

**业务规则**:
- 全部数据只读展示（状态为"拟合中"时的候选增补在 FUNC-04 单独处理）
- 综合分排名高亮（第1名绿色标记），selected 候选特殊标记
- 回测未执行时候选明细的指标列为空

#### FUNC-04 添加候选策略 (add_candidate)

**功能描述**: 系统根据需求形态自动枚举候选策略（方法×参数×配套库存策略），总部计划可审核、增补或删减

**用户流程**:
1. 拟合单创建后，系统自动枚举候选策略
2. 方法枚举逻辑：根据 demand_shape 从方法库中匹配合适的方法族——稳定 → 移动平均+指数平滑；波动/季节 → 季节分解+指数平滑；短生命周期 → 生命周期模板+类比；断续 → 移动平均+模板
3. 参数网格：每种方法自动生成参数网格（如指数平滑 α ∈ {0.1, 0.2, 0.3, 0.5}、移动平均 N ∈ {2, 3, 4, 6}）
4. 配套库存策略网格：安全库存天数 ∈ {2, 3, 5, 7} + 补货频率 ∈ {日/周/双周}
5. 系统枚举 = 方法 × 参数 × 配套库存策略 的笛卡尔积（受 max_candidates 上限约束，待确认默认上限值）
6. 总部计划可手动增补策略（输入 method+params+inv_policy）或删减冗余候选

**输入数据**（人工增补时）:

| 字段名称 | 字段类型 | 是否必填 | 默认值 | 业务逻辑 |
|---------|---------|---------|-------|---------|
| fit_no | 文本 | 是 | — | 目标拟合单 |
| strategy | 文本 | 是 | — | 方法+参数，格式"方法名 参数=值"，如"指数平滑 α=0.3" (BR-12) |
| inv_policy | 文本 | 是 | — | 配套库存策略，格式"安全库存 X 天 / 补货频率" (BR-13) |

**输出数据**:
- 新增候选明细行（cand_no 自动递增）

**业务规则**:
- BR-11: 候选明细 >= 2 方可执行回测
- 系统枚举的候选数上限待确认（建议默认 50）
- 人工增补的 strategy 字段自由文本但建议规范格式
- 可删除候选（回测未执行前），回测已执行后不可删除

#### FUNC-05 候选策略列表

**功能描述**: 作为详情页内嵌 Tab，展示某拟合单的全部候选策略明细

**输出数据**:

| 字段名称 | 字段类型 | 说明 |
|---------|---------|------|
| cand_no | 整数 | 候选序号 |
| strategy | 文本 | 方法+参数 |
| inv_policy | 文本 | 配套库存策略 |
| mape | 数字 | 回测 MAPE（回测未执行时为空） |
| bias | 数字 | 回测 Bias（回测未执行时为空） |
| service_level | 数字 | 服务水平（回测未执行时为空） |
| inv_cost | 数字 | 库存代价（回测未执行时为空） |
| score | 数字 | 综合分（回测未执行时为空） |
| rank | 整数 | 排名（回测未执行时为空） |
| selected | 布尔 | 选定标记 |

#### FUNC-06 执行滚动回测 (run_backtest)

**功能描述**: 系统对拟合单的全部候选策略执行滚动回测，产出各候选的 MAPE/Bias/服务水平/库存代价/综合分/排名，以及分段诊断结果

**用户流程**:
1. 总部计划在拟合单详情页点击"执行回测"
2. 系统校验：候选明细 >= 2 (BR-11)、回测数据已清洗 (BR-01)
3. 系统逐候选执行滚动回测：
   a. 取清洗后历史数据（通过 independent_event.list 排除脉冲/断点/异常期间，BR-01）
   b. 按 backtest_spec 设置训练窗口 / 验证步长
   c. 从最早可训练时点开始，训练段拟合 → 验证段出预测 → 记录预测误差
   d. 窗口向前滚动一步长，重复上一步（严格时序，验证段只用当时点可见数据，BR-02）
   e. 汇总全部验证段的预测值 vs 实际值，计算 MAPE / Bias
   f. 在配套库存策略下模拟库存推演，计算服务水平 / 库存代价
   g. 分段评估：若数据含峰期/稳期/衰减期，分段输出各段指标 (BR-16)
   h. 综合打分：score = w1*MAPE_score + w2*Bias_score + w3*ServiceLevel_score + w4*InvCost_score (BR-14)，Bias 评分非对称 (BR-15)
4. 全部候选完成回测后，按 score 降序排名，rank=1 为最优

**输入数据**:
- fit_no: 拟合单号

**输出数据**:
- 各候选明细的 mape / bias / service_level / inv_cost / score / rank
- 分段诊断结果（峰期/稳期/衰减期各段指标）
- 回测执行日志（起止时间、各候选回测耗时）

**业务规则**:
- BR-01: 回测数据必须清洗，通过 independent_event.list 取清洗标记
- BR-02: 严禁未来信息泄漏，训练窗口截止时间 <= 验证窗口起始时间
- BR-14: 综合分加权计算，权重可配置
- BR-15: Bias 评分非对称，正向偏差权重 < 负向偏差权重
- BR-16: 分段诊断，生命周期转折点单独考核
- BR-03: 最优候选综合分 < θ_accept 时标记"无可接受候选"

**特殊处理**:
- 若某候选在回测过程中出现数值异常（如 MAPE > 100%），标记为异常但继续完成回测
- 回测中断（如系统超时）支持断点续跑，已完成候选的结果保留
- 回测过程中历史数据不足（如某些候选因参数需要更长历史）的候选跳过并标注原因

#### FUNC-07 回测结果查看

**功能描述**: 作为详情页 Tab，展示回测结果，含候选指标对比表 + 综合排名 + 分段诊断展开

**输出数据**:
- 候选指标对比表（同 FUNC-05 候选策略列表，回测后字段已填充）
- 分段诊断折线图（峰期/稳期/衰减期各候选 MAPE 对比）
- 综合得分雷达图（MAPE/Bias/服务水平/库存代价四维）

#### FUNC-08 选定策略 (select)

**功能描述**: 总部计划从候选列表选定最优策略，状态→"已选定"

**用户流程**:
1. 在回测结果页，计划选择排名最优的候选（或基于判断选择其他候选）
2. 点击"选定策略"
3. 系统校验：综合分 >= θ_accept (BR-03)
4. 若校验通过，填写选定理由
5. 确认后该候选 selected=True，拟合单状态→"已选定"

**输入数据**:
- fit_no: 拟合单号
- cand_no: 选定候选序号
- select_reason: 选定理由（文本，必填，BR-04）

**业务规则**:
- BR-03: 综合分 < θ_accept 时阻断选定，提示转 D05
- BR-04: 选定理由必填，留痕
- 只能选定一个候选
- 选定后候选明细不可再增删

**特殊处理**:
- 若计划不选 rank=1 而选 rank=2，需填写额外说明（非排名第一选定的理由）

#### FUNC-09 确认生效

**功能描述**: 总部计划确认选定策略正式生效，状态→"生效中"，fit_no 可供外部调用 get_strategy

**用户流程**:
1. 在"已选定"状态拟合单上，计划点击"确认生效"
2. 系统确认后状态→"生效中"
3. 该 fit_no 的选定策略可通过 get_strategy 被 D04 等外部应用查询引用

**输入数据**:
- fit_no: 拟合单号

**前置条件**: 拟合单状态为"已选定"

**业务规则**:
- 同一 part_no+veh_model 只能有一个生效中的拟合单（唯一约束）
- 若当前已有生效中拟合单，系统提示"已有生效策略，确认后将替代旧策略"，旧单自动→"已替代" (BR-19)

#### FUNC-10 取生效策略 (get_strategy)

**功能描述**: 供外部应用（demand_processing）调用，查询指定 part_no+veh_model 的当前生效策略方法+参数

**用户流程**: 纯接口调用，无界面

**输入数据**:
- part_no: 零件号
- veh_model: 客户·车型

**输出数据**:
- strategy: 策略（方法+参数）
- inv_policy: 配套库存策略
- fit_no: 来源拟合单号
- fit_date: 拟合日期

**业务规则**:
- 查询 part_no+veh_model 下 status="生效中" 的唯一拟合单的 selected=True 候选
- 若无生效中策略，返回空并提示"该物料尚无生效策略，请走 D05 借用基线或执行首次拟合"

**跨应用调用**:
- 被 `demand_processing.generate_baseline` 调用（D04 基线生成取策略方法与参数）

#### FUNC-11 执行预测外推 (forecast)

**功能描述**: 供外部应用（demand_processing）调用，使用指定方法+参数对历史数据执行前向外推，返回未来各期预测值。封装 §8 所有方法的 forecast 函数。

**用户流程**: 纯接口调用，无界面

**输入数据**:
- method: 方法名（"SMA" / "HoltWinters" / "SeasonalDecomp" / "Gompertz" / "Analogy"）
- params: 方法参数字典（如 {"alpha": 0.3, "beta": 0.1, "gamma": 0.2}）
- history_data: 清洗后历史需求序列 [(period, qty), ...]，按时间升序，长度 >= 方法最小要求
- horizon: 外推期数（M0~M+N 的 N+1）

**输出数据**:
- forecasts: [(period, predicted_qty), ...] 逐期预测值列表，长度 = horizon

**业务规则**:
- 方法名不合法时 raise FdeError("未知预测方法: {method}")
- history_data 长度不满足方法最小要求时 raise FdeError("{method} 需要至少 {min_len} 期历史数据，当前仅 {len} 期")
- 计算逻辑严格按 §8 对应方法的数学定义执行

**跨应用调用**:
- 被 `demand_processing.generate_baseline` 调用（D04 基线生成执行实际外推计算）

**特殊处理**:
- SMA（§8.1）：flat extrapolation，所有未来期 = 最近 N 期均值
- HoltWinters（§8.2）：iterative forecast，逐期递推 ℓ, b, s 并输出预测
- SeasonalDecomp（§8.3）：去季节 → 趋势外推 → 加回季节分量
- Gompertz（§8.4）：直接用拟合曲线函数计算未来各期值
- Analogy（§8.5）：时间平移 + 峰值缩放 + 早期校准混合

#### FUNC-12 月度轻量重拟合

**功能描述**: 月初自动或手动触发，对已生效策略用最新数据重新估计参数（不换方法），参数变化超阈值时记录新拟合单

**用户流程**:
1. 系统定时触发（月初）或计划手动触发
2. 对生效中拟合单的选定策略方法，用新增数据重新估计参数
3. 若新参数与当前参数差异在容忍范围内（如 α 变化 < δ_alpha），保持原参数
4. 若新参数变化超阈值，生成新拟合单（新 fit_no），状态"拟合中"，记录新旧参数对比

**输入数据**:
- fit_no (原生效中拟合单)

**输出数据**:
- 新拟合单（若参数变化超阈值），含更新后的 strategy（新参数）

**业务规则**:
- BR-20: 仅参数重估，不换方法、不重选候选全集
- 参数变化容忍阈值待确认（建议 α 变化 < 0.05、N 变化=0）
- 生成新单后自动触发影子并行对比 (FUNC-14)

#### FUNC-13 季度全量重拟合 (refit)

**功能描述**: 每季度自动或手动触发，完整重做候选枚举+回测+打分+选定全流程，方法可能变更

**用户流程**:
1. 系统定时触发（季初）或计划手动触发
2. 对生效中拟合单的 part_no+veh_model，取最新完整历史数据
3. 重新枚举候选策略（方法库可能有新增方法）
4. 完整执行滚动回测
5. 产出新候选排名
6. 若最优方法与当前不同，生成新拟合单，触发影子并行对比

**输入数据**:
- fit_no (原生效中拟合单) 或 part_no+veh_model

**输出数据**:
- 新拟合单（含全部回测结果）

**业务规则**:
- BR-21: 完整回测重选，方法可能变更
- BR-19: 新拟合单号独立于旧单
- 若最优方法未变但参数有优化，仍生成新单（保留完整回测记录）

#### FUNC-13 事件触发重拟合

**功能描述**: 当需求形态变化或 D12 告警时，自动触发即时重拟合

**触发条件**:
1. **形态变化**: vehicle_part_map 中 lc_stage 或 lc_shape 变更 → 自动建议重拟合
2. **D12 告警**: forecast_assessment 检测到连续 N 期（默认 3）基线准确率恶化 (BR-23)

**用户流程**:
1. 系统检测到触发条件，自动创建新拟合单
2. 执行完整回测重选（同 FUNC-12）
3. 生成重拟合建议通知总部计划

**业务规则**:
- BR-22: 形态变化触发
- BR-23: D12 告警触发，连续期数阈值可配置
- 形态变化时，生命周期转折点单独考核（拐点预测作为选优关键指标）

**跨应用调用**:
- 接收 `forecast_assessment` 的告警联动（D12 闭环 → D10 重拟合）

#### FUNC-14 影子并行对比 (shadow_compare)

**功能描述**: 新旧策略同时运行 1~2 期，对比实际表现指标，出对比报告供切换决策

**用户流程**:
1. 重拟合产生新拟合单后，系统自动触发影子并行
2. 旧策略（生效中）继续供 D04 基线生成引用
3. 新策略（拟合中）同步运行：用同样的输入数据并行产出预测，但不正式发布
4. 每期结束后更新对比指标（新旧策略各自 MAPE/Bias/服务水平）
5. 1~2 期后系统生成对比报告

**输入数据**:
- fit_no (旧单): 原生效中拟合单
- new_fit_no (新单): 重拟合产生的新拟合单

**输出数据**:
- 影子对比报告（FUNC-15）

**业务规则**:
- BR-17: 策略切换须登记依据（对比报告或人工判定）
- BR-18: 影子并行期间旧策略仍为"生效中"，新单状态保持"拟合中"
- 若影子验证通过（新策略实际指标优于旧策略），系统建议正式切换
- 若验证不通过（新策略实际不如旧策略或不如回测预期），标记异常并暂不切换

**特殊处理**:
- 影子并行期间若旧策略本身出现问题（如 D12 紧急告警），以旧策略问题为先，不影响新策略评估
- 验证不通过的新单不删除，保留复盘

#### FUNC-15 影子对比报告

**功能描述**: 报表形式展示新旧策略在影子并行期间的指标对比

**输出数据**:
- 对比期间
- 旧策略指标：MAPE/Bias/服务水平/库存代价（逐期+汇总）
- 新策略指标：MAPE/Bias/服务水平/库存代价（逐期+汇总）
- 各指标差异率
- 切换建议：建议切换 / 暂不切换 / 需人工判定

## 8. 算法规格（§8 Algorithm Specifications）

> 本章给出 strategy_fitting 中所有候选预测方法的数学定义、滚动回测的完整算法、综合评分的计算公式。所有符号约定、边界处理、参数范围在此一次性冻结，后续编码直接引用本章。

### 8.0 符号约定

| 符号 | 含义 |
|------|------|
| $y_t$ | 第 $t$ 期的实际需求量（清洗后 true_qty，消耗口径） |
| $\hat{y}_{t}$ | 第 $t$ 期的预测值 |
| $\hat{y}_{t+h|t}$ | 站在第 $t$ 期末，对第 $t+h$ 期的 h 步前向预测 |
| $T$ | 历史序列总期数（月） |
| $L$ | 季节周期长度（月），默认 $L=12$ |
| $m$ | 外推期数（预测 horizon），即 M0~M+N 的 N+1 |
| $e_t = y_t - \hat{y}_t$ | 第 $t$ 期的预测误差（实际 − 预测，正=低估、负=高估） |

### 8.1 方法一：简单移动平均（SMA）

**适用形态**：稳定、断续

**算法定义**：

$$MA(N)_t = \frac{1}{N}\sum_{i=1}^{N} y_{t-i}$$

前向外推：

$$\hat{y}_{t+h|t} = MA(N)_t \quad (h = 1, 2, \dots, m)$$

即所有未来期的预测值均为最近 N 期历史均值（平坦外推）。

**参数网格**：

$$N \in \{2, 3, 4, 6\}$$

**边界处理**：
- 首期（$t < N$）：可用历史不足 N 期时，用全部可用历史计算均值
- 序列含缺口（非连续月份）：跳过缺口月，取最近 N 个**有数据的期间**
- 零值/负值：不参与平均（标记为异常），可用期数相应减少；若可用期数 = 0，返回 None

**适用判定**：历史变异系数 $CV = \sigma / \mu < 0.3$ 且无明显趋势（线性回归斜率不显著，p > 0.1）

---

### 8.2 方法二：Holt-Winters 加性三重指数平滑

**适用形态**：波动、季节

**模型结构**（加性形式）：

$$y_t = \ell_{t-1} + b_{t-1} + s_{t-L} + \varepsilon_t$$

其中 $\ell_t$ 为水平（level）、$b_t$ 为趋势（trend）、$s_t$ 为季节分量（seasonal）。

**递推公式**（加性 Holt-Winters）：

$$\begin{aligned}
\ell_t &= \alpha(y_t - s_{t-L}) + (1-\alpha)(\ell_{t-1} + b_{t-1}) \\
b_t &= \beta(\ell_t - \ell_{t-1}) + (1-\beta)b_{t-1} \\
s_t &= \gamma(y_t - \ell_{t-1} - b_{t-1}) + (1-\gamma)s_{t-L}
\end{aligned}$$

**前向外推**（h 步预测）：

$$\hat{y}_{t+h|t} = \ell_t + h \cdot b_t + s_{t+h-L\lceil h/L \rceil}$$

即水平 + h 倍趋势 + 对应季节分量。

**参数网格**：

$$\alpha \in \{0.1, 0.2, 0.3, 0.5\}, \quad \beta \in \{0.05, 0.1, 0.2, 0.3\}, \quad \gamma \in \{0.05, 0.1, 0.2, 0.3\}$$

**初始化**（需要至少 2L = 24 期数据做经典分解初始化；不足时降级到简单初始化）：

经典分解初始化（推荐，$T \ge 2L$）：
1. 移动平均去季节：$\tilde{y}_t = \frac{1}{L}\sum_{i=-(L-1)/2}^{(L-1)/2} y_{t+i}$（居中 MA-L）
2. 趋势初值：对 $\tilde{y}_t$ 做线性回归，取截距=$\ell_0$、斜率=$b_0$
3. 季节初值：$s_k = y_k - \tilde{y}_k$（第 k 期的去趋势值），同月平均后零均值化

简单初始化（$T < 2L$ 时降级）：
- $\ell_0 = y_1$（首期实际值）
- $b_0 = (y_T - y_1) / (T-1)$（首尾斜率）
- $s_1, \dots, s_L = 0$（季节分量从零开始学习）

**边界处理**：
- 训练数据不足 2 期：不适用此方法，跳过
- 外推期数 $m > 2L$：发出警告（远期为纯趋势外推，季节分量循环复用）
- 序列含缺口：缺口月跳过递推，$\ell_t$ 不更新、$b_t$ 不更新、$s_t$ 沿用上周期同月值

---

### 8.3 方法三：经典季节分解 + 趋势外推

**适用形态**：季节（历史 >= 36 期时使用，数据更多时分解更稳定）

**Step 1 — 分解**（经典加性分解）：

$$y_t = T_t + S_t + R_t$$

其中 $T_t$ = 趋势分量、$S_t$ = 季节分量（$\sum_{k=1}^{L} S_k = 0$）、$R_t$ = 残差。

a) 趋势分量（MA-L 居中移动平均，L=12）：
$$T_t = \frac{1}{L}\sum_{i=-5}^{6} y_{t+i} \quad (t = 7, \dots, T-6)$$

首尾 6 期用非对称 MA 延拓。

b) 去趋势序列：$D_t = y_t - T_t$

c) 季节分量：对 $D_t$ 按同月分组取均值，再零均值化：
$$S_k = \frac{1}{N_k}\sum_{j=1}^{N_k} D_{k+(j-1)L} - \frac{1}{L}\sum_{i=1}^{L} \frac{1}{N_i}\sum_{j=1}^{N_i} D_{i+(j-1)L}$$

d) 残差：$R_t = y_t - T_t - S_t$

**Step 2 — 趋势外推**：

去季节后的序列 $T'_t = y_t - S_t$ 用以下子方法外推未来趋势：
- 线性回归：$T'_t = a + b \cdot t$（默认）
- 或 Holt 双指数平滑（二阶平滑，当趋势非线性时）

设趋势外推得到 $\hat{T}_{T+h}$，则最终预测：

$$\hat{y}_{T+h|T} = \hat{T}_{T+h} + S_{(T+h) \bmod L}$$

**参数网格**：

趋势外推子方法 $\in \{$ 线性回归，Holt 双指数 $\}$

Holt 参数：$\alpha_{trend} \in \{0.1, 0.2, 0.3\}$, $\beta_{trend} \in \{0.05, 0.1, 0.2\}$

**适用判定**：$T \ge 24$（至少 2 个完整季节周期）、季节强度 $F_s = 1 - Var(R_t)/Var(T_t+S_t) > 0.3$

---

### 8.4 方法四：生命周期模板拟合（Gompertz 曲线）

**适用形态**：短生命周期、上市高后下滑

**模型定义**（Gompertz 累积曲线）：

$$F(t) = K \cdot \exp\left(-\exp\left(-\frac{e}{K}(t - \tau)\right)\right)$$

其中：
- $K$ = 渐近上限（成熟期峰值需求，单位：件/月）$\quad K > 0$
- $\tau$ = 拐点时刻（爬坡加速度最大点，单位：月）$\quad \tau \in [SOP, SOP + 24]$
- $e \approx 2.71828$ = 自然常数
- $\frac{e}{K}$ 控制曲线陡峭程度（K 越大爬坡越快）

**瞬时需求率**（导数形式，预测的是每月需求量而非累积量）：

$$\dot{F}(t) = \frac{e}{K} \cdot K \cdot \exp\left(-\exp\left(-\frac{e}{K}(t - \tau)\right)\right) \cdot \exp\left(-\frac{e}{K}(t - \tau)\right)$$

即：$\dot{F}(t) = e \cdot \exp\left(-\exp(-\frac{e}{K}(t-\tau)) - \frac{e}{K}(t-\tau)\right)$

**简化形式**（实际使用时建议此形式）：

$$y(t) = K \cdot \frac{e}{K} \cdot \exp\left(-\exp\left(-\frac{e}{K}(t-\tau)\right) - \frac{e}{K}(t-\tau)\right)$$

或等效的峰值参数化：

$$y(t) = P \cdot \exp\left(1 - \exp\left(-r(t-\tau)\right) - r(t-\tau)\right)$$

其中 $P$ = 峰值需求、$r$ = 爬坡速率（$r = e/K$）。

**参数估计**（非线性最小二乘）：

1. 初始值估计：
   - $P_0 = \max(\{y_t\})$（历史峰值）
   - $\tau_0$ = $P_0$ 对应的月份
   - $r_0 = 0.3$（默认爬坡速率，月<sup>-1</sup>）

2. Levenberg-Marquardt 迭代拟合：
   $$\min_{P, r, \tau} \sum_{t} (y_t - \hat{y}_t)^2$$

   迭代上限 100 轮，收敛容差 $10^{-6}$；不收敛时降级为分段线性。

3. 拟合优度 $R^2_{adj}$：调整后决定系数，$< 0.5$ 时标记"拟合质量差"。

**模板库先验**（历史不足时用模板先验约束参数）：

| 模板编号 | 适用场景 | 先验分布 |
|---------|---------|---------|
| TPL-01 | 传统·A级车 | $P \sim \mathcal{N}(\mu_{peak}, \sigma_{peak}^2)$, $r \sim \mathcal{N}(0.25, 0.05^2)$ |
| TPL-02 | 短生命周期·改款 | $P \sim \mathcal{N}(\mu_{peak}, \sigma_{peak}^2)$, $r \sim \mathcal{N}(0.35, 0.08^2)$ |
| TPL-03 | 上市高后下滑 | $P \sim \mathcal{N}(\mu_{peak}, \sigma_{peak}^2)$, $r \sim \mathcal{N}(0.20, 0.04^2)$ |

模板参数 $(\mu, \sigma)$ 由沉淀库（system_config.template_lib）提供，回测后更新。

**前向外推**：

$$\hat{y}_{t+h|t} = y(t+h) \quad (h = 1, 2, \dots, m)$$

即直接用拟合后的 Gompertz 函数计算未来各期的瞬时需求率。

**分段线性降级**（Gompertz 不收敛或 $R^2_{adj} < 0.5$ 时）：

将历史数据按生命周期分段：
- 爬坡期（SOP → 峰值月）：线性回归 $y = a_1 + b_1 \cdot t$
- 成熟期（峰值月 → 衰减起点）：水平线 $y = \bar{y}_{成熟期}$
- 衰减期（衰减起点 → EOP）：线性回归 $y = a_3 + b_3 \cdot t$（$b_3 < 0$）

外推时按当前所处阶段对应公式计算。

### 8.5 方法五：类比法

**适用形态**：短生命周期（有相似车型参照）

**算法**：

1. 选定相似车型 $M_{ref}$（按 vehicle_part_map 的 platform / 细分 / 价格带 / 动力形式匹配）
2. 取 $M_{ref}$ 的清洗后历史需求序列 $\{y_t^{ref}\}$
3. 时间平移对齐：$\tilde{t} = t - (SOP_{new} - SOP_{ref})$
4. 峰值缩放：$\hat{y}_t^{new} = \frac{P_{new, observed}}{P_{ref, observed}} \cdot y_{\tilde{t}}^{ref}$

其中 $P_{new, observed}$ 和 $P_{ref, observed}$ 为各自已观测到的峰值（若新车型尚无峰值数据，用相似车型峰值 × 份额比）。

5. 有早期数据时做贝叶斯校准：
   $$\hat{y}_t^{calibrated} = w_t \cdot \hat{y}_t^{new} + (1-w_t) \cdot y_t^{actual}$$

   混合权重 $w_t = \frac{\sigma_{actual}^2}{\sigma_{actual}^2 + \sigma_{ref}^2}$（按各自方差自适应加权，数据越多 $w_t$ 越小）。

**适用判定**：存在相似车型（D05 类比库中有生效类比条目），且自身历史 < 12 期。

### 8.6 滚动回测算法

**输入**：
- 清洗后历史序列 $\{y_t\}_{t=1}^{T}$（$T \ge 12$）
- 训练窗口长度 $W_{train}$（月），默认 $\min(24, T-3)$
- 验证步长 $W_{step}$（月），默认 1
- 预测 horizon $H = W_{step}$ （一步前向验证）

**算法流程**：

```
results = []
for i in range(0, T - W_train - H + 1, W_step):
    train_start = i                    # 训练窗口起始索引
    train_end   = i + W_train          # 训练窗口结束索引（不含）
    test_point  = train_end + H        # 验证点索引

    # 取训练数据（严格时序：只用 <= train_end-1 的数据）
    train_data = y[train_start : train_end]

    # 用候选方法拟合 train_data，产出预测值
    y_hat = forecast(method, train_data, H)

    # 取实际值
    y_actual = y[test_point - 1 : test_point + H - 1]  # H 期实际值

    # 记录逐期误差
    for h in range(H):
        results.append({
            'train_end': train_end,
            'horizon': h+1,
            'predicted': y_hat[h],
            'actual': y_actual[h],
            'error': y_actual[h] - y_hat[h]
        })

    # 若 test_point + H > T，停止滚动
```

**防泄漏约束（运行时强制校验）**：
- $\forall$ 验证点，$\max(\text{train\_indices}) < \min(\text{test\_indices})$ —— 训练数据的时间索引严格小于验证数据
- 若回测规格违反此约束，回测拒绝执行并报错

---

### 8.7 回测指标计算

从 `results` 列表中计算以下指标（$n$ = results 中的预测点总数）：

#### MAPE（平均绝对百分比误差）

$$\text{MAPE} = \frac{1}{n} \sum_{i=1}^{n} \left| \frac{y_i - \hat{y}_i}{y_i} \right| \times 100\%$$

**边界处理**：
- $y_i = 0$：该点不计入 MAPE（分母为零），计入分母缺失计数
- 分母缺失比例 > 20%：MAPE 标记为"不可靠"，附加缺失计数
- $y_i < 0$（极端异常）：该点不计入 MAPE，计入异常计数

#### Bias（偏差方向）

$$\text{Bias} = \frac{1}{n} \sum_{i=1}^{n} \frac{\hat{y}_i - y_i}{y_i} \times 100\%$$

- 正值 = 系统性高报（预测 > 实际）→ 呆滞风险
- 负值 = 系统性低报（预测 < 实际）→ 断线风险
- Bias > +10%：标记"高报倾向"
- Bias < -10%：标记"低报倾向"

#### MAD（平均绝对偏差，辅助）

$$\text{MAD} = \frac{1}{n} \sum_{i=1}^{n} |y_i - \hat{y}_i|$$

#### RMSE（均方根误差，辅助）

$$\text{RMSE} = \sqrt{\frac{1}{n} \sum_{i=1}^{n} (y_i - \hat{y}_i)^2}$$

### 8.8 服务水平模拟

在配套库存策略下，模拟历史验证段的库存推演，计算服务水平：

**模拟参数**（来自候选的 inv_policy）：
- $SS$ = 安全库存天数
- $RF$ = 补货频率（日/周/双周 → 转换为月补货次数 $f$）

**模拟过程**（逐月）：

```
inventory = SS_days * daily_demand_avg  # 初始库存 = 安全库存量
stockouts = 0
total_demand = 0

for each validation month t:
    daily_demand = y_actual[t] / 30    # 日均需求
    lead_time_demand = daily_demand * (lead_time_days)  # 提前期需求

    # 期初盘点
    if inventory < 0: inventory = 0

    # 消耗
    inventory -= y_actual[t]
    if inventory < 0:
        stockouts += 1                 # 该月发生缺货
        total_demand += y_actual[t]

    # 补货（按补货频率）
    if t % (1/f) == 0:
        order_qty = max(0, SS_days * daily_demand - inventory)
        inventory += order_qty         # 补货到达（简化：无提前期）
```

**服务水平**：

$$\text{ServiceLevel} = \left(1 - \frac{\text{stockouts}}{n}\right) \times 100\%$$

即验证期间不缺货的月份比例。

**库存代价**：

$$\text{InvCost} = \frac{1}{n}\sum_{t} \max(0, \text{inventory}_t) \cdot c_h$$

其中 $c_h$ 为单位持有成本系数（默认 0.01，即每月每件库存代价为 0.01 单位成本，可配置）。仅当 inventory > 0 时产生持有成本；缺货时的缺货损失不计入 InvCost（已在服务水平中体现）。

---

### 8.9 综合评分（Score）

**Step 1 — 各指标归一化**（Min-Max 归一化，跨同一拟合单的全部候选）：

$$\text{MAPE}_{norm} = \frac{\text{MAPE} - \min(\text{MAPE})}{\max(\text{MAPE}) - \min(\text{MAPE})}$$

若所有候选 MAPE 相同，$\text{MAPE}_{norm} = 0$。

同理对 MAD、RMSE 做归一化。

对 Bias 做归一化后用非对称变换（见 Step 2）。

服务水平归一化（方向反转——越大越好）：

$$\text{SL}_{norm} = 1 - \frac{\text{ServiceLevel} - \min(\text{SL})}{\max(\text{SL}) - \min(\text{SL})}$$

库存代价归一化同 MAPE（越小越好）。

**Step 2 — Bias 非对称损失**：

$$\text{Bias}_{score} = \begin{cases}
|\text{Bias}_{norm}| \times 0.6 & \text{if Bias} > 0 \text{（高报 → 呆滞，惩罚系数 0.6）} \\
|\text{Bias}_{norm}| \times 1.0 & \text{if Bias} < 0 \text{（低报 → 断线，惩罚系数 1.0）} \\
0 & \text{if Bias} = 0
\end{cases}$$

断线损失权重大于呆滞（1.0 > 0.6），使系统倾向温和偏高而非断线。

**Step 3 — 加权综合**：

$$\text{Score} = w_1 \cdot \text{MAPE}_{norm} + w_2 \cdot \text{Bias}_{score} + w_3 \cdot \text{SL}_{norm} + w_4 \cdot \text{InvCost}_{norm}$$

默认权重（可配置）：

$$w_1 = 0.40,\quad w_2 = 0.25,\quad w_3 = 0.20,\quad w_4 = 0.15$$

**排名**：Score 越小越好（越小 = 误差越小、Bias 越小、服务水平越高、库存代价越小）。rank 按 Score 升序排列，Score 相同则并列。

**可接受线**：

$$\theta_{accept} = 0.30 \quad \text{（默认值，可配置）}$$

Score > $\theta_{accept}$ 的候选标记为"不可接受"。

### 8.10 分段诊断

当物料有明确的峰期/稳期/衰减期标记（来自 vehicle_part_map.lc_stage 或 D02 生命周期阶段）时：

1. 按阶段将验证结果分组，每组独立计算 MAPE 和 Bias
2. 拐点误差单独标注——衰减期起始月的前后各 1 期（共 3 期）标记为"拐点窗口"
3. 拐点窗口的 MAPE 单独列出，作为选优关键指标
4. 最终综合分中增加拐点惩罚项（若拐点 MAPE > 25%）：

$$\text{Score}_{final} = \text{Score} + w_{turn} \cdot \max(0, \text{MAPE}_{turn} - 0.25)$$

其中 $w_{turn} = 0.10$（默认，可配置）。

### 8.11 候选策略枚举逻辑

系统根据 demand_shape 自动枚举候选策略，规则如下：

| demand_shape | 方法候选 | 参数网格 |
|-------------|---------|---------|
| 稳定 | SMA, Holt-Winters | SMA: N∈{2,3,4,6}; HW: α∈{0.1,0.2,0.3,0.5}, β∈{0.05,0.1,0.2}, γ∈{0.05,0.1} |
| 波动 | Holt-Winters, SMA | HW: α∈{0.1,0.2,0.3,0.5}, β∈{0.05,0.1,0.2,0.3}, γ∈{0.05,0.1,0.2}; SMA: N∈{3,4,6} |
| 季节 | Holt-Winters, 季节分解 | HW: α∈{0.1,0.2,0.3,0.5}, β∈{0.05,0.1,0.2}, γ∈{0.1,0.2,0.3}; SD: 趋势子方法∈{线性回归,Holt} |
| 短生命周期 | Gompertz, 类比 | Gompertz: 无参数网格（自由拟合）+ 模板先验变体; 类比: 相似车候选∈{top1, top2, top3} |
| 断续 | SMA, Gompertz(分段线性) | SMA: N∈{2,3,4}; Gompertz: 分段线性降级模式 |

配套库存策略网格（所有方法共用）：

$$\text{inv\_policy} \in \{\text{"安全库存 2 天 / 周补货"}, \text{"安全库存 3 天 / 周补货"}, \text{"安全库存 5 天 / 双周补货"}, \text{"安全库存 7 天 / 双周补货"}\}$$

候选总数上限：$\max\_candidates = 50$（BRD 待确认默认值），超出时按以下优先级裁剪：优先保留不同方法，再在同方法内按参数覆盖度（$\alpha, \beta, \gamma$ 取值分散度）择优保留。

```
    │   └── 否 → 继续
```
