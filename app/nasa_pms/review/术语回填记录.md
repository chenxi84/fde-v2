## 3. 字典值新增（评审类型，术语表未收的三个）

术语表已收 MCR / SRR / SDR / PDR / CDR / TRR / PRR / SIR 八种，本应用补三个：

| 原词 | 语境 / 所属类型 | 业务名 |
| :--- | :--- | :--- |
| ORR | 评审 / 材料附录 A、第 03 章生命周期评审表、TABLE 6.7-1 | 运行就绪评审（ORR） |
| FRR | 评审 / 材料附录 A、TABLE 6.7-1 | 飞行就绪评审（FRR） |
| SAR | 评审 / 材料附录 A、TABLE 6.7-1 | 系统验收评审（SAR） |

> 其余出现在材料里但**未进字典**的评审类型（MDR、MRR、PLAR、PFAR、CERR、DR、DRR、LRR…）：
> 它们是同一族生命周期评审，本版按"最常用的 11 种"收口；要用时往 `REVIEW_TYPES` 加一个枚举值
> 并在此回填一行即可。

## 5. 就地细化的说明（诚实记录）

材料只给了 **"action items"** 这个词，**没有**给出行动项的字段口径。本版按卡片 I-2
（"行动项必须指定责任人与期限"）就地细化为 `content` / `owner` / `due_date` 三必填 + `status` / `close_note`，
其中**期限格式**（`YYYY-MM-DD`）与**状态二值**（未完成 / 已完成）无原文可引，属第②步**工程口径**，
已在此登记 —— 与同组 `configuration_item` 处理"类型字典/基线名称"的方式一致。
