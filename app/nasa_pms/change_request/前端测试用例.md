# 前端测试用例：变更请求（change_request）

> 产出技能：第⑧步 前端测试用例（规格 `design-plus/前端测试.md`）
> 来源：`前端详设.md`（F-1..F-11）+ `change_request.py` 的服务契约**同源**
> 执行：第⑨步 `python app/nasa_pms/tests/verify_view_nasa_pms_change_request.py`
> 硬件指标：**0 console error · 0 pageerror · 0 HTTP≥400**

---

## §0 自足造数（前置）

| 步骤 | 动作 |
|---|---|
| S-1 | 经 REST 直调造**跨应用靶子**（**必须用组限定名**，短名会 404「应用不存在」）：<br>① `nasa_pms/configuration_item.create` ×2（飞控软件 / 接口控制文档）→ `control(CI-001)` → `release(CI-001)`<br>② `nasa_pms/requirement.create` ×2（REQ-001 / REQ-002） |
| S-2 | `nasa_pms/change_request.create` ×4，覆盖**四态**：<br>`CR-001` 已提交（张三，范围 CI-001 + REQ-001）<br>`CR-002` 审批中（李四，范围 CI-002）<br>`CR-003` 已批准（张三，范围 CI-001 + REQ-001）<br>`CR-004` 已拒绝（李四，范围 CI-002） |

> 造数走 REST 而非 UI：避免用例依赖"提出功能本身是否正确"（那是 §2 的覆盖对象）。
> 四态齐备是刻意的 —— §4 的「动作按钮按状态显隐」（F-6 / F-9）需要四种状态同屏可比。
> **本页是本组第一个真跨应用页**：不先造配置项 / 需求，影响范围会一律被后端拒（BR-05）。

## §4 状态机动作（F-6 / F-7 / F-8 / F-9 / F-11）

| 编号 | 用例 | 预期 |
|---|---|---|
| `VT-ACT-31` | **F-6 按钮按状态显隐** | 已提交行：有「提交影响分析」、无「审批」「实施」；已批准行：有「实施」、无「提交影响分析」；**已拒绝行：动作按钮全隐**（`BR-04`） |
| `VT-ACT-33` | 点 `CR-001`「提交影响分析」 | 模态出现；**影响分析为空 → 提交 disabled**（`BR-02`） |
| `VT-ACT-34` | 填写影响分析 → 提交 | 状态变「影响分析」、该行出现「提交审批」 |
| `VT-ACT-35` | 点「提交审批」（二次确认） | 状态变「审批中」、出现「审批」 |
| `VT-ACT-36` | 点「审批」 | **审批意见为空 → 「确认批准」「确认拒绝」都 disabled**（`BR-02`） |
| `VT-ACT-37` | 填写审批意见 | 两个按钮**同时**可点 |
| `VT-ACT-38` | 点「确认批准」 | 状态变「已批准」、出现「实施」 |
| `VT-ACT-39` | 点「实施」→「确认实施」 | 状态变「已实施」 |
| `VT-ACT-40` | **F-9 终态行** | 已实施行只剩「详情」，五个动作按钮**均不可见** |

> ⚠ **动作按钮用 `x-show` 隐藏**（元素仍在 DOM，仅 `display:none`）⇒ 断言按钮存在性**必须带 `:visible`**。
> ⚠ 断言按钮用**精确文本** `:text-is("审批")` —— `has-text("审批")` 会同时命中「提交审批」（本用例集实测）。
> ⚠ 状态断言定位到**徽标本身**（`[data-role="cr-status"]`）—— 行文本里含按钮文字（「提交影响分析」含「提交」），
> `"已提交" in row.inner_text()` 会被按钮文本干扰而**假过**。

## §7 本轮踩到并修正的坑（记录）

| # | 现象 | 根因 | 修法 |
|---|---|---|---|
| 1 | `VT-HW-90` 报 2 条 `Cannot read properties of null (reading 'trim')` | 「提交影响分析」模态里 `canAnalyze()` 直接 `modal.d.impact_analysis.trim()`，而**已提交的变更请求该字段本就是 NULL**（还没分析过） | ① `openDetail` 把可空文本字段归一为 `''`；② `canAnalyze()` 加 `(d.impact_analysis || "").trim()` 第二道防线 |
| 2 | `VT-ACT-31` / `VT-ACT-40` 终态行"动作按钮全隐"断言口径 | 行的**编号单元格也是 `button.b-link`**（`button[class*="b-link"]` 会把单号按钮数进去） | 改为逐个动作按钮名做 `:visible` 计数为 0，不用类名计数 |
| 3 | 筛选下拉选择器 | `page.locator("select")` 在打开过表单后会同时命中模态里（隐藏的）多选下拉 | 筛选下拉一律限定到 `main .card` 的第一张卡内取 `select` |
