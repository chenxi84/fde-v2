> 产出技能：第⑥步 前端设计（规格 `design-plus/前端设计.md`，规范正本 `VIEW_CONVENTION.md`）
> 输入：`activity/应用详设.md`（状态机 / 字典字段 / BR-01..08）+ 材料 `brd/SCH-第*.md`
> 落点：`app/nasa_pms/activity/view.js` + `view.html`（PAGE_META.key = 目录名 = `activity`）

---

## 1. 页面定位

| 项 | 内容 |
|---|---|
| key / name | `activity` / **进度活动** |
| `order` | `730`（本组 13 个应用里最后一位 —— 与 `architecture.md` ① 的聚合根序号同序） |
| 一句话 | 活动网络 + **派生**排程视图 + 网络体检；基线锁计划、实绩随时填 |
| 数据来源类型 | **独立创建**（活动由 WBS 叶子元素分解而来） |

## 2. 页面结构（**三态一板**）

```
┌ 工具条：状态 · 类型 · 关键词 · [搜索] [网络体检] [排程视图/台账视图] [新建活动] [新建里程碑] ┐
├ 体检面板（点「网络体检」展开）：问题合计 / 开口端 / 冗余 / 环 / 挂靠非叶子               │
├ 排程视图 `[data-role="schedule"]`：编号 名称 类型 工期 最早开始 最早完成 最晚开始 浮时 关键路径
├ 甘特视图 `[data-role="gantt"]`：横轴按日历天，每行一条活动；**关键路径用琥珀色**（`data-crit`）
└ 台账视图：13 列（编号 名称 类型 挂靠元素 工期 前置 状态 完成 基线 责任方 实绩 变更号 操作）
     五个模态：详情/编辑 · 新建（活动或里程碑）· 连前置 · 发起修订 · 回填实绩
```

## 3. 交互规则（逐条对应后端约束）

| # | 规则 | 依据 |
|---|---|---|
| A-1 | **没有"计划开始/完成"输入框** —— 日期是派生量，只在排程视图里现算 | BR（§5.5.9.3：日期由逻辑与工期决定） |
| A-2 | 新建时「挂靠的 WBS 元素」候选**只列叶子**（`wbs.list` 里无子元素者）；后端另有硬闸 | BR-05；本组惯例：前端镜像 ≠ 判据 |
| A-3 | 「发起修订」的变更号候选**只列已批准**；值仍是文本，后端再校验一次 | BR-07（§7.3） |
| A-4 | 已基线活动：行内「基线」消失、「发起修订」出现；详情里**不给「编辑」** | BR-07；同组 `wbs`/`decision` 对锁定态同款处理 |
| A-5 | 「回填实绩」**任何时候都可用**（含已基线） —— 它不动基线 | BR-08（§7.3 原话） |
| A-6 | 动作按钮用 `x-show` 控制（元素仍在 DOM），**e2e 断言存在性必须按可见性判** | pitfalls |
| A-7 | ⚠ 页面上**两张 `table.tbl`**（台账 + 排程），排程那张隐藏但仍在 DOM —— e2e 的行定位必须限定 `.scroll-x table.tbl` | 本页踩过：行数翻倍 + 严格模式报错 |
| A-8 | 连前置给**四种关系类型**（静态 option）+ 滞后 + 理由；**非 FS 时理由**在前端就拦一次（后端另有硬闸） | §5.5.8.2 的四种关系模型 + BoE 要求 |
| A-9 | 工具条上的**日历选择**（datalist，候选来自服务）：它决定**工期口径**（工作日 / 日历天）与假日表 | §5.5.9.1 / §5.5.9.2 |
| A-10 | 甘特视图的时间轴按**日历天**画（派生日期已折算成日期，直接取差值），不引入日期库 | 简化：只画条、不画依赖箭头 |

## 4. 字段展示（业务名取自术语表）

| 列 / 字段 | 业务名 | 备注 |
|---|---|---|
| `act_no` / `name` | 活动编号 / 名称 | 名称提示「必须唯一；离散活动名建议含动词」（§5.5.5） |
| `kind` | 类型 | 汇总 / 活动 / 里程碑 |
| `wbs_no` | 挂靠元素 | **只能是叶子**（BR-05） |
| `duration_days` | 工期 | 工作日；里程碑恒 0 |
| `predecessors` | 前置 | 逻辑链（完成→开始） |
| `status` / `percent_complete` | 状态 / 完成 | 计划 / 进行中 / 已完成（语义色） |
| `baseline_start→finish` | 基线 | 未基线时显示「未基线」 |
| `actual_start→finish` | 实绩 | 回填后显示 |
| 排程视图的四个日期 + 浮时 | 最早/最晚 开始/完成 · 浮时 | **派生量**（不落库） |

## 5. 权限

平台注入 `ctx`，应用不实现鉴权；页面授权走「页→服务」隐式放行（`X-Fde-Page`）。
本页挂在 `nasa_planner` 角色名下。

## 6. 依赖的主数据 / 跨应用

| 依赖 | 用途 | 在哪一层 | 失败时 |
|---|---|---|---|

> （变更已批准），见 `architecture.md` 的跨应用调用方向表，由 `verify_app_edges.py` 对账。

## 7. 已知限制

- **甘特图很简**（2026-09-26 补）：只画活动条与关键路径着色，**不画依赖箭头**（FS/SS/FF/SF 的关系在台账列与详情里看）；
  里程碑画成**窄条**而不是菱形；只有周刻度，没有月/年缩放
- **不显示四种关系类型**：本版逻辑链只有"完成→开始"（口径见 `术语表.md` 附 #5 的延伸）
- **排程日期随"今天"漂移**：不传 `project_start` 时按当天起算，页面上标注了实际起始日
